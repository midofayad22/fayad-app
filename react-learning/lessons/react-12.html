مقدمة إلى Hooks

افهم مفهوم React Hooks ولماذا أصبحت أساسية في كتابة المكونات الحديثة.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

Hooks هي Functions توفر للمكونات إمكانية استخدام خصائص React مثل State وEffects.

من أشهر Hooks: useState وuseEffect وuseRef وuseContext.

Hooks تسمح بكتابة منطق قابل لإعادة الاستخدام دون الحاجة إلى Class Components في الأسلوب الحديث.

Hooks توفر وظائف React الأساسية داخل Function Components.

مثال برمجي

الكود

import { useState } from "react";
function App() {
const [name, setName] = useState("FAYBIT");
return <h1>{name}</h1>;
}

فهم الكود

كل Hook لها وظيفة محددة، ويجب الالتزام بقواعد استخدامها.
