useContext

تعلم كيف تسمح useContext بمشاركة البيانات بين Components دون تمرير Props عبر كل مستوى.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

عندما تحتاج عدة Components إلى نفس البيانات، قد يصبح تمرير Props عبر مستويات كثيرة أمرًا مزعجًا.

Context يوفر طريقة لمشاركة بيانات معينة عبر شجرة Components.

useContext تستخدم لقراءة القيمة الموجودة في Context داخل Component.

Context مناسب للبيانات المشتركة التي تحتاجها Components متعددة.

مثال برمجي

الكود

const ThemeContext = createContext("light");
function App() {
return (
<ThemeContext.Provider value="dark">
<Page />
</ThemeContext.Provider>
);
}

فهم الكود

مثل Theme أو معلومات المستخدم أو إعدادات عامة للتطبيق.
جرّب بنفسك

غيّر قيمة ThemeContext من light إلى dark.
