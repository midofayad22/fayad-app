Props

تعلم كيف تسمح Props بتمرير البيانات من Component إلى Component آخر.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

Props هي البيانات التي يمررها Component إلى Component آخر.

غالبًا يتم استخدام Props لجعل المكون قابلًا لإعادة الاستخدام، لأن نفس المكون يستطيع استقبال بيانات مختلفة كل مرة.

Props تكون للقراءة داخل المكون، ولا ينبغي تعديلها مباشرة.

Props هي وسيلة أساسية لتمرير البيانات إلى Components.

مثال برمجي

الكود

function Welcome({ name }) {
return <h1>مرحبًا {name}</h1>;
}
function App() {
return <Welcome name="FAYBIT" />;
}

فهم الكود

يمكنك إرسال name أو title أو image أو أي قيمة أخرى إلى Component.
جرّب بنفسك

غيّر قيمة name وجرب تمرير اسم مختلف إلى Welcome.

اختبر نفسك

  1. ما الاستخدام الأساسي لـ Props؟

    • تمرير البيانات إلى Components
    • إنشاء ملفات CSS
    • إنشاء قواعد بيانات
    • تشغيل الخادم

    الإجابة الصحيحة: تمرير البيانات إلى Components

    • من Component الأب
    • من CSS
    • من HTML فقط
    • من قاعدة البيانات مباشرة دائمًا
    الإجابة والشرح

    الإجابة الصحيحة: من Component الأب

  3. هل يجب تعديل Props مباشرة داخل Component؟

    • لا
    • نعم دائمًا
    • نعم باستخدام CSS
    • فقط داخل HTML
    الإجابة والشرح

    الإجابة الصحيحة: لا

  4. ما ناتج هذا الكود؟ function Hi({name}){ return <p>Hi {name}</p>; } ... <Hi name="Sara" />

    • خطأ
    • Hi name
    • Hi Sara
    • Hi
    الإجابة والشرح

    الإجابة الصحيحة: Hi Sara

    القيمة المرسلة في الوسم name تصل للمكون كـ prop وتُعرض داخل JSX.

  5. ما الخطأ هنا؟ function A(props){ props.title = 'x'; return <h1>{props.title}</h1>; }

    • لا يوجد خطأ
    • الـ props للقراءة فقط ولا تُعدّل مباشرة
    • h1 غير مسموح
    • يجب استخدام var
    الإجابة والشرح

    الإجابة الصحيحة: الـ props للقراءة فقط ولا تُعدّل مباشرة

    لتغيير القيمة نستخدم state أو نمرر قيمة جديدة من المكون الأب.
