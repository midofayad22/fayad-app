JSX

تعلم JSX وكيف تسمح لك بكتابة صيغة تشبه HTML داخل JavaScript عند بناء Components.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

JSX هي صيغة تستخدمها React لكتابة واجهة المستخدم بطريقة قريبة من HTML داخل JavaScript.

JSX ليست HTML عادية، بل يتم تحويلها أثناء عملية البناء إلى JavaScript تفهمه البيئة التي تشغل التطبيق.

يمكنك أيضًا إدخال expressions من JavaScript داخل JSX باستخدام الأقواس المعقوفة.

JSX تجعل وصف واجهة React داخل JavaScript أكثر وضوحًا وسهولة.

مثال برمجي

الكود

function App() {
return (
<div>
<h1>مرحبًا بك</h1>
<p>تعلم React مع FAYBIT</p>
</div>
);
}

فهم الكود

يمكنك كتابة عناصر مثل h1 وp وbutton داخل Component، واستخدام JavaScript expressions داخل {}.
جرّب بنفسك

غيّر النص داخل h1 وأضف فقرة p جديدة.

اختبر نفسك

  1. ماذا تسمح JSX للمطور أن يكتب؟

    • صيغة تشبه HTML داخل JavaScript
    • SQL داخل CSS
    • CSS داخل قاعدة البيانات
    • HTML فقط بدون JavaScript
    الإجابة والشرح

    الإجابة الصحيحة: صيغة تشبه HTML داخل JavaScript

  2. أين نستخدم JavaScript expressions داخل JSX؟

    • داخل { }
    • داخل [ ] فقط
    • داخل SQL
    • داخل CSS
    الإجابة والشرح

    الإجابة الصحيحة: داخل { }

  3. هل JSX هي HTML عادية تمامًا؟

    • لا
    • نعم دائمًا
    • هي CSS
    • هي قاعدة بيانات
    الإجابة والشرح

    الإجابة الصحيحة: لا

  4. ماذا سيعرض هذا الكود؟ const n = 3; <p>{n + 2}</p>

    • 32
    • 5
    • خطأ
    • n + 2
    الإجابة والشرح

    الإجابة الصحيحة: 5

    الأقواس المعقوفة تقيّم تعبير JavaScript فيصبح الناتج 5.

  5. أي سطر JSX هو الصحيح لإضافة class؟

    • <div klass="box">
    • <div .box>
    • <div class="box">
    • <div className="box">
    الإجابة والشرح

    الإجابة الصحيحة: <div className="box">

    في JSX نستخدم className لأن class كلمة محجوزة في JavaScript.
