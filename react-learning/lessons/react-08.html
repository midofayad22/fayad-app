العرض الشرطي

تعلم كيف تعرض React عناصر مختلفة بناءً على قيمة شرط معين.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

Conditional Rendering يعني عرض جزء مختلف من الواجهة حسب حالة أو شرط معين.

يمكن استخدام if أو ternary operator أو && لتنفيذ العرض الشرطي.

هذه الفكرة مهمة جدًا في حالات مثل تسجيل الدخول وحالات التحميل والصلاحيات.

يمكن لـReact تغيير ما يظهر للمستخدم بناءً على البيانات الحالية.

مثال برمجي

الكود

function App({ isLoggedIn }) {
return (
<h1>
{isLoggedIn ? "مرحبًا بك مجددًا!" : "يرجى تسجيل الدخول"}
</h1>
);
}

فهم الكود

مثل عرض Dashboard للمستخدم المسجل وإظهار Login للمستخدم غير المسجل.

    • في حالات تسجيل الدخول والتحميل
    • في CSS فقط

    • في ملفات الصور

  4. ماذا يظهر؟ {isLoggedIn && <p>Welcome</p>} وكانت isLoggedIn = false

    • لا شيء
    • خطأ
    • isLoggedIn
    • Welcome

    الإجابة الصحيحة: لا شيء

    عندما يكون الشرط false لا يُعرض العنصر بعد &&.

    • {for user}
    • {user -> Login}
