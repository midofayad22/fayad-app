useRef

تعلم كيف تستخدم useRef للاحتفاظ بقيمة أو الوصول إلى عنصر DOM دون التسبب في Re-render.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

useRef ترجع Object يحتوي على خاصية current يمكن أن تحتفظ بقيمة بين عمليات Render.

من الاستخدامات الشائعة الوصول إلى DOM element مثل input للتركيز عليه.

تغيير ref.current لا يسبب Re-render للمكون.

useRef مفيدة للقيم التي تحتاج إلى الاحتفاظ بها دون التسبب في إعادة Render.

مثال برمجي

الكود

import { useRef } from "react";
function App() {
const inputRef = useRef(null);
return <input ref={inputRef} />;
}

فهم الكود

يمكن استخدامها أيضًا لحفظ reference إلى DOM element.
