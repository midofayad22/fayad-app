React Router

تعلم كيف تستخدم React Router لإنشاء التنقل بين الصفحات والمشاهد داخل تطبيق React.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

React Router مكتبة تستخدم لإدارة Navigation داخل تطبيقات React.

يمكنك تعريف Routes مختلفة مثل / و/about و/profile وربط كل Route بـComponent معين.

هذا يسمح ببناء تطبيقات متعددة الصفحات من ناحية تجربة المستخدم دون الحاجة إلى إعادة تحميل الصفحة في كل انتقال.

React Router يدير Navigation وربط URLs بالمكونات.

مثال برمجي

الكود

import {
BrowserRouter,
Routes,
Route
} from "react-router-dom";
<BrowserRouter>
<Routes>
<Route path="/" element={<Home />} />
<Route path="/about" element={<About />} />
</Routes>
</BrowserRouter>
