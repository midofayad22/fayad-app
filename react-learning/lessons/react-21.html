تحسين الأداء Performance

تعرف على المبادئ الأساسية لتحسين أداء تطبيقات React وتقليل العمل غير الضروري.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

Performance optimization يعني تقليل العمليات غير الضرورية التي يقوم بها التطبيق.

من المهم أولًا فهم سبب إعادة Render ثم تحديد الجزء الذي يحتاج إلى تحسين.

أدوات مثل React.memo وuseMemo وuseCallback قد تساعد في حالات معينة، لكنها ليست مطلوبة لكل Component.

تحسين الأداء يبدأ بفهم المشكلة وليس بإضافة أدوات Optimization عشوائيًا.

مثال برمجي

الكود

function ProductList({ products }) {
return products.map((product) => (
<Product
key={product.id}
product={product}
/>
));
}

فهم الكود

راقب عمليات Render والعمليات الحسابية الثقيلة قبل اختيار طريقة التحسين.
