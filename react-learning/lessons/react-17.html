Custom Hooks

تعلم كيفية إنشاء Custom Hooks لإعادة استخدام منطق React بين عدة Components.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

Custom Hook هي Function تبدأ عادة بكلمة use وتستخدم Hooks أخرى بداخلها.

الهدف الأساسي منها هو استخراج منطق مشترك وإعادة استخدامه في أكثر من Component.

Custom Hooks لا تشارك State نفسها بين Components، لكنها تشارك منطق التعامل مع State أو Effects.

Custom Hooks تساعدك على إعادة استخدام Logic بدلًا من تكراره.

مثال برمجي

الكود

function useGreeting(name) {
return `مرحبًا ${name}`;
}

فهم الكود

يمكنك إنشاء useFetch أو useToggle أو useLocalStorage مثلًا.
