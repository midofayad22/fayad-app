React + APIs

اربط بين React وState وEffects وAPIs لبناء تطبيقات تعتمد على البيانات الحقيقية.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

معظم التطبيقات العملية تحتاج إلى جلب بيانات من Backend أو API خارجي.

غالبًا يتم استخدام useEffect لبدء عملية الجلب، ثم يتم تخزين النتيجة داخل State.

يجب أيضًا التعامل مع Loading وError وSuccess states حتى تكون تجربة المستخدم جيدة.

التطبيقات المعتمدة على البيانات تحتاج إلى تنسيق جيد بين API وState وUI.

مثال برمجي

الكود

useEffect(() => {
fetch("/api/users")
.then((response) => response.json())
.then((data) => setUsers(data));
}, []);

يمكن فصل منطق API في services لتقليل مسؤوليات Components.
