State

افهم مفهوم State وكيف تستخدمه React لتخزين البيانات التي يمكن أن تتغير أثناء تشغيل التطبيق.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

State هي بيانات داخل Component يمكن أن تتغير مع مرور الوقت.

عندما تتغير State، يمكن أن تعيد React حساب الواجهة وعرض البيانات الجديدة.

من أشهر الأدوات المستخدمة لإدارة State داخل Component هي Hook تسمى useState.

State تمثل البيانات المتغيرة التي تؤثر في واجهة المستخدم.

مثال برمجي

الكود

const [count, setCount] = useState(0);
return (
<button onClick={() => setCount(count + 1)}>
{count}
</button>
);

فهم الكود

مثل عداد clicks أو حالة تسجيل الدخول أو قيمة input.

جرّب تغيير القيمة الأولية للعداد.

  1. ماذا تمثل State؟

    • بيانات يمكن أن تتغير بمرور الوقت
    • CSS Selector
    • ملف HTML
    • جدول قاعدة بيانات فقط

    الإجابة الصحيحة: بيانات يمكن أن تتغير بمرور الوقت

    • تُعاد معالجة الواجهة لعرض البيانات الجديدة
    • يتم حذف Component
    • يتم حذف CSS
    • يتوقف التطبيق
    الإجابة والشرح

    الإجابة الصحيحة: تُعاد معالجة الواجهة لعرض البيانات الجديدة

  3. أي Hook تستخدم لإدارة State البسيطة؟

    • useState
    • useHTML
    • useCSS
    • useDatabase
    الإجابة والشرح

    الإجابة الصحيحة: useState

  4. أي مما يلي مناسب ليكون state؟

    • عدد العناصر في السلة الذي يتغير عند الضغط
    • اسم الدالة
    • اسم الملف
    • اسم الثابت PI
    الإجابة والشرح

    الإجابة الصحيحة: عدد العناصر في السلة الذي يتغير عند الضغط

    State للبيانات التي تتغير مع الوقت وتؤثر على ما يظهر.

  5. ما الخطأ؟ const [n,setN]=useState(0); n = n + 1;

    • useState لا تقبل صفر
    • يجب أن يكون n نصاً
    • لا يوجد خطأ
    • تغيير المتغير مباشرة لا يعيد الرسم؛ يجب استخدام setN
    الإجابة والشرح

    الإجابة الصحيحة: تغيير المتغير مباشرة لا يعيد الرسم؛ يجب استخدام setN

    التغيير المباشر لا يخبر React، أما دالة التحديث فتطلب إعادة الرسم.
