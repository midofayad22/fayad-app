إدارة الحالة State Management

افهم الطرق المختلفة لإدارة State عندما يكبر حجم تطبيق React.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

في التطبيقات الصغيرة قد تكفي useState وuseContext لإدارة معظم الحالات.

عندما يكبر التطبيق قد تحتاج إلى تنظيم State بشكل أفضل أو استخدام مكتبة مخصصة لإدارة الحالة.

اختيار الطريقة يعتمد على حجم التطبيق وطبيعة البيانات وكيف تشاركها Components.

اختيار State Management المناسب يعتمد على طبيعة وحجم التطبيق.

مثال برمجي

الكود

const [user, setUser] = useState(null);
function login(userData) {
setUser(userData);
}

فهم الكود

لا توجد أداة واحدة مناسبة لكل المشاريع.
