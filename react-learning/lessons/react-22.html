React.memo

تعلم كيف يمكن لـReact.memo تقليل بعض عمليات إعادة Render غير الضرورية.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

React.memo هي API تساعد على إعادة استخدام نتيجة Render للمكون عندما لا تتغير Props الخاصة به.

إذا أعيد Render للمكون الأب وكانت Props للمكون الابن مساوية حسب المقارنة المستخدمة، يمكن لـReact تخطي Render للابن.

React.memo ليست حلًا سحريًا، ويجب استخدامها عندما يكون لها تأثير مفيد على الأداء.

React.memo يمكن أن تمنع بعض عمليات Render غير الضرورية عندما لا تتغير Props.

مثال برمجي

الكود

const UserCard = React.memo(function UserCard({ name }) {
return <h2>{name}</h2>;
});

فهم الكود

تكون مفيدة خصوصًا عندما يكون Component مكلفًا في Render ويتلقى Props مستقرة.
جرّب بنفسك

غيّر اسم UserCard وجرب استخدامه مع Props مختلفة.
