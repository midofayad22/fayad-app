طلبات API

تعلم كيف تتواصل تطبيقات React مع APIs للحصول على بيانات خارجية.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

التطبيقات الحقيقية غالبًا تحتاج إلى بيانات من Server أو خدمة خارجية.

يمكن استخدام fetch أو مكتبات أخرى لإرسال HTTP Requests واستقبال البيانات.

بعد وصول البيانات يمكن تخزينها في State وعرضها داخل Components.

API هي حلقة الاتصال بين واجهة React ومصدر البيانات الخارجي.

مثال برمجي

الكود

async function getUsers() {
const response = await fetch(
"https://example.com/users"
);
const data = await response.json();
return data;
}

فهم الكود

عادة يتم جلب البيانات ثم تحويل Response إلى JSON ثم تخزينها في State.

  3. ما وظيفة response.json()؟

    • تحويل Response إلى بيانات JSON

    الإجابة والشرح

    الإجابة الصحيحة: تحويل Response إلى بيانات JSON

  4. ما الخطأ؟ fetch(url).then(res => setData(res))

    • setData لا تقبل كائنات
    • لا خطأ
    • res هي Response وليست البيانات؛ يجب res.json() أولاً
    • then ممنوعة
    الإجابة والشرح

    الإجابة الصحيحة: res هي Response وليست البيانات؛ يجب res.json() أولاً

    نحوّل الاستجابة إلى JSON ثم نخزن البيانات.

  5. أي طريقة HTTP تُستخدم عادة لإنشاء سجل جديد؟

    • GET
    • POST
    • HEAD
    • TRACE

    الإجابة الصحيحة: POST
