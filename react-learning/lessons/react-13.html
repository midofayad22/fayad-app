useState

تعلم كيف تستخدم useState لإضافة State إلى Function Components وتحديث الواجهة.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

useState هي Hook تسمح للمكون بامتلاك قيمة State.

ترجع useState قيمتين: القيمة الحالية، وFunction لتحديثها.

عند استدعاء Function التحديث، تقوم React بإعادة معالجة Component لعرض القيمة الجديدة.

useState ترجع State value وState setter.

مثال برمجي

الكود

import { useState } from "react";
function Counter() {
const [count, setCount] = useState(0);
return (
<button onClick={() => setCount(count + 1)}>
{count}
</button>
);
}

فهم الكود

مثال: const [count, setCount] = useState(0).
