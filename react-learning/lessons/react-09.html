Lists & Keys

تعلم كيفية عرض مجموعة من البيانات باستخدام map ولماذا تحتاج React إلى Keys.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

غالبًا تكون البيانات في التطبيقات على شكل Array، مثل قائمة المستخدمين أو المنتجات.

يمكن استخدام map لإنشاء عنصر UI لكل عنصر داخل Array.

تحتاج العناصر الناتجة عن القوائم إلى key مستقرة تساعد React على معرفة هوية كل عنصر.

map تعرض عناصر القائمة، وkey تساعد React على تحديد هوية كل عنصر.

مثال برمجي

الكود

const skills = ["HTML", "CSS", "JavaScript"];
function App() {
return (
<ul>
{skills.map((skill) => (
<li key={skill}>{skill}</li>
))}
</ul>
);
}

فهم الكود

يفضل استخدام ID فريد كمفتاح بدلًا من استخدام index عندما تكون القائمة قابلة للتغيير.
