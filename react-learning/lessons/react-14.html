useEffect

تعلم كيف تستخدم useEffect للتعامل مع Side Effects مثل جلب البيانات والاشتراكات.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

useEffect تستخدم لتنفيذ Side Effects المرتبطة بعملية عرض Component أو بتغير بيانات معينة.

من الاستخدامات الشائعة جلب البيانات من API أو التعامل مع subscriptions أو تحديث عنوان الصفحة.

Dependency Array تحدد متى يتم تشغيل Effect مرة أخرى.

useEffect مناسبة للعمليات التي تحدث خارج حساب الواجهة المباشر.

مثال برمجي

الكود

import { useEffect } from "react";
useEffect(() => {
console.log("تم تشغيل Effect");
}, []);

فهم الكود

يمكن تشغيل Effect مرة بعد Mount باستخدام dependency array فارغة، أو عند تغير قيم محددة.
