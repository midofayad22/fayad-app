الأحداث Events

تعلم كيف تتعامل React مع تفاعل المستخدم مثل الضغط والكتابة وإرسال النماذج.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

Events تسمح للتطبيق بالاستجابة لتصرفات المستخدم.

في React تستخدم خصائص مثل onClick وonChange وonSubmit للتعامل مع الأحداث.

عادة نمرر function إلى event handler ليتم تنفيذها عند وقوع الحدث.

Events تربط تصرف المستخدم بالسلوك الذي تريد تنفيذه داخل التطبيق.

مثال برمجي

الكود

function App() {
function handleClick() {
console.log("تم الضغط على الزر");
}
return <button onClick={handleClick}>اضغط هنا</button>;
}

فهم الكود

عند الضغط على زر يمكن تنفيذ function، وعند الكتابة في input يمكن تحديث State.
