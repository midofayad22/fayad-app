تركيب المكونات Component Composition

تعلم كيف تجمع عدة Components معًا لبناء واجهات أكبر وأكثر تنظيمًا.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

Component Composition يعني بناء Component كبير من مجموعة Components أصغر.

هذه الطريقة تجعل كل Component مسؤولًا عن جزء محدد، ثم يتم تركيب الأجزاء معًا لتكوين واجهة كاملة.

التطبيق الكبير يمكن بناؤه من مجموعة Components صغيرة ومتخصصة.

مثال برمجي

الكود

function Header() {
return <header>FAYBIT</header>;
}
function App() {
return (
<>
<Header />
<main>تعلم React</main>
</>
);
}
