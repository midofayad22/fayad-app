useMemo وuseCallback

تعلم الفرق بين useMemo وuseCallback ومتى يمكن استخدامهما في تحسين الأداء.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

useMemo تستخدم لحفظ نتيجة عملية حسابية بين عمليات Render عندما لا تتغير dependencies.

useCallback تستخدم لحفظ نفس Function reference بين عمليات Render عندما لا تتغير dependencies.

يجب استخدامهما عند وجود سبب حقيقي متعلق بالأداء، لأن استخدامهما بلا حاجة قد يزيد التعقيد.

useMemo تحفظ قيمة محسوبة، بينما useCallback تحفظ Function reference.

مثال برمجي

الكود

const total = useMemo(() => {
return calculateTotal(items);
}, [items]);

فهم الكود

الاثنتان أدوات Optimization وليستا بديلًا عن تصميم التطبيق الجيد.
