التحقق ومجموعات الإدخال والتسميات العائمة

رسائل التحقق، وinput-group، وform-floating.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

التحقق

أضف novalidate للنموذج وneeds-validation، ثم عند الإرسال أضف was-validated ليظهر الأخضر/الأحمر حسب قواعد HTML (required وtype وminlength). أو ضع is-invalid/is-valid يدويًا مع .invalid-feedback. التحقق من الخادم لا غنى عنه.

مجموعات وتسميات

.input-group يدمج نصًا أو زرًا مع الحقل (.input-group-text). .form-floating يضع التسمية داخل الحقل وترتفع عند الكتابة (يجب أن يأتي الـ input قبل الـ label).

التحقق في المتصفح للتجربة فقط، تحقق دائمًا من الخادم أيضًا.

مثال برمجي

كود HTML

<form class="container py-3 needs-validation" novalidate style="max-width:480px" onsubmit="event.preventDefault(); this.classList.add('was-validated')">
<div class="input-group mb-3">
<span class="input-group-text">@</span>
<input type="text" class="form-control" placeholder="اسم المستخدم" aria-label="اسم المستخدم" required minlength="3">
<div class="invalid-feedback">الاسم مطلوب (3 أحرف على الأقل).</div>
</div>
<div class="form-floating mb-3">
<input type="email" class="form-control" id="mail" placeholder="name@example.com" required>
<label for="mail">البريد الإلكتروني</label>
<div class="invalid-feedback">أدخل بريدًا صحيحًا.</div>
</div>
<button class="btn btn-primary" type="submit">إرسال</button>
</form>

فهم الكود

اضغط «إرسال» بحقول فارغة لتظهر الرسائل الحمراء. الفئة was-validated تضيف التنسيق حسب حالة كل حقل.

جرّب بنفسك

عدّل وجرّب

أضف حقل كلمة مرور <code>required minlength="8"</code> داخل <code>form-floating</code>.

اختبر نفسك

  1. ماذا تفعل was-validated؟

    • تفعّل تنسيق الصح والخطأ حسب حالة الحقول
    • ترسل النموذج
    • تحذف الحقول
    • تحفظ البيانات
    الإجابة والشرح

    الإجابة الصحيحة: تفعّل تنسيق الصح والخطأ حسب حالة الحقول

  2. لماذا نحتاج التحقق من الخادم رغم التحقق في المتصفح؟

    • لأن التحقق في المتصفح يمكن تجاوزه
    • لأن المتصفح لا يدعمه
    • للسرعة فقط
    • لا نحتاج
    الإجابة والشرح

    الإجابة الصحيحة: لأن التحقق في المتصفح يمكن تجاوزه

  3. ما الشرط في form-floating؟

    • أن يأتي input قبل label
    • أن يأتي label قبل input
    • وجود select فقط
    • عدم وجود placeholder
    الإجابة والشرح

    الإجابة الصحيحة: أن يأتي input قبل label

  4. أي فئة تحمل الرمز @ بجانب حقل الإدخال داخل input-group؟

    • input-addon
    • form-text-box
    • group-label
    • input-group-text
    الإجابة والشرح

    الإجابة الصحيحة: input-group-text

    input-group-text ينسّق النص أو الأيقونة الملاصقة للحقل.

  5. كيف تُظهر رسالة خطأ حمراء يدوياً تحت حقل؟

    • is-invalid على الحقل و invalid-feedback للرسالة
    • text-error على الحقل
    • was-validated على الحقل وحده
    • alert-red بعد الحقل
    الإجابة والشرح

    الإجابة الصحيحة: is-invalid على الحقل و invalid-feedback للرسالة

    الفئة is-invalid تلوّن الحقل وتُظهر النص الموجود في invalid-feedback.
