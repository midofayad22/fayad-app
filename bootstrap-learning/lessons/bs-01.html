مقدمة: ما هو Bootstrap وكيف نبدأ

إطار CSS/JS جاهز لبناء واجهات متجاوبة بسرعة، مع الصفحة الأولى بخطوات الإعداد الصحيحة.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

ما هو Bootstrap؟

Bootstrap مكتبة مفتوحة المصدر توفر ملف CSS جاهزًا (أزرار، شبكة، نماذج، مكونات) وملف JavaScript للمكونات التفاعلية. تكتب فئات (classes) على عناصر HTML بدل كتابة CSS من الصفر. هذا الكورس مبني على الإصدار 5.3 (المثبت محليًا في المعاينة: 5.3.8).

الإعداد الأساسي

أي صفحة Bootstrap تحتاج: <!doctype html> و<meta name="viewport" content="width=device-width, initial-scale=1"> (أساس التجاوب)، ورابط ملف CSS، ثم ملف bootstrap.bundle.min.js في آخر الصفحة إن استخدمت المكونات التفاعلية. المعاينة هنا تضيف هذه الملفات لك تلقائيًا.

اكتب الفئات على العناصر، ولا تنسَ وسم viewport وإلا لن يتجاوب التصميم على الهاتف.

مثال برمجي

كود HTML

<div class="container py-4">
<h1 class="display-6">مرحبًا Bootstrap</h1>
<p class="lead">هذه صفحتي الأولى بدون كتابة CSS.</p>
<button type="button" class="btn btn-primary">زر أساسي</button>
</div>

فهم الكود

container يمركز المحتوى ويحدد عرضه، وpy-4 يضيف حشوة رأسية، وdisplay-6 وlead فئات للنصوص، وbtn btn-primary يحول العنصر إلى زر ملوّن.

جرّب بنفسك

عدّل وجرّب

غيّر لون الزر إلى <code>btn-success</code> وأضف زرًا ثانيًا بفئة <code>btn-outline-secondary</code>.

اختبر نفسك

  1. ما الوسم الضروري لعمل التصميم المتجاوب على الهاتف؟

    • meta viewport
    • meta charset فقط
    • link rel=icon
    • script defer
    الإجابة والشرح

    الإجابة الصحيحة: meta viewport

  2. كيف نستخدم Bootstrap أساسًا؟

    • بإضافة فئات جاهزة إلى عناصر HTML
    • بكتابة Sass يدويًا دائمًا
    • بتحويل HTML إلى PDF
    • بتثبيت برنامج على الجهاز
    الإجابة والشرح

    الإجابة الصحيحة: بإضافة فئات جاهزة إلى عناصر HTML

  3. أي ملف يلزم للمكونات التفاعلية مثل Modal وDropdown؟

    • bootstrap.bundle.min.js
    • bootstrap.min.css فقط
    • favicon.ico
    • robots.txt
    الإجابة والشرح

    الإجابة الصحيحة: bootstrap.bundle.min.js

  4. أين يُوضع ملف bootstrap.bundle.min.js في الصفحة عادة؟

    • في آخر الصفحة قبل إغلاق body
    • داخل وسم title
    • قبل وسم doctype
    • داخل ملف CSS
    الإجابة والشرح

    الإجابة الصحيحة: في آخر الصفحة قبل إغلاق body

    يوضع في آخر الصفحة ليعمل بعد تحميل العناصر التي سيتحكم بها.

  5. أي كود يحوّل عنصراً إلى زر أزرق جاهز؟

    • <button class="button blue">
    • <button class="primary">
    • <button class="btn btn-primary">
    • <button style="btn-primary">
    الإجابة والشرح

    الإجابة الصحيحة: <button class="btn btn-primary">

    الزر يحتاج الفئة الأساسية btn مع فئة اللون btn-primary.
