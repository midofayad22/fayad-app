الأزرار ومجموعات الأزرار

أنماط الأزرار وأحجامها وحالاتها والمجموعات.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

الأنماط

btn + btn-primary|secondary|success|danger|warning|info|light|dark|link. النسخة المحيطة: btn-outline-*. الأحجام: btn-lg وbtn-sm. التعطيل: disabled (وللروابط aria-disabled="true"). الزر بعرض كامل: w-100 أو داخل d-grid.

المجموعات

.btn-group يجمع أزرارًا في شريط واحد، ويفضل إضافة role="group" وaria-label لإمكانية الوصول.

استخدم button للإجراءات و a للتنقل، وأضف aria-label لمجموعات الأزرار.

مثال برمجي

كود HTML

<div class="container py-3 d-grid gap-3">
<div>
<button class="btn btn-primary">أساسي</button>
<button class="btn btn-outline-danger">حذف</button>
<button class="btn btn-secondary btn-sm">صغير</button>
<button class="btn btn-success btn-lg" disabled>معطل</button>
</div>
<div class="btn-group" role="group" aria-label="مجموعة التنسيق">
<button type="button" class="btn btn-outline-dark">عريض</button>
<button type="button" class="btn btn-outline-dark">مائل</button>
<button type="button" class="btn btn-outline-dark">تحته خط</button>
</div>
<a class="btn btn-link" href="#">رابط بمظهر زر</a>
</div>

فهم الكود

الصف الأول يعرض الأنماط المختلفة، والمجموعة تدمج الحدود بين الأزرار. الفئة d-grid على الحاوية تجعل أبناءها بعرض كامل.

جرّب بنفسك

عدّل وجرّب

أضف زر <code>btn-warning btn-lg</code> بنص «تحذير».

اختبر نفسك

  1. كيف نصنع زرًا بحدود فقط؟

    • btn-outline-primary
    • btn-border
    • btn-ghost
    • btn-line
    الإجابة والشرح

    الإجابة الصحيحة: btn-outline-primary

  2. ما فائدة role=group مع aria-label في btn-group؟

    • إخبار قارئ الشاشة أن الأزرار مجموعة واحدة بوصف
    • تلوين الأزرار
    • تسريع الصفحة
    • تعطيل الأزرار
    الإجابة والشرح

    الإجابة الصحيحة: إخبار قارئ الشاشة أن الأزرار مجموعة واحدة بوصف

  3. أي فئة تغير حجم الزر إلى أكبر؟

    • btn-lg
    • btn-xl
    • btn-big
    • btn-large
    الإجابة والشرح

    الإجابة الصحيحة: btn-lg

  4. كيف تعطّل رابطاً بشكل زر btn بطريقة صحيحة؟

    • إضافة الفئة disabled مع aria-disabled="true"
    • كتابة disabled كخاصية فقط على a
    • إضافة btn-off
    • حذف href فقط
    الإجابة والشرح

    الإجابة الصحيحة: إضافة الفئة disabled مع aria-disabled="true"

    الروابط لا تدعم الخاصية disabled، لذا نستخدم الفئة مع aria-disabled للقارئات.

  5. أي فئة تجعل الزر بعرض الحاوية بالكامل؟

    • btn-wide
    • btn-block-100
    • d-inline
    • w-100
    الإجابة والشرح

    الإجابة الصحيحة: w-100

    w-100 يعطي عرض 100%، وبديلها وضع الزر داخل d-grid.
