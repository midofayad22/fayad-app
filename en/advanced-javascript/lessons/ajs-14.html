Symbols and Tagged Templates

Unique, collision-proof keys, and template strings you can process with a custom function.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Symbol

Every Symbol() is a completely unique value. They work as property keys that do not collide with others and do not show up in for...in or Object.keys.

Tagged Templates

When you write tag`text ${value}`, the function tag is called with an array of the string parts followed by the values. They are used for escaping HTML, building safe queries, and custom languages.

Symbols are for unique keys, and tagged templates let you process interpolated values before building the string.

Code example

JavaScript code

const id = Symbol("id");
const user = { name: "Lina", [id]: 101 };
console.log(Object.keys(user), user[id]);
console.log(Symbol("a") === Symbol("a"), Symbol.for("a") === Symbol.for("a"));
const escapeHtml = (s) => String(s).replace(/[&<>"']/g, (c) => ({ "&": "&amp;", "<": "&lt;", ">": "&gt;", '"': "&quot;", "'": "&#39;" }[c]));
const html = (strings, ...values) =>
strings.reduce((out, s, i) => out + s + (i < values.length ? escapeHtml(values[i]) : ""), "");
const input = "<script>alert(1)</script>";
console.log(html`<p>${input}</p>`);
[ 'name' ] 101
false true
<p>&lt;script&gt;alert(1)&lt;/script&gt;</p>

Understanding the code

The key id did not appear in keys. The html function automatically escapes every interpolated value, making it safer to build HTML from user input.

  3. Which use suits tagged templates?

    • Escaping HTML and building safe queries
    • Changing page colors
    • Downloading files
    • Compressing images
    Answer and explanation

    Correct answer: Escaping HTML and building safe queries

  4. What does this code print? const s = Symbol(); const o = { [s]: 1, a: 2 }; console.log(Object.keys(o), JSON.stringify(o));

    • ["a"] and {"a":2}
    • ["a", "s"] and {"a":2,"s":1}
    • [] and {}
    • ["a"] and {"a":2,"s":1}
    Answer and explanation

    Correct answer: ["a"] and {"a":2}

    Symbol keys do not show in Object.keys or for...in, and JSON.stringify ignores them. So only the property a remains.

  5. What does this code print? function tag(strings, ...vals) { return strings.length + ":" + vals.join("-"); } console.log(tag`a${1}b${2}c`);

    • 2:1-2
    • 3:1-2
    • 5:1-2
    • 3:12
    Answer and explanation

    Correct answer: 3:1-2

    The template is split at each interpolation into the static strings "a", "b" and "c", which is 3 elements, and the values 1 and 2 arrive in the rest arguments. Joining with a dash gives 1-2.
