The Event Loop: Microtasks and Macrotasks

Understand precisely the execution order of synchronous and asynchronous code.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

The Call Stack and Task Queues

JavaScript runs on a single thread. Synchronous code runs first on the Call Stack. When it is empty, the Event Loop runs all Microtasks (Promise.then and queueMicrotask), then one task from the Macrotasks (setTimeout and DOM events), and repeats.

All Microtasks run before any Macrotask, even if setTimeout is zero.

Code example

JavaScript code

console.log("1 sync");
setTimeout(() => console.log("5 timeout"), 0);
Promise.resolve().then(() => console.log("3 promise"));
queueMicrotask(() => console.log("4 microtask"));
(async () => {
console.log("2 inside async (sync part)");
await null;
console.log("4b after await");
})();
console.log("2b sync end");
1 sync
2 inside async (sync part)
2b sync end
3 promise
4 microtask
4b after await
5 timeout

Understanding the code

The first part of an async function runs immediately. Everything after await moves to the microtask queue, and all of it runs before the turn reaches setTimeout.

  2. Does setTimeout(fn, 0) run immediately?

    Answer and explanation

  3. Where does code resume after await?

    • As a Microtask
    • As a Macrotask
    • On a new thread
    • On the network
    Answer and explanation

    Correct answer: As a Microtask

  4. What is the print order? console.log("1"); setTimeout(() => console.log("2")); Promise.resolve().then(() => console.log("3")); console.log("4");

    • 1, 2, 3, 4
    • 1, 4, 2, 3
    • 1, 3, 4, 2
    • 1, 4, 3, 2
    Answer and explanation

    Correct answer: 1, 4, 3, 2

    Synchronous code runs first, printing 1 and 4, then the microtask queue is drained, printing 3, and only then does the timer macrotask print 2.

  5. What is the print order? async function f() { console.log("a"); await null; console.log("b"); } f(); console.log("c");

    • a, c, b
    • a, b, c
    • c, a, b
    • a, c only
    Answer and explanation

    Correct answer: a, c, b

    An async function runs synchronously up to the first await, printing a, then pauses and hands control back so c prints. The code after await is scheduled as a microtask, so b prints last.
