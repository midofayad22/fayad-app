Map, Set, WeakMap, and WeakRef

Choose the right data structure, and understand weak references and when they help prevent memory leaks.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Map and Set

Map accepts any key type and preserves insertion order. Set is a collection of unique values. Both are faster and clearer than objects in many cases.

Weak References

WeakMap and WeakSet hold object keys without preventing the garbage collector from removing them. They suit attaching private data to an object without leaking memory. Their keys must be objects and they cannot be enumerated.

WeakMap does not prevent the key from being removed from memory, and its entries cannot be iterated.

Code example

JavaScript code

const counts = new Map();
for (const w of "to be or not to be".split(" ")) {
counts.set(w, (counts.get(w) ?? 0) + 1);
}
console.log([...counts].filter(([, n]) => n > 1));
const unique = [...new Set([3, 1, 3, 2, 1])];
console.log(unique);
const keyObj = { id: 1 };
const m = new Map([[keyObj, "object key"], [NaN, "nan key"]]);
console.log(m.get(keyObj), m.get(NaN), m.size);
const meta = new WeakMap();
const el = {};
meta.set(el, { clicks: 0 });
meta.get(el).clicks++;
console.log(meta.get(el), meta.has({}));
[ [ 'to', 2 ], [ 'be', 2 ] ]
[ 3, 1, 2 ]
object key nan key 2
{ clicks: 1 } false

Understanding the code

Map accepts an object and NaN as keys, which plain objects do not offer. WeakMap attaches data to the object, and the data disappears automatically if the object disappears.

  3. How do you quickly remove duplicates from an array?

    • [...new Set(arr)]
    • arr.unique()
    • arr.deleteDuplicates()
    • Object.keys(arr)
    Answer and explanation

    Correct answer: [...new Set(arr)]

  4. What does this code print? console.log(new Map([[{}, 1]]).get({}));

    • 1
    • undefined
    • null
    • An error
    Answer and explanation

    Correct answer: undefined

    Object keys in a Map are compared by identity, not content, and the second {} is a new, different object. So the key is not found and the result is undefined.

  5. What does this code print? console.log(new Set([{ a: 1 }, { a: 1 }]).size, new Set([NaN, NaN]).size);

    • 1 and 1
    • 1 and 2
    • 2 and 2
    • 2 and 1
    Answer and explanation

    Correct answer: 2 and 1

    The two look-alike objects are different references, so both stay and the size is 2. Set treats NaN as equal to itself, unlike ===, so only one remains.
