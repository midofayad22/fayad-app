Advanced Regular Expressions

Named groups, lookahead and lookbehind, and matchAll for precise data extraction.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Modern Tools

  • Named groups: (?<year>\d{4}).
  • Lookahead (?=...) and Lookbehind (?<=...).
  • matchAll to get all results along with their groups.
  • The u flag for correct Unicode handling.

Named groups make a regex readable, and matchAll requires the g flag.

Code example

JavaScript code

const date = /(?<year>\d{4})-(?<month>\d{2})-(?<day>\d{2})/u;
const { groups } = "Due 2026-03-09".match(date);
console.log(groups.year, groups.month, groups.day);
const prices = "usd:10 eur:20 usd:35";
const usd = [...prices.matchAll(/usd:(\d+)/g)].map((m) => Number(m[1]));
console.log(usd);
console.log("1234567".replace(/\B(?=(\d{3})+(?!\d))/g, ","));
console.log("price: $45".match(/(?<=\$)\d+/)[0]);
console.log("2026-03-09".replace(date, "$<day>/$<month>/$<year>"));
2026 03 09
[ 10, 35 ]
1,234,567
45
09/03/2026

Understanding the code

The lookahead inserts separators every 3 digits without consuming the digits. And the lookbehind captures the number after the $ sign without including it in the result.

  1. What is the benefit of named groups?

    • Accessing results by name instead of by number
    • Speeding up the page
    • Encrypting text
    • Converting text to numbers
    Answer and explanation

    Correct answer: Accessing results by name instead of by number

  2. What does matchAll require?

    • The g flag
    • The i flag only
    • No requirement
    • The y flag only
    Answer and explanation

    Correct answer: The g flag

  3. What does (?<=\$) do?

    • Checks that $ exists before the position without consuming it
    • Matches $ and removes it
    • Checks after the position
    • Returns the whole text
    Answer and explanation

    Correct answer: Checks that $ exists before the position without consuming it

  4. What does this code print? console.log("[a][b]".match(/\[.*\]/)[0], "[a][b]".match(/\[.*?\]/)[0]);

    • [a] and [a]
    • [a][b] and [a]
    • [a] and [a][b]
    • [a][b] and [a][b]
    Answer and explanation

    Correct answer: [a][b] and [a]

    The greedy .* grabs as much as possible up to the last ], giving [a][b]. Adding ? makes it lazy, so it stops at the first ] and gives [a].

  5. What does console.log("10px 20em".match(/\d+(?=px)/)[0]) print?

    • 20
    • 10px
    • 10
    • null
    Answer and explanation

    Correct answer: 10

    (?=px) is a lookahead that requires px to follow the digits without including it in the match. So the match is 10 without px.
