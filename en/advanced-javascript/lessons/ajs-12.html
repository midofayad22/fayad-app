Generators

Functions that can be paused and resumed to produce lazy values and infinite streams.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

function* and yield

A generator function function* returns an Iterator. At yield it pauses and hands out a value, and the next call resumes from the same place with its saved state.

Laziness and Streams

A value is only computed when requested, so you can define an infinite sequence and take only the part you need. Values can also be passed into the generator via next(value).

yield pauses execution and saves state, and next(value) sends a value back into the generator.

Code example

JavaScript code

function* naturals() {
let n = 1;
while (true) yield n++;
}
function* take(iter, count) {
let i = 0;
for (const v of iter) {
if (i++ >= count) return;
yield v;
}
}
console.log([...take(naturals(), 5)]);
function* conversation() {
const name = yield "name?";
const lang = yield "language?";
return name + " likes " + lang;
}
const g = conversation();
console.log(g.next().value);
console.log(g.next("Sara").value);
console.log(g.next("JS"));
[ 1, 2, 3, 4, 5 ]
name?
language?
{ value: 'Sara likes JS', done: true }

Understanding the code

The naturals sequence is infinite but does not hang the program because take requests only 5 values. In the conversation, the answers are sent via next.

Test yourself

  1. What happens at yield?

    • The function pauses, hands out the value, and saves its state
    • The function ends permanently
    • It throws an error
    • It restarts from the beginning
    Answer and explanation

    Correct answer: The function pauses, hands out the value, and saves its state

  2. Why can an infinite sequence be defined with a generator?

    • Because values are computed only on demand
    • Because memory is infinite
    • Because the generator copies arrays
    • It cannot
    Answer and explanation

    Correct answer: Because values are computed only on demand

  3. What does next('x') do?

    • Returns 'x' as the result of the paused yield expression
    • Deletes the generator
    • Adds an element to the array
    • Changes the function's name
    Answer and explanation

    Correct answer: Returns 'x' as the result of the paused yield expression

  4. What does this code print? function* g() { yield 1; yield 2; return 3; } console.log([...g()]);

    • [1, 2, 3]
    • [1, 2]
    • [3]
    • [1, 2, undefined]
    Answer and explanation

    Correct answer: [1, 2]

    Spread and loops stop when done becomes true and ignore the return value. So only the values produced by yield appear.

  5. With the same generator function* g() { yield 1; yield 2; return 3; } and it = g() after one it.next(), what do the next three calls return, in order?

    • {value:2,done:false} then {value:3,done:true} then {value:undefined,done:true}
    • {value:2,done:false} then {value:3,done:false} then {value:undefined,done:true}
    • {value:2,done:true} then {value:3,done:true} then an error
    • {value:2,done:false} then {value:undefined,done:true} then {value:undefined,done:true}
    Answer and explanation

    Correct answer: {value:2,done:false} then {value:3,done:true} then {value:undefined,done:true}

    return delivers its value once with done: true, after which the generator stays finished and yields an undefined value. That is why 3 appears with done true and then undefined.
