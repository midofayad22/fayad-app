Proxy and Reflect

Intercept operations on objects to build validation, logging, and default values.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Proxy

new Proxy(target, handler) wraps an object and intercepts operations such as get, set, has, and deleteProperty through functions called traps.

Reflect

Reflect provides the same default operations as functions, so you call them inside the trap to preserve the original behavior.

Always return via Reflect.set/get inside traps to preserve correct behavior.

Code example

JavaScript code

const validator = {
set(target, key, value, receiver) {
if (key === "age" && !Number.isInteger(value)) {
throw new TypeError("age must be an integer");
}
return Reflect.set(target, key, value, receiver);
},
get(target, key, receiver) {
return key in target ? Reflect.get(target, key, receiver) : "n/a";
},
};
const person = new Proxy({}, validator);
person.age = 30;
console.log(person.age, person.name);
try { person.age = "x"; } catch (e) { console.log(e.message); }
const logs = [];
const tracked = new Proxy({ n: 1 }, {
set(t, k, v) { logs.push(k + "=" + v); t[k] = v; return true; },
});
tracked.n = 2; tracked.m = 3;
console.log(logs);
30 n/a
age must be an integer
[ 'n=2', 'm=3' ]

Understanding the code

The first Proxy validates values before writing and returns a default value for missing keys. The second logs every modification without changing the original object.

  1. What is a trap?

    • A type of error

  2. Why do we use Reflect inside traps?

    • To perform the default behavior correctly
    • To slow down the code
    • To disable the Proxy
    • To create classes
    Answer and explanation

    Correct answer: To perform the default behavior correctly

  3. Which of the following is a suitable use of Proxy?

    • Validating values and logging changes
    • Coloring the page
    • Loading images
    • Encrypting passwords
    Answer and explanation

    Correct answer: Validating values and logging changes

  4. What does this code print? const p = new Proxy({}, { set(t, k, v) { t[k] = v * 2; return true; } }); p.x = 5; console.log(p.x);

    • 5
    • undefined
    • An error because set cannot change the value
    • 10
    Answer and explanation

    Correct answer: 10

    The set trap intercepts the assignment and decides what is stored on the target, so 10 is stored. Reading p.x has no trap and passes straight to the target.

  5. What does this code print? const p = new Proxy({}, { get: (t, k) => (k in t ? t[k] : 0) }); console.log(p.a, p.b + 1);

    • 0 and 1
    • undefined and NaN
    • 0 and NaN
    • 0 and 0
    Answer and explanation

    Correct answer: 0 and 1

    The get trap returns 0 for any missing key instead of undefined, so p.a is 0 and p.b + 1 is 1. This shows how a Proxy changes read behavior.
