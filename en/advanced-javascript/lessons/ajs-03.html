this and call / apply / bind

The rules that determine the value of this in each case, and how to control it manually.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

The Rules

The value of this is determined at call time, not at definition time (except for arrow functions):

  1. obj.method(): this is obj.
  2. A plain call fn(): undefined in strict mode.
  3. new F(): the new object.
  4. call / apply / bind: the value you specify.
  5. An arrow function: inherits this from the surrounding scope.

An arrow function has no this of its own, and bind returns a new function with this fixed.

Code example

JavaScript code

"use strict";
const user = {
name: "Sara",
hello() { return "Hi " + this.name; },
later() { return [1].map(() => this.name); },
};
console.log(user.hello());
console.log(user.later());
const detached = user.hello;
try {
detached();
} catch (e) {
console.log(e.name);
}
function greet(greeting) { return greeting + ", " + this.name; }
console.log(greet.call({ name: "Omar" }, "Hello"));
console.log(greet.apply({ name: "Lina" }, ["Hey"]));
const bound = greet.bind({ name: "Zain" });
console.log(bound("Yo"));
Hi Sara
[ 'Sara' ]
TypeError
Hello, Omar
Hey, Lina
Yo, Zain

Understanding the code

Detaching the function from its object (detached) makes this equal to undefined, so it throws an error. call passes arguments one by one, apply passes them as an array, and bind creates a new function.

Test yourself

  1. When is the value of this determined in regular functions?

    • At call time
    • At definition time
    • At page load time
    • At save time
    Answer and explanation

    Correct answer: At call time

  2. What is the difference between call and apply?

    • call takes arguments separately and apply takes them in an array
    • No difference
    • apply is always faster
    • call is for objects only
    Answer and explanation

    Correct answer: call takes arguments separately and apply takes them in an array

  3. What does bind return?

    • A new function with this fixed
    • The result of the function
    • undefined
    • An empty object
    Answer and explanation

    Correct answer: A new function with this fixed

  4. What does this code print? function f() { return this.n; } const b = f.bind({ n: 1 }); console.log(b.call({ n: 2 }));

    • 2
    • 1
    • undefined
    • An error
    Answer and explanation

    Correct answer: 1

    The function returned by bind has this fixed permanently, and a later call, apply or bind cannot change it. So the result stays 1.

  5. What does this code print? const o = { n: 1, f() { return [1].map(() => this.n); } }; console.log(o.f());

    • [undefined]
    • A TypeError
    • [1]
    • [0]
    Answer and explanation

    Correct answer: [1]

    An arrow function has no own this and inherits it from the enclosing f, which is o in the call o.f(). A regular function there would lose this inside map.
