Classes: Privacy and static

Build modern classes with private fields, static methods, and Getters and Setters.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Syntactic Sugar over Prototypes

A class is a clearer way to write the same prototype system. Methods go onto prototype automatically.

Private and Static

Fields that start with # are truly private and cannot be accessed from outside the class. static members belong to the class itself, not to instances.

Use #private to protect state, and getter/setter to validate values.

Code example

JavaScript code

class Account {
#balance = 0;
static count = 0;
constructor(owner) {
this.owner = owner;
Account.count++;
}
get balance() { return this.#balance; }
deposit(n) {
if (n <= 0) throw new RangeError("amount must be positive");
this.#balance += n;
return this;
}
static compare(a, b) { return a.balance - b.balance; }
}
const a = new Account("Ali").deposit(50).deposit(25);
const b = new Account("Noor").deposit(10);
console.log(a.balance, Account.count);
console.log([a, b].sort(Account.compare).map((x) => x.owner));
console.log(a.balance = 5, a.balance);
try { a.deposit(-1); } catch (e) { console.log(e.name + ": " + e.message); }
75 2
[ 'Noor', 'Ali' ]
5 75
RangeError: amount must be positive

Understanding the code

There is no setter for balance, so the assignment changes nothing (it is silently ignored outside strict mode). The #balance field can only be accessed from inside the class.

  1. What does a field that starts with # mean?

    • Private and cannot be read from outside the class
    • Constant only

    Answer and explanation

    Correct answer: Private and cannot be read from outside the class

  2. What do static members belong to?

    • The class itself, not instances
    • Every instance
    • The prototype only
    • window
    Answer and explanation

    Correct answer: The class itself, not instances

  3. What is the purpose of a getter?

    • Reading a computed value as if it were a property
    • Deleting the property
    • Freezing the object
    • Duplicating the object
    Answer and explanation

    Correct answer: Reading a computed value as if it were a property

  4. What does this code print? class A { #x = 1; } const a = new A(); console.log(a.x, Object.keys(a));

    • 1 and ["x"]
    • 1 and []
    • undefined and []
    • undefined and ["#x"]
    Answer and explanation

    Correct answer: undefined and []

    The private field #x is not a normal property named x and does not appear in the keys, so a.x is undefined. It can only be reached inside the class through this.#x.

  5. What does this code print? class C { static n = 0; constructor() { C.n++; } } new C(); new C(); console.log(C.n);

    • 0
    • 1
    • 2
    • undefined
    Answer and explanation

    Correct answer: 2

    A static field belongs to the class itself with a single shared copy, and each constructor call increments it. After two instances it is 2.
