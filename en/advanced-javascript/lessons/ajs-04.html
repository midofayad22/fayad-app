Higher-Order Functions and Composition

Write functions that take functions and return them: Currying, Compose, and Pipe.

Higher-Order Functions

A higher-order function takes a function as an argument or returns a function. map, filter, and reduce are well-known examples, and you can build your own tools.

Currying and Composition

Currying converts a multi-argument function into a chain of single-argument functions. Pipe passes the result from one function to the next, from left to right.

Build small pure functions and then compose them instead of writing one huge function.

Code example

JavaScript code

const curry = (fn) => function curried(...args) {
return args.length >= fn.length
? fn(...args)
: (...more) => curried(...args, ...more);
};
const add3 = curry((a, b, c) => a + b + c);
console.log(add3(1)(2)(3), add3(1, 2)(3));
const pipe = (...fns) => (x) => fns.reduce((v, f) => f(v), x);
const slugify = pipe(
(s) => s.trim(),
(s) => s.toLowerCase(),
(s) => s.replace(/\s+/g, "-"),
);
console.log(slugify("  Advanced JS Course "));

Understanding the code

fn.length is the number of declared parameters, so we keep collecting arguments until they are complete. pipe uses reduce to pass the value through a chain of transformations.

  1. What is a higher-order function?

    • A function that takes a function or returns a function
    • A function with more than 5 arguments

    • An async function

  2. What is Currying?

    • Converting a multi-argument function into a sequence of single-argument functions
    • Copying functions
    • Deleting functions
    • Speeding up loops
    Answer and explanation

    Correct answer: Converting a multi-argument function into a sequence of single-argument functions

  3. How does pipe differ from compose?

    • pipe goes left to right and compose goes right to left
    • There is no difference at all
    • pipe is for numbers only
    • compose does not exist
    Answer and explanation

    Correct answer: pipe goes left to right and compose goes right to left

  4. What does this code print? const add = a => b => a + b; console.log([1, 2].map(add(10)));

    • [11, 12]
    • [10, 10]
    • [1, 2]
    • [NaN, NaN]
    Answer and explanation

    Correct answer: [11, 12]

    add(10) returns a function that waits for b and remembers a = 10, and map feeds it each element. This is currying with partial application.

  5. Given inc = x => x + 1 and dbl = x => x * 2, what do compose(inc, dbl)(5) and pipe(inc, dbl)(5) return, in order?

    • 12 and 12
    • 11 and 12
    • 12 and 11
    • 11 and 11
    Answer and explanation

    Correct answer: 11 and 12

    compose applies functions right to left: dbl(5) = 10 then inc = 11. pipe applies them left to right: inc(5) = 6 then dbl = 12.
