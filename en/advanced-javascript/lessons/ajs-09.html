Property Descriptors and Freezing

Control whether a property is writable and enumerable, and understand the difference between freeze and seal and between shallow and deep copying.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Descriptors

Every property has attributes: writable, enumerable, and configurable (or get/set). You control them via Object.defineProperty.

freeze and structuredClone

Object.freeze is shallow: it only prevents modifying direct properties. For deep copying use structuredClone (it does not support functions).

freeze is shallow. Nested objects remain modifiable unless you freeze them too.

Code example

JavaScript code

"use strict";
const cfg = {};
Object.defineProperty(cfg, "id", { value: 7, enumerable: false });
console.log(cfg.id, Object.keys(cfg));
try { cfg.id = 8; } catch (e) { console.log(e.name); }
const state = Object.freeze({ user: { name: "A" }, n: 1 });
try { state.n = 2; } catch (e) { console.log("frozen"); }
state.user.name = "B";
console.log(state.user.name);
const deep = structuredClone({ d: new Date(0), list: [1, { x: 2 }] });
console.log(deep.list[1].x, deep.d.getTime());

Understanding the code

A property defined with defineProperty without writable is read-only and not visible in keys. Freezing did not prevent changing state.user.name because it is a nested object.

  1. What does Object.freeze prevent?

    • Modifying, adding, and deleting direct properties
    • Reading properties
    • Using the object in loops
    • Converting to JSON
    Answer and explanation

    Correct answer: Modifying, adding, and deleting direct properties

  2. What is the limitation of freeze?

    • It is shallow and does not freeze nested objects
    • It deeply freezes everything
    • It works on numbers only
    • It prevents nothing
    Answer and explanation

    Correct answer: It is shallow and does not freeze nested objects

  3. What does structuredClone not support?

    • Functions
    • Arrays
    • Dates
    • Nested objects
    Answer and explanation

    Correct answer: Functions

  4. What does this code print? const o = {}; Object.defineProperty(o, "id", { value: 1 }); console.log(Object.keys(o), o.id, Object.getOwnPropertyDescriptor(o, "id").writable);

    • ["id"] 1 true
    • [] 1 false
    • ["id"] 1 false
    • [] undefined false
    Answer and explanation

    Correct answer: [] 1 false

    With defineProperty, writable, enumerable and configurable all default to false. So the property is not writable and does not show in Object.keys, but its value can be read.

  5. What does this code print? const o = Object.freeze({ list: [1] }); o.list.push(2); console.log(o.list);

    • [1], because the object is frozen
    • [1, 2], because freeze is shallow and does not cover the inner array
    • A TypeError
    • [2]
    Answer and explanation

    Correct answer: [1, 2], because freeze is shallow and does not cover the inner array

    freeze locks only the object's direct properties, so list cannot be replaced by another array. The array itself is a separate unfrozen object and can still be changed with push.
