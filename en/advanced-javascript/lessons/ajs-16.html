Promise.all, allSettled, race, and any

Coordinate several asynchronous operations with the right strategy for each case.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

The Comparison

  • all: waits for everyone and fails at the first failure.
  • allSettled: waits for everyone and returns the status of each one.
  • race: the first one to finish (success or failure).
  • any: the first success, and fails only if all fail.

Choose all when you need every result, and allSettled when some may fail.

Code example

JavaScript code

const ok = (v, ms) => new Promise((r) => setTimeout(() => r(v), ms));
const fail = (m, ms) => new Promise((_, j) => setTimeout(() => j(new Error(m)), ms));
(async () => {
console.log(await Promise.all([ok("a", 20), ok("b", 5)]));
try { await Promise.all([ok("a", 20), fail("boom", 5)]); }
catch (e) { console.log("all failed:", e.message); }
const settled = await Promise.allSettled([ok("x", 5), fail("no", 5)]);
console.log(settled.map((s) => s.status));
console.log(await Promise.race([ok("slow", 30), ok("fast", 5)]));
console.log(await Promise.any([fail("e1", 5), ok("winner", 15)]));
})();
[ 'a', 'b' ]
all failed: boom
[ 'fulfilled', 'rejected' ]
fast
winner

Understanding the code

The order of results in all matches the order of the inputs, not the order of completion. any ignores early failures and waits for the first success.

Test yourself

  1. Which function fails at the first failure?

    • Promise.all
    • Promise.allSettled
    • Promise.any
    • None of them
    Answer and explanation

    Correct answer: Promise.all

  2. Which function gives you the status of every promise no matter what?

    • Promise.allSettled
    • Promise.race
    • Promise.all
    • Promise.resolve
    Answer and explanation

    Correct answer: Promise.allSettled

  3. What does Promise.any return when all fail?

    • It rejects with an AggregateError
    • It succeeds with an empty array
    • It returns undefined
    • It freezes
    Answer and explanation

    Correct answer: It rejects with an AggregateError

  4. What does this code print? Promise.allSettled([Promise.resolve(1), Promise.reject("x")]).then(r => console.log(r.map(i => i.status)));

    • ["fulfilled", "rejected"]
    • ["fulfilled"]
    • Nothing, with an unhandled error
    • [1, "x"]
    Answer and explanation

    Correct answer: ["fulfilled", "rejected"]

    allSettled never rejects because of one element and returns an object per promise with a status and a value or reason. So then runs and both statuses appear.

  5. One promise rejects after 10ms and another fulfills after 50ms. What do Promise.race and Promise.any give for them?

    • race fulfills with the second value and any rejects
    • Both race and any reject
    • Both race and any fulfill with the second value
    • race rejects because the first settled first, and any fulfills with the second value
    Answer and explanation

    Correct answer: race rejects because the first settled first, and any fulfills with the second value

    race follows the first promise to settle, whether it fulfills or rejects, and here the rejection comes at 10ms. any ignores rejections and waits for the first success, so it fulfills with the second value.
