Iterators and Iterables

The protocol behind for...of, spread, and destructuring.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

The Protocol

An Iterable object has [Symbol.iterator]() which returns an Iterator, an object with a next() function that returns { value, done }.

Why Does It Matter?

Any Iterable object works with for...of, ...spread, Array.from, and new Set. You can make your own objects iterable.

Build an Iterator when loading is lazy or the data is huge.

Code example

JavaScript code

const range = {
from: 1, to: 4,
[Symbol.iterator]() {
let cur = this.from;
const end = this.to;
return {
next: () => cur <= end ? { value: cur++, done: false } : { value: undefined, done: true },
};
},
};
console.log([...range]);
for (const n of range) if (n % 2 === 0) console.log("even", n);
const [first, second] = range;
console.log(first, second);
console.log(Math.max(...range));
[ 1, 2, 3, 4 ]
even 2
even 4
1 2
4

Understanding the code

As soon as Symbol.iterator exists, the object works with spread, destructuring, and for...of without writing anything extra.

Test yourself

  1. What does next() return?

    • An object with value and done
    • A number only
    • An array
    • Always a Promise
    Answer and explanation

    Correct answer: An object with value and done

  2. What makes an object Iterable?

    • Having the [Symbol.iterator] function
    • Having a length property
    • Being an array only
    • Having next in it
    Answer and explanation

    Correct answer: Having the [Symbol.iterator] function

  3. Which of these work with Iterables?

    • spread, for...of, and destructuring
    • typeof only
    • delete only
    • with only
    Answer and explanation

    Correct answer: spread, for...of, and destructuring

  4. What does this code print? console.log([..."a😀"].length, "a😀".length);

    • 2 and 3
    • 3 and 2
    • 2 and 2
    • 3 and 3
    Answer and explanation

    Correct answer: 2 and 3

    A string is iterable by full code points, so the emoji counts as one element, giving 2. length counts UTF-16 units and the emoji takes two, giving 3.

  5. What is the result of for (const x of { a: 1 }) { }?

    • It iterates over the key a
    • It iterates over the value 1
    • It throws a TypeError because a plain object is not iterable
    • It silently does nothing
    Answer and explanation

    Correct answer: It throws a TypeError because a plain object is not iterable

    for...of requires an iterable, meaning an object with Symbol.iterator, and a plain object has none. To loop over its keys use Object.keys or Object.entries.
