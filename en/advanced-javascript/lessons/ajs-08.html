Class Inheritance and Mixins

extends, super, and combining behaviors via Mixins, and preferring composition over inheritance.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

extends and super

extends links the child class's prototype to the parent's. super() is mandatory in the constructor before using this, and super.method() calls the parent's version.

Composition First

Deep inheritance chains become brittle. When you need shared behavior from more than one source, use Mixins or pass in dependencies (Composition).

Prefer composition (has-a) over inheritance (is-a) unless there is a genuine relationship.

Code example

JavaScript code

class Shape {
constructor(name) { this.name = name; }
area() { return 0; }
describe() { return this.name + " area=" + this.area().toFixed(1); }
}
class Circle extends Shape {
constructor(r) { super("circle"); this.r = r; }
area() { return Math.PI * this.r ** 2; }
describe() { return super.describe() + "!"; }
}
console.log(new Circle(2).describe());
const Serializable = (Base) => class extends Base {
toJSON() { return { type: this.name }; }
};
class Tagged extends Serializable(Shape) {}
console.log(JSON.stringify(new Tagged("tag")));
console.log(new Circle(1) instanceof Shape);
circle area=12.6!
{"type":"tag"}
true

Understanding the code

Serializable is a function that takes a class and returns a new class that extends it, so we add behavior without complicating the hierarchy.

  3. What does the rule "composition over inheritance" mean?

    • Building objects from independent parts instead of expanding the hierarchy
    • Not using classes
    • Using var
    • Not writing tests
    Answer and explanation

    Correct answer: Building objects from independent parts instead of expanding the hierarchy

  4. What does this code print? class A { hi() { return "A"; } } class B extends A { hi() { return super.hi() + "B"; } } console.log(new B().hi());

    • B
    • A
    • AB
    • BA
    Answer and explanation

    Correct answer: AB

    super.hi() calls the parent version returning A, then the child appends B to give AB. Overriding does not discard the parent; it lets you build on it.

  5. What does this code print? const Fly = Base => class extends Base { fly() { return "fly"; } }; class Bird extends Fly(Object) {} console.log(new Bird().fly(), new Bird() instanceof Bird);

    • fly true
    • fly false
    • undefined true
    • An error because a class cannot be returned from a function
    Answer and explanation

    Correct answer: fly true

    A class is an ordinary value in JavaScript, so a function can create a class extending the Base it receives, which is the mixin pattern. Bird inherits fly through the chain and stays an instanceof itself.
