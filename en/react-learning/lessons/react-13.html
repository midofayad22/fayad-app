useState

Learn how to use useState to add State to Function Components and update the interface.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

useState is a Hook that lets a component have a State value.

useState returns two values: the current value, and a Function to update it.

When the update Function is called, React re-renders the Component to display the new value.

useState returns a State value and a State setter.

Code example

The code

import { useState } from "react";
function Counter() {
const [count, setCount] = useState(0);
return (
<button onClick={() => setCount(count + 1)}>
{count}
</button>
);
}

Understanding the code

Example: const [count, setCount] = useState(0).
Try it yourself

Change the counter's initial number or the increment value.

Test yourself

  1. What does useState provide?

    • A State value and a Function to update it
    • CSS only
    • HTML only
    • Database only
    Answer and explanation

    Correct answer: A State value and a Function to update it

  2. What does setCount represent?

    • A Function to update State
    • A CSS Selector
    • An HTML Tag
    • A Database
    Answer and explanation

    Correct answer: A Function to update State

  3. What is the initial value in useState(0)?

    • 0
    • 1
    • null
    • Always undefined
    Answer and explanation

    Correct answer: 0

  4. What is count after one click? const [count,setCount]=useState(0); onClick={() => setCount(count + 1)}

    • undefined
    • 0
    • 1
    • 2
    Answer and explanation

    Correct answer: 1

    The call triggers a re-render with the new value 1.

  5. Which is the safe way to update state from its previous value?

    • setCount(prev => prev + 1)
    • count++
    • count = count + 1
    • useState(count + 1)
    Answer and explanation

    Correct answer: setCount(prev => prev + 1)

    The function form guarantees the latest value is used.
