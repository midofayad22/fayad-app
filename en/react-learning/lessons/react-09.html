Lists & Keys

Learn how to display a collection of data using map and why React needs Keys.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

In applications, data is often in the form of an Array, such as a list of users or products.

You can use map to create a UI element for each item in an Array.

The elements produced from lists need a stable key that helps React identify each item.

map renders the list items, and key helps React identify each item.

Code example

The code

const skills = ["HTML", "CSS", "JavaScript"];
function App() {
return (
<ul>
{skills.map((skill) => (
<li key={skill}>{skill}</li>
))}
</ul>
);
}

Understanding the code

It is preferable to use a unique ID as the key rather than the index when the list can change.

    Answer and explanation

    Correct answer: Each element is missing a key

    React needs a stable key to identify each item in the list.

  5. Which key is best for a reorderable list of users?

    • The array index
    • Math.random()

    • The fixed text 'a'

    Correct answer: user.id

    A stable id stays with the item when reordered, unlike the index.
