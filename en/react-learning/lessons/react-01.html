Introduction to React

Learn about React and why it has become one of the most popular libraries for building modern user interfaces.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

React is a JavaScript library used to build user interfaces, especially interactive applications whose data changes constantly.

React is based on the idea of splitting the interface into small pieces called Components, so each component has a clear responsibility and can be reused in more than one place.

React does not replace HTML, CSS, or JavaScript; it works with them to build interfaces that are better organized and easier to maintain.

The core idea in React is building the interface with reusable Components.

Code example

The code

function App() {
return <h1>Welcome to FAYBIT</h1>;
}

Understanding the code

In React you write components that describe what you want to display, and React takes care of updating the interface when the data changes.

  3. Does React completely replace HTML, CSS, and JavaScript?

    Answer and explanation

  4. What does React typically do when data changes?

    • It deletes the browser
    • It updates the affected parts of the interface
    • It rewrites the CSS files
    • It closes the application
    Answer and explanation

    Correct answer: It updates the affected parts of the interface

    React is built for interfaces whose data changes constantly, so it updates what was affected.

  5. A team builds a large interactive dashboard. Why might it choose React?

    Correct answer: Because it splits the UI into organized reusable components

    Components organize large interactive UIs and make them easier to maintain.
