useContext

Learn how useContext lets you share data between Components without passing Props through every level.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

When several Components need the same data, passing Props through many levels can become tedious.

Context provides a way to share certain data across the Components tree.

useContext is used to read the value stored in a Context inside a Component.

Context is suited to shared data that many Components need.

Code example

The code

const ThemeContext = createContext("light");
function App() {
return (
<ThemeContext.Provider value="dark">
<Page />
</ThemeContext.Provider>
);
}

Understanding the code

Such as a Theme, user information, or global app settings.
Try it yourself

Change the value of ThemeContext from light to dark.

    • Writing CSS

    • Creating a Database

    Correct answer: Sharing data between Components

  2. What does Context provide?

    • A value that Components inside a Provider can access
    • CSS Animation

    • SQL table
    Answer and explanation

    Correct answer: A value that Components inside a Provider can access

  3. Which data is suitable for Context?

    • A Theme or global user data
    • Always just the color of a single button
    • A CSS file
    • A single image
    Answer and explanation

    Correct answer: A Theme or global user data

  4. What does a Provider supply?

    • CSS files
    • Page routes
    • An internet connection
    • The context value to all components beneath it
    Answer and explanation

    Correct answer: The context value to all components beneath it

    Components inside the Provider read its value via useContext.

  5. What does useContext(ThemeContext) return outside any Provider?

    • Always null
    • The component name
    • Always an error
    • The default value passed to createContext
    Answer and explanation

    Correct answer: The default value passed to createContext

    With no Provider the default value is used.
