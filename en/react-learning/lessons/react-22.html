React.memo

Learn how React.memo can reduce some unnecessary re-renders.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

React.memo is an API that helps reuse a component's Render result when its Props have not changed.

If the parent component re-renders and the child's Props are equal according to the comparison used, React can skip rendering the child.

React.memo is not a magic solution, and it should be used when it has a beneficial effect on performance.

React.memo can prevent some unnecessary Renders when Props do not change.

Code example

The code

const UserCard = React.memo(function UserCard({ name }) {
return <h2>{name}</h2>;
});

Understanding the code

It is especially useful when a Component is expensive to Render and receives stable Props.
