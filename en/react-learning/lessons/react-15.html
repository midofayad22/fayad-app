useRef

Learn how to use useRef to keep a value or access a DOM element without causing a Re-render.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

useRef returns an Object with a current property that can hold a value between Renders.

A common use is accessing a DOM element such as an input in order to focus it.

Changing ref.current does not cause the component to Re-render.

useRef is useful for values you need to keep without triggering a re-Render.

Code example

The code

import { useRef } from "react";
function App() {
const inputRef = useRef(null);
return <input ref={inputRef} />;
}

Understanding the code

It can also be used to store a reference to a DOM element.
