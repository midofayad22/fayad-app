JSX

Learn JSX and how it lets you write HTML-like syntax inside JavaScript when building Components.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

JSX is a syntax React uses to write the user interface in a way that is close to HTML, inside JavaScript.

JSX is not plain HTML; it is transformed during the build process into JavaScript that the environment running the application understands.

You can also embed JavaScript expressions inside JSX using curly braces.

JSX makes describing a React interface inside JavaScript clearer and easier.

Code example

The code

function App() {
return (
<div>
<h1>Welcome</h1>
<p>Learn React with FAYBIT</p>
</div>
);
}

Understanding the code

You can write elements such as h1, p, and button inside a Component, and use JavaScript expressions inside {}.

  1. What does JSX allow the developer to write?

    • HTML-like syntax inside JavaScript
    • SQL inside CSS
    • CSS inside a database
    • HTML only, without JavaScript
    Answer and explanation

    Correct answer: HTML-like syntax inside JavaScript

  2. Where do we use JavaScript expressions inside JSX?

    • Inside { }
    • Inside [ ] only
    • Inside SQL
    • Inside CSS
    Answer and explanation

    Correct answer: Inside { }

  3. Is JSX exactly the same as plain HTML?

    • No
    • Yes, always
    • It is CSS
    • It is a database
    Answer and explanation

    Correct answer: No

  4. What will this render? const n = 3; <p>{n + 2}</p>

    • 32
    • 5
    • An error
    • n + 2
    Answer and explanation

    Correct answer: 5

    Curly braces evaluate a JavaScript expression, so the result is 5.

  5. Which JSX line correctly adds a class?

    • <div klass="box">
    • <div .box>
    • <div class="box">
    • <div className="box">
    Answer and explanation

    Correct answer: <div className="box">

    JSX uses className because class is a reserved word in JavaScript.
