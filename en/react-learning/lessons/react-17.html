Custom Hooks

Learn how to create Custom Hooks to reuse React logic across multiple Components.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

A Custom Hook is a Function that usually starts with the word use and uses other Hooks inside it.

Its main goal is to extract shared logic and reuse it in more than one Component.

Custom Hooks do not share the same State between Components, but they do share the logic for handling State or Effects.

Custom Hooks help you reuse Logic instead of repeating it.

Code example

The code

function useGreeting(name) {
return `Hello ${name}`;
}

Understanding the code

For example, you can create useFetch, useToggle, or useLocalStorage.

  1. Why do we create a Custom Hook?

    • To reuse Logic
    • To replace CSS
    • To create HTML
    • To create a Database
    Answer and explanation

    Correct answer: To reuse Logic

  2. What does a Custom Hook name usually start with?

    • use
    • hook
    • react
    • custom
    Answer and explanation

    Correct answer: use

  3. Can a Custom Hook use other Hooks?

    • Yes
    • No
    • Only CSS
    • Only HTML
    Answer and explanation

    Correct answer: Yes

  4. What does this Custom Hook return? function useCounter(){ const [n,setN]=useState(0); return [n,()=>setN(n+1)]; }

    • A CSS file
    • A counter value and an incrementer
    • Nothing
    • A component
    Answer and explanation

    Correct answer: A counter value and an incrementer

    A custom hook wraps state and logic and hands them to the component.

  5. Two components call useCounter. Do they share the counter value?

    • Yes, always
    • No, each call gets its own state
    • Only on the same page
    • Only if they are siblings
    Answer and explanation

    Correct answer: No, each call gets its own state

    A hook shares logic, not the state itself.
