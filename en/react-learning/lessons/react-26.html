Reusable Components

Learn how to design flexible Components that can be used in more than one place in the app.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

A reusable component should be flexible enough to accept different data.

You can use Props and children to specify the content or behavior that changes from one use to another.

The goal is to reduce repetition while keeping the component clear.

Design a generic Component when there is truly shared behavior or UI.

Code example

The code

function Button({ children }) {
return (
<button className="button">
{children}
</button>
);
}

Understanding the code

Button is a simple example of a Component that can be used with different text or functionality.
