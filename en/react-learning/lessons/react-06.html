State

Understand the concept of State and how React uses it to store data that can change while the application is running.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

State is data inside a Component that can change over time.

When State changes, React can recompute the interface and display the new data.

One of the most popular tools for managing State inside a Component is a Hook called useState.

State represents changing data that affects the user interface.

Code example

The code

const [count, setCount] = useState(0);
return (
<button onClick={() => setCount(count + 1)}>
{count}
</button>
);

Understanding the code

For example, a clicks counter, login status, or an input value.

  1. What does State represent?

    • Data that can change over time
    • A CSS Selector
    • An HTML file
    • A database table only
    Answer and explanation

    Correct answer: Data that can change over time

  2. What usually happens when State is updated?

    • The interface is re-rendered to display the new data
    • The Component is deleted
    • The CSS is deleted
    • The application stops
    Answer and explanation

    Correct answer: The interface is re-rendered to display the new data

  3. Which Hook do you use to manage simple State?

    • useState
    • useHTML
    • useCSS
    • useDatabase
    Answer and explanation

    Correct answer: useState

  4. Which of these is suitable as state?

    • The cart item count that changes on click
    • A function name
    • A file name
    • The constant PI
    Answer and explanation

    Correct answer: The cart item count that changes on click

    State is for data that changes over time and affects what is displayed.

  5. What is wrong? const [n,setN]=useState(0); n = n + 1;

    • useState does not accept zero
    • n must be a string
    • Nothing is wrong
    • Mutating directly does not re-render; use setN
    Answer and explanation

    Correct answer: Mutating directly does not re-render; use setN

    Direct mutation does not notify React; the setter schedules a re-render.
