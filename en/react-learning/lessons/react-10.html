Forms

Learn how to work with input fields and forms in React applications.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Forms are used to collect data from the user, such as name, email, and password.

You can control field values using State, which is called Controlled Components.

You can handle form submission with onSubmit and prevent the browser's default behavior when needed.

React lets you bind form field values to State and control them.

Code example

The code

function App() {
return (
<form>
<input placeholder="Type your name" />
<button type="submit">Submit</button>
</form>
);
}

Understanding the code

This makes validating data and sending it to an API easier.

  1. What are Forms used to collect?

    • User data
    • CSS colors only
    • Images only
    • JavaScript files only
    Answer and explanation

    Correct answer: User data

  2. Which event is commonly used when submitting a Form?

    • onSubmit
    • onFormOnly
    • onSendCSS
    • submitHTML
    Answer and explanation

    Correct answer: onSubmit

  3. What does Controlled Component mean?

    • The field's value is controlled through React State
    • A CSS element
    • An HTML file
    • A database
    Answer and explanation

    Correct answer: The field's value is controlled through React State

  4. What makes an input controlled?

    • <input value={name} onChange={e => setName(e.target.value)} />
    • <input type="text">
    • <input id="name">
    • <input />
    Answer and explanation

    Correct answer: <input value={name} onChange={e => setName(e.target.value)} />

    The value comes from state and onChange updates it.

  5. Why call e.preventDefault() in onSubmit?

    • To delete the form
    • To encrypt the data
    • To speed up the network
    • To stop the default page reload on submit
    Answer and explanation

    Correct answer: To stop the default page reload on submit

    Without it the browser reloads the page and state is lost.
