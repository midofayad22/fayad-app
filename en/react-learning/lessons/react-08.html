Conditional Rendering

Learn how React displays different elements based on the value of a condition.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Conditional Rendering means displaying a different part of the interface depending on a certain state or condition.

You can use if, the ternary operator, or && to implement conditional rendering.

This idea is very important in cases such as login, loading states, and permissions.

React can change what the user sees based on the current data.

Code example

The code

function App({ isLoggedIn }) {
return (
<h1>
{isLoggedIn ? "Welcome back!" : "Please log in"}
</h1>
);
}

Understanding the code

For example, showing a Dashboard to a logged-in user and showing Login to a logged-out user.

Change the value of isLoggedIn and see the result.
