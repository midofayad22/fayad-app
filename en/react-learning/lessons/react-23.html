useMemo and useCallback

Learn the difference between useMemo and useCallback and when you can use them to improve performance.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

useMemo is used to cache the result of a computation between Renders when the dependencies have not changed.

useCallback is used to cache the same Function reference between Renders when the dependencies have not changed.

Use them only when there is a real performance-related reason, because using them unnecessarily can add complexity.

useMemo caches a computed value, while useCallback caches a Function reference.

Code example

The code

const total = useMemo(() => {
return calculateTotal(items);
}, [items]);

Understanding the code

Both are Optimization tools and are not a substitute for good app design.

    Correct answer: Only when a changes

    Correct answer: When passing a function to a memo-wrapped child

    A stable function reference prevents needless child re-renders.
