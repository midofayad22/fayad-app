API Requests

Learn how React applications communicate with APIs to get external data.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Real applications often need data from a Server or an external service.

You can use fetch or other libraries to send HTTP Requests and receive data.

Once the data arrives, it can be stored in State and displayed inside Components.

An API is the communication link between the React UI and an external data source.

Code example

The code

async function getUsers() {
const response = await fetch(
"https://example.com/users"
);
const data = await response.json();
return data;
}

Understanding the code

Typically you fetch the data, convert the Response to JSON, and then store it in State.
