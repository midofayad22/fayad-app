React + APIs

Connect React, State, Effects, and APIs to build apps that rely on real data.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Most practical apps need to fetch data from a Backend or an external API.

useEffect is often used to start the fetch, and then the result is stored in State.

You should also handle Loading, Error, and Success states so the user experience is good.

Data-driven apps need good coordination between the API, State, and UI.

Code example

The code

useEffect(() => {
fetch("/api/users")
.then((response) => response.json())
.then((data) => setUsers(data));
}, []);

Understanding the code

You can separate API logic into services to reduce the responsibilities of Components.

  3. Which Hook is commonly used to perform a Fetch when a Component loads?

    • useEffect
    • useHTML
    • useCSS
    • useDatabase
    Answer and explanation

    Correct answer: useEffect

  4. Why add [] in useEffect when fetching?

    • To change CSS
    • To fetch once when the component mounts
    • To fetch forever
    • To cancel the component
    Answer and explanation

    Correct answer: To fetch once when the component mounts

    Without it the effect runs after every render and can loop.

  5. Why can this loop forever? useEffect(() => { fetch(u).then(r=>r.json()).then(setData); });

    • No dependency array, so it runs after each render and setData causes another
    • fetch is forbidden
    • json is wrong
    • No loop
    Answer and explanation

    Correct answer: No dependency array, so it runs after each render and setData causes another

    Add [] or the proper dependencies.
