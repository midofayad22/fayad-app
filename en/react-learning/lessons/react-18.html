React Router

Learn how to use React Router to create navigation between pages and views inside a React app.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

React Router is a library used to manage Navigation inside React applications.

You can define different Routes such as /, /about, and /profile, and link each Route to a specific Component.

This allows building apps that feel multi-page from a user experience standpoint, without reloading the page on every navigation.

React Router manages Navigation and maps URLs to components.

Code example

The code

import {
BrowserRouter,
Routes,
Route
} from "react-router-dom";
<BrowserRouter>
<Routes>
<Route path="/" element={<Home />} />
<Route path="/about" element={<About />} />
</Routes>
</BrowserRouter>

Understanding the code

You can define a Route for each page in the app.
