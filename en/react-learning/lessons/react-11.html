Component Composition

Learn how to combine several Components to build larger, better-organized interfaces.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Component Composition means building a large Component from a set of smaller Components.

This approach makes each Component responsible for a specific part, and then the parts are combined to form a complete interface.

A large application can be built from a set of small, specialized Components.

Code example

The code

function Header() {
return <header>FAYBIT</header>;
}
function App() {
return (
<>
<Header />
<main>Learn React</main>
</>
);
}

Understanding the code

For example, composing a page from a Header, Sidebar, Content, and Footer.

  1. What does Component Composition mean?

    • Combining Components to build an interface
    • Deleting Components
    • Writing CSS only
    • Creating a Database
    Answer and explanation

    Correct answer: Combining Components to build an interface

  2. What is the benefit of Composition?

    • Organizing the interface into parts
    • Eliminating JavaScript
    • Eliminating Props
    • Preventing reuse
    Answer and explanation

    Correct answer: Organizing the interface into parts

  3. Which example represents Composition?

    • An App that contains a Header and Footer
    • A CSS file only
    • A Database table
    • An image only
    Answer and explanation

    Correct answer: An App that contains a Header and Footer

  4. Which is closest to composition?

    • Deleting components
    • <Page><Header /><Content /></Page>
    • Writing everything in one file
    • Copying code
    Answer and explanation

    Correct answer: <Page><Header /><Content /></Page>

    A large component is built by combining smaller ones.

  5. What does <Box>Hello</Box> render if Box returns <div>{children}</div>?

    • An empty div
    • A div containing Hello
    • An error
    • children
    Answer and explanation

    Correct answer: A div containing Hello

    Content between the tags arrives as children.
