State Management

Understand the different ways to manage State as a React app grows.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

In small apps, useState and useContext may be enough to manage most state.

As the app grows, you may need to organize State better or use a dedicated state management library.

The choice depends on the app's size, the nature of the data, and how Components share it.

Choosing the right State Management depends on the nature and size of the app.

Code example

The code

const [user, setUser] = useState(null);
function login(userData) {
setUser(userData);
}

Understanding the code

There is no single tool that suits every project.

  1. What is meant by State Management?

    • Managing app data and its changes
    • Styling CSS
    • Creating HTML only
    • Compressing images
    Answer and explanation

    Correct answer: Managing app data and its changes

  2. Does every React app need an external State Management library?

    • No
    • Yes, always
    • Only in HTML
    • Only in CSS
    Answer and explanation

    Correct answer: No

  3. What influences the choice of State management approach?

    • The app's size and the nature of the data
    • The site's color
    • Only the Component name
    • The image type
    Answer and explanation

    Correct answer: The app's size and the nature of the data

  4. Two distant components need the same state. What is the simplest solution?

    • Copy it in both
    • Use a random global variable
    • Delete one
    • Lift state to a common parent or use Context
    Answer and explanation

    Correct answer: Lift state to a common parent or use Context

    Start with simple solutions before state libraries.

  5. What does Lifting State Up mean?

    • Storing it in CSS
    • Turning it into an array
    • Moving state to a shared parent and passing it down via props
    • Deleting state
    Answer and explanation

    Correct answer: Moving state to a shared parent and passing it down via props

    The parent owns the state and shares it with its children.
