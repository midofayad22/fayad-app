Events

Learn how React handles user interaction such as clicking, typing, and submitting forms.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Events allow the application to respond to user actions.

In React, you use props such as onClick, onChange, and onSubmit to handle events.

We usually pass a function to an event handler so that it runs when the event occurs.

Events connect a user action to the behavior you want to run in the application.

Code example

The code

function App() {
function handleClick() {
console.log("The button was clicked");
}
return <button onClick={handleClick}>Click here</button>;
}

Understanding the code

When a button is clicked, a function can run, and when typing in an input, State can be updated.

  1. Which event is commonly used when clicking a button?

    • onClick
    • onButton
    • buttonEvent
    • clickOnly
    Answer and explanation

    Correct answer: onClick

  2. What do we usually pass to onClick?

    • Function
    • CSS file
    • Database
    • HTML document
    Answer and explanation

    Correct answer: Function

  3. What is the purpose of Events?

    • Handling user interaction
    • Creating databases
    • Writing CSS
    • Removing Components
    Answer and explanation

    Correct answer: Handling user interaction

  4. Which click handler is written correctly?

    • <button click={handle}>
    • <button onClick={handle()}>
    • <button onClick={handle}>
    • <button onclick=handle>
    Answer and explanation

    Correct answer: <button onClick={handle}>

    Pass the function itself without calling it, otherwise it runs during render.

  5. What does e.target.value return in an input's onChange?

    • The current text in the field
    • The page name
    • The field color
    • Nothing
    Answer and explanation

    Correct answer: The current text in the field

    The event carries the element that fired it, and its value is what the user typed.
