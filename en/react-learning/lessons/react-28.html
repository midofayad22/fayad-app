Best Practices

Learn a set of practices that help you write clear, maintainable React code.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Clean Code is very important when the project grows and more than one person works on it.

Good practices include using clear names, keeping Components relatively small, and reducing repetition.

You should also separate responsibilities and avoid putting all of the app's logic in one huge Component.

Good code is not just code that works, but code that can be easily understood and developed.

Code example

The code

function UserCard({ user }) {
return (
<article>
<h2>{user.name}</h2>
<p>{user.email}</p>
</article>
);
}

Understanding the code

Use clear names and keep each Component focused on a specific responsibility as much as possible.
