Performance Optimization

Learn the basic principles of improving React app performance and reducing unnecessary work.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Performance optimization means reducing the unnecessary work the app does.

It is important first to understand why re-renders happen, and then identify the part that needs improvement.

Tools such as React.memo, useMemo, and useCallback may help in certain cases, but they are not needed for every Component.

Performance optimization starts with understanding the problem, not with randomly adding Optimization tools.

Code example

The code

function ProductList({ products }) {
return products.map((product) => (
<Product
key={product.id}
product={product}
/>
));
}

Understanding the code

Observe Render operations and heavy computations before choosing an optimization approach.
