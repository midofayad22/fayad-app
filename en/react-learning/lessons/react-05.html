Props

Learn how Props let you pass data from one Component to another.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Props are the data that one Component passes to another Component.

Props are often used to make a component reusable, because the same component can receive different data each time.

Props are read-only inside the component and should not be modified directly.

Props are a fundamental way to pass data to Components.

Code example

The code

function Welcome({ name }) {
return <h1>Hello {name}</h1>;
}
function App() {
return <Welcome name="FAYBIT" />;
}

Understanding the code

You can send a name, title, image, or any other value to a Component.
Try it yourself

Change the value of name and try passing a different name to Welcome.

  1. What is the primary use of Props?

    • Passing data to Components
    • Creating CSS files
    • Creating databases
    • Running the server
    Answer and explanation

    Correct answer: Passing data to Components

  2. Where do Props usually come from?

    • From the parent Component
    • From CSS
    • From HTML only
    • Always directly from the database
    Answer and explanation

    Correct answer: From the parent Component

  3. Should Props be modified directly inside a Component?

    • No
    • Yes, always
    • Yes, using CSS
    • Only inside HTML
    Answer and explanation

    Correct answer: No

  4. What is the output? function Hi({name}){ return <p>Hi {name}</p>; } ... <Hi name="Sara" />

    • An error
    • Hi name
    • Hi Sara
    • Hi
    Answer and explanation

    Correct answer: Hi Sara

    The value passed as name arrives as a prop and is rendered in the JSX.

  5. What is wrong here? function A(props){ props.title = 'x'; return <h1>{props.title}</h1>; }

    • Nothing is wrong
    • Props are read-only and must not be mutated
    • h1 is not allowed
    • var must be used
    Answer and explanation

    Correct answer: Props are read-only and must not be mutated

    To change a value use state or pass a new value from the parent.
