useEffect

Learn how to use useEffect to handle Side Effects such as fetching data and subscriptions.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

useEffect is used to run Side Effects tied to rendering a Component or to changes in certain data.

Common uses include fetching data from an API, handling subscriptions, or updating the page title.

The Dependency Array determines when the Effect runs again.

useEffect is suited to operations that happen outside the direct computation of the interface.

Code example

The code

import { useEffect } from "react";
useEffect(() => {
console.log("Effect ran");
}, []);

Understanding the code

An Effect can run once after Mount using an empty dependency array, or whenever specific values change.
