Introduction to Hooks

Understand the concept of React Hooks and why they have become essential for writing modern components.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Hooks are Functions that give components the ability to use React features such as State and Effects.

Some of the most popular Hooks are useState, useEffect, useRef, and useContext.

Hooks allow you to write reusable logic without needing Class Components in the modern style.

Hooks provide React's core features inside Function Components.

Code example

The code

import { useState } from "react";
function App() {
const [name, setName] = useState("FAYBIT");
return <h1>{name}</h1>;
}

Understanding the code

Each Hook has a specific purpose, and you must follow the rules for using them.

  3. Why are Hooks used?

    • To use and reorganize React logic
    • To write CSS only
    • To create databases
    • To eliminate Components
    Answer and explanation

    Correct answer: To use and reorganize React logic

  4. Where must a Hook like useState be called?

    • At the top level of the component
    • After return
    • Outside any function
    • Inside a loop or condition
    Answer and explanation

    Correct answer: At the top level of the component

    Hooks are called at the top level in the same order on every render.

  5. What is wrong? if (open) { const [n,setN] = useState(0); }

    • Zero is not allowed
    • open is a bad name
    • Nothing
    • A Hook inside a condition breaks the rules of Hooks
    Answer and explanation

    Correct answer: A Hook inside a condition breaks the rules of Hooks

    A Hook must run on every render so the order stays stable.
