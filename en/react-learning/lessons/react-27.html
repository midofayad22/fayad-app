Project Structure

Learn how to organize the files and folders of a React project in a way that helps it scale.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Project Structure shows how the project's files are arranged.

You can separate assets, components, pages, hooks, and services according to the project's needs.

The goal is not to create many folders, but to reach a clear organization that makes files easy to find.

File organization should serve the project's clarity, not add complexity.

Code example

The code

src/
├── components/
├── pages/
├── assets/
├── hooks/
├── services/
└── main.jsx

Understanding the code

Choose a clear structure that fits the app's size and how your team works.

Test yourself

  1. What does Project Structure describe?

    • The organization of the project's files and folders
    • Only the site's colors
    • Only the database
    • Internet speed
    Answer and explanation

    Correct answer: The organization of the project's files and folders

  2. Where can images and assets be placed?

    • assets/
    • database/
    • hooks-only/
    • sql/
    Answer and explanation

    Correct answer: assets/

  3. What is the goal of organizing the project?

    • Making files easy to find and the project easy to maintain
    • Increasing the project size
    • Cancelling Components
    • Preventing reuse
    Answer and explanation

    Correct answer: Making files easy to find and the project easy to maintain

  4. Where would a full-page component like Home go?

    • Outside the project
    • The pages folder
    • The assets folder
    • Only styles
    Answer and explanation

    Correct answer: The pages folder

    Pages are grouped in their own folder.

  5. What is wrong with one folder holding hundreds of files?

    • Files become hard to find
    • React stops working
    • The site gets faster
    • Nothing
    Answer and explanation

    Correct answer: Files become hard to find

    Clear organization eases navigation and maintenance.
