Loading and Error States

Learn how to show an appropriate UI while data is loading or when an error occurs.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

When fetching data from an API, the app may need some time before the result arrives.

So it is best to show a Loading state so the user knows the operation is still in progress.

If the request fails, you should show an appropriate Error state instead of leaving the user with no information.

Loading and Error states are an essential part of a good user experience.

Code example

The code

if (loading) {
return <p>Loading...</p>;
}
if (error) {
return <p>An error occurred.</p>;
}

Understanding the code

A professional app doesn't just display data; it also handles waiting and failure states.
