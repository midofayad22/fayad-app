React Architecture

Learn the basic principles of organizing a React project into clear, maintainable layers and components.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Architecture describes the way the parts of an app are divided and organized.

You can separate Components, Pages, Hooks, Services, and more into clear folders according to the project's needs.

Good organization reduces coupling and helps the team understand and develop the project easily.

Good architecture makes a project easier to understand, develop, and maintain.

Code example

The code

src/
├── components/
├── pages/
├── hooks/
├── services/
└── App.jsx

Understanding the code

There is no single mandatory folder structure for all React projects; you choose the structure that suits the project.

  1. Why is Architecture important?

    • It makes the project easier to maintain
    • It deletes JavaScript
    • It replaces React
    • It prevents using Components
    Answer and explanation

    Correct answer: It makes the project easier to maintain

  2. Where can shared Components be placed?

    • components/
    • database/
    • css-only/
    • sql/
    Answer and explanation

    Correct answer: components/

  3. Is there a single mandatory folder structure for all React projects?

    • No
    • Yes, always
    • Yes, only on Vercel
    • Yes, only on Windows
    Answer and explanation

    Correct answer: No

  4. Where is API-calling logic best placed?

    • In the images folder
    • In a service file or custom hook
    • Inside every button
    • In CSS
    Answer and explanation

    Correct answer: In a service file or custom hook

    Separating responsibilities reduces coupling.

  5. What does reducing coupling mean?

    • Making parts depend less on each other
    • Merging all files
    • Copying code
    • Deleting tests
    Answer and explanation

    Correct answer: Making parts depend less on each other

    Independent parts are easier to change.
