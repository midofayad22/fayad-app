Components

Learn the concept of Components and how React uses them to split the interface into independent, reusable parts.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

A Component is an independent piece of the user interface that can contain HTML-like JSX, data, and behavior.

A component can be very simple, like a Button, or large, like a Dashboard that contains several other components.

This approach makes building applications better organized than putting everything in a single file.

A Component is a fundamental building block in React that represents a part of the user interface.

Code example

The code

function Welcome() {
return <h1>Welcome to FAYBIT</h1>;
}

Understanding the code

You can compose multiple Components together to build a complete page.

  1. What is a React Component?

    • A reusable part of the interface
    • A database table
    • A CSS property
    • A SQL file
    Answer and explanation

    Correct answer: A reusable part of the interface

  2. Can a Component contain other Components?

    • Yes
    • No
    • Only in CSS
    • Only in HTML
    Answer and explanation

    Correct answer: Yes

  3. What is the purpose of splitting the interface into Components?

    • Organizing and reusing code
    • Eliminating JavaScript
    • Eliminating HTML
    • Preventing interaction
    Answer and explanation

    Correct answer: Organizing and reusing code

  4. Which of these is a valid React component?

    • return Card;
    • const x = 5;
    • function Card() { return <div>Hi</div>; }
    • Card = <div>
    Answer and explanation

    Correct answer: function Card() { return <div>Hi</div>; }

    A component is a function that returns JSX, and its name should start with a capital letter.

  5. What is wrong here? function card(){ return <p>Hi</p>; } used as <card />

    • Nothing is wrong
    • React treats card as a plain HTML tag because it starts lowercase
    • You cannot return p
    • The function must return nothing
    Answer and explanation

    Correct answer: React treats card as a plain HTML tag because it starts lowercase

    Component names must start with a capital letter, otherwise React treats them as HTML elements.
