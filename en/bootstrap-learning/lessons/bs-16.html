Modal and Offcanvas

Dialog windows and side panels with data attributes and a JavaScript API.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Modal

A button with data-bs-toggle="modal" data-bs-target="#id" opens the .modal element, which contains .modal-dialog > .modal-content with .modal-header, .modal-body, and .modal-footer. Bootstrap handles focus trapping and closing with Escape.

Offcanvas

A panel that slides in from the side: .offcanvas.offcanvas-start|end|top|bottom, opened the same way with data-bs-toggle="offcanvas".

JavaScript API

const m = new bootstrap.Modal(el); m.show(); m.hide(); and it fires events such as shown.bs.modal and hidden.bs.modal.

Use aria-labelledby for the dialog, and let Bootstrap manage focus.

Code example

HTML code

<div class="container py-3">
<button class="btn btn-primary" data-bs-toggle="modal" data-bs-target="#demoModal">Open modal</button>
<button class="btn btn-outline-secondary" data-bs-toggle="offcanvas" data-bs-target="#side">Side panel</button>
<div class="modal fade" id="demoModal" tabindex="-1" aria-labelledby="demoTitle" aria-hidden="true">
<div class="modal-dialog modal-dialog-centered">
<div class="modal-content">
<div class="modal-header"><h2 class="modal-title fs-5" id="demoTitle">Confirm</h2><button type="button" class="btn-close" data-bs-dismiss="modal" aria-label="Close"></button></div>
<div class="modal-body">Do you want to continue?</div>
<div class="modal-footer"><button class="btn btn-secondary" data-bs-dismiss="modal">Cancel</button><button class="btn btn-primary">Yes</button></div>
</div>
</div>
</div>
<div class="offcanvas offcanvas-end" tabindex="-1" id="side" aria-labelledby="sideTitle">
<div class="offcanvas-header"><h2 class="offcanvas-title fs-5" id="sideTitle">Menu</h2><button type="button" class="btn-close" data-bs-dismiss="offcanvas" aria-label="Close"></button></div>
<div class="offcanvas-body">Side panel content.</div>
</div>
</div>

Understanding the code

Try both buttons. The modal has a dimmed backdrop and closes with Escape. The side panel slides in from the end (offcanvas-end).

Test yourself

  1. Which two attributes open a Modal from a button?

    • data-bs-toggle="modal" and data-bs-target
    • href and onclick
    • data-open and data-id
    • role and tabindex
    Answer and explanation

    Correct answer: data-bs-toggle="modal" and data-bs-target

  2. How do you open a Modal programmatically?

    • new bootstrap.Modal(el).show()
    • el.openModal()
    • bootstrap.show(el)
    • modal(el)
    Answer and explanation

    Correct answer: new bootstrap.Modal(el).show()

  3. Which class makes the panel slide in from the right in LTR?

    • offcanvas-end
    • offcanvas-right
    • offcanvas-slide
    • offcanvas-open
    Answer and explanation

    Correct answer: offcanvas-end

  4. Which element contains modal-header, modal-body and modal-footer?

    • modal-backdrop
    • modal-trigger
    • modal-content
    • modal-root
    Answer and explanation

    Correct answer: modal-content

    The order is modal, then modal-dialog, then modal-content, then the parts.

  5. Which event fires after the Modal is fully shown?

    • shown.bs.modal
    • hidden.bs.modal
    • open.bs.modal
    • load.bs.modal
    Answer and explanation

    Correct answer: shown.bs.modal

    shown fires after the animation ends, while hidden fires after closing.
