Containers and Breakpoints

container, container-fluid, and the breakpoints on which all responsive classes are built.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Containers

.container has a fixed width that changes at each breakpoint, .container-fluid is always 100% wide, and .container-md and its siblings are 100% wide until the specified breakpoint and then become fixed.

Breakpoints

The breakpoints (mobile-first): sm ≥576px, md ≥768px, lg ≥992px, xl ≥1200px, xxl ≥1400px. A class without a breakpoint (such as col-6) applies from the smallest screens, and a class with a breakpoint (col-md-6) applies from that breakpoint upward.

Bootstrap is mobile-first: a class without a breakpoint always applies, and responsive classes apply from the breakpoint and above.

Code example

HTML code

<div class="container bg-light border py-2 mb-3">.container</div>
<div class="container-fluid bg-light border py-2 mb-3">.container-fluid</div>
<div class="container-md bg-light border py-2">.container-md</div>

Understanding the code

Change the preview width or open the page on different screens: the first container changes its width at the breakpoints, the second fills the full width, and the third fills the full width until 768px.

Test yourself

  1. At what width does the md breakpoint start?

    • 768px
    • 576px
    • 992px
    • 1200px
    Answer and explanation

    Correct answer: 768px

  2. What is the difference between container and container-fluid?

    • The first has a fixed width per breakpoint, and the second is always 100%
    • No difference
    • The second is for mobile only
    • The first is for print
    Answer and explanation

    Correct answer: The first has a fixed width per breakpoint, and the second is always 100%

  3. What does mobile-first mean?

    • Base styles target small screens and are extended with breakpoints for larger ones
    • Designing for desktop first
    • Removing small screens
    • It doesn't support mobile
    Answer and explanation

    Correct answer: Base styles target small screens and are extended with breakpoints for larger ones

  4. You want a container that is 100% wide on phones and becomes fixed-width from lg. Which class do you use?

    • container-fluid
    • container-lg
    • container-sm
    • container-xxl-fluid
    Answer and explanation

    Correct answer: container-lg

    container-lg stays 100% wide until the lg breakpoint and then becomes fixed.

  5. The screen is 700px wide. Which statement is correct?

    • col-md-6 applies and col-6 does not
    • Both apply together
    • Neither applies
    • col-6 applies and col-md-6 does not
    Answer and explanation

    Correct answer: col-6 applies and col-md-6 does not

    A class with no breakpoint always applies, while md starts at 768px and above.
