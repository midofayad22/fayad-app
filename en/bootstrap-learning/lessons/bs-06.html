Spacing and Sizing

margin, padding, gap, and logical width and height classes (RTL-aware).

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Spacing syntax

{property}{sides}-{size} where property is m (margin) or p (padding), sides is t b s (start) e (end) x y or empty for all, and size is from 0 to 5 or auto. Values: 1=0.25rem, 2=0.5rem, 3=1rem, 4=1.5rem, 5=3rem.

start and end

Use ms-* and me-* (instead of left/right) so they flip automatically in Arabic RTL interfaces.

Sizing

w-25 w-50 w-75 w-100 w-auto and h-* with the same idea, plus mw-100, vh-100, and min-vh-100.

Use ms/me instead of ml/mr so designs work in both directions.

Code example

HTML code

<div class="container">
<div class="bg-light border p-3 mb-3">p-3 (1rem on every side)</div>
<div class="bg-light border px-5 py-1 mb-3">px-5 py-1</div>
<div class="bg-light border ms-5 mb-3">ms-5: margin at the start</div>
<div class="bg-light border mx-auto w-50 text-center">mx-auto w-50: centered</div>
</div>

Understanding the code

The letter x is for horizontal and y for vertical. mx-auto with a set width centers the element. The value 5 equals 3rem.

Edit and try

Give the last element a width of <code>w-75</code> and a bottom margin of <code>mb-5</code>.

Test yourself

  1. What does the mt-4 class mean?

    • A top margin of 1.5rem
    • A bottom margin of 4px
    • A top padding of 4rem
    • A width of 4
    Answer and explanation

    Correct answer: A top margin of 1.5rem

  2. Why do we prefer ms-3 over ml-3?

    • Because it flips automatically in RTL
    • Because it is shorter
    • Because ml doesn't exist in any version
    • No difference and no reason
    Answer and explanation

    Correct answer: Because it flips automatically in RTL

  3. Which class makes the width half of the container?

    • w-50
    • col-50
    • half
    • mw-50
    Answer and explanation

    Correct answer: w-50

  4. What margin does the class mb-5 give?

    • A bottom margin of 3rem
    • A bottom margin of 0.5rem
    • A bottom padding of 3rem
    • A top margin of 3rem
    Answer and explanation

    Correct answer: A bottom margin of 3rem

    m is margin, b is bottom and size 5 equals 3rem.

  5. Which class horizontally centers an element with a set width inside its parent?

    • my-auto
    • px-auto
    • ms-100
    • mx-auto
    Answer and explanation

    Correct answer: mx-auto

    mx-auto makes both horizontal margins automatic so the element is centered.
