Cards

The most widely used content component: image, title, text, buttons, and layouts.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Structure

.card and then .card-body, inside which are .card-title, .card-text, and the buttons. Optionally: .card-header, .card-footer, and .card-img-top. A card takes the parent's width by default, so it needs a grid or style="width".

Equal-height cards

Put the cards inside .row.row-cols-1.row-cols-md-3.g-4 and add h-100 to the card so the heights are equal.

Put cards in a row-cols grid with h-100 for a responsive, equal-height layout.

Code example

HTML code

<div class="container py-3">
<div class="row row-cols-1 row-cols-md-3 g-3">
<div class="col">
<div class="card h-100">
<div class="card-header">HTML</div>
<div class="card-body">
<h5 class="card-title">Web Basics</h5>
<p class="card-text">Learn page structure step by step.</p>
</div>
<div class="card-footer"><a href="#" class="btn btn-primary btn-sm">Start</a></div>
</div>
</div>
<div class="col"><div class="card h-100"><div class="card-body"><h5 class="card-title">CSS</h5><p class="card-text">Styling and responsive design.</p></div></div></div>
<div class="col"><div class="card h-100 text-bg-dark"><div class="card-body"><h5 class="card-title">JavaScript</h5><p class="card-text">Interaction and logic.</p></div></div></div>
</div>
</div>

Understanding the code

Three cards of the same height thanks to h-100. The text-bg-dark class sets the background and text color together with proper contrast.

Test yourself

  1. What is the main container for a card's content?

    • card-body
    • card-content
    • card-main
    • card-inner
    Answer and explanation

    Correct answer: card-body

  2. How do we make the cards in a row the same height?

    • h-100 on each card inside the grid
    • width:100%
    • d-none
    • position-absolute
    Answer and explanation

    Correct answer: h-100 on each card inside the grid

  3. What is text-bg-dark for?

    • It sets the background and text together with suitable contrast
    • It hides the text
    • It changes the font
    • It adds a shadow
    Answer and explanation

    Correct answer: It sets the background and text together with suitable contrast

  4. Which class places an image at the top of a card?

    • card-top-image
    • card-img-top
    • card-body-img
    • img-card
    Answer and explanation

    Correct answer: card-img-top

    card-img-top is made for a top image and stretches to the card width.

  5. A card stretches awkwardly across the whole page. What is the fix?

    • Put it inside a grid column or set its width
    • Add card-narrow
    • Remove card-body
    • Use h-100 only
    Answer and explanation

    Correct answer: Put it inside a grid column or set its width

    A card takes its parent's width by default, so control it with the grid.
