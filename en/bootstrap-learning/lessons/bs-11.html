Navbar and Nav

A responsive navigation bar that collapses into a dropdown menu on mobile, along with tabs.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Navbar

.navbar with .navbar-expand-lg appears expanded from lg and collapsed below it. The components: .navbar-brand, .navbar-toggler, .collapse.navbar-collapse, .navbar-nav, and .nav-link. The button controls it through data-bs-toggle="collapse" and data-bs-target.

Accessibility

Add aria-controls, aria-expanded, and aria-label to the menu button, and aria-current="page" to the current link.

navbar-expand-{bp} sets the breakpoint at which the menu expands, and the button opens it with data-bs-toggle.

Code example

HTML code

<nav class="navbar navbar-expand-md bg-body-tertiary border-bottom">
<div class="container-fluid">
<a class="navbar-brand fw-bold" href="#">FAYBIT</a>
<button class="navbar-toggler" type="button" data-bs-toggle="collapse" data-bs-target="#nav" aria-controls="nav" aria-expanded="false" aria-label="Open menu">
<span class="navbar-toggler-icon"></span>
</button>
<div class="collapse navbar-collapse" id="nav">
<ul class="navbar-nav me-auto mb-2 mb-md-0">
<li class="nav-item"><a class="nav-link active" aria-current="page" href="#">Home</a></li>
<li class="nav-item"><a class="nav-link" href="#">Courses</a></li>
<li class="nav-item"><a class="nav-link disabled" aria-disabled="true">Coming soon</a></li>
</ul>
<a class="btn btn-primary" href="#">Log in</a>
</div>
</div>
</nav>

Understanding the code

Shrink the preview width (below 768px) to show the menu icon. me-auto pushes the links to the start and the button to the end.

Add a fourth link named "About Us" to the menu.

Test yourself

  1. Which class determines when the menu expands horizontally?

    • navbar-expand-md
    • navbar-open
    • navbar-fixed
    • navbar-md-only
    Answer and explanation

    Correct answer: navbar-expand-md

  2. Which attribute links the button to the element it opens?

    • data-bs-target
    • href only
    • id only
    • for
    Answer and explanation

    Correct answer: data-bs-target

  3. What is aria-current="page" for?

    • Informing assistive technologies of the current page
    • Coloring the link
    • Disabling the link
    • Opening the link in a new window
    Answer and explanation

    Correct answer: Informing assistive technologies of the current page

  4. The screen is 800px and the navbar has navbar-expand-lg. How does the menu appear?

    • Collapsed behind the toggler button
    • Expanded horizontally
    • Hidden permanently
    • Shown as a Modal
    Answer and explanation

    Correct answer: Collapsed behind the toggler button

    lg starts at 992px, and below it the menu stays collapsed.

  5. Which element wraps the links so they fold and open with the toggler?

    • navbar-brand
    • nav-link-wrap
    • collapse navbar-collapse
    • navbar-expand
    Answer and explanation

    Correct answer: collapse navbar-collapse

    The collapse navbar-collapse wrapper is what data-bs-target points to.
