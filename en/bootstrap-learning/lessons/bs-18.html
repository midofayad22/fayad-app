Tooltips, Popovers, and Toasts

The components that need JavaScript initialization, and how to enable them.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Why do they need initialization?

Tooltips and Popovers don't work automatically for performance reasons, so they must be created: new bootstrap.Tooltip(el) (or for all elements with data-bs-toggle="tooltip"). The same goes for Toast: new bootstrap.Toast(el).show().

Accessibility

A Tooltip isn't easily shown to touch users, and essential information must not be placed only in it. Use it as a helper, not as the main content.

Enable Tooltips/Popovers/Toasts manually, and don't put critical information in them.

Code example

HTML code

<div class="container py-4">
<button id="tipBtn" class="btn btn-secondary" data-bs-toggle="tooltip" data-bs-title="Help text">Hover here</button>
<button id="toastBtn" class="btn btn-primary">Show Toast</button>
<div class="toast-container position-fixed bottom-0 end-0 p-3">
<div id="liveToast" class="toast" role="status" aria-live="polite" aria-atomic="true">
<div class="toast-header"><strong class="me-auto">FAYBIT</strong><small>Now</small><button type="button" class="btn-close" data-bs-dismiss="toast" aria-label="Close"></button></div>
<div class="toast-body">Progress saved.</div>
</div>
</div>
</div>
<script>
new bootstrap.Tooltip(document.getElementById('tipBtn'));
document.getElementById('toastBtn').addEventListener('click', () => {
bootstrap.Toast.getOrCreateInstance(document.getElementById('liveToast')).show();
});
</script>

Understanding the code

The Tooltip is created programmatically because Bootstrap doesn't enable it automatically. getOrCreateInstance creates the instance if it doesn't exist or returns the existing one.

  2. Which function shows a Toast?

    • bootstrap.Toast(el).show()
    • toast.open()
    • el.showToast()
    • alert(el)
    Answer and explanation

    Correct answer: bootstrap.Toast(el).show()

  3. What is the main caveat about using a Tooltip?

    • Don't put essential information in it because it is hard to reach on touch devices
    • It slows down the network
    • It cancels the form
    • It needs a license
    Answer and explanation

    Correct answer: Don't put essential information in it because it is hard to reach on touch devices

  4. How do you enable all Tooltips on the page?

    • Select elements with data-bs-toggle="tooltip" and create new bootstrap.Tooltip for each
    • Just add the tooltip class
    • Nothing is needed
    • Call bootstrap.Modal
    Answer and explanation

    Correct answer: Select elements with data-bs-toggle="tooltip" and create new bootstrap.Tooltip for each

    The attribute alone is not enough; a Tooltip object must be created per element.

  5. Putting the password rules only inside a Tooltip. What is the problem?

    • The Tooltip slows the server
    • Tooltips do not support text
    • Touch users may not be able to reach it
    • It blocks form submission
    Answer and explanation

    Correct answer: Touch users may not be able to reach it

    A Tooltip is only a helper; essential info must appear in the page itself.
