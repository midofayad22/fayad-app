The Grid System

12 columns, rows and columns, and changing the layout by screen size.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

The idea

A .row inside a container divides the width into 12 parts. A column .col-N occupies N parts. If you don't specify a number (.col), the columns share the width equally.

Responsive columns

Combine classes for several breakpoints: col-12 col-md-6 col-lg-4 = a full-width column on mobile, half on tablets, and a third on large screens. If the columns' total exceeds 12, the excess wraps to a new line.

A row contains only columns, and the columns in a single line add up to 12.

Code example

HTML code

<div class="container text-center">
<div class="row g-2">
<div class="col-12 col-md-6 col-lg-4"><div class="p-3 bg-primary-subtle border">1</div></div>
<div class="col-12 col-md-6 col-lg-4"><div class="p-3 bg-primary-subtle border">2</div></div>
<div class="col-12 col-md-12 col-lg-4"><div class="p-3 bg-primary-subtle border">3</div></div>
</div>
</div>

Understanding the code

On mobile each column takes its own line. From md, columns 1 and 2 sit side by side and the third takes a full line. From lg, all three columns are on one line. g-2 sets the spacing between columns.

Try it yourself

Edit and try

Make the row contain four equal columns on large screens using <code>col-lg-3</code>.

Test yourself

  1. How many columns are in the Bootstrap grid?

    • 12
    • 10
    • 16
    • 24
    Answer and explanation

    Correct answer: 12

  2. What does col-12 col-md-6 mean?

    • A full-width column on mobile and half width from md upward
    • Half width always
    • Hidden on mobile
    • Two columns together
    Answer and explanation

    Correct answer: A full-width column on mobile and half width from md upward

  3. What happens if the columns in a row add up to more than 12?

    • The excess wraps to a new line
    • An error occurs
    • The columns are deleted
    • They overlap
    Answer and explanation

    Correct answer: The excess wraps to a new line

  4. You want three equal columns per line on large screens. Which class goes on each column?

    • col-lg-3
    • col-lg-6
    • col-lg-4
    • col-4-lg
    Answer and explanation

    Correct answer: col-lg-4

    12 divided by 3 gives 4 parts per column, so use col-lg-4.

  5. What happens to columns that just use col with no number?

    • They share the row width equally
    • Each takes two columns
    • They become hidden
    • They get a fixed 100px width
    Answer and explanation

    Correct answer: They share the row width equally

    A bare col divides the available space equally among the columns.
