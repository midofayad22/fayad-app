Buttons and Button Groups

Button styles, sizes, states, and groups.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Styles

btn + btn-primary|secondary|success|danger|warning|info|light|dark|link. The outline version: btn-outline-*. Sizes: btn-lg and btn-sm. Disabling: disabled (and for links aria-disabled="true"). A full-width button: w-100 or inside d-grid.

Groups

.btn-group combines buttons into a single bar, and it is best to add role="group" and aria-label for accessibility.

Use button for actions and a for navigation, and add aria-label to button groups.

Code example

HTML code

<div class="container py-3 d-grid gap-3">
<div>
<button class="btn btn-primary">Primary</button>
<button class="btn btn-outline-danger">Delete</button>
<button class="btn btn-secondary btn-sm">Small</button>
<button class="btn btn-success btn-lg" disabled>Disabled</button>
</div>
<div class="btn-group" role="group" aria-label="Formatting group">
<button type="button" class="btn btn-outline-dark">Bold</button>
<button type="button" class="btn btn-outline-dark">Italic</button>
<button type="button" class="btn btn-outline-dark">Underline</button>
</div>
<a class="btn btn-link" href="#">Link that looks like a button</a>
</div>

Understanding the code

The first row shows the different styles, and the group merges the borders between buttons. The d-grid class on the container makes its children full width.

Try it yourself

Edit and try

Add a <code>btn-warning btn-lg</code> button with the text "Warning".

Test yourself

  1. How do we make a button with only a border?

    • btn-outline-primary
    • btn-border
    • btn-ghost
    • btn-line
    Answer and explanation

    Correct answer: btn-outline-primary

  2. What is role=group with aria-label in btn-group for?

    • Telling a screen reader that the buttons are one described group
    • Coloring the buttons
    • Speeding up the page
    • Disabling the buttons
    Answer and explanation

    Correct answer: Telling a screen reader that the buttons are one described group

  3. Which class makes a button larger?

    • btn-lg
    • btn-xl
    • btn-big
    • btn-large
    Answer and explanation

    Correct answer: btn-lg

  4. How do you correctly disable a link styled as a btn?

    • Add the disabled class with aria-disabled="true"
    • Only write the disabled attribute on a
    • Add btn-off
    • Just remove href
    Answer and explanation

    Correct answer: Add the disabled class with aria-disabled="true"

    Links do not support the disabled attribute, so use the class plus aria-disabled for screen readers.

  5. Which class makes a button as wide as its container?

    • btn-wide
    • btn-block-100
    • d-inline
    • w-100
    Answer and explanation

    Correct answer: w-100

    w-100 gives 100% width; the alternative is placing the button inside d-grid.
