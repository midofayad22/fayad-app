Introduction: What Is Bootstrap and How Do We Start

A ready-made CSS/JS framework for quickly building responsive interfaces, starting with the first page and the correct setup steps.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

What is Bootstrap?

Bootstrap is an open-source library that provides a ready-made CSS file (buttons, grid, forms, components) and a JavaScript file for interactive components. You write classes on HTML elements instead of writing CSS from scratch. This course is based on version 5.3 (installed locally in the preview: 5.3.8).

Basic setup

Any Bootstrap page needs: <!doctype html>, <meta name="viewport" content="width=device-width, initial-scale=1"> (the basis of responsiveness), a link to the CSS file, and then the bootstrap.bundle.min.js file at the end of the page if you use interactive components. The preview here adds these files for you automatically.

Write classes on elements, and don't forget the viewport tag, or the design won't respond on mobile.

Code example

HTML code

<div class="container py-4">
<h1 class="display-6">Hello Bootstrap</h1>
<p class="lead">This is my first page without writing any CSS.</p>
<button type="button" class="btn btn-primary">Primary button</button>
</div>

Understanding the code

container centers the content and sets its width, py-4 adds vertical padding, display-6 and lead are text classes, and btn btn-primary turns the element into a colored button.

Edit and try

Change the button color to <code>btn-success</code> and add a second button with the class <code>btn-outline-secondary</code>.

Test yourself

  1. Which tag is required for responsive design to work on mobile?

    • meta viewport
    • meta charset only
    • link rel=icon
    • script defer
    Answer and explanation

    Correct answer: meta viewport

  2. How do we use Bootstrap at its core?

    • By adding ready-made classes to HTML elements
    • By always writing Sass by hand
    • By converting HTML to PDF
    • By installing a program on the computer
    Answer and explanation

    Correct answer: By adding ready-made classes to HTML elements

  3. Which file is required for interactive components such as Modal and Dropdown?

    • bootstrap.bundle.min.js
    • bootstrap.min.css only
    • favicon.ico
    • robots.txt
    Answer and explanation

    Correct answer: bootstrap.bundle.min.js

  4. Where is bootstrap.bundle.min.js usually placed in the page?

    • At the end of the page, before closing body
    • Inside the title tag
    • Before the doctype
    • Inside the CSS file
    Answer and explanation

    Correct answer: At the end of the page, before closing body

    It goes at the end so it runs after the elements it controls have loaded.

  5. Which markup turns an element into a ready-made blue button?

    • <button class="button blue">
    • <button class="primary">
    • <button class="btn btn-primary">
    • <button style="btn-primary">
    Answer and explanation

    Correct answer: <button class="btn btn-primary">

    A button needs the base class btn plus the color class btn-primary.
