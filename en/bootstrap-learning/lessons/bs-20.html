Project: A Responsive Landing Page

Combine what you've learned in a full page: navbar, hero section, cards, form, and footer.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Project plan

  1. A navbar-expand-md navbar.
  2. A hero section with a heading and a call-to-action button.
  3. A row-cols-1 row-cols-md-3 card grid.
  4. A simple subscription form with validation.
  5. A footer with a bg-body-tertiary background.

Tips

  • Start with mobile, then expand with breakpoints.
  • Use container once per section.
  • Test dark mode and RTL direction.

Start from mobile, build each section with a container and a grid, then test both modes and both directions.

Test yourself

  1. Where do you start when designing a responsive page with Bootstrap?

    • From the mobile design, then expanding with breakpoints
    • From the large screen only
    • From print
    • From the JavaScript file
    Answer and explanation

    Correct answer: From the mobile design, then expanding with breakpoints

  2. Which class gives a secondary background for the footer that adapts to dark mode?

    • bg-body-tertiary
    • bg-white
    • bg-light always
    • bg-transparent
    Answer and explanation

    Correct answer: bg-body-tertiary

  3. Where is container usually placed in the page?

    • Inside each section to align the content
    • Around the html
    • Inside each button
    • It is never used
    Answer and explanation

    Correct answer: Inside each section to align the content

  4. Which classes show one card per line on phones and three from md?

    • row row-cols-1 row-cols-md-3
    • row col-1 col-md-3
    • row cols-1 cols-md-3
    • container col-md-3
    Answer and explanation

    Correct answer: row row-cols-1 row-cols-md-3

    row-cols-* sets columns per row without writing col on each item.

  5. What is the recommended last step before finalizing the landing page?

    • Removing the viewport tag
    • Replacing the grid with tables
    • Testing dark mode and the RTL direction
    • Adding a single container for the whole page
    Answer and explanation

    Correct answer: Testing dark mode and the RTL direction

    Testing in both modes and directions reveals late design bugs.
