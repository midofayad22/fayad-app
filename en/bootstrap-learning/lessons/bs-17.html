Collapse, Accordion, and Dropdown

Interactive collapsing components and dropdown menus.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Collapse and Accordion

The .collapse element is shown and hidden with a button using data-bs-toggle="collapse". The .accordion groups collapse items, and when data-bs-parent is set on each item, the others close when one is opened.

Dropdown

.dropdown contains a data-bs-toggle="dropdown" button and a .dropdown-menu list with .dropdown-item entries. Direction: dropup/dropend/dropstart.

Use button for triggers (not an empty link), and aria-expanded is managed automatically.

Code example

HTML code

<div class="container py-3">
<div class="dropdown mb-3">
<button class="btn btn-outline-primary dropdown-toggle" type="button" data-bs-toggle="dropdown" aria-expanded="false">Language</button>
<ul class="dropdown-menu">
<li><a class="dropdown-item active" href="#">Arabic</a></li>
<li><a class="dropdown-item" href="#">English</a></li>
<li><hr class="dropdown-divider"></li>
<li><a class="dropdown-item disabled" aria-disabled="true">Français</a></li>
</ul>
</div>
<div class="accordion" id="faq">
<div class="accordion-item">
<h2 class="accordion-header"><button class="accordion-button" type="button" data-bs-toggle="collapse" data-bs-target="#q1" aria-expanded="true" aria-controls="q1">What is Bootstrap?</button></h2>
<div id="q1" class="accordion-collapse collapse show" data-bs-parent="#faq"><div class="accordion-body">A library for building responsive interfaces.</div></div>
</div>
<div class="accordion-item">
<h2 class="accordion-header"><button class="accordion-button collapsed" type="button" data-bs-toggle="collapse" data-bs-target="#q2" aria-expanded="false" aria-controls="q2">Is it free?</button></h2>
<div id="q2" class="accordion-collapse collapse" data-bs-parent="#faq"><div class="accordion-body">Yes, under the MIT license.</div></div>
</div>
</div>
</div>

Understanding the code

The data-bs-parent="#faq" attribute makes opening one item close the others. The dropdown closes when you click outside it or press Escape.

Test yourself

  1. What does data-bs-parent do in an accordion?

    • Makes opening one item close the other items
    • Colors the accordion
    • Deletes the accordion
    • Changes the direction
    Answer and explanation

    Correct answer: Makes opening one item close the other items

  2. Which class gives a dropdown menu?

    • dropdown-menu inside dropdown
    • menu-list
    • select-box
    • popup
    Answer and explanation

    Correct answer: dropdown-menu inside dropdown

  3. Why use a button for a Collapse trigger?

    • Accessibility with the keyboard and screen readers
    • To color it
    • To speed it up
    • No benefit
    Answer and explanation

    Correct answer: Accessibility with the keyboard and screen readers

  4. Which class makes the dropdown open upward?

    • dropend
    • dropup
    • dropdown-up-menu
    • dropstart
    Answer and explanation

    Correct answer: dropup

    dropup opens upward, dropend to the end side and dropstart to the start side.

  5. An accordion without data-bs-parent on its items. What happens when you open a second item?

    • The first stays open
    • The first closes automatically
    • The buttons stop working
    • The page reloads
    Answer and explanation

    Correct answer: The first stays open

    data-bs-parent is what closes the others; without it each item works independently.
