Text and Colors

Typography classes, contextual colors, and subtle backgrounds in version 5.3.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Typography

  • h1–h6 for size without changing the semantic tag, display-1–display-6 for large headings, and lead for an introductory paragraph.
  • fw-bold, fst-italic, text-center, text-uppercase, and text-truncate.
  • fs-1…fs-6 for font sizes.

Contextual colors

The colors: primary secondary success danger warning info light dark. They are used with text-*, bg-*, and border-*. In 5.3 there are also text-primary-emphasis and bg-primary-subtle, which adapt to dark mode.

Choose a color for its meaning (danger for an error), not only for its look, and prefer -subtle and -emphasis to support dark mode.

Code example

HTML code

<div class="container py-3">
<p class="h3 text-primary-emphasis">Heading sized like h3 (p tag)</p>
<p class="fw-bold fst-italic text-uppercase">bold italic uppercase</p>
<p class="text-success">Success</p>
<p class="text-danger">Error</p>
<p class="bg-warning-subtle text-warning-emphasis p-2 rounded">Note with a light background</p>
<p class="bg-dark text-white p-2 rounded">White text on a dark background</p>
</div>

Understanding the code

The .h3 class gives the look of a heading without changing the page structure. The -subtle and -emphasis classes give good contrast in both light and dark modes.

Test yourself

  1. What does the h3 class do on a p tag?

    • Gives it the look of a heading without changing its semantics
    • Turns it into an h3 tag
    • Hides it
    • Makes it a link
    Answer and explanation

    Correct answer: Gives it the look of a heading without changing its semantics

  2. Which class gives a light background that adapts to dark mode?

    • bg-primary-subtle
    • bg-white
    • bg-dark only
    • text-bg
    Answer and explanation

    Correct answer: bg-primary-subtle

  3. Which class cuts off long text with an ellipsis?

    • text-truncate
    • text-wrap
    • text-break
    • text-nowrap
    Answer and explanation

    Correct answer: text-truncate

  4. You want an introductory paragraph slightly larger than normal text. Which class?

    • display-1
    • lead
    • h6 small
    • fs-6 only
    Answer and explanation

    Correct answer: lead

    lead is meant for introductory paragraphs, while display-* is for very large headings.

  5. Which class fits an error message by meaning?

    • text-danger
    • text-success
    • text-info
    • text-light
    Answer and explanation

    Correct answer: text-danger

    Choose colors for meaning: danger for errors and success for success.
