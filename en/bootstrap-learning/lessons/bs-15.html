Alerts, Badges, Progress, and Spinners

Status components: alert, badge, progress, and spinner.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Alerts and Badges

.alert.alert-{color} with role="alert", and for dismissing use alert-dismissible and btn-close with data-bs-dismiss="alert". The badge is .badge.text-bg-{color}.

Progress and Spinner

The progress bar: .progress containing .progress-bar with a width set by style="width: 60%", along with role="progressbar", aria-valuenow, aria-valuemin, and aria-valuemax. The spinner: .spinner-border with .visually-hidden for the "Loading" text.

Don't rely on color alone: add text and aria attributes for progress and loading.

Code example

HTML code

<div class="container py-3">
<div class="alert alert-warning alert-dismissible fade show" role="alert">
<strong>Heads up!</strong> Complete your profile.
<button type="button" class="btn-close" data-bs-dismiss="alert" aria-label="Close"></button>
</div>
<p>Lessons <span class="badge text-bg-primary">12</span></p>
<div class="progress mb-3" role="progressbar" aria-label="Course progress" aria-valuenow="60" aria-valuemin="0" aria-valuemax="100">
<div class="progress-bar progress-bar-striped" style="width: 60%">60%</div>
</div>
<div class="spinner-border text-primary" role="status"><span class="visually-hidden">Loading...</span></div>
</div>

Understanding the code

Click the close button and the alert disappears (thanks to the JavaScript file). visually-hidden hides the text visually but keeps it for screen readers.

Try it yourself

Edit and try

Change the alert to <code>alert-success</code> and set the progress to 85%.

Test yourself

  1. Which attribute closes the alert when clicked?

    • data-bs-dismiss="alert"
    • onclick="close"
    • href="#close"
    • data-close
    Answer and explanation

    Correct answer: data-bs-dismiss="alert"

  2. What is the purpose of visually-hidden?

    • Hiding text visually while keeping it for screen readers
    • Deleting the element
    • Hiding it from everyone
    • Shrinking the font
    Answer and explanation

    Correct answer: Hiding text visually while keeping it for screen readers

  3. Which attribute sets the width of the progress bar?

    • style="width: 60%"
    • data-width
    • col-60
    • value
    Answer and explanation

    Correct answer: style="width: 60%"

  4. Which aria attribute holds the current value of a progress bar?

    • aria-valuemax
    • aria-valuenow
    • aria-label
    • aria-current
    Answer and explanation

    Correct answer: aria-valuenow

    aria-valuenow is the current value, while min and max set the limits.

  5. Which set makes a dismissible alert?

    • alert-dismissible with btn-close and data-bs-dismiss="alert"
    • alert-close only
    • badge with data-bs-toggle
    • btn-close with no attribute
    Answer and explanation

    Correct answer: alert-dismissible with btn-close and data-bs-dismiss="alert"

    The class prepares the space and data-bs-dismiss closes the alert.
