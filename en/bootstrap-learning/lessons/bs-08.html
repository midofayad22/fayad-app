Borders, Shadows, Position, and Display

borders, rounded, shadow, position, and d-none to show and hide elements by screen size.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Borders, corners, and shadows

border border-top border-primary border-2, the corners rounded rounded-3 rounded-circle rounded-pill, and the shadows shadow-sm shadow shadow-lg.

Display and position

Hide/show by breakpoint: d-none d-md-block (hidden on mobile, visible from md). Position: position-relative and position-absolute with top-0 start-0 translate-middle, plus sticky-top and fixed-bottom.

d-none d-md-block hides the element on mobile and shows it from md.

Code example

HTML code

<div class="container py-3">
<div class="p-3 border border-2 border-primary rounded-3 shadow-sm mb-3">Card with border and shadow</div>
<div class="d-none d-md-block p-3 bg-success-subtle mb-3">Visible from md and up</div>
<div class="d-md-none p-3 bg-danger-subtle mb-3">Visible on phones only</div>
<div class="position-relative d-inline-block">
<button class="btn btn-outline-dark">Messages</button>
<span class="position-absolute top-0 start-100 translate-middle badge rounded-pill bg-danger">9</span>
</div>
</div>

Understanding the code

The red badge is absolutely positioned at the corner of the button that has position-relative, and translate-middle shifts it so it is centered on the corner.

Try it yourself

Edit and try

Give the first element a <code>shadow-lg</code> shadow and <code>rounded-pill</code> corners.

Test yourself

  1. Which classes hide the element on mobile and show it from md?

    • d-none d-md-block
    • d-md-none
    • invisible
    • hidden-xs
    Answer and explanation

    Correct answer: d-none d-md-block

  2. What is position-relative on the parent for?

    • So it becomes the positioning reference for the absolutely positioned elements inside it
    • To enlarge the parent
    • To hide it
    • To color it
    Answer and explanation

    Correct answer: So it becomes the positioning reference for the absolutely positioned elements inside it

  3. Which class gives fully rounded corners (like a pill)?

    • rounded-pill
    • rounded-0
    • border-0
    • shadow
    Answer and explanation

    Correct answer: rounded-pill

  4. Which class shows an element on phones only and hides it from md?

    • d-md-none
    • d-none d-md-block
    • d-md-block
    • d-none
    Answer and explanation

    Correct answer: d-md-none

    d-md-none hides the element from md up, so it stays visible on smaller screens.

  5. Which class makes a bar stick to the top while scrolling?

    • fixed-bottom
    • sticky-top
    • position-static
    • top-0 only
    Answer and explanation

    Correct answer: sticky-top

    sticky-top pins the element at the top once scrolling reaches it.
