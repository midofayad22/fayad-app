Tables and Lists

Styling tables and making them responsive, and list-group lists.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Tables

.table is the base, and you can add table-striped (stripes), table-hover, table-bordered, table-sm, and table-dark. To scroll a table horizontally on mobile, wrap it in .table-responsive.

Lists

.list-group + .list-group-item (they can be links with list-group-item-action), and to add a badge use d-flex justify-content-between with .badge.

Put wide tables inside table-responsive.

Code example

HTML code

<div class="container py-3">
<div class="table-responsive">
<table class="table table-striped table-hover align-middle">
<thead class="table-dark"><tr><th scope="col">#</th><th scope="col">Lesson</th><th scope="col">Status</th></tr></thead>
<tbody>
<tr><th scope="row">1</th><td>Grid</td><td><span class="badge text-bg-success">Completed</span></td></tr>
<tr><th scope="row">2</th><td>Forms</td><td><span class="badge text-bg-warning">In progress</span></td></tr>
</tbody>
</table>
</div>
<ul class="list-group mt-3">
<li class="list-group-item d-flex justify-content-between align-items-center">Notifications <span class="badge text-bg-primary rounded-pill">3</span></li>
<a href="#" class="list-group-item list-group-item-action active" aria-current="true">Messages</a>
</ul>
</div>

Understanding the code

The alternating shading and the hover highlight come from table-striped and table-hover. The table inside table-responsive scrolls horizontally instead of breaking the layout.

Test yourself

  1. Which class wraps a table so it scrolls horizontally on small screens?

    • table-responsive
    • table-scroll
    • overflow-table
    • table-mobile
    Answer and explanation

    Correct answer: table-responsive

  2. What is scope="col" in th for?

    • Specifying that the cell is a column header for a screen reader
    • Coloring the header
    • Merging columns
    • Sorting the table
    Answer and explanation

    Correct answer: Specifying that the cell is a column header for a screen reader

  3. Which class makes a list item interactive as a link?

    • list-group-item-action
    • list-link
    • list-active
    • item-click
    Answer and explanation

    Correct answer: list-group-item-action

  4. Which class adds alternating stripes to table rows?

    • table-zebra
    • table-alt
    • table-striped
    • table-lined
    Answer and explanation

    Correct answer: table-striped

    table-striped shades alternate rows with a light background.

  5. How do you put a badge at the end of a list-group-item?

    • d-flex justify-content-between with a badge
    • badge-end on the item
    • table-responsive around the item
    • list-group-badge only
    Answer and explanation

    Correct answer: d-flex justify-content-between with a badge

    Flex with between spacing pushes the badge to the opposite edge.
