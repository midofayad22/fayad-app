Validation, Input Groups, and Floating Labels

Validation messages, input-group, and form-floating.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Validation

Add novalidate to the form along with needs-validation, then on submit add was-validated so that green/red appears according to the HTML rules (required, type, and minlength). Or set is-invalid/is-valid manually with .invalid-feedback. Server-side validation is indispensable.

Groups and labels

.input-group combines text or a button with the field (.input-group-text). .form-floating places the label inside the field and it floats up when typing (the input must come before the label).

Browser validation is for convenience only; always validate on the server too.

Code example

HTML code

<form class="container py-3 needs-validation" novalidate style="max-width:480px" onsubmit="event.preventDefault(); this.classList.add('was-validated')">
<div class="input-group mb-3">
<span class="input-group-text">@</span>
<input type="text" class="form-control" placeholder="Username" aria-label="Username" required minlength="3">
<div class="invalid-feedback">Name is required (at least 3 characters).</div>
</div>
<div class="form-floating mb-3">
<input type="email" class="form-control" id="mail" placeholder="name@example.com" required>
<label for="mail">Email address</label>
<div class="invalid-feedback">Enter a valid email.</div>
</div>
<button class="btn btn-primary" type="submit">Submit</button>
</form>

Understanding the code

Click "Submit" with empty fields to show the red messages. The was-validated class adds the styling according to each field's state.

Test yourself

  1. What does was-validated do?

    • Enables valid and invalid styling according to the fields' state
    • Submits the form
    • Deletes the fields
    • Saves the data
    Answer and explanation

    Correct answer: Enables valid and invalid styling according to the fields' state

  2. Why do we need server-side validation despite browser validation?

    • Because browser validation can be bypassed
    • Because the browser doesn't support it
    • For speed only
    • We don't need it
    Answer and explanation

    Correct answer: Because browser validation can be bypassed

  3. What is the requirement in form-floating?

    • That input comes before label
    • That label comes before input
    • Only a select is present
    • No placeholder
    Answer and explanation

    Correct answer: That input comes before label

  4. Which class holds the @ symbol beside the field inside input-group?

    • input-addon
    • form-text-box
    • group-label
    • input-group-text
    Answer and explanation

    Correct answer: input-group-text

    input-group-text styles the text or icon attached to the field.

  5. How do you manually show a red error message under a field?

    • is-invalid on the field and invalid-feedback for the message
    • text-error on the field
    • was-validated on the field alone
    • alert-red after the field
    Answer and explanation

    Correct answer: is-invalid on the field and invalid-feedback for the message

    is-invalid colors the field and reveals the text inside invalid-feedback.
