Flexbox and Utilities

Distribution, alignment, direction, and wrapping of elements with d-flex classes.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Basics

d-flex turns the container into a Flex container. Direction: flex-row / flex-column. Main-axis alignment: justify-content-start|center|end|between|around|evenly. Cross-axis alignment: align-items-start|center|end|stretch. Wrapping: flex-wrap. Spacing: gap-*.

On items

flex-fill and flex-grow-1 stretch an item, and ms-auto pushes an item to the end. All of them support breakpoints (flex-md-row).

d-flex + justify-content + align-items cover most alignment needs.

Code example

HTML code

<div class="container">
<div class="d-flex justify-content-between align-items-center border p-3 mb-3">
<strong>FAYBIT</strong>
<span class="text-muted">left/right depending on direction</span>
<button class="btn btn-sm btn-primary">Action</button>
</div>
<div class="d-flex flex-column flex-md-row gap-2">
<div class="p-3 bg-light border flex-fill">1</div>
<div class="p-3 bg-light border flex-fill">2</div>
<div class="p-3 bg-light border ms-md-auto">ms-md-auto</div>
</div>
</div>

Understanding the code

The first row spreads the items to the edges and centers them vertically. The second is vertical on mobile and horizontal from md, and ms-md-auto pushes the last item to the end of the line.

Try it yourself

Edit and try

Make the first row <code>justify-content-center</code> and see the effect.

Test yourself

  1. Which class vertically centers items inside a horizontal d-flex?

    • align-items-center
    • justify-content-center
    • text-center
    • m-auto only
    Answer and explanation

    Correct answer: align-items-center

  2. What does justify-content-between do?

    • Distributes the space between items and places the first and last at the edges
    • Centers everything
    • Reverses the order
    • Hides the items
    Answer and explanation

    Correct answer: Distributes the space between items and places the first and last at the edges

  3. What does flex-column do?

    • Makes the direction vertical
    • Makes the width 100%
    • Removes gap
    • Cancels d-flex
    Answer and explanation

    Correct answer: Makes the direction vertical

  4. Inside d-flex you want to push a button to the end of the row. Which class goes on it?

    • me-0
    • ms-auto
    • flex-fill
    • align-self-start
    Answer and explanation

    Correct answer: ms-auto

    ms-auto takes all the free space before the item, pushing it to the end.

  5. Which classes stack items on phones and put them in a row from md?

    • d-flex flex-row flex-md-column
    • d-block flex-md-row
    • d-flex flex-column flex-md-row
    • flex-column d-md-flex-row
    Answer and explanation

    Correct answer: d-flex flex-column flex-md-row

    The base direction is column, then flex-md-row turns it horizontal from md.
