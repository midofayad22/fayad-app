Advanced Grid: Spacing, Ordering, and Nesting

gutters, offset, order, nested rows, and equal columns with row-cols.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Gutters

The spacing between columns is set with the g-* classes (horizontal and vertical) or gx-* and gy-*. Values range from 0 to 5.

Offset, Order, and Nesting

  • offset-md-2 shifts the column by two columns.
  • order-1…order-5 changes the visual order (not the HTML order that a screen reader reads).
  • A new .row can be placed inside a column to divide it.
  • row-cols-2 row-cols-md-4 sets the number of columns per row without writing col-* for each element.

Visual ordering with order does not change the reading order for a screen reader, so use it with care.

Code example

HTML code

<div class="container">
<div class="row row-cols-2 row-cols-md-4 g-3 mb-3">
<div class="col"><div class="p-2 border bg-light">A</div></div>
<div class="col"><div class="p-2 border bg-light">B</div></div>
<div class="col"><div class="p-2 border bg-light">C</div></div>
<div class="col"><div class="p-2 border bg-light">D</div></div>
</div>
<div class="row">
<div class="col-md-4 offset-md-4 order-2 order-md-1"><div class="p-2 border bg-warning-subtle">Offset</div></div>
<div class="col-md-4 order-1 order-md-2">
<div class="row"><div class="col-6"><div class="p-1 border">Nested</div></div><div class="col-6"><div class="p-1 border">Nested</div></div></div>
</div>
</div>
</div>

Understanding the code

row-cols-* sets the number of columns in a row. The second column contains an inner row. The order is swapped on mobile thanks to order-1 and order-2.

Test yourself

  1. What does the g-3 class do?

    • Sets the spacing between columns horizontally and vertically
    • Changes the color
    • Doubles the column
    • Hides the row
    Answer and explanation

    Correct answer: Sets the spacing between columns horizontally and vertically

  2. What does offset-md-2 do?

    • Shifts the column by two columns from md upward
    • Deletes two columns
    • Changes the color
    • Makes the column hidden
    Answer and explanation

    Correct answer: Shifts the column by two columns from md upward

  3. What is row-cols-md-3 for?

    • Three columns per row from md without specifying col for each element
    • Three rows
    • Three containers
    • Three breakpoints
    Answer and explanation

    Correct answer: Three columns per row from md without specifying col for each element

  4. Which class sets only the horizontal spacing between columns?

    • gx-4
    • gy-4
    • g-0 row
    • offset-4
    Answer and explanation

    Correct answer: gx-4

    gx-* is horizontal, gy-* is vertical and g-* sets both.

  5. Where do you place a nested row?

    • Directly inside another row
    • Outside the container
    • Inside a col column
    • Inside the head tag
    Answer and explanation

    Correct answer: Inside a col column

    A new .row goes inside a column to split that column into its own 12 parts.
