Forms

Basic form elements: fields, labels, selects, and checkboxes.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Elements

.form-label for the label, .form-control for text fields, .form-select for select menus, .form-check with .form-check-input and .form-check-label for checkboxes and radios, .form-switch for switches, and .form-range for the slider. Sizes: form-control-lg and -sm.

Linking

Link each label to its field through for and id — this is the foundation of accessibility.

Every field needs a label linked with for/id.

Code example

HTML code

<form class="container py-3" style="max-width:480px">
<div class="mb-3">
<label for="email" class="form-label">Email address</label>
<input type="email" class="form-control" id="email" placeholder="name@example.com">
</div>
<div class="mb-3">
<label for="level" class="form-label">Level</label>
<select class="form-select" id="level"><option>Beginner</option><option>Intermediate</option></select>
</div>
<div class="form-check form-switch mb-3">
<input class="form-check-input" type="checkbox" role="switch" id="news" checked>
<label class="form-check-label" for="news">Receive news</label>
</div>
<button type="button" class="btn btn-primary">Save</button>
</form>

Understanding the code

Each field group is in mb-3 for even spacing. The switch is a checkbox with form-switch and role="switch".

Test yourself

  1. Which class styles a text input field?

    • form-control
    • input-box
    • form-input
    • text-field
    Answer and explanation

    Correct answer: form-control

  2. How do we link a label to a field?

    • The for in the label equals the id in the field
    • Just by putting them on the same line
    • By giving them the same color
    • No need
    Answer and explanation

    Correct answer: The for in the label equals the id in the field

  3. Which class creates a toggle switch?

    • form-switch
    • form-toggle
    • btn-switch
    • switch-box
    Answer and explanation

    Correct answer: form-switch

  4. Which class styles a select dropdown?

    • form-control-select
    • form-select
    • select-menu
    • form-dropdown
    Answer and explanation

    Correct answer: form-select

    form-select is for the select element, while form-control is for text fields.

  5. What is the correct structure for a checkbox?

    • Only input.form-control
    • div.form-check holding input.form-check-input and label.form-check-label
    • Only label.form-switch
    • div.checkbox holding a span
    Answer and explanation

    Correct answer: div.form-check holding input.form-check-input and label.form-check-label

    These three classes together give the correct alignment and styling.
