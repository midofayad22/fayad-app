Dark Mode, RTL, and Customization with CSS Variables

data-bs-theme, bootstrap.rtl.css, and changing Bootstrap's look without Sass.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Color modes

Since 5.3, put data-bs-theme="dark" on <html> or on any element to switch it and its children to dark mode. Use the adaptive classes (bg-body, text-body, bg-body-tertiary, -subtle) instead of bg-white and text-dark.

RTL

For Arabic: <html lang="ar" dir="rtl"> with the bootstrap.rtl.min.css file instead of the regular one. The logical classes (ms-*, me-*, text-start) flip automatically.

Customizing with variables

Each component defines CSS variables such as --bs-btn-bg, and you can modify them on your own class, or change --bs-primary and --bs-body-font-family globally. This is easier than Sass in small projects.

Set data-bs-theme on the element, and change the look with --bs-* variables instead of forcefully overriding CSS.

Code example

HTML code

<style>
.btn-brand {
--bs-btn-bg: #0b6b78;
--bs-btn-border-color: #0b6b78;
--bs-btn-hover-bg: #095561;
--bs-btn-hover-border-color: #095561;
--bs-btn-color: #fff;
--bs-btn-hover-color: #fff;
}
</style>
<div class="container py-3">
<div class="p-3 border rounded mb-3 bg-body text-body">Current system mode</div>
<div class="p-3 border rounded mb-3 bg-body text-body" data-bs-theme="dark">Dark mode on this element only</div>
<button class="btn btn-brand">Brand-colored button</button>
</div>

Understanding the code

The second element is dark only because the attribute is set on it. The button customizes its color by setting the component's variables in a single class without modifying the base code.

Test yourself

  1. How do we enable dark mode for a specific element?

    • data-bs-theme="dark" on the element
    • class="dark" only
    • style="dark"
    • theme.css
    Answer and explanation

    Correct answer: data-bs-theme="dark" on the element

  2. Which file do we need for right-to-left direction?

    • bootstrap.rtl.min.css
    • bootstrap-arabic.js
    • rtl.json
    • bootstrap.dark.css
    Answer and explanation

    Correct answer: bootstrap.rtl.min.css

  3. What is the easiest way to customize a button without Sass?

    • Setting --bs-btn-* variables in your own class
    • Editing the bootstrap.min.css file
    • Using !important everywhere
    • Deleting the btn class
    Answer and explanation

    Correct answer: Setting --bs-btn-* variables in your own class

  4. What is the correct setup for an Arabic page with RTL support?

    • <html lang="ar" dir="rtl"> with bootstrap.rtl.min.css
    • <html dir="ltr"> with the regular CSS file
    • Only a meta tag named rtl
    • Only an rtl class on body
    Answer and explanation

    Correct answer: <html lang="ar" dir="rtl"> with bootstrap.rtl.min.css

    You need the direction on html and the dedicated RTL file together.

  5. Which class replaces bg-white and adapts to dark mode?

    • bg-light-fixed
    • bg-body
    • bg-white-dark
    • bg-static
    Answer and explanation

    Correct answer: bg-body

    bg-body follows the current mode's background instead of a fixed color.
