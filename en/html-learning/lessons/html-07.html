Test yourself

  1. Which tag is used to give text strong importance and make it bold?

    • <strong>
    • <small>
    • <mark>
    Answer and explanation

    Correct answer: <strong>

  2. Which tag is used to emphasize text and make it italic?

    • <em>
    • <bold>
    • <i>
    Answer and explanation

    Correct answer: <em>

  3. Which tag is used to highlight text in yellow?

    • <mark>
    • <color>
    • <highlight>
    Answer and explanation

    Correct answer: <mark>

  4. What is the main difference between strong and b?

    • strong is smaller than b
    • b does not work in modern browsers
    • strong marks real importance, while b is just a bold look
    • There is no difference in meaning at all
    Answer and explanation

    Correct answer: strong marks real importance, while b is just a bold look

    Both usually look bold, but strong carries meaning of importance and screen readers can stress it. Prefer it when the meaning matters.

  5. Which approach shows the word important in italics, not bold, to stress its meaning?

    • Wrap it in the em element
    • Wrap it in the strong element
    • Wrap it in the mark element
    • Wrap it in the h1 element
    Answer and explanation

    Correct answer: Wrap it in the em element

    The em element stresses meaning and shows in italics by default. strong looks bold, mark gets a highlighted background, and h1 is a heading, not text formatting.
