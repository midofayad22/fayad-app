Headings in HTML

Headings from h1 to h6 are used to define the hierarchy of the content.

Code example

Heading Levels

<h1>Main heading</h1>
<h2>Subheading</h2>
<h3>Smaller heading</h3>
Main heading
Subheading
Smaller heading

Understanding the code

h1 is the most important and largest heading, while h6 is the smallest.

Test yourself

  1. Which tag represents the largest and most important heading on the page?

    • <h1>
    • <h6>
    • <head>
    Answer and explanation

    Correct answer: <h1>

  2. How many heading levels are available in HTML?

    • 6 levels, from h1 to h6
    • Only 3 levels
    • 10 graded levels
    Answer and explanation

    Correct answer: 6 levels, from h1 to h6

  3. Which tag represents the lowest and smallest heading level?

    • <h6>
    • <h1>
    • <h3>
    Answer and explanation

    Correct answer: <h6>

  4. You write a page with a main title, two sections, and two subsections inside the first section. Which heading outline fits best?

    • h1, then h3 for the sections, then h5 for the subsections
    • h1 for the title, h2 for the sections, h3 for the subsections under the first
    • h2 for everything so it looks consistent
    • h6 for the main title because it is the smallest
    Answer and explanation

    Correct answer: h1 for the title, h2 for the sections, h3 for the subsections under the first

    Levels express a hierarchy without skipping: h1, then h2 for sections, then h3 for subsections. This helps readers, screen readers and search engines.

  5. A developer used h4 for the main title because he likes its small size. What is the problem?

    • No problem, size is the purpose of headings
    • h4 is not supported by browsers
    • h4 prevents the text from being displayed
    • The level defines importance and structure; size should be set with CSS
    Answer and explanation

    Correct answer: The level defines importance and structure; size should be set with CSS

    The heading level should reflect importance in the page structure, not appearance. To change the size, use CSS while keeping the correct level.
