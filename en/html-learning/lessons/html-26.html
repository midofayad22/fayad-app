Select & Option

Learn how to create dropdown selection lists using select and option.

Dropdown Lists

Create a dropdown list using <select> and its options <option>.

Code example

A Selection List

<select>
<option>Egypt</option>
<option>Saudi Arabia</option>
</select>

Understanding the code

Each option can be given its real value using the value attribute.

Test yourself

  1. Which tag creates the dropdown selection list?

    • <select>
    • <dropdown>
    • <choose>
    Answer and explanation

    Correct answer: <select>

  2. Which tag represents each individual choice inside a select list?

    • <option>
    • <item>
    • <list>
    Answer and explanation

    Correct answer: <option>

  3. Which attribute specifies the value sent to the server when an option is chosen?

    • value
    • name
    • data
    Answer and explanation

    Correct answer: value

  4. An option has value="eg" and the text Egypt. What is sent to the server when it is chosen?

    • Egypt
    • eg
    • EgyptEg
    • Nothing
    Answer and explanation

    Correct answer: eg

    The browser sends the value attribute, not the displayed text. If there is no value attribute, the option text is sent.

  5. How do you let the user choose more than one option from the list?

    • Add several select elements
    • Add the multiple attribute to select
    • Write several values
    • It is not possible
    Answer and explanation

    Correct answer: Add the multiple attribute to select

    The multiple attribute turns the control into a multi-choice list, and users hold Ctrl or Shift to select several items.
