Test yourself

  1. What is the proper, well-organized sequence for building an excellent semantic web page?

    • <header> then <main> then <footer>
    • <footer> then <header> then <main>
    • <main> only, without the other tags
    Answer and explanation

    Correct answer: <header> then <main> then <footer>

  2. Which tag wraps the entire document and specifies its direction and language?

    • <html>
    • <body>
    • <head>
    Answer and explanation

    Correct answer: <html>

  3. Which of the following is the best practice when building any website today?

    • Using meaningful semantic elements and professional organization
    • Using div everywhere in the code with no semantics
    • Ignoring headings completely
    Answer and explanation

    Correct answer: Using meaningful semantic elements and professional organization

  4. Before publishing you find your page looks tiny on phones. What do you check first?

    • That images exist
    • The font size of h1
    • That meta viewport exists in head
    • The number of li elements
    Answer and explanation

    Correct answer: That meta viewport exists in head

    Without meta viewport a phone renders the page at desktop width and shrinks it. Adding it, with flexible layout, fixes the issue.

  5. Which final-review finding reveals a real defect in the project page?

    • The page has explanatory comments
    • Using footer for copyright
    • Important images with no alt and form fields with no label
    • Having nav inside header
    Answer and explanation

    Correct answer: Important images with no alt and form fields with no label

    Images without alt and fields without labels harm accessibility and break good practice. Comments, footer and nav inside header are all fine.
