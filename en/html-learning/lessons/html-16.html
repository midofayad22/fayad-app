Page Header and Navigation

Use <header> for the page header and <nav> for menu links.

Code example

Header Menu

<header>
<nav>
<a href="#">Home</a>
</nav>
</header>
Home

Understanding the code

The nav element groups the site's main navigation links.

Try it yourself

Write HTML code

Create a header that contains two links.

Test yourself

  1. Which semantic element is meant for grouping a site's main navigation links?

    • <nav>
    • <header>
    • <menu>
    Answer and explanation

    Correct answer: <nav>

  2. Where is the top header tag of a site or article usually placed?

    • <header>
    • <footer>
    • <aside>
    Answer and explanation

    Correct answer: <header>

  3. Can a header contain the site logo, its title, and navigation links together?

    • Yes, this is standard practice
    • No, adding more than one element inside it is not allowed
    • Only when special styling is used
    Answer and explanation

    Correct answer: Yes, this is standard practice

  4. Which content suits the header element at the top of a page?

    • Only copyright notices
    • The logo, site title and navigation links
    • Side advertisements
    • The entire page content
    Answer and explanation

    Correct answer: The logo, site title and navigation links

    header holds introductory content such as logo, title and navigation. Copyright belongs in footer and ads in aside.

  5. A page has three small terms links at the bottom. Must they go in nav?

    • Yes, every group of links must be in nav
    • No, nav cannot be used more than once on a page
    • nav is only used with images
    • Not necessarily; nav is meant for major navigation blocks
    Answer and explanation

    Correct answer: Not necessarily; nav is meant for major navigation blocks

    nav is meant for major navigation blocks. A few links in the footer can simply stay in footer, and several nav elements are allowed when needed.
