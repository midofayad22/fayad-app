Forms

Forms are used to collect input from users and send it to the server.

Code example

A Simple Form

<form action="/submit">
<input type="text">
<button type="submit">Submit</button>
</form>

Understanding the code

The form element contains the various input controls.

Create a simple text input form with a submit button.

Test yourself

  1. What is the main container for all user input controls in a form?

    • <form>
    • <input>
    • <group>
    Answer and explanation

    Correct answer: <form>

  2. Which attribute specifies the destination URL for submitting the form data?

    • action
    • method
    • href
    Answer and explanation

    Correct answer: action

  3. Which button type is used to submit the form data as soon as it is clicked?

    • type="submit"
    • type="button"
    • type="reset"
    Answer and explanation

    Correct answer: type="submit"

  4. A form has a text input with no name attribute, and the user submits. What happens to the field value?

    • It is sent using the id automatically
    • It is sent but with a blank name always
    • It is not included in the submitted data
    • The browser blocks submission with an error
    Answer and explanation

    Correct answer: It is not included in the submitted data

    Only controls with a name are sent, as the name is the key in the request. A field without name is skipped on submit.

  5. A login form includes a password. Which method fits best?

    • get, because it is faster and shows data in the URL
    • post, because it sends data in the request body, not the URL
    • It does not matter, both are the same
    • method is not used with forms
    Answer and explanation

    Correct answer: post, because it sends data in the request body, not the URL

    get appends data to the URL, where it shows in the address bar and history. post sends it in the request body, which suits sensitive data (together with HTTPS).
