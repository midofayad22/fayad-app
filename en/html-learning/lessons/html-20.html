Accessibility

It means making a site usable by everyone, including people with special needs, through assistive reading tools.

Code example

Image Accessibility

<img src="cat.jpg" alt="A white cat sleeping on the sofa">

A clear descriptive image for screen readers

Understanding the code

Adding an accurate alt description helps screen readers serve blind users.

Test yourself

  1. What is the main goal of applying accessibility on the web?

    • Making the site available and understandable to all users, including those with special needs
    • Speeding up the server
    • Preventing copying of images and code
    Answer and explanation

    Correct answer: Making the site available and understandable to all users, including those with special needs

  2. Which attribute is most important for helping screen readers with images?

    • alt
    • title
    • src
    Answer and explanation

    Correct answer: alt

  3. Which approaches help magnification and screen-reading tools the most?

    • Using well-structured semantic HTML elements
    • Using extremely bright colors
    • Using images instead of text
    Answer and explanation

    Correct answer: Using well-structured semantic HTML elements

  4. An image is purely decorative and adds no meaning. What is best for its alt?

    • A long description sentence
    • Remove the attribute completely
    • Write the word image
    • An empty alt so screen readers skip it
    Answer and explanation

    Correct answer: An empty alt so screen readers skip it

    An empty alt tells assistive technology the image is decorative so it skips it. Omitting the attribute may make a reader announce the file name.

  5. A clickable div acts as a button but cannot be reached with the keyboard. What is the best fix?

    • Use the native button element
    • Make its color red
    • Add alt to it
    • Hide it from everyone
    Answer and explanation

    Correct answer: Use the native button element

    The native button supports keyboard focus, activation with Enter and Space, and is announced as a button, with no extra work.
