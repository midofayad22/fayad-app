Semantic Elements

These are elements with a clear meaning to both the browser and the developer, such as <header> and <article>.

Code example

A Semantic Structure

<header>Page header</header>
<main>Content</main>
<footer>Footer</footer>
Page header
Content
Footer

Understanding the code

Semantic elements help improve search engine optimization (SEO) and accessibility.

Write the structure of a page using semantic elements.

Test yourself

  1. What is the main benefit of using semantic elements (Semantic HTML)?

    • Better code structure, SEO, and screen reader support
    • Faster internet connection speed for the user
    • Automatically changing the page design
    Answer and explanation

    Correct answer: Better code structure, SEO, and screen reader support

  2. Which semantic element is preferred for self-contained content such as articles and news?

    • <article>
    • <div>
    • <span>
    Answer and explanation

    Correct answer: <article>

  3. Which semantic element represents a side section or sidebar on the page?

    • <aside>
    • <section>
    • <nav>
    Answer and explanation

    Correct answer: <aside>

  4. Which element should hold the copyright and contact links at the bottom of the page, semantically?

    • A plain div
    • header
    • footer
    • aside
    Answer and explanation

    Correct answer: footer

    footer is a semantic element describing closing content. A div may look the same but tells neither the browser nor a screen reader what it is.

  5. A site is built entirely from nested div elements. What is the main drawback versus semantic elements?

    • The page will not render at all
    • div slows the site down greatly
    • CSS cannot be applied to div
    • They do not express each part's role, hurting readability, accessibility and indexing
    Answer and explanation

    Correct answer: They do not express each part's role, hurting readability, accessibility and indexing

    div works fine and can be styled, but it carries no meaning. Semantic elements clarify roles for developers, screen readers and search engines.
