HTML Document Structure

Document Structure

An HTML document is made up of organized parts that help the browser understand the page and display it correctly.

The most important basic elements are <html>, <head>, and <body>.

Code example

A Basic HTML Document

<!DOCTYPE html>
<html>
<head>
<title>My Page</title>
</head>
<body>
<h1>Hello</h1>
<p>This is my page.</p>
</body>
</html>
Hello

This is my page.

Understanding the code

<!DOCTYPE html> tells the browser that the document uses HTML5.

<head> contains information about the page, and <body> contains the visible content.

Test yourself

  1. Where do you put the content that appears to the user on the page?

    • <body>
    • <head>
    • <title>
    Answer and explanation

    Correct answer: <body>

  2. What is the role of the <head> element in an HTML document?

    • It contains data, information, and settings about the page for the browser
    • It displays images and text directly to the user
    • It creates submit buttons on the page
    Answer and explanation

    Correct answer: It contains data, information, and settings about the page for the browser

  3. What is the purpose of the DOCTYPE declaration at the start of the document?

    • To tell the browser the version and type of the web document
    • To create a new text paragraph
    • To link an external stylesheet file
    Answer and explanation

    Correct answer: To tell the browser the version and type of the web document

  4. What is the correct order of the main parts of a document?

    • body, then head, then DOCTYPE
    • DOCTYPE, then html containing head and then body
    • head, then DOCTYPE, then body outside html
    • html, then DOCTYPE, then head inside body
    Answer and explanation

    Correct answer: DOCTYPE, then html containing head and then body

    A document starts with the DOCTYPE, then the root html element, which contains head (page information) and then body (visible content). head and body are siblings inside html.

  5. A page has a title element inside head with the text Shop, and an h1 inside body with the text Welcome. What does the browser show?

    • Welcome in the browser tab and Shop in the page
    • Both Shop and Welcome inside the page
    • Nothing, because head is entirely hidden
    • Shop in the browser tab and Welcome inside the page
    Answer and explanation

    Correct answer: Shop in the browser tab and Welcome inside the page

    The title text appears in the browser tab, not inside the page, while the h1 is visible content in body. Most of head is not displayed, but its title shows in the tab.
