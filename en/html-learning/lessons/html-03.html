Tags and Elements

Learn the difference between Tags and Elements and how an HTML element is made up.

What are a Tag and an Element?

A Tag is an opening or closing marker such as <p>. An Element, on the other hand, includes the opening tag, the content, and the closing tag together.

Test yourself

  1. Which of the following is a complete paragraph Element?

    • <p>Welcome</p>
    • <p>
    • </p>
    Answer and explanation

    Correct answer: <p>Welcome</p>

  2. What distinguishes the closing tag from the opening tag?

    • It contains a forward slash / before the tag name
    • It contains an exclamation mark !
    • It is always written in capital letters
    Answer and explanation

    Correct answer: It contains a forward slash / before the tag name

  3. Where is the text content of an element placed?

    • Between the opening and closing tags
    • Before the opening tag
    • Inside a JavaScript file
    Answer and explanation

    Correct answer: Between the opening and closing tags

  4. Which of these elements needs no closing tag because it holds no content?

    • p
    • h1
    • br
    • div
    Answer and explanation

    Correct answer: br

    The br element inserts a line break and wraps no content, so it is a void element with no closing tag. p, h1 and div wrap content and need to be closed.

  5. The code has an opening p, an opening b, some text, a closing p, then a closing b. What is wrong?

    • Nothing, any order is fine
    • The elements overlap; the inner b must be closed before p
    • b can never be placed inside p
    • One closing tag should have closed both
    Answer and explanation

    Correct answer: The elements overlap; the inner b must be closed before p

    Correct nesting closes the most recently opened element first: open p, open b, close b, close p. Putting b inside p is perfectly valid; only the closing order is wrong.
