Lists in HTML

Use <ul> for bulleted lists and <ol> for numbered lists.

Code example

Lists

<ul>
<li>Apple</li>
<li>Banana</li>
</ul>
  • Apple
  • Banana

Understanding the code

The <li> element represents an item inside the list.

Try it yourself

Write HTML code

Create a numbered list containing 3 of your goals.

Test yourself

  1. Which tag creates an unordered list (displayed as bullet points)?

    • <ul>
    • <ol>
    • <list>
    Answer and explanation

    Correct answer: <ul>

  2. Which tag creates an ordered list (displayed as sequential numbers)?

    • <ol>
    • <ul>
    • <dl>
    Answer and explanation

    Correct answer: <ol>

  3. Which tag is used for each individual item inside a list?

    • <li>
    • <item>
    • <point>
    Answer and explanation

    Correct answer: <li>

  4. What does the browser show for an ol containing three li items?

    • Three bullet points
    • A numbered list 1, 2 and 3
    • Three lines with no markers
    • A table of three rows
    Answer and explanation

    Correct answer: A numbered list 1, 2 and 3

    ol is an ordered list that numbers its items automatically, while ul shows bullets. The numbers are generated for you.

  5. A ul directly contains the text Apple with no li. What is correct?

    • This is perfectly valid
    • The text must go inside a p within the ul
    • Every item must be inside an li; direct text is invalid
    • ul must be replaced with ol
    Answer and explanation

    Correct answer: Every item must be inside an li; direct text is invalid

    The direct children of ul and ol must be li elements. For a nested list, place the inner list inside an li.
