Hyperlinks

Create a link that takes the user to another page using the <a> tag and the href attribute.

Code example

Creating a Link

<a href="https://google.com" target="_blank">Visit Google</a>
Visit Google

Understanding the code

The target="_blank" attribute opens the link in a new tab.

Test yourself

  1. Which tag is used to create a hyperlink for navigating between pages?

    • <a>
    • <link>
    • <url>
    Answer and explanation

    Correct answer: <a>

  2. Which attribute specifies the web address of the link's destination?

    • href
    • src
    • target
    Answer and explanation

    Correct answer: href

  3. How do you make a link open in a new window or tab?

    • target="_blank"
    • new="page"
    • open="tab"
    Answer and explanation

    Correct answer: target="_blank"

  4. What happens when you write an a element without the href attribute?

    • It works and goes to the home page
    • It does not become a real, navigable link
    • It opens in a new tab
    • It stops the browser from showing the page
    Answer and explanation

    Correct answer: It does not become a real, navigable link

    The href attribute defines the destination; without it the browser does not know where to go and does not treat it as a link. It stays plain text.

  5. Which link text is best for accessibility and clarity?

    • Click here
    • Here
    • Read more
    • Download the HTML guide for beginners
    Answer and explanation

    Correct answer: Download the HTML guide for beginners

    Descriptive text states the destination even when the link is read alone, as screen reader users often do. Texts like Click here mean nothing out of context.
