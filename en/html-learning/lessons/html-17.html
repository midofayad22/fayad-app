Main Content and Sections

Use <main> for the page's unique content and <section> to group sections.

Code example

Site Sections

<main>
<section>
<h2>Our Services</h2>
</section>
</main>
Our Services

Understanding the code

main appears only once per page.

Test yourself

  1. How many times should the <main> element be used in a single page?

    • Only once per page
    • Several times, in every section
    • Unlimited
    Answer and explanation

    Correct answer: Only once per page

  2. Which tag is intended for dividing a page into independent topics and sections?

    • <section>
    • <div>
    • <span>
    Answer and explanation

    Correct answer: <section>

  3. Is it valid to put several <section> elements inside <main>?

    • Yes, it is a correct and excellent practice
    • No, it is prevented programmatically
    • Only on the site's home page
    Answer and explanation

    Correct answer: Yes, it is a correct and excellent practice

  4. What is the correct use of the main element?

    • Once, holding the unique main content of the page
    • In every section of the page
    • Inside footer to group links
    • To wrap the logo and menu
    Answer and explanation

    Correct answer: Once, holding the unique main content of the page

    A page should have one visible main holding the unique content, without repeating the site header or footer.

  5. What is the best use of the section element?

    • For any visual styling, instead of div
    • To group content on one theme, ideally with a heading
    • To embed an external page
    • To replace html
    Answer and explanation

    Correct answer: To group content on one theme, ideally with a heading

    section groups thematic content and should ideally start with a heading. If the goal is only styling, div is more appropriate.
