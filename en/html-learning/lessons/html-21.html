Search Engine Optimization (SEO)

Heading tags and descriptive Meta tags help you rank at the top of Google search results.

Code example

SEO Tags

<title>Learn HTML Easily</title>
<meta name="description" content="Educational course">

Page header settings to improve visibility

Understanding the code

The meta description appears under the site link in Google results.

Test yourself

  1. What does the abbreviation SEO stand for?

    • Search Engine Optimization
    • Site Engine Options
    • System Easy Output
    Answer and explanation

    Correct answer: Search Engine Optimization

  2. Which tag sets the page name and title shown in the browser tab and in search engines?

    • <title>
    • <header>
    • <meta>
    Answer and explanation

    Correct answer: <title>

  3. Which tag sets the page description that appears under the title in search results?

    • <meta name="description">
    • <p class="desc">
    • <link rel="seo">
    Answer and explanation

    Correct answer: <meta name="description">

  4. Which page title is best for search engines?

    • Home
    • Untitled
    • HTML Course for Beginners - FAYBIT
    • Page 1
    Answer and explanation

    Correct answer: HTML Course for Beginners - FAYBIT

    A descriptive title naming the topic and site is clear to users and search engines. Generic titles do not distinguish the page.

  5. Which practice helps both SEO and accessibility?

    • Stuffing the page with repeated keywords
    • Writing meaningful alt text for important images
    • Using images instead of text for headings
    • Leaving the h1 empty
    Answer and explanation

    Correct answer: Writing meaningful alt text for important images

    Meaningful alt text helps search engines understand the image and is read by screen readers. Keyword stuffing hurts, and image headings are not read as text.
