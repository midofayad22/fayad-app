Adding Images

The <img> element is a self-closing element used to embed images in the page.

Code example

Adding an Image

<img src="logo.png" alt="Logo" width="200">

An image element appears here according to the specified path

Understanding the code

src specifies the path, and alt provides a description of the image.

Test yourself

  1. Which element creates an image in HTML?

    • <img>
    • <image>
    • <pic>
    Answer and explanation

    Correct answer: <img>

  2. Does the <img> element have a separate closing tag </img>?

    • No, it is a self-closing element
    • Yes, it must always be closed with a separate tag
    • Only in old code
    Answer and explanation

    Correct answer: No, it is a self-closing element

  3. Which attribute specifies the path or URL of the image file?

    • src
    • href
    • path
    Answer and explanation

    Correct answer: src

  4. An image has only src="pic.jpg" and the file is missing. What shows and what else is wrong?

    • A broken-image icon appears and there is no alt text describing it
    • Automatic text describing the image appears
    • The image turns into a link
    • The whole page is blank
    Answer and explanation

    Correct answer: A broken-image icon appears and there is no alt text describing it

    When loading fails the browser shows a broken icon; with an alt attribute its text would be shown instead. A missing alt also hurts screen reader users.

  5. What is the best way to display an image 200 pixels wide without distorting its proportions?

    • Set width and height to values unrelated to the original
    • Set only width to 200 and let the height be calculated
    • Write 200 in the alt attribute
    • Put the image inside a p
    Answer and explanation

    Correct answer: Set only width to 200 and let the height be calculated

    When only one dimension is set, the browser keeps the aspect ratio. Setting two unrelated values stretches and distorts the image.
