Data Tables

A table is made up of rows <tr>, headers <th>, and cells <td>.

Code example

A Simple Table

<table>
<tr>
<th>Name</th>
<th>Score</th>
</tr>
<tr>
<td>Ahmed</td>
<td>100</td>
</tr>
</table>
NameScore
Ahmed100

Understanding the code

The table tag contains the entire structure of the table.

Test yourself

  1. Which tag represents a row in a table (Table Row)?

    • <tr>
    • <td>
    • <th>
    Answer and explanation

    Correct answer: <tr>

  2. Which tag is used for a prominent header cell in a table?

    • <th>
    • <td>
    • <head>
    Answer and explanation

    Correct answer: <th>

  3. Which tag is used for a regular data cell inside a row?

    • <td>
    • <tr>
    • <data>
    Answer and explanation

    Correct answer: <td>

  4. A table has a first row with two th cells (Name, Age) and a second row with two td cells (Sara, 20). How many rows and columns show?

    • Two rows and two columns
    • Four rows and one column
    • One row and four columns
    • Two rows and four columns
    Answer and explanation

    Correct answer: Two rows and two columns

    The number of rows equals the number of tr elements, and columns equal the cells per row. Here there are two tr elements with two cells each.

  5. td cells were placed directly inside table without any tr. What is the verdict?

    • Correct, browsers do not need rows
    • Wrong; cells must be inside a tr that represents the row
    • Correct if th is used instead of td
    • Wrong, because tables cannot have cells
    Answer and explanation

    Correct answer: Wrong; cells must be inside a tr that represents the row

    Table structure is table containing tr, and each row containing th or td. A browser may auto-correct it, but the code is still invalid.
