Textarea

Multi-Line Text Box

The <textarea> element allows writing long text, articles, and contact messages.

Code example

A Notes Box

<textarea rows="4" cols="50" placeholder="Write your note"></textarea>

Understanding the code

The rows and cols attributes set the dimensions in columns and lines.

Test yourself

  1. Which element is suitable for entering long, multi-line text such as notes?

    • <textarea>
    • <input type="text">
    • <p>
    Answer and explanation

    Correct answer: <textarea>

  2. Which attribute sets the height of the text box in number of lines?

    • rows
    • cols
    • height
    Answer and explanation

    Correct answer: rows

  3. Does the textarea tag have a separate closing tag?

    • Yes, it has a </textarea> closing tag
    • No, it is a self-closing tag
    • Only with advanced forms
    Answer and explanation

    Correct answer: Yes, it has a </textarea> closing tag

  4. Where is the initial text of a textarea written?

    • In the value attribute
    • Between its opening and closing tags
    • In the rows attribute
    • In the alt attribute
    Answer and explanation

    Correct answer: Between its opening and closing tags

    textarea takes its content as text between its tags rather than via value like input does, which is why it needs a closing tag.

  5. A textarea has rows=3 and the user types ten lines. What happens?

    • The text is cut off and lost
    • The field grows endlessly by itself
    • A scrollbar appears so all the text stays accessible
    • It stops accepting input
    Answer and explanation

    Correct answer: A scrollbar appears so all the text stays accessible

    rows sets only the visible height; the extra text is kept and a vertical scrollbar appears.
