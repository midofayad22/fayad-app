Text Paragraphs

The <p> tag is used to divide text into paragraphs that are easier to read.

Code example

Creating Paragraphs

<p>This is the first paragraph.</p>
<p>This is the second paragraph.</p>

This is the first paragraph.

This is the second paragraph.

Understanding the code

The browser automatically leaves space before and after each paragraph.

Try it yourself

Write HTML code

Write two paragraphs about your passion for learning web development.

Test yourself

  1. Which tag is used to create a text paragraph?

    • <p>
    • <paragraph>
    • <text>
    Answer and explanation

    Correct answer: <p>

  2. What does the browser do automatically when you add a new <p> element?

    • It adds vertical space before and after the paragraph
    • It automatically makes the text italic
    • It turns the color blue
    Answer and explanation

    Correct answer: It adds vertical space before and after the paragraph

  3. Can you add more than one <p> element on the same page?

    • Yes, with no maximum
    • No, only one paragraph per document
    • Only when using CSS styling
    Answer and explanation

    Correct answer: Yes, with no maximum

  4. In the source, one paragraph contains Hello, then many spaces and blank lines, then World. What does the browser show?

    • Each word on its own line with the blank lines kept
    • Hello World on one line separated by a single space
    • Only Hello
    • An error, because extra spaces are not allowed
    Answer and explanation

    Correct answer: Hello World on one line separated by a single space

    The browser collapses consecutive spaces and line breaks into one space. To get a new line you need a br or a new paragraph.

  5. How do you move to a new line inside the same paragraph without creating a new paragraph?

    • Insert the br element
    • Press Enter in the source code
    • Add several spaces
    • Add an empty p
    Answer and explanation

    Correct answer: Insert the br element

    br forces a line break while keeping the text in the same paragraph. Enter and spaces in the source have no effect because the browser collapses them.
