What is HTML?

HTML stands for HyperText Markup Language. It is the core markup language used to build the structure of web pages.

HTML tells the browser what kind of content is on the page, such as headings, paragraphs, links, images, and forms.

The Key Idea

HTML builds the page structure

You can think of a website as a building: HTML builds the structure, CSS takes care of the appearance, and JavaScript adds behavior and interactivity.

Code example

Your First HTML Code

<h1>Welcome</h1>
<p>Welcome to FAYBIT.</p>
Welcome

Welcome to FAYBIT.

Understanding the code

The <h1> element is used to create the main heading.

The <p> element is used to create a paragraph.

Test yourself

  1. What does the abbreviation HTML stand for?

    • HyperText Markup Language
    • HighText Machine Language
    • Home Tool Markup Language
    Answer and explanation

    Correct answer: HyperText Markup Language

  2. What is the main purpose of HTML?

    • Building the basic structure of a web page
    • Only styling and coloring elements
    • Managing databases and controlling the server
    Answer and explanation

    Correct answer: Building the basic structure of a web page

  3. Which element is used to create a regular text paragraph?

    • <p>
    • <text>
    • <paragraph>
    Answer and explanation

    Correct answer: <p>

  4. Which statement about HTML is correct?

    • A programming language with loops and conditions like other languages
    • A markup language that describes the structure and meaning of page content
    • A styling language responsible only for colors and fonts
    • A database language for storing user data
    Answer and explanation

    Correct answer: A markup language that describes the structure and meaning of page content

    HTML marks up content so the browser knows what is a heading, a paragraph or a link. It has no programming logic; styling belongs to CSS and behavior to JavaScript.

  5. You want the page to change color and show a calculation when a visitor presses a button. What do you need besides HTML?

    • More HTML tags only
    • An image file in another format
    • JavaScript for the interaction and CSS for the colors
    • Nothing, HTML does it automatically
    Answer and explanation

    Correct answer: JavaScript for the interaction and CSS for the colors

    HTML alone only describes content and cannot run logic on a click. JavaScript handles the interaction and CSS the styling, both built on top of the HTML structure.
