The Page Footer

The footer contains copyright notices, contact links, and legal information.

Code example

A Simple Footer

<footer>
<p>© 2026 All rights reserved</p>
</footer>

© 2026 All rights reserved

Understanding the code

The footer is usually placed at the end of the page document.

Try it yourself

Write HTML code

Create a page footer containing a copyright notice with your name.

Test yourself

  1. Where is the <footer> tag usually placed in a page?

    • At the bottom of the page
    • At the top of the page
    • Only inside the sidebar
    Answer and explanation

    Correct answer: At the bottom of the page

  2. What kind of information typically appears inside a footer?

    • Copyright, publishing, and contact information
    • Main article headings
    • Direct purchase inputs
    Answer and explanation

    Correct answer: Copyright, publishing, and contact information

  3. Can the footer tag be used inside other elements such as article?

    • Yes, to add a footer with author details to an article
    • No, it exists only on the home page
    • Only with forms
    Answer and explanation

    Correct answer: Yes, to add a footer with author details to an article

  4. Must a footer always appear at the very bottom of the screen visually?

    • Yes, always
    • No, it describes a closing role; its visual position is set by CSS
    • Yes, because the browser pins it
    • Its position can never be changed
    Answer and explanation

    Correct answer: No, it describes a closing role; its visual position is set by CSS

    footer is semantic: it describes closing content for a section or page, while where it sits on screen is controlled by styling.

  5. A news article needs the author name and date at its end. Where should they go?

    • Only in the page footer
    • In head
    • In a footer inside the article itself
    • In title
    Answer and explanation

    Correct answer: In a footer inside the article itself

    A footer can be used inside article or section to carry its own closing information, such as author and sources. head does not display its content.
