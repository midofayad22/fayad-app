Input Types

Learn the different input types and how they determine the kind of data the user enters.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Input Field Types

The type attribute determines the kind of data, such as text, password, email, number.

Code example

Input Types

<input type="email" placeholder="Email">
<input type="password">


Understanding the code

In the password type, the text is hidden to protect its secrecy.

Write HTML code

Create an email field and a password field.

Test yourself

  1. Which field type is suitable for entering passwords and masking them on screen?

    • type="password"
    • type="text"
    • type="hidden"
    Answer and explanation

    Correct answer: type="password"

  2. Which input type is used to pick a date from an interactive calendar?

    • type="date"
    • type="time"
    • type="calendar"
    Answer and explanation

    Correct answer: type="date"

  3. Which type ensures that the input matches an email address format?

    • type="email"
    • type="text"
    • type="mail"
    Answer and explanation

    Correct answer: type="email"

  4. What does the browser do with an input whose type is the unknown value foo?

    • It treats it as a normal text field
    • It hides the field
    • It shows an error message
    • It treats it as a button
    Answer and explanation

    Correct answer: It treats it as a normal text field

    The default type is text, and unknown values fall back to it, so the field stays usable for typing.

  5. You want a field for quantity with increase and decrease arrows. Which type fits?

    • text
    • password
    • email
    • number
    Answer and explanation

    Correct answer: number

    The number type accepts numbers only and shows spinner arrows in most browsers. text accepts any character without these features.
