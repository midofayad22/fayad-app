Attributes

Learn how Attributes add extra information to HTML elements.

What is an Attribute?

An attribute adds extra information and options to an element, and it is always written inside the opening tag.

Code example

An Example of Attributes

<a href="https://example.com">Visit the website</a>
<img src="image.jpg" alt="Image">
Visit the website

An example of attributes

Understanding the code

An attribute consists of a name and a value, such as href="url".

Test yourself

  1. Where are attributes usually written in HTML?

    • Inside the opening tag
    • Inside the closing tag
    • Completely outside the document
    Answer and explanation

    Correct answer: Inside the opening tag

  2. Which attribute is used to specify the destination of a link in the <a> element?

    • href
    • src
    • link
    Answer and explanation

    Correct answer: href

  3. Which attribute provides alternative text for an image in case it fails to load?

    • alt
    • src
    • title
    Answer and explanation

    Correct answer: alt

  4. In width="300", what are width and 300?

    • The attribute name and its value
    • The element name and its content
    • The tag and its text
    • The value and the attribute name
    Answer and explanation

    Correct answer: The attribute name and its value

    An attribute is a name, an equals sign and a quoted value. Here the name is width and the value is 300.

  5. A student wrote a link with hrf="page.html" instead of href. What happens?

    • The link works because the browser fixes it
    • An error message appears and the page stops rendering
    • The unknown attribute is ignored, so it is not a working link
    • The link opens in a new tab
    Answer and explanation

    Correct answer: The unknown attribute is ignored, so it is not a working link

    The browser does not know hrf, so it silently ignores it without any error, and with no href it has nowhere to go. Attribute names must be spelled exactly.
