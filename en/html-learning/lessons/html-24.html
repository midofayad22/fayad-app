Comments in HTML

Comments are code notes for the developer that do not appear to users on the page.

Code example

Writing a Comment

<!-- This is an explanatory comment -->
<p>Visible content</p>

Visible content

Understanding the code

Comments start with <!-- and end with -->.

Write HTML code

Write an explanatory comment before the main tag.

Test yourself

  1. What is the correct syntax for writing a comment in HTML?

    • <!-- comment -->
    • // comment
    • /* comment */
    Answer and explanation

    Correct answer: <!-- comment -->

  2. Does comment text appear to users while browsing the page?

    • No, the browser completely ignores it when rendering
    • Yes, always
    • It appears only at the bottom of the page
    Answer and explanation

    Correct answer: No, the browser completely ignores it when rendering

  3. What is the benefit of writing comments in HTML code?

    • Clarifying and organizing the code and making it easier for developers to read
    • Making the page open faster
    • Changing colors for free
    Answer and explanation

    Correct answer: Clarifying and organizing the code and making it easier for developers to read

  4. You wrapped an h1 heading inside an HTML comment. What does the browser show?

    • The heading in a faded color
    • The heading with the comment marks
    • Nothing; commented content is not rendered
    • An error message
    Answer and explanation

    Correct answer: Nothing; commented content is not rendered

    The browser ignores everything inside a comment when rendering, which makes comments handy for temporarily disabling code. The text still shows in the page source.

  5. You opened a comment and forgot its closing marker mid-page. What is the likely result?

    • No effect
    • The content after it disappears because it is treated as part of the comment
    • The page repeats
    • The comment becomes a heading
    Answer and explanation

    Correct answer: The content after it disappears because it is treated as part of the comment

    An unclosed comment runs until a closing marker is found, so it can hide a large part of the page. Always close it.
