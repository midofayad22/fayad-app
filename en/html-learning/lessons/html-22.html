Audio and Video Media

Use <audio> for audio and <video> for video clips.

Code example

Embedding Video and Audio

<video controls width="300">
<source src="video.mp4" type="video/mp4">
</video>

A media player that supports the controls buttons

Understanding the code

The controls attribute adds play buttons and volume control.

Test yourself

  1. Which attribute displays the play and pause buttons for media on screen?

    • controls
    • autoplay
    • loop
    Answer and explanation

    Correct answer: controls

  2. Which tag is intended for embedding audio in HTML5?

    • <audio>
    • <sound>
    • <mp3>
    Answer and explanation

    Correct answer: <audio>

  3. Which child tag specifies the source and link of the media file inside the video tag?

    • <source>
    • <src>
    • <file>
    Answer and explanation

    Correct answer: <source>

  4. A video element has neither controls nor autoplay. What does the visitor see?

    • A video that does not start and has no visible play buttons
    • A video that plays automatically with sound
    • A page error
    • Controls always appear
    Answer and explanation

    Correct answer: A video that does not start and has no visible play buttons

    controls is what shows the playback interface, and without autoplay the video will not start by itself, leaving a clip that is hard to play.

  5. Several source elements with different formats are placed inside video. How does the browser behave?

    • It plays all of them together
    • It always uses the last one
    • It picks the first format it supports
    • It shows an error unless they match
    Answer and explanation

    Correct answer: It picks the first format it supports

    The browser reads source elements in order and uses the first file it can play, which is why several formats are offered for compatibility.
