Meta Tags

Encoding and Screen Tags

<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">

Basic meta tags for setting encoding and responsiveness

Understanding the code

UTF-8 ensures Arabic is supported correctly without strange symbols.

Write the tag that sets the UTF-8 encoding for Arabic.

Test yourself

  1. What is the purpose of the <meta charset="UTF-8"> tag?

    • Supporting and displaying Arabic and all languages without garbled characters
    • Changing the page width
    • Protecting the site
    Answer and explanation

    Correct answer: Supporting and displaying Arabic and all languages without garbled characters

  2. Which meta tag makes the page responsive on phone and mobile screens?

    • <meta name="viewport">
    • <meta name="mobile">
    • <meta name="screen">
    Answer and explanation

    Correct answer: <meta name="viewport">

  3. Where are all Meta tags placed in the document structure?

    • Inside the <head> element
    • Inside the <body> element
    • In the page footer
    Answer and explanation

    Correct answer: Inside the <head> element

  4. What might happen to Arabic text if the UTF-8 charset declaration is missing?

    • Characters may appear garbled or as strange symbols
    • The text turns into an image
    • The page stops working
    • The direction switches to right-to-left automatically
    Answer and explanation

    Correct answer: Characters may appear garbled or as strange symbols

    Without a clear encoding the browser may guess wrongly and garble non-English characters. That is why meta charset goes in head.

  5. A developer says meta viewport shrinks the page on phones. Which description is more accurate?

    • It sets the page width and initial zoom to match the device
    • It compresses images
    • It changes page colors
    • It prevents printing
    Answer and explanation

    Correct answer: It sets the page width and initial zoom to match the device

    The usual value width=device-width, initial-scale=1 makes the browser use the real device width instead of assuming a wide one, so responsive designs work.
