Show and Hide Elements

Use <details> with <summary> to create an interactive FAQ list.

Code example

A Collapsed Question and Answer

<details>
<summary>What is the course?</summary>
<p>A comprehensive educational course.</p>
</details>
What is the course?

A comprehensive educational course.

Understanding the code

When summary is clicked, the browser opens the content of details.

Create a frequently asked question with its collapsed answer.

Test yourself

  1. Which element provides the visible, clickable heading that shows and hides the content?

    • <summary>
    • <details>
    • <title>
    Answer and explanation

    Correct answer: <summary>

  2. Which tag wraps the entire collapsible interactive behavior without needing JavaScript?

    • <details>
    • <toggle>
    • <accordion>
    Answer and explanation

    Correct answer: <details>

  3. Does the detailed content of details show automatically before the user clicks it?

    • It is hidden by default until it is clicked
    • It is always shown open
    • It needs CSS to be hidden
    Answer and explanation

    Correct answer: It is hidden by default until it is clicked

  4. A details element has no open attribute. What does the visitor see before clicking?

    • Only the summary line, with the content hidden
    • The full content
    • Nothing at all
    • An error message
    Answer and explanation

    Correct answer: Only the summary line, with the content hidden

    The default state is collapsed, showing only the summary. Adding open makes the content visible from the start.

  5. Where should summary be placed inside details?

    • At its end
    • Completely outside it
    • Only inside a p
    • As its first child element
    Answer and explanation

    Correct answer: As its first child element

    The specification expects summary to be the first child of details so it works as the clickable heading.
