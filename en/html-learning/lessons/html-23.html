Div & Span

Learn to use div as a generic container and span for styling small parts.

Container Elements Div and Span

<div> is a block element for grouping elements, while <span> is an inline element for a piece of text.

Code example

Div and Span

<div class="card">
<p>I am studying <span style="color:red">HTML</span></p>
</div>

I am studying HTML

Understanding the code

Div starts a new line, while Span does not break the line.

Test yourself

  1. What type of element is <div> in terms of how it is displayed on the page?

    • A block-level element that takes the full line
    • An inline element
    • An element hidden by default
    Answer and explanation

    Correct answer: A block-level element that takes the full line

  2. Which tag is suitable for wrapping a word inside a paragraph to style it without breaking the line?

    • <span>
    • <div>
    • <p>
    Answer and explanation

    Correct answer: <span>

  3. Do div or span have any default visual appearance without CSS?

    • No, they are containers with no default look or borders
    • Yes, they add a light border
    • They change the font automatically
    Answer and explanation

    Correct answer: No, they are containers with no default look or borders

  4. What happens when two span elements with text are placed next to each other?

    • Each on a separate line
    • They appear on the same line because span is inline
    • The second disappears
    • They turn into a list
    Answer and explanation

    Correct answer: They appear on the same line because span is inline

    span is inline: it does not break the line and takes only its content width, unlike div which takes a full line.

  5. When should you prefer a semantic element like nav over div?

    • When a semantic element matches the content's role
    • Never, always use div
    • When we want a different color
    • When we want to hide content
    Answer and explanation

    Correct answer: When a semantic element matches the content's role

    div and span are generic containers with no meaning, so use them only when no suitable semantic element exists or purely for styling.
