Articles and Asides

Use <article> for independently publishable content and <aside> for the sidebar.

Code example

Article and Sidebar

<article><h2>Today's News</h2></article>
<aside>Related links</aside>
Today's News

Understanding the code

article is ideal for posts, articles, and news.

Try it yourself

Write HTML code

Write an article tag with a heading and some simple text inside it.

Test yourself

  1. Which tag suits news and articles that can stand and be published on their own?

    • <article>
    • <aside>
    • <div>
    Answer and explanation

    Correct answer: <article>

  2. Which tag suits sidebars, ads, and additional links?

    • <aside>
    • <article>
    • <section>
    Answer and explanation

    Correct answer: <aside>

  3. Can multiple <article> elements be used in a single page?

    • Yes, for example when showing a list of articles or news items
    • No, it is not possible at all
    • Only with images
    Answer and explanation

    Correct answer: Yes, for example when showing a list of articles or news items

  4. Which of these suits the article element?

    • The navigation links list
    • A side ad
    • The site logo
    • A blog post that could be published on its own
    Answer and explanation

    Correct answer: A blog post that could be published on its own

    article is self-contained content that makes sense outside the page context, like a post or news item. The test: could it be published separately?

  5. Inside an article there is a side block titled Related sources. Which element fits it?

    • aside, because it is tangentially related content
    • main
    • header
    • table
    Answer and explanation

    Correct answer: aside, because it is tangentially related content

    aside represents tangentially related content and may be placed inside an article. main is used once for the primary content only.
