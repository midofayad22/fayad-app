Embedding with Iframe

The <iframe> lets you embed Google Maps, YouTube clips, or external pages.

Code example

Embedding a Page

<iframe src="https://example.com" width="100%" height="200"></iframe>

An external content embed box appears here

Understanding the code

The src attribute specifies the link of the embedded page.

Test yourself

  1. What is the function of the <iframe> element?

    • Embedding an external page, site, or media inside the current page
    • Creating a red frame around a paragraph
    • Playing audio only
    Answer and explanation

    Correct answer: Embedding an external page, site, or media inside the current page

  2. Which attribute specifies the link of the external page embedded inside an iframe?

    • src
    • href
    • link
    Answer and explanation

    Correct answer: src

  3. Which attributes are used to set the dimensions of the embed frame?

    • width and height
    • size and scale
    • max and min
    Answer and explanation

    Correct answer: width and height

  4. You embedded another site with an iframe and got a blank frame. What is one likely reason?

    • The browser does not support iframe
    • The other site forbids being embedded in frames
    • The frame needs alt
    • The link must be written inside a p
    Answer and explanation

    Correct answer: The other site forbids being embedded in frames

    Many sites send headers such as X-Frame-Options or CSP that block embedding, so the frame is blank even if your code is correct.

  5. A student wrote iframe href="https://example.com". What is the mistake?

    • It should be link
    • It should be alt
    • The correct attribute is src
    • There is no mistake
    Answer and explanation

    Correct answer: The correct attribute is src

    iframe sets the embedded page with src, not href, which belongs to links. Adding a title to describe the frame is also recommended.
