Outputs

Learn how child components send events back to their parent components.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Outputs are commonly implemented with EventEmitter. The child emits an event and the parent listens to that event. This creates a clear communication path from child to parent.
Code example

Code Example

@Output()
selected = new EventEmitter<string>();
selectItem() {
this.selected.emit('Angular');
}
