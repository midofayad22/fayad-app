Component Communication

Learn how Angular components communicate and exchange information.

  3. Which statement best describes this topic?

    • Component communication becomes important as applications grow. A parent can pass data to a child through inputs, while a child can notify its parent through outputs and emitted events.
    • An input is a public value that a child component can receive from its parent. This makes components reusable because the parent can provide different values to the same component.
    • Outputs are commonly implemented with EventEmitter. The child emits an event and the parent listens to that event. This creates a clear communication path from child to parent.
    Answer and explanation

    Correct answer: Component communication becomes important as applications grow. A parent can pass data to a child through inputs, while a child can notify its parent through outputs and emitted events.
