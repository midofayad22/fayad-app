Inputs

Learn how parent components pass data into child components using inputs.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

An input is a public value that a child component can receive from its parent. This makes components reusable because the parent can provide different values to the same component.
Code example

Code Example

@Input()
userName = '';
<h2>{{ userName }}</h2>
