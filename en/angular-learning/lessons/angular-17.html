Services

Learn how Angular services organize reusable application logic and shared functionality.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Services are classes designed to contain reusable logic. They are commonly used for API communication, authentication, shared data, business logic, logging, and other functionality that should not live directly inside a component.
Code example

Code Example

import { Injectable } from '@angular/core';
@Injectable({
providedIn: 'root'
})
export class UserService {
getUsers() {
return ['Ali', 'Mido', 'Sara'];
}
}
