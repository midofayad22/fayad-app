Standalone Components

Learn the modern Angular approach to building components without traditional NgModules.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Standalone components can declare their own imports and work without being declared inside a traditional NgModule. This approach simplifies application structure and is now a central part of modern Angular development.
Code example

Code Example

import { Component } from '@angular/core';
@Component({
selector: 'app-home',
standalone: true,
template: '<h1>Home</h1>'
})
export class HomeComponent {}
