State Management

Learn how applications manage shared and changing data using reactive state techniques.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

State management is about controlling important application data and keeping the UI synchronized with that state. Small applications can use local component state, while larger applications may require shared services, signals, or dedicated state-management solutions.
Code example

Code Example

count = signal(0);
increase() {
this.count.update(
value => value + 1
);
}
decrease() {
this.count.update(
value => value - 1
);
}
