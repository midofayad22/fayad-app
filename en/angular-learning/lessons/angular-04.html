Components

Learn how Angular components organize an application into reusable UI and logic.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

A component represents a part of the user interface. It normally contains a TypeScript class for logic, an HTML template for the view, and optional styles. Components are the main building blocks of Angular applications.
Code example

Code Example

import { Component } from '@angular/core';
@Component({
selector: 'app-card',
template: '<h2>Product Card</h2>'
})
export class CardComponent {}
