group, peer, and Other Variants

One element's state affecting another, child patterns, and aria and data variants.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

group

Put group on the parent and then group-hover:* on the children so they change when the parent is hovered.

peer

Put peer on a preceding element and then peer-checked:* or peer-invalid:* on the next sibling. Great for custom checkboxes.

Others

first: last: odd: even: for children, and aria-expanded:* and data-[state=open]:* for states expressed through attributes.

peer must come before the affected element in HTML order.

Code example

HTML code

<div class="space-y-4 p-4">
<a href="#" class="group flex items-center gap-3 rounded-lg border p-3 hover:border-sky-500">
<span class="text-slate-700 group-hover:text-sky-700">Hover over the whole card</span>
<span id="arrow" class="ms-auto opacity-0 transition group-hover:opacity-100">←</span>
</a>
<label class="flex items-center gap-2">
<input type="checkbox" id="chk" class="peer size-5">
<span class="text-slate-500 peer-checked:font-bold peer-checked:text-emerald-700">I agree to the terms</span>
</label>
<ul><li class="odd:bg-slate-100 p-2">1</li><li class="odd:bg-slate-100 p-2">2</li><li class="odd:bg-slate-100 p-2">3</li></ul>
</div>

Understanding the code

The arrow appears when the whole card is hovered thanks to group. The text changes when the checkbox is checked thanks to peer-checked. odd: shades the odd-numbered items.

    • It lets children react to the parent's state via group-hover
    • Groups colors
    • Creates a grid
    • Hides children
    Answer and explanation

    Correct answer: It lets children react to the parent's state via group-hover

  2. What is the requirement for peer-checked?

    • The peer must come before the affected element in HTML
    • The element must be a div
    • The parent must be a grid
    • No requirement
    Answer and explanation

    Correct answer: The peer must come before the affected element in HTML

  3. What does odd:bg-slate-100 do?

    • Shades only the odd-numbered items
    • Shades the even-numbered items
    • Shades only the first
    • Hides the odd-numbered items
    Answer and explanation

    Correct answer: Shades only the odd-numbered items

  4. Which prefix styles only the first child?

    • start:
    • first:
    • top:
    • head:
    Answer and explanation

    Correct answer: first:

    first: and last: target the first and last child.

  5. Which prefix styles an element when aria-expanded is true?

    • aria-expanded:
    • expanded-aria:
    • open:aria
    • state-expanded:
    Answer and explanation

    Correct answer: aria-expanded:

    aria-* variants read the attribute state directly.
