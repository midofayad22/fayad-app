Spacing: padding, margin, and gap

Tailwind's spacing scale: each unit equals 0.25rem.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

The Scale

In v4 all spacing is derived from a single variable, --spacing: 0.25rem. So p-1 = 0.25rem, p-4 = 1rem, p-8 = 2rem, and any number works (p-13 = 3.25rem).

The Syntax

p is padding and m is margin, followed by a direction: t b x y, and for logical directions s (start) and e (end), such as ps-4 me-2. gap-* sets the space between flex/grid items, and space-x-* sets the space between children. Negative margin: -mt-2. mx-auto is for centering.

Spacing number × 0.25rem. Use s/e instead of l/r to support RTL.

Code example

HTML code

<div class="p-4">
<div id="a" class="mb-4 bg-slate-100 p-4">p-4 = 1rem</div>
<div id="b" class="mb-4 bg-slate-100 px-8 py-2">px-8 py-2</div>
<div id="c" class="ms-8 bg-slate-100 p-3">ms-8 (margin at the start)</div>
<div class="mt-4 flex gap-3"><span class="bg-amber-200 p-2">1</span><span class="bg-amber-200 p-2">2</span></div>
</div>

Understanding the code

p-4 gives 16px because 4 × 0.25rem = 1rem. px-8 gives 32px horizontally. gap-3 puts 12px between the two items.

Test yourself

  1. What does p-4 equal?

    • 1rem (16px)
    • 4px
    • 4rem
    • 0.4rem
    Answer and explanation

    Correct answer: 1rem (16px)

  2. Which class adds a margin at the start of the element in an RTL-friendly way?

    • ms-4
    • ml-4
    • mt-4
    • mb-4
    Answer and explanation

    Correct answer: ms-4

  3. What does gap-3 do?

    • Space between flex/grid items
    • Padding inside the element
    • The element's width
    • Border color
    Answer and explanation

    Correct answer: Space between flex/grid items

  4. What does the class p-13 equal in v4?

    • 1.3rem
    • 13rem
    • 3.25rem
    • 13px
    Answer and explanation

    Correct answer: 3.25rem

    13 times 0.25rem gives 3.25rem because any number works.

  5. Which class centers a block horizontally?

    • my-auto
    • mx-auto
    • px-auto
    • gap-auto
    Answer and explanation

    Correct answer: mx-auto

    mx-auto makes both horizontal margins automatic.
