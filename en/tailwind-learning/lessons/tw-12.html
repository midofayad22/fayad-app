States: hover, focus, active, and disabled

Changing appearance based on element state using variants.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

variants

Put the prefix before the class: hover:bg-sky-700 focus:ring-2 focus-visible:outline-2 active:scale-95 disabled:opacity-50. They can be combined with responsive prefixes: md:hover:bg-sky-700.

Accessibility

Use focus-visible to show the focus indicator during keyboard navigation, and make sure hover is not the only way to reveal information (because touch has no hover).

Combine hover, focus-visible, active, and disabled for every interactive element.

Code example

HTML code

<div class="space-x-3 p-4">
<button id="btn" class="rounded-lg bg-sky-600 px-4 py-2 font-semibold text-white transition hover:bg-sky-700 focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-sky-600 active:scale-95">Interactive</button>
<button class="rounded-lg bg-slate-300 px-4 py-2 font-semibold text-slate-600 disabled:cursor-not-allowed disabled:opacity-50" disabled>Disabled</button>
</div>

Understanding the code

Hover over the first button or click it. The second button is disabled, so it appears at 50% opacity thanks to disabled:opacity-50.

Try it yourself

Edit and try

Add <code>hover:-translate-y-0.5</code> to the first button.

Test yourself

  1. What does hover:bg-sky-700 do?

    • Changes the background when the pointer hovers
    • Changes it always
    • Changes it on press
    • Hides the element
    Answer and explanation

    Correct answer: Changes the background when the pointer hovers

  2. Why do we sometimes prefer focus-visible over focus?

    • The indicator shows during keyboard navigation, not on every click
    • Faster
    • Doesn't work with buttons
    • Changes the color
    Answer and explanation

    Correct answer: The indicator shows during keyboard navigation, not on every click

  3. What does disabled:opacity-50 do?

    • Reduces the opacity of the disabled element
    • Disables the element
    • Removes the element
    • Changes the font
    Answer and explanation

    Correct answer: Reduces the opacity of the disabled element

  4. Which class slightly shrinks a button while pressed?

    • active:scale-95
    • hover:scale-95
    • focus:scale-0
    • pressed:shrink
    Answer and explanation

    Correct answer: active:scale-95

    active: applies during the press and scale-95 shrinks it to 95%.

  5. Why shouldn't hover be the only way to reveal information?

    • Because touch screens have no hover
    • Because hover is slow
    • Because hover disables colors
    • Because Tailwind does not support it
    Answer and explanation

    Correct answer: Because touch screens have no hover

    Touch users would miss the information, so provide an alternative.
