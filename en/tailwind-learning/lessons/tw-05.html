Sizing: Width and Height

w, h, size, max-w, min-h, fractions, and special values.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Width and Height

Same spacing scale: w-16 = 4rem. Fractions: w-1/2 w-2/3. Keywords: w-full w-screen w-fit w-auto. For a square use size-12 (width and height together).

Limits

max-w-sm|md|lg|xl|2xl… sets the maximum width of text content, min-h-screen gives a height of at least the screen, and aspect-video gives a 16/9 ratio.

Use max-w instead of a fixed w so the element adapts to small screens.

Code example

HTML code

<div class="space-y-3 p-4">
<div id="half" class="w-1/2 bg-sky-200 p-2">w-1/2</div>
<div class="size-16 bg-amber-300"></div>
<div id="mx" class="max-w-xs bg-slate-200 p-2">max-w-xs: never exceeds 20rem however large the screen gets.</div>
<div class="aspect-video w-48 bg-emerald-200"></div>
</div>

Understanding the code

size-16 gives a square element of 4rem × 4rem. aspect-video preserves the width-to-height ratio.

Test yourself

  1. What does w-1/2 mean?

    • Width of 50% of the parent
    • Width of 1 pixel
    • Half the height
    • Always half the screen
    Answer and explanation

    Correct answer: Width of 50% of the parent

  2. Which class makes width and height equal in a single line?

    • size-12
    • wh-12
    • square-12
    • box-12
    Answer and explanation

    Correct answer: size-12

  3. Why do we prefer max-w over a fixed w?

    • So the element shrinks on small screens
    • Because it is faster
    • Because it changes the color
    • No difference
    Answer and explanation

    Correct answer: So the element shrinks on small screens

  4. What does the class aspect-video give?

    • A 16/9 aspect ratio
    • Screen-sized height
    • 100% width
    • Video playback
    Answer and explanation

    Correct answer: A 16/9 aspect ratio

    aspect-video sets the element to a 16:9 ratio.

  5. Which class makes the height at least the screen height?

    • h-min
    • min-h-screen
    • max-h-full
    • h-fit
    Answer and explanation

    Correct answer: min-h-screen

    min-h-screen fills the screen while still allowing growth.
