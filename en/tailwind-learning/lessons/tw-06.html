Flexbox

Row and column layouts, alignment, and distribution.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

The Basics

flex for the container, flex-col for vertical direction, flex-wrap for wrapping, items-start|center|end|stretch for the cross axis, justify-start|center|between|around|evenly for the main axis, and gap-* for spacing.

On Items

flex-1 makes the item expand to fill the available space, shrink-0 prevents shrinking, plus grow, order-*, and ms-auto to push the item to the end.

flex + items-center + justify-between + gap covers most cases.

Code example

HTML code

<nav id="nav" class="flex items-center justify-between gap-4 bg-slate-900 px-4 py-3 text-white">
<span class="font-bold">FAYBIT</span>
<div class="flex gap-4 text-sm"><a href="#">Courses</a><a href="#">Blog</a></div>
<button class="rounded bg-sky-500 px-3 py-1 text-sm font-semibold">Sign in</button>
</nav>
<div class="mt-4 flex flex-col gap-2 p-4 sm:flex-row">
<div class="flex-1 bg-slate-100 p-3">Grows</div>
<div class="shrink-0 bg-slate-200 p-3">Fixed</div>
</div>

Understanding the code

The bar spreads the items to the edges and aligns them vertically. The second container is a column on small screens and a row from sm up.

Try it yourself

Edit and try

Make the bar <code>justify-center</code>, then change it back to <code>justify-between</code>.

Test yourself

  1. Which class vertically aligns items in a horizontal flex container?

    • items-center
    • justify-center
    • text-center
    • place-center only
    Answer and explanation

    Correct answer: items-center

  2. What does flex-1 do?

    • Makes the item expand to fill the available space
    • Fixes its width at 1px
    • Reverses the direction
    • Hides it
    Answer and explanation

    Correct answer: Makes the item expand to fill the available space

  3. What does sm:flex-row mean?

    • The direction becomes horizontal from the sm breakpoint and up
    • Always horizontal
    • Always vertical
    • Hidden at sm
    Answer and explanation

    Correct answer: The direction becomes horizontal from the sm breakpoint and up

  4. An element has items-center justify-between but nothing happens. What is the likely cause?

    • Forgetting the flex class on the container
    • A missing gap class
    • Using Tailwind v4
    • A missing shrink-0 class
    Answer and explanation

    Correct answer: Forgetting the flex class on the container

    Alignment classes do nothing until flex or grid is set on the container.

  5. How do you push the last item in a flex row to the end?

    • me-0
    • flex-1 only
    • ms-auto
    • shrink-0
    Answer and explanation

    Correct answer: ms-auto

    The auto margin absorbs the free space before the item.
