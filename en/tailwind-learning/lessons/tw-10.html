Backgrounds, Gradients, and Images

bg, bg-linear gradients, object-fit, and image filtering.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Gradients (v4)

In v4 gradients became: bg-linear-to-r from-indigo-500 to-purple-500 (instead of bg-gradient-to-r in v3). Middle stop: via-sky-500. There are also bg-radial and bg-conic.

Images

object-cover and object-contain control how an image fills its frame, object-center sets the position, rounded-full makes circular images, and blur-sm and grayscale add effects.

v4 gradients: bg-linear-to-{direction} with from/via/to.

Code example

HTML code

<div class="space-y-3 p-4">
<div id="grad" class="h-24 rounded-xl bg-linear-to-r from-indigo-500 via-sky-500 to-emerald-400"></div>
<div class="flex items-center gap-3">
<svg class="size-16 rounded-full bg-slate-200 object-cover" viewBox="0 0 10 10"><circle cx="5" cy="5" r="3" fill="#0b6b78"/></svg>
<p class="text-slate-700">Real images use <code>object-cover</code> inside a fixed-size frame.</p>
</div>
<div class="h-16 rounded-xl bg-slate-900 bg-radial from-sky-400/40 to-transparent"></div>
</div>

Understanding the code

The first gradient passes through three colors from left to right. The radial gradient bg-radial is available in v4.

Test yourself

  1. What is the syntax of a linear gradient in Tailwind v4?

    • bg-linear-to-r
    • bg-gradient-to-r only
    • gradient-right
    • linear-r
    Answer and explanation

    Correct answer: bg-linear-to-r

  2. What does object-cover do?

    • Fills the image frame, cropping the excess without distortion
    • Stretches the image in a distorted way
    • Hides the image
    • Repeats the image
    Answer and explanation

    Correct answer: Fills the image frame, cropping the excess without distortion

  3. Which classes set the start and end colors of a gradient?

    • from-* and to-*
    • start-* and end-*
    • bg-start and bg-end
    • color-1 and color-2
    Answer and explanation

    Correct answer: from-* and to-*

  4. A developer wrote bg-gradient-to-r and no gradient shows in v4. What is the fix?

    • bg-gradient-r
    • bg-grad-to-r
    • gradient-to-right
    • bg-linear-to-r
    Answer and explanation

    Correct answer: bg-linear-to-r

    The new v4 syntax is bg-linear-to-*.

  5. What is via-sky-500 for in a gradient?

    • A middle color stop between start and end
    • The start color
    • The end color
    • The element's border color
    Answer and explanation

    Correct answer: A middle color stop between start and end

    via adds a color in the middle between from and to.
