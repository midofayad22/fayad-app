Borders, Shadows, and Rings

border, rounded, shadow, ring, and outline (with the changes in version 4).

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Borders and Corners

border border-2 border-t border-slate-300 divide-y between items. Corners: rounded rounded-lg rounded-full.

Shadows and Rings

shadow-xs shadow-sm shadow-md shadow-lg. The ring ring-2 ring-sky-500 is drawn outside the element without affecting layout, and is common for focus states. In v4 the default ring is 1px wide, and to hide the default focus outline use outline-hidden (instead of the old outline-none) together with a visible alternative.

Don't hide the focus indicator without a visible alternative (ring) for accessibility.

Code example

HTML code

<div class="space-y-4 p-4">
<div id="b" class="rounded-lg border-2 border-sky-500 p-3">border-2 rounded-lg</div>
<div class="rounded-xl p-3 shadow-md">shadow-md</div>
<button class="rounded-lg bg-white px-4 py-2 ring-2 ring-sky-500 ring-offset-2">ring-2</button>
<ul class="divide-y divide-slate-200 rounded-lg border border-slate-200">
<li class="p-3">Item 1</li><li class="p-3">Item 2</li><li class="p-3">Item 3</li>
</ul>
</div>

Understanding the code

divide-y adds a dividing line between children without writing a border for each item. The ring does not change the button's dimensions because it is an outer shadow.

Test yourself

  1. What is the advantage of ring compared to border?

    • It does not affect the element's dimensions
    • Always faster
    • Colors the background
    • Works with text only
    Answer and explanation

    Correct answer: It does not affect the element's dimensions

  2. What does divide-y do?

    • Places a dividing line between child elements vertically
    • Splits the screen
    • Hides borders
    • Colors the background
    Answer and explanation

    Correct answer: Places a dividing line between child elements vertically

  3. What should you watch out for when hiding the default outline?

    • You must provide a visible alternative such as ring for focus
    • Nothing
    • The button breaks
    • The font changes
    Answer and explanation

    Correct answer: You must provide a visible alternative such as ring for focus

  4. Which class replaced outline-none in v4?

    • outline-off
    • outline-0-none
    • outline-hidden
    • focus-none
    Answer and explanation

    Correct answer: outline-hidden

    outline-hidden hides the default outline while keeping it for high contrast modes.

  5. What is the default ring width in v4?

    • 1px
    • 3px
    • 0px
    • 5px
    Answer and explanation

    Correct answer: 1px

    In v4 the default is 1px, and ring-2 gives a thicker ring.
