Responsive Design

mobile-first, breakpoints, and variants like md: and max-md:.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

mobile-first

A class without a prefix applies to all screens, and a prefix applies from that breakpoint and up: sm ≥640px, md ≥768px, lg ≥1024px, xl ≥1280px, 2xl ≥1536px. Example: text-sm md:text-lg.

Ranges and Containers

max-md:hidden hides below md. md:max-lg:flex targets a specific range. And @container with @md: makes a component respond to its container's size rather than the screen's.

Design for the phone first, then add md: and lg: to scale up.

Code example

HTML code

<div class="p-4">
<h1 id="r" class="text-lg font-bold md:text-3xl lg:text-5xl">Responsive heading</h1>
<div class="mt-3 grid grid-cols-1 gap-3 sm:grid-cols-2 lg:grid-cols-4">
<div class="bg-sky-100 p-3">1</div><div class="bg-sky-100 p-3">2</div>
<div class="bg-sky-100 p-3">3</div><div class="bg-sky-100 p-3">4</div>
</div>
<p class="mt-3 hidden text-slate-600 md:block">This paragraph appears from md and up.</p>
<div class="@container mt-3"><div class="grid grid-cols-1 gap-2 @md:grid-cols-2"><div class="bg-amber-100 p-2">A</div><div class="bg-amber-100 p-2">B</div></div></div>
</div>

Understanding the code

Resize the browser window to see the heading size and the number of columns change. The @container responds to its own width, not the screen width.

    • lg size always
    • Hides the text

  2. How do we hide an element on phones and show it from md?

    • hidden md:block
    • md:hidden
    • block md:none
    • invisible md:visible
    Answer and explanation

    Correct answer: hidden md:block

  3. What is @container useful for?

    • Making a component respond to its container's width
    • Changing the page color
    • Creating a library
    • Loading fonts
    Answer and explanation

    Correct answer: Making a component respond to its container's width

  4. What does max-md:hidden do?

    • Hides the element on screens smaller than md
    • Hides it from md and up
    • Always hides it
    • Hides it on hover
    Answer and explanation

    Correct answer: Hides the element on screens smaller than md

    The max- prefix applies below the given breakpoint.

  5. The screen is 500px with text-sm md:text-lg. What is the font size?

    • text-lg
    • text-sm
    • text-base
    • text-md
    Answer and explanation

    Correct answer: text-sm

    md only starts at 768px, so the base class stays.
