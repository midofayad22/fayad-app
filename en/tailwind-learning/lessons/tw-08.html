Positioning, the Container, and Layer Order

relative, absolute, sticky, inset, z-index, and overflow.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Position

relative absolute fixed sticky with inset-0 top-0 start-0 end-4 (logical). An absolute element is positioned relative to its nearest relative ancestor.

z-index and Overflow

z-10 z-50 for layer order. overflow-hidden and overflow-auto clip or scroll the content. container sets a maximum width per breakpoint, and is usually used with mx-auto px-4.

Make the parent relative before placing an absolute element inside it.

Code example

HTML code

<div class="container mx-auto px-4 py-6">
<div id="wrap" class="relative h-32 overflow-hidden rounded-xl bg-slate-200">
<span class="absolute end-3 top-3 rounded-full bg-rose-500 px-2 py-1 text-xs font-bold text-white">New</span>
<div class="absolute inset-x-0 bottom-0 bg-black/60 p-2 text-sm text-white">Bottom bar</div>
</div>
<div class="sticky top-0 z-10 mt-4 bg-white p-2 shadow">Sticky bar</div>
</div>

Understanding the code

The badge and the bottom bar are absolutely positioned inside the relative parent. inset-x-0 stretches the bar horizontally. overflow-hidden clips whatever spills past the rounded corners.

Test yourself

  1. What makes an absolute element position itself inside its parent?

    • The parent being relative
    • The parent being flex
    • Having z-10
    • Having gap
    Answer and explanation

    Correct answer: The parent being relative

  2. What does inset-0 do?

    • top/right/bottom/left = 0
    • Adds borders
    • Changes the color
    • Hides the element
    Answer and explanation

    Correct answer: top/right/bottom/left = 0

  3. What is the purpose of overflow-hidden together with rounded?

    • Clipping content that extends beyond the rounded corners
    • Enlarging the image
    • Animating the element
    • Always disabling scrolling only
    Answer and explanation

    Correct answer: Clipping content that extends beyond the rounded corners

  4. What does the container class do in Tailwind?

    • Sets a max width at each breakpoint
    • Centers the content automatically
    • Adds 1rem of padding
    • Makes the element position fixed
    Answer and explanation

    Correct answer: Sets a max width at each breakpoint

    It does not center by itself, so add mx-auto and px-4.

  5. Two overlapping elements, z-10 and z-50. Which one is on top?

    • z-10
    • z-50
    • Both are on the same level
    • By alphabetical order
    Answer and explanation

    Correct answer: z-50

    The higher z-index value sits in the front layer.
