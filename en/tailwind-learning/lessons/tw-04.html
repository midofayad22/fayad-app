Typography

Font sizes, weights, line height, alignment, and truncation.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

The Basics

  • Size: text-xs text-sm text-base text-lg … text-9xl.
  • Weight: font-light font-normal font-semibold font-bold.
  • Line height: leading-tight leading-relaxed or leading-7.
  • Letter spacing: tracking-wide.
  • Alignment: text-start text-center text-end.

Useful Utilities

truncate cuts text with an ellipsis, line-clamp-2 limits to a set number of lines, text-balance balances headings, plus uppercase, italic, underline, and decoration-sky-500.

Combine size, weight, and line height to get a clear visual hierarchy.

Code example

HTML code

<article class="max-w-md p-4">
<h1 id="h" class="text-3xl font-bold leading-tight tracking-tight text-slate-900">Big main heading</h1>
<p class="mt-2 text-base leading-relaxed text-slate-600">A paragraph with base size and comfortable line height that makes long reading easier.</p>
<p class="mt-2 line-clamp-1 text-sm text-slate-500">This very long text will be cut off at a single line no matter how long it is, followed by an ellipsis showing there is more text.</p>
<a class="mt-2 inline-block text-sky-700 underline decoration-sky-300 underline-offset-4" href="#">Underlined link</a>
</article>

Understanding the code

text-3xl sets the size (1.875rem) and its line height along with it. line-clamp-1 cuts off at one line.

Try it yourself

Edit and try

Change the heading to <code>text-5xl</code> and add <code>uppercase</code> to the first paragraph.

Test yourself

  1. Which class cuts text to a single line and adds an ellipsis?

    • truncate
    • line-through
    • text-wrap
    • break-all
    Answer and explanation

    Correct answer: truncate

  2. What does leading-relaxed do?

    • Increases line height for comfortable reading
    • Enlarges the font
    • Changes the color
    • Reduces the weight
    Answer and explanation

    Correct answer: Increases line height for comfortable reading

  3. Which class makes the font bold?

    • font-bold
    • text-bold
    • weight-700
    • bold
    Answer and explanation

    Correct answer: font-bold

  4. Which class clamps text to two lines with an ellipsis?

    • truncate-2
    • line-clamp-2
    • text-2
    • max-lines-2
    Answer and explanation

    Correct answer: line-clamp-2

    line-clamp-N sets the number of visible lines.

  5. Which alignment class follows the language direction?

    • text-left
    • text-justify-fixed
    • text-start
    • text-top
    Answer and explanation

    Correct answer: text-start

    start and end are logical and flip automatically in RTL.
