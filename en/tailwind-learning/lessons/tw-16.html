Arbitrary Values

When the built-in scale isn't enough: w-[17rem], bg-[#...], and full properties.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Square Brackets

w-[17rem] top-[117px] bg-[#0b6b78] grid-cols-[1fr_2fr] (the underscore means a space). For variables in v4: w-(--sidebar-width).

Arbitrary Properties and Variants

[mask-type:luminance] is a full CSS property. And arbitrary variants: [&>p]:mt-2 and [@media(min-width:900px)]:flex. Use them sparingly: if a value repeats, add it to @theme.

A repeated value belongs in @theme; arbitrary values are for exceptional cases.

Code example

HTML code

<div class="space-y-3 p-4" style="--sidebar-width: 12rem">
<div id="w" class="w-[17rem] rounded bg-[#0b6b78] p-2 text-white">w-[17rem] bg-[#0b6b78]</div>
<div class="w-(--sidebar-width) rounded bg-slate-200 p-2">w-(--sidebar-width)</div>
<div class="grid grid-cols-[1fr_2fr] gap-2"><div class="bg-amber-100 p-2">1fr</div><div class="bg-amber-200 p-2">2fr</div></div>
<div class="[&>p]:mt-2 rounded border p-2"><p>First paragraph</p><p>Second paragraph</p></div>
</div>

Understanding the code

Brackets allow values that aren't in the scale. The w-(--sidebar-width) syntax reads a CSS variable directly (v4).

Test yourself

  1. What does the underscore mean inside grid-cols-[1fr_2fr]?

    • A space between the two values
    • A minus
    • A comment
    • An error
    Answer and explanation

    Correct answer: A space between the two values

  2. When do you prefer @theme over arbitrary values?

    • When the value repeats in more than one place
    • When it is used once
    • When writing text
    • Never prefer it
    Answer and explanation

    Correct answer: When the value repeats in more than one place

  3. What is the syntax for using a CSS variable in v4?

    • w-(--my-var)
    • w-$my-var
    • w-@my-var
    • w-var
    Answer and explanation

    Correct answer: w-(--my-var)

  4. What does the class w-[17rem] do?

    • Sets the width to exactly 17rem
    • Sets the width to 17 items
    • Adds 17rem of padding
    • Rejects the value
    Answer and explanation

    Correct answer: Sets the width to exactly 17rem

    Square brackets accept any CSS value directly.

  5. What does the class [&>p]:mt-2 do?

    • Adds a top margin to direct-child paragraphs
    • Adds a margin only to the element itself
    • Deletes paragraphs
    • Hides paragraphs
    Answer and explanation

    Correct answer: Adds a top margin to direct-child paragraphs

    An arbitrary variant writes a custom CSS selector before the utility.
