Customizing with @theme

Define your colors, fonts, and breakpoints as variables that automatically generate classes.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

From config to CSS

In v4 customization happens inside CSS via @theme: --color-brand: #0b6b78; automatically generates bg-brand, text-brand, and border-brand. Likewise --font-display, --breakpoint-3xl, --spacing, and --radius-card.

Colors with Shades

Define --color-brand-500 and --color-brand-700 to get classes with shades. To remove the default color palette: --color-*: initial;.

Every variable in @theme automatically generates its corresponding utility classes.

Code example

HTML code

<style type="text/tailwindcss">
@theme {
--color-brand-500: #0b6b78;
--color-brand-700: #095561;
--radius-card: 1.25rem;
--breakpoint-3xl: 100rem;
}
</style>
<div class="p-4">
<button id="b" class="rounded-card bg-brand-500 px-5 py-2 font-semibold text-white hover:bg-brand-700">Brand-colored button</button>
<p class="mt-3 text-brand-700">Text in the dark brand color.</p>
</div>

Understanding the code

The --color-brand-* variables generated the classes bg-brand-500, text-brand-700, and hover:bg-brand-700, and the --radius-card variable generated rounded-card.
