Forms and Field States

Tailwind doesn't style forms by default: design the fields, focus states, and error states yourself.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Field Basics

Preflight removes default styling, so write: w-full rounded-lg border border-slate-300 px-3 py-2 focus:border-sky-500 focus:ring-2 focus:ring-sky-200 focus:outline-hidden. For placeholder text use placeholder:text-slate-400.

States

invalid:border-rose-500 with required, user-invalid: (shown after the user interacts), disabled:bg-slate-100, and accent-sky-600 for native checkboxes.

Tie every field to a label, and give focus a clear visual indicator.

Code example

HTML code

<form class="max-w-sm space-y-4 p-4" onsubmit="return false">
<div>
<label for="mail" class="mb-1 block text-sm font-medium text-slate-700">Email</label>
<input id="mail" type="email" required placeholder="name@example.com"
class="w-full rounded-lg border border-slate-300 px-3 py-2 placeholder:text-slate-400 focus:border-sky-500 focus:ring-2 focus:ring-sky-200 focus:outline-hidden user-invalid:border-rose-500">
</div>
<label class="flex items-center gap-2 text-sm"><input type="checkbox" class="size-4 accent-sky-600"> Remember me</label>
<button class="w-full rounded-lg bg-sky-600 py-2 font-semibold text-white hover:bg-sky-700">Submit</button>
</form>

Understanding the code

The field gets a blue ring on focus, and a red border when an invalid email is entered after interaction (user-invalid).

Test yourself

  1. Why do we need to style fields manually?

    • Because Preflight removes the browser's default styles
    • Because Tailwind doesn't support fields
    • Because fields are removed
    • We don't need to
    Answer and explanation

    Correct answer: Because Preflight removes the browser's default styles

  2. What is user-invalid useful for?

    • It shows the error state after the user interacts
    • It disables the field
    • It deletes the field
    • It changes the language
    Answer and explanation

    Correct answer: It shows the error state after the user interacts

  3. What is the requirement when hiding a field's outline?

    • Provide a visible alternative such as ring
    • No requirement
    • Delete the label
    • Use a div
    Answer and explanation

    Correct answer: Provide a visible alternative such as ring

  4. Which class colors placeholder text?

    • text-placeholder-slate
    • hover:text-slate-400
    • placeholder:text-slate-400
    • ph-slate-400
    Answer and explanation

    Correct answer: placeholder:text-slate-400

    The placeholder: prefix targets the hint text inside the field.

  5. Which class changes the native checkbox color?

    • bg-sky-600
    • accent-sky-600
    • check-sky-600
    • ring-checkbox
    Answer and explanation

    Correct answer: accent-sky-600

    accent-* colors native form controls without rebuilding them.
