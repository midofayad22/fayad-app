Transitions, Transforms, and Animation

transition, transform, and animate for light, smooth motion.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Transitions

transition (or transition-colors) with duration-300, ease-in-out, and delay-100. Add them on the base state, not only on hover.

Transforms and Animations

scale-105 rotate-6 -translate-y-1 translate-x-2. Ready-made animations: animate-spin animate-pulse animate-bounce animate-ping. Respect users who prefer reduced motion with motion-safe: and motion-reduce:.

Wrap animations in motion-safe: to respect the reduced-motion preference.

Code example

HTML code

<div class="flex items-center gap-4 p-6">
<div id="card" class="rounded-xl bg-white p-4 shadow transition duration-300 ease-in-out hover:-translate-y-1 hover:shadow-lg">Hover here</div>
<div class="size-8 rounded-full border-4 border-sky-200 border-t-sky-600 motion-safe:animate-spin"></div>
<div class="size-4 rounded-full bg-emerald-500 motion-safe:animate-pulse"></div>
</div>

Understanding the code

The card rises slightly and gains a deeper shadow smoothly on hover. The circle spins only if the user has not enabled "reduce motion".

Try it yourself

Edit and try

Change <code>duration-300</code> to <code>duration-700</code> and compare the speed.

Test yourself

  1. Which class sets the transition duration?

    • duration-300
    • time-300
    • speed-300
    • delay-only
    Answer and explanation

    Correct answer: duration-300

  2. Why do we use motion-safe:?

    • To respect the user's preference for reduced motion
    • To speed up the animation
    • To hide the element
    • To change the color
    Answer and explanation

    Correct answer: To respect the user's preference for reduced motion

  3. What does hover:-translate-y-1 do?

    • Lifts the element slightly on hover
    • Hides it
    • Flips it
    • Rotates it
    Answer and explanation

    Correct answer: Lifts the element slightly on hover

  4. Where do you put the transition class so the motion works both ways?

    • On the element's base state
    • Only inside hover
    • Only on body
    • In the head tag
    Answer and explanation

    Correct answer: On the element's base state

    Placing it on the base animates both entering and leaving the state.

  5. Which class suits a spinning loading indicator?

    • animate-ping
    • animate-bounce
    • animate-pulse-fast
    • animate-spin
    Answer and explanation

    Correct answer: animate-spin

    animate-spin rotates continuously, and we wrap it in motion-safe.
