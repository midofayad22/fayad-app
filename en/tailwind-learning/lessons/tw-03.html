Colors and Opacity

The color palette with shades from 50 to 950 and how to control opacity.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

The Palette

Each color has shades: 50, 100, 200 … 900, 950. The syntax is bg-{color}-{shade}, plus text-, border-, ring-, and fill-. For example bg-sky-600 and text-slate-700. Special colors: white black transparent current.

Opacity

Add /opacity after the color: bg-black/50 and text-sky-700/80. For the whole element use opacity-50. Choose shades that are far apart (such as 50 for the background and 800 for the text) to ensure contrast.

bg-sky-600/50 means the same color at 50% opacity. Make sure there is enough contrast between text and background.

Code example

HTML code

<div class="space-y-3 p-4">
<div class="rounded bg-sky-100 p-3 text-sky-900">Light background with dark text</div>
<div class="rounded bg-slate-800 p-3 text-white">Dark background with white text</div>
<div class="rounded bg-black/10 p-3">Black at 10% opacity</div>
<div id="o" class="rounded bg-emerald-500 p-3 opacity-50">opacity-50</div>
</div>

Understanding the code

Shades close to 50 are light, and those close to 900 are dark. /10 changes only the color's opacity, whereas opacity-50 affects the element and its content.

    Correct answer: A black background at 50% opacity

    Correct answer: bg-slate-800 with text-white

  3. What is the difference between bg-black/50 and opacity-50?

    • The first affects only the background color, and the second affects the whole element

    Answer and explanation

    Correct answer: The first affects only the background color, and the second affects the whole element

  4. What does text-sky-700/80 mean?

    • Text 80px in size
    • Text at shade 780
    • A maximum of 80 characters
    Answer and explanation

    Correct answer: Text in sky-700 at 80% opacity

    The number after the slash is the opacity percentage.

  5. What is the darkest shade in the default color scale?

    • 50
    • 500
    • 1000
    • 950
    Answer and explanation

    Correct answer: 950

    The shades run from 50 to 950.
