@apply, @layer, and Reuse

When to extract a component, and how to write custom classes with @apply.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Best: Components

The first solution to repetition is a component (a template or function in your framework), not a new CSS class. When no component is available (such as in raw HTML), use @layer components with @apply.

The Syntax

@layer components { .btn { @apply rounded-lg px-4 py-2 font-semibold; } }. Keep these classes few, or you lose the benefit of Utility-First.

Use @apply with caution: components first, then custom classes when necessary.

Code example

HTML code

<style type="text/tailwindcss">
@layer components {
.btn {
@apply rounded-lg px-4 py-2 font-semibold transition;
}
.btn-primary {
@apply bg-sky-600 text-white hover:bg-sky-700;
}
}
</style>
<div class="flex gap-3 p-4">
<button id="x" class="btn btn-primary">Primary</button>
<button class="btn bg-slate-200 text-slate-800 hover:bg-slate-300">Secondary</button>
</div>

Understanding the code

The btn and btn-primary classes bundled Tailwind utilities under a single name. They can be overridden with direct utility classes when needed, as in the second button.

  3. What does @apply do?

    • Inserts Tailwind utilities into a custom CSS rule
    • Loads a font
    • Creates a React component
    • Deletes utilities
    Answer and explanation

    Correct answer: Inserts Tailwind utilities into a custom CSS rule

  4. What is the downside of overusing @apply classes?

    • You lose the Utility-First benefit
    • Colors stop working
    • The browser blocks loading
    • They can't be used in v4
    Answer and explanation

    Correct answer: You lose the Utility-First benefit

    You go back to naming classes and managing a CSS file.

  5. Where do you write an @apply rule for a custom button?

    • Inside a CSS rule within @layer components
    • Inside an HTML class attribute
    • Inside a script tag
    • In the file name
    Answer and explanation

    Correct answer: Inside a CSS rule within @layer components

    @apply is used inside CSS rules, not inside HTML.
