Introduction: The Utility-First Philosophy and Setup Options

What Tailwind CSS is, why we write small classes directly in HTML, and how to get started.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Utility-First

Instead of writing a CSS file and naming classes, you build the interface from small single-purpose classes: p-4 padding, text-lg font size, bg-sky-600 background. Each class maps to roughly one CSS property, so designs stay consistent without leaving the HTML file.

How to Get Started (Version 4)

This course is based on Tailwind CSS v4 (version 4.3.3 is installed in the preview). In real projects you install Tailwind and add the line @import "tailwindcss"; to your CSS file (via the Vite plugin or the CLI). Here, the preview uses the browser build, which converts classes to CSS on the fly. It is for experimenting and learning only, not for production.

One small class per purpose, composed together in HTML. Version 4 starts with @import "tailwindcss".

Code example

HTML code

<div id="card" class="m-6 max-w-sm rounded-xl bg-white p-6 shadow-lg">
<h1 class="text-xl font-bold text-slate-900">First Tailwind card</h1>
<p class="mt-2 text-slate-600">Without a single line of hand-written CSS.</p>
<button class="mt-4 rounded-lg bg-sky-600 px-4 py-2 font-semibold text-white">Start</button>
</div>

Understanding the code

p-6 is 1.5rem of padding, rounded-xl gives rounded corners, shadow-lg a large shadow, mt-2 a top margin, and px-4 py-2 horizontal and vertical padding for the button.

  4. Which class gives a sky-blue background at shade 600?

    • bg-sky-600
    • text-sky-600
    • sky-600-bg
    • background-sky:600
    Answer and explanation

    Correct answer: bg-sky-600

    The syntax is bg-{color}-{shade}.

  5. Why does the design stay consistent with Tailwind classes?

    • Because Tailwind forbids changing colors

    • Because every page needs a different CSS file
    • Because classes use random names
    Answer and explanation

    Correct answer: Because each class maps to about one property with values from a shared scale

    Values come from a fixed scale, so spacing and sizes look alike everywhere.
