Dark Mode

dark: in both forms (system-based or class-based) and designing colors that adapt to both modes.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Default

The dark: prefix applies by default when the system prefers dark mode (prefers-color-scheme: dark).

Manual Control

For a manual toggle with the .dark class, define the variant: @custom-variant dark (&:where(.dark, .dark *)); inside <style type="text/tailwindcss"> (or a CSS file). Then add the dark class to the parent to enable it.

Write colors for both modes together: bg-white dark:bg-slate-900.

Code example

HTML code

<style type="text/tailwindcss">
@custom-variant dark (&:where(.dark, .dark *));
</style>
<div class="dark">
<div id="panel" class="rounded-xl bg-white p-4 text-slate-900 dark:bg-slate-900 dark:text-white">
<h1 class="font-bold">Dark mode panel</h1>
<p class="text-slate-600 dark:text-slate-300">The dark class on the parent enabled dark: for the children.</p>
</div>
</div>
<div class="mt-3 rounded-xl bg-white p-4 text-slate-900 dark:bg-slate-900 dark:text-white">Without the dark class: appears light</div>

Understanding the code

After defining @custom-variant, dark: is tied to the presence of the dark class rather than the system setting. The first panel is inside .dark, so it appears dark.

Try it yourself

Edit and try

Remove the <code>dark</code> class from the parent and notice the panel return to light mode.

Test yourself

  1. When does dark: apply by default?

    • When the system prefers dark mode
    • Always
    • Never
    • In print only
    Answer and explanation

    Correct answer: When the system prefers dark mode

  2. How do we tie dark: to a manual class?

    • @custom-variant dark (&:where(.dark, .dark *));
    • dark: true
    • data-dark
    • <dark>
    Answer and explanation

    Correct answer: @custom-variant dark (&:where(.dark, .dark *));

  3. Which pair supports both modes?

    • bg-white dark:bg-slate-900
    • bg-white only
    • dark:bg-white only
    • text-black only
    Answer and explanation

    Correct answer: bg-white dark:bg-slate-900

  4. A user's system is in light mode. What happens to dark: classes by default?

    • They are not applied
    • They always apply
    • They apply at half strength
    • They cause an error
    Answer and explanation

    Correct answer: They are not applied

    dark: follows prefers-color-scheme unless a manual variant is defined.

  5. After defining @custom-variant with a dark class, where do you put the dark class to enable the mode?

    • On each child element alone
    • Only inside a JavaScript file
    • On a parent element such as html
    • In the title tag
    Answer and explanation

    Correct answer: On a parent element such as html

    Children inherit the activation from the parent that carries dark.
