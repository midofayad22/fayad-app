Grid

Two-dimensional grids with columns, rows, and cell spanning.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Columns and Rows

grid grid-cols-3 gap-4 gives three equal columns. col-span-2 spans two columns, and row-span-2 two rows. Responsive automatic columns: grid-cols-[repeat(auto-fit,minmax(10rem,1fr))].

Alignment

place-items-center centers cells, plus justify-items and items-*, and auto-rows-fr for rows of equal height.

grid-cols-1 sm:grid-cols-2 lg:grid-cols-4 is a common pattern for a responsive grid.

Code example

HTML code

<div id="g" class="grid grid-cols-2 gap-3 p-4 md:grid-cols-4">
<div class="col-span-2 bg-sky-200 p-4">col-span-2</div>
<div class="bg-sky-100 p-4">1</div>
<div class="bg-sky-100 p-4">2</div>
<div class="bg-sky-100 p-4">3</div>
<div class="bg-sky-100 p-4">4</div>
<div class="col-span-2 bg-sky-200 p-4 md:col-span-4">Full width from md</div>
</div>

Understanding the code

On small screens there are two columns, and from md up there are four. The last item spans all four columns with md:col-span-4.

Try it yourself

Edit and try

Change <code>md:grid-cols-4</code> to <code>md:grid-cols-3</code> and watch the items redistribute.

Test yourself

  1. Which class creates three equal columns?

    • grid grid-cols-3
    • grid-3
    • cols-3
    • flex-3
    Answer and explanation

    Correct answer: grid grid-cols-3

  2. What does col-span-2 do?

    • Makes the cell span two columns
    • Doubles the number of columns
    • Hides two columns
    • Changes the borders
    Answer and explanation

    Correct answer: Makes the cell span two columns

  3. What is the purpose of gap in grid?

    • The space between cells
    • The color of the cells
    • The number of rows
    • The page width
    Answer and explanation

    Correct answer: The space between cells

  4. The screen is 800px with grid-cols-1 sm:grid-cols-2 lg:grid-cols-4. How many columns show?

    • 2
    • 1
    • 4
    • 3
    Answer and explanation

    Correct answer: 2

    sm applies from 640px, while lg only starts at 1024px.

  5. Which class centers cell content both ways in a grid?

    • items-grid
    • place-items-center
    • justify-center-all
    • grid-center
    Answer and explanation

    Correct answer: place-items-center

    place-items-center combines align-items and justify-items.
