Selecting Elements

Learn the basic ways to select HTML elements using JavaScript.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Code example

JavaScript code

const title =
document.querySelector("h1");
document.getElementById("jsResult").textContent =
title.textContent;

Understanding the code

querySelector() selects the first element that matches a given CSS Selector.

getElementById() selects an element by its ID value.

Selecting elements is the first step before modifying them or working with them.

You can use Selectors such as h1, .class, and #id.

Test yourself

  1. Which Method uses a CSS Selector to select an element?

    • querySelector()
    • selectElement()
    • getCSS()
    • findCSS()
    Answer and explanation

    Correct answer: querySelector()

  2. What does getElementById() use?

    • The element's ID
    • A CSS name
    • The file name
    • The browser name
    Answer and explanation

    Correct answer: The element's ID

  3. What does querySelector() return when more than one element matches?

    • The first matching element
    • All elements
    • Only the last element
    • Nothing
    Answer and explanation

    Correct answer: The first matching element

  4. What is wrong with this code? document.getElementById("#title")

    • Nothing, the # sign is always required
    • getElementById requires a full CSS Selector
    • It returns an array instead of an element
    • getElementById takes the id alone without #, so it returns null
    Answer and explanation

    Correct answer: getElementById takes the id alone without #, so it returns null

    getElementById looks for an id matching the text exactly, and no id starts with #, so it returns null. The # sign is used with querySelector.

  5. A page has three elements with the class item. What does document.querySelectorAll(".item").length return?

    • 3
    • 1
    • undefined
    • 0
    Answer and explanation

    Correct answer: 3

    querySelectorAll returns a NodeList of all matching elements, which has a length of 3. querySelector returns only the first match.
