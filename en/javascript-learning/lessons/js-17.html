Changing Content

Learn how JavaScript changes the text and content inside HTML elements.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Code example

JavaScript code

const title =
document.querySelector("h1");
title.textContent = "Hello from JavaScript";
document.getElementById("jsResult").textContent =
title.textContent;

Understanding the code

textContent lets you read or change the text inside an element.

It can be used to update page content based on user interaction or data.

When a new value is assigned to textContent, the text on the page updates immediately.

This is one of the most commonly used DOM operations.

  1. Which Property changes the text inside an element?

    • textContent
    • textChange
    • contentText
    • changeText
    Answer and explanation

    Correct answer: textContent

  2. What happens when you write element.textContent = "Hello"?

    • The text inside the element changes
    • JavaScript is deleted
    • Only CSS changes
    • An Array is created
    Answer and explanation

    Correct answer: The text inside the element changes

  3. Can textContent be used to read text?

    • Yes
    • No
    • Only inside CSS
    • Only inside HTML
    Answer and explanation

    Correct answer: Yes

  4. You assign to textContent a string containing HTML markup such as a b element. How does it appear on the page?

    • As literal text exactly as written, so the markup itself is visible
    • As bold text
    • Nothing appears
    • It throws a syntax error
    Answer and explanation

    Correct answer: As literal text exactly as written, so the markup itself is visible

    textContent treats the value as plain text and does not parse it as HTML, so the markup shows as written. This makes it safer for displaying user-provided text.

  5. What is wrong with this code? document.querySelector("#msg").textContent("Hi");

    • textContent is a property, not a function; the correct form is textContent = "Hi"
    • Only getElementById may be used
    • Text cannot be written inside an element
    • The # sign is not allowed in querySelector
    Answer and explanation

    Correct answer: textContent is a property, not a function; the correct form is textContent = "Hi"

    textContent is a property assigned with =, and calling it with parentheses throws a TypeError because it is not a function. The # sign is correct with querySelector.
