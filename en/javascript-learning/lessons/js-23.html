Promises

Learn how Promises represent the result of an asynchronous operation that may succeed or fail.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Code example

JavaScript code

const promise = new Promise((resolve) => {
resolve("The operation succeeded");
});
promise.then((result) => {
document.getElementById("jsResult").textContent =
result;
});

Understanding the code

A Promise represents the future result of an asynchronous operation.

The operation can be in a Pending, Fulfilled, or Rejected state.

resolve is used to signal that the operation succeeded.

then() is used to handle the result when the Promise succeeds.

  1. What does a Promise represent?

    • The future result of an asynchronous operation
    • An HTML element
    • A CSS color

  2. What does Fulfilled mean?

    • The operation succeeded
    • The operation has only started
    • The operation failed
    • The Promise was deleted
    Answer and explanation

    Correct answer: The operation succeeded

  3. Which Method is used to handle a Promise's success?

    • then()
    • success()
    • doneOnly()
    • resolveThen()
    Answer and explanation

    Correct answer: then()

  4. What does this code print? Promise.resolve(1).then(v => v + 1).then(v => console.log(v));

    • 1
    • 2
    • undefined
    • Promise
    Answer and explanation

    Correct answer: 2

    The value returned from the first then becomes the value of the next promise, so 2 reaches the second then. That is promise chaining.

  5. What does this code print? Promise.reject("x").then(() => console.log("ok")).catch(e => console.log("caught", e));

    • ok
    • caught x
    • ok then caught x
    • Nothing, with an unhandled error
    Answer and explanation

    Correct answer: caught x

    The promise is rejected, so then is skipped and the rejection travels down to the nearest catch in the chain. Only caught x is printed.
