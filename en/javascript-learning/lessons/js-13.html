Objects

Learn how Objects store related data using Properties and Values.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Code example

JavaScript code

const user = {
name: "FAYBIT",
age: 20,
student: true
};
document.getElementById("jsResult").textContent =
user.name;

Understanding the code

An Object is used to group related data in a single structure.

An Object contains Properties, and each Property has a value.

In the example, name, age, and student are Properties.

You can access a Property using dot notation, such as user.name.

  2. How do you access name inside user?

    Answer and explanation

    Correct answer: user.name

  3. What is name in user.name?

    • Property
    • Loop
    • Function
    • Array
    Answer and explanation

    Correct answer: Property

  4. What does this code print? const u = { name: "A" }; const key = "name"; console.log(u.key, u[key]);

    • A and A
    • undefined and A
    • name and A
    • A and undefined
    Answer and explanation

    Correct answer: undefined and A

    u.key looks for a property literally named key and does not find it. Brackets evaluate the variable first, so u[key] becomes u["name"].

  5. What does this code print? const u = { name: "A" }; console.log(u.age);

    • A ReferenceError
    • null
    • 0
    • undefined
    Answer and explanation

    Correct answer: undefined

    Reading a missing property from an object does not throw; it returns undefined. An error appears only when reading an undeclared variable or accessing a property of undefined.
