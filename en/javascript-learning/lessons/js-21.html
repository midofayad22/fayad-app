Modules

Learn how to split JavaScript into separate files using export and import.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Code example

JavaScript code

// math.js
export function add(a, b) {
return a + b;
}
// app.js
import { add } from "./math.js";
document.getElementById("jsResult").textContent =
add(5, 3);

Understanding the code

Modules let you split a program into separate, organized files.

export makes a value or Function available to other files.

import is used to bring in what was exported from another Module.

Using Modules helps organize large projects.

  1. Why do we use Modules?

    • To split and organize code across multiple files
    • To change CSS colors
    • To replace HTML
    • To create images
    Answer and explanation

    Correct answer: To split and organize code across multiple files

  2. Which keyword is used to export a Function?

    • export
    • send
    • public
    • share
    Answer and explanation

    Correct answer: export

  3. Which keyword is used to import a value?

    • import
    • include
    • requireOnly
    • load
    Answer and explanation

    Correct answer: import

  4. The file contains export default add;. Which import is correct?

    • import { add } from "./math.js";
    • import add from "./math.js";
    • import * add from "./math.js";
    • require add from "./math.js";
    Answer and explanation

    Correct answer: import add from "./math.js";

    A default export is imported without braces under any name you choose. Braces are for named exports.

  5. We declared const secret = 1 in a module file without export. Can another file read it?

    • Yes, because it is a global variable
    • Yes, if we just write import secret
    • Yes, but read-only
    • No, everything in a module is private unless exported with export
    Answer and explanation

    Correct answer: No, everything in a module is private unless exported with export

    A module has its own scope, so its variables do not leak into the global scope. Others can see only what is explicitly exported, which is a key benefit of modules.
