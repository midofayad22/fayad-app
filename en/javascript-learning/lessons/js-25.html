Error Handling

Learn how to handle errors using try, catch, and finally.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Code example

JavaScript code

try {
const result = unknownVariable;
document.getElementById("jsResult").textContent =
result;
} catch (error) {
document.getElementById("jsResult").textContent =
"An error occurred";
}

Understanding the code

Errors can occur while JavaScript is running for various reasons.

try contains the code that might produce an error.

catch receives the error and lets us handle it instead of letting the program stop unexpectedly.

finally can be used to run code whether or not an error occurred.

  1. Which Block is used to handle an error?

    • errorBlock

  2. Where do we put code that might produce an error?

    Answer and explanation

  3. When can finally be used?

    • To run code after try/catch finishes, whether or not an error occurred
    • Only when an error occurs
    • Only when try succeeds
    • To create a Function
    Answer and explanation

    Correct answer: To run code after try/catch finishes, whether or not an error occurred

  4. What does this code print? try { JSON.parse("{bad"); } catch (e) { console.log("err"); } finally { console.log("done"); }

    • done only
    • err only
    • done then err
    • err then done
    Answer and explanation

    Correct answer: err then done

    JSON.parse throws because the text is invalid, so catch runs and then finally always runs last. The order is err then done.

  5. What does this code print? function f() { try { return 1; } finally { console.log("f"); } } console.log(f());

    • 1 only
    • f then 1
    • 1 then f
    • f only
    Answer and explanation

    Correct answer: f then 1

    finally runs even when try contains a return, and it runs before the function actually exits. So f is printed first and then the returned 1.
