Variables

Learn how variables store values and data inside a JavaScript program.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Code example

JavaScript code

let name = "FAYBIT";
let age = 20;
document.getElementById("jsResult").textContent =
name + " - " + age;

Understanding the code

let is used to create a variable whose value can be changed later.

name stores a text value.

age stores a numeric value.

A variable created with let can be reassigned a new value.

Test yourself

  1. Which keyword allows a variable's value to be changed?

    • let
    • const
    • fixed
    • value
    Answer and explanation

    Correct answer: let

  2. What does a variable store?

    • A value or data
    • Only the screen color
    • Only an HTML file
    • Only an image
    Answer and explanation

    Correct answer: A value or data

  3. Which variable can be reassigned?

    • let
    • const
    • static
    • constant
    Answer and explanation

    Correct answer: let

  4. What does this code output? const user = { n: 1 }; user.n = 2; console.log(user.n);

    • 1
    • 2
    • A TypeError because user is declared with const
    • undefined
    Answer and explanation

    Correct answer: 2

    const prevents reassigning the variable itself, but it does not stop changes to the properties of the object it points to. So it prints 2 with no error.

  5. What is wrong with this code? const total = 0; total = total + 5;

    • A const variable cannot be reassigned; let should be used here
    • A number cannot be added to itself
    • The variable name must be written in capital letters
    • Zero is not a valid value for variables
    Answer and explanation

    Correct answer: A const variable cannot be reassigned; let should be used here

    The second assignment tries to change a const binding and throws a TypeError. When the value will change, use let.
