Object Methods

Learn how objects can contain Functions known as Methods.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Code example

JavaScript code

const user = {
name: "FAYBIT",
greet() {
return "Hello " + this.name;
}
};
document.getElementById("jsResult").textContent =
user.greet();

Understanding the code

A Method is a Function attached to an Object.

A Method can be defined inside an Object.

In this context, the this keyword refers to the object the Method belongs to.

Methods let an object bundle data and behavior together.

  1. What is a Method?

    • A Function inside an Object
    • A CSS property
    • HTML Attribute
    • Array
    Answer and explanation

    Correct answer: A Function inside an Object

  2. What does this usually refer to inside an object's Method?

    • The current object
    • A CSS file
    • Only the browser
    • Always an Array
    Answer and explanation

    Correct answer: The current object

  3. How do you call greet inside user?

    • user.greet()
    • greet.user
    • user->greet
    • call.user
    Answer and explanation

    Correct answer: user.greet()

  4. What does this code print? const c = { count: 0, inc() { this.count++; } }; c.inc(); c.inc(); console.log(c.count);

    • 0
    • 1
    • 2
    • NaN
    Answer and explanation

    Correct answer: 2

    When c.inc() is called, this points to c, so count increases on every call. After two calls the value is 2.

  5. What is the problem? const c = { count: 0, inc() { count++; } }; c.inc();

    • this is missing, so the code looks for a separate count variable that does not exist and throws a ReferenceError
    • ++ cannot be used inside a method
    • A method cannot be defined inside an object this way
    • count is a read-only property
    Answer and explanation

    Correct answer: this is missing, so the code looks for a separate count variable that does not exist and throws a ReferenceError

    Object properties do not become variables inside a method; they must be reached through this.count. Without this, a count variable is looked up in scope and does not exist.
