Arrow Functions

Learn the modern syntax for writing functions using Arrow Functions.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Code example

JavaScript code

const add = (a, b) => {
return a + b;
};
document.getElementById("jsResult").textContent =
add(5, 3);

Understanding the code

An Arrow Function is a short, modern syntax for writing functions.

The => symbol is placed between the parameters and the function body.

A function can be shortened further if it contains a single expression.

Arrow Functions are very common in modern JavaScript.

Test yourself

  1. Which symbol is used in an Arrow Function?

    • =>
    • ->
    • ::
    • ==>
    Answer and explanation

    Correct answer: =>

  2. Which syntax is correct?

    • const add = (a, b) => a + b;
    • const add => (a, b)
    • arrow add(a, b)
    • function => add
    Answer and explanation

    Correct answer: const add = (a, b) => a + b;

  3. What is the benefit of Arrow Functions?

    • Writing functions in a modern, concise syntax
    • Creating HTML
    • Changing CSS colors
    • Only managing databases
    Answer and explanation

    Correct answer: Writing functions in a modern, concise syntax

  4. What does this code print? const f = () => { a: 1 }; console.log(f());

    • { a: 1 }
    • 1
    • undefined
    • A syntax error
    Answer and explanation

    Correct answer: undefined

    Curly braces after the arrow are read as a function body, not an object, and a: 1 becomes a label with no return. To return an object, wrap it in parentheses: () => ({ a: 1 }).

  5. What does this code print? const sq = n => n * n; console.log([1, 2, 3].map(sq));

    • [1, 4, 9]
    • [1, 2, 3]
    • 14
    • [2, 4, 6]
    Answer and explanation

    Correct answer: [1, 4, 9]

    An arrow function without curly braces returns the expression result automatically, and map applies it to each element and returns a new array of the squares.
