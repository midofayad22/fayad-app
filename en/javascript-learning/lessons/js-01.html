What Is JavaScript?

JavaScript is a programming language used to add behavior and interactivity to web pages and websites.

HTML is used to build the structure of the page, CSS is used to control its appearance and design, while JavaScript is used to add logic, interactivity, and behavior.

For example, JavaScript can make a button respond when it is clicked, change the content of the page, or validate the data a user enters.

The Core Idea

JavaScript makes web pages interactive

You can think of a website as a human body: HTML is the skeleton, CSS is the appearance, and JavaScript is the behavior, movement, and interaction.

Code example

JavaScript code

const message = "Hello FAYBIT";
document.getElementById("jsResult").textContent = message;

Understanding the code

const is used to create a variable that cannot be reassigned a new value.

message is the name of the variable that stores the text.

"Hello FAYBIT" is a text value of type String.

textContent is used to change the text inside an HTML element.

  1. What is the main use of JavaScript?

    • Adding interactivity and behavior to web pages
    • Creating only the page structure
    • Changing only the page colors
    • Creating image files
    Answer and explanation

    Correct answer: Adding interactivity and behavior to web pages

  2. Which language is used to add behavior and logic to a website?

    • JavaScript
    • HTML
    • CSS
    • SQL
    Answer and explanation

    Correct answer: JavaScript

  3. What can JavaScript do?

    • Interact with the user and change page content
    • Create only the structure
    • Only write image files
    • Replace the operating system
    Answer and explanation

    Correct answer: Interact with the user and change page content

  4. What is the relationship between Java and JavaScript?

    • They are the same language in two versions
    • JavaScript is a simplified version of Java
    • They are two completely different languages that only share part of a name
    • Java runs in the browser and JavaScript runs only on servers
    Answer and explanation

    Correct answer: They are two completely different languages that only share part of a name

    Java and JavaScript are independent languages with different rules and goals; the similar name is a historical marketing choice. JavaScript is neither a version of Java nor built on it.

  5. A site checks that the email field is not empty before submitting the form, without reloading the page. Which part does this work?

    • HTML, because it builds the input field
    • CSS, because it controls the look of the field
    • The domain name of the site
    • JavaScript, because it runs the logic and validation on submit
    Answer and explanation

    Correct answer: JavaScript, because it runs the logic and validation on submit

    HTML creates the field and CSS styles it, but checking the value and deciding what to do is program logic, which JavaScript handles.
