Loops

Learn how JavaScript repeats a set of statements using loops.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Code example

JavaScript code

let result = "";
for (let i = 1; i <= 5; i++) {
result += i + " ";
}
document.getElementById("jsResult").textContent = result;

Understanding the code

Loops let you repeat a set of instructions.

A for loop usually consists of an initialization, a condition, and an update.

In the example, i starts at 1 and continues until it reaches 5.

Loops reduce the need to write the same code many times.

  3. What happens when the loop condition becomes false?

    • The loop stops
    • It starts over
    • The browser stops
    • The variable is deleted
    Answer and explanation

    Correct answer: The loop stops

  4. What does this code print? for (let i = 0; i !== 5; i++) { if (i === 2) continue; if (i === 4) break; console.log(i); }

    • 0 1 3
    • 0 1 2 3
    • 0 1
    • 0 1 3 4
    Answer and explanation

    Correct answer: 0 1 3

    continue skips only the i = 2 iteration, and break ends the whole loop at i = 4 before it is printed. So 0, 1 and 3 are printed.

  5. What is the problem in this code? let i = 0; while (i !== 3) { console.log(i); }

    • while does not accept the !== condition
    • The loop never runs because i equals 0
    • Nothing increases i, so the loop is infinite
    • const should be used instead of let
    Answer and explanation

    Correct answer: Nothing increases i, so the loop is infinite

    The condition i !== 3 stays true forever because i never changes inside the loop. We need something like i++ so it reaches 3 and stops.
