Destructuring

Learn how to extract values from Arrays and Objects in a concise and organized way.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Code example

JavaScript code

const user = {
name: "FAYBIT",
age: 20
};
const { name, age } = user;
document.getElementById("jsResult").textContent =
name + " - " + age;

Understanding the code

Destructuring lets you extract values from an Object or Array into variables.

Instead of writing user.name and user.age many times, you can extract the values directly.

Destructuring is widely used in modern JavaScript.

It can be used with both Objects and Arrays.

  1. What is the benefit of Destructuring?

    • Easily extracting values from Objects and Arrays
    • Creating CSS
    • Creating HTML
    • Running the browser
    Answer and explanation

    Correct answer: Easily extracting values from Objects and Arrays

  2. Which syntax uses Destructuring on an Object?

    • const { name } = user;
    • const name = { user };
    • const [name] = user;
    • destructure(user)
    Answer and explanation

    Correct answer: const { name } = user;

  3. Can Destructuring be used with Arrays?

    • Yes
    • No
    • Only with CSS
    • Only with Functions
    Answer and explanation

    Correct answer: Yes

  4. What does this code print? const [x, y = 5] = [1]; const { name, age = 30 } = { name: "Z" }; console.log(x, y, name, age);

    • 1 undefined Z undefined
    • 1 5 Z 30
    • 1 5 Z undefined
    • An error because the array is shorter than the variables
    Answer and explanation

    Correct answer: 1 5 Z 30

    Defaults in destructuring are used when the matching value is undefined or missing. So y becomes 5 and age becomes 30.

  5. What does this statement do? [a, b] = [b, a];

    • It copies a into b only
    • It swaps the two variables without a temporary variable
    • It throws because an array cannot be assigned
    • It only creates a new array without changing the variables
    Answer and explanation

    Correct answer: It swaps the two variables without a temporary variable

    The right side first builds an array of the current values, then destructuring assigns them back to a and b in swapped order. That swaps them without a third variable.
