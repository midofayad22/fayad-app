Understanding the code

DOM is short for Document Object Model.

The browser represents an HTML document as a structure of elements and objects.

JavaScript can access these elements, change them, and interact with them.

The DOM is the foundation that lets JavaScript work with the page interface.

Test yourself

  1. What does DOM stand for?

    • Document Object Model
    • Data Object Method
    • Document Order Manager
    • Dynamic Object Module
    Answer and explanation

    Correct answer: Document Object Model

  2. What does the DOM allow JavaScript to work with?

    • HTML page elements
    • Only system files
    • Graphics cards
    • Only audio files
    Answer and explanation

    Correct answer: HTML page elements

  3. Who creates the DOM when an HTML page loads?

    • The browser
    • CSS
    • The database
    • The user manually
    Answer and explanation

    Correct answer: The browser

  4. What happens to the original HTML file when JavaScript modifies an element in the DOM?

    • The file on the server changes too
    • The file saved on the user's device changes
    • Only what the browser holds in memory changes, and a reload brings back the original
    • Nothing changes because the DOM is read-only
    Answer and explanation

    Correct answer: Only what the browser holds in memory changes, and a reload brings back the original

    The DOM is a live in-memory representation of the page, and changing it changes only the display. The HTML file on the server is untouched, so changes are lost on reload unless saved another way.

  5. Which object is the starting point for reaching page elements from JavaScript?

    • window.html
    • document
    • console
    • navigator
    Answer and explanation

    Correct answer: document

    document represents the loaded page and offers lookup methods such as querySelector. console is for logging and navigator holds browser information, so neither reaches page elements.
