Data Types

Learn the most important data types JavaScript works with.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Code example

JavaScript code

const name = "FAYBIT";
const age = 20;
const isStudent = true;
document.getElementById("jsResult").textContent =
name + " | " + age + " | " + isStudent;

Understanding the code

String is used for text such as "FAYBIT".

Number is used for numbers such as 20.

Boolean has only two values: true or false.

Choosing the right data type helps the program handle information correctly.

Test yourself

  1. Which of the following values is a Boolean?

    • true
    • "Hello"
    • 25
    • null
    Answer and explanation

    Correct answer: true

  2. What is the type of the value "FAYBIT"?

    • String
    • Number
    • Boolean
    • Object
    Answer and explanation

    Correct answer: String

  3. What is the type of the value 25?

    • Number
    • String
    • Boolean
    • Array
    Answer and explanation

    Correct answer: Number

  4. What does console.log(typeof null) print?

    • null
    • undefined
    • object
    • string
    Answer and explanation

    Correct answer: object

    typeof null returns object, a historical quirk kept for backward compatibility. It does not mean null is really an object.

  5. What does console.log(typeof NaN) print?

    • NaN
    • number
    • undefined
    • error
    Answer and explanation

    Correct answer: number

    NaN stands for Not a Number, yet it is a value of type number that appears from invalid math such as 0 / 0. So typeof returns number.
