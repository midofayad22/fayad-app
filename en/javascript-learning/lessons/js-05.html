Conditions

Learn how to use if and else so a program can make decisions based on certain conditions.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Code example

JavaScript code

const age = 20;
if (age >= 18) {
document.getElementById("jsResult").textContent = "Adult";
} else {
document.getElementById("jsResult").textContent = "Minor";
}

Understanding the code

if checks whether a certain condition holds.

If the condition is true, the code inside it runs.

else is used to run alternative code when the condition is false.

Conditions let a program make different decisions depending on the data.

  1. Which keyword is used to create a condition?

    • if
    • loop
    • check
    • condition
    Answer and explanation

  2. When does else run?

    • When the if condition is false
    • Always
    • Before if
    • When a variable is declared
    Answer and explanation

    Correct answer: When the if condition is false

  3. What is the result of the condition 20 >= 18?

    • true
    • false
    • undefined
    • null
    Answer and explanation

    Correct answer: true

  4. Which of these values is falsy in a condition?

    • The string "0"
    • The empty array []
    • The number 0
    • The empty object {}
    Answer and explanation

    Correct answer: The number 0

    The falsy values are false, 0, "", null, undefined and NaN. The string "0" and empty arrays or objects are truthy because they are not on that list.

  5. What does this code print? let n = 7; if (n === 7) { console.log("a"); } else if (n === 7) { console.log("b"); } else { console.log("c"); }

    • a only
    • a then b
    • b only
    • c
    Answer and explanation

    Correct answer: a only

    Conditions are checked in order, and the first true one runs while the rest are skipped. So else if is never reached even though its condition is also true.
