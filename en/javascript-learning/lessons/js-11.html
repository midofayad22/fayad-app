Arrays

Learn how arrays store multiple values in a single variable and how to access their elements.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Code example

JavaScript code

const fruits = [
"Apple",
"Banana",
"Orange"
];
document.getElementById("jsResult").textContent =
fruits[0];

Understanding the code

An Array is a data structure that stores multiple values in a single variable.

Elements inside an Array have a numeric index that starts at 0.

To access the first element we use array[0].

Arrays are very important when working with collections of data.

  1. What does an Array store?

    • Multiple values in a single variable
    • Only one value
    • Only CSS
    • Only HTML
    Answer and explanation

    Correct answer: Multiple values in a single variable

  2. What is the index of the first element in an Array?

    • 0
    • 1
    • -1
    • 10
    Answer and explanation

    Correct answer: 0

  3. How do you access the first element in fruits?

    • fruits[0]
    • fruits[1]
    • fruits.first
    • fruits()
    Answer and explanation

    Correct answer: fruits[0]

  4. What does this code print? const a = [1, 2, 3]; a[5] = 9; console.log(a.length);

    • 4
    • 3
    • 6
    • 5
    Answer and explanation

    Correct answer: 6

    length is the highest index plus one, so assigning to index 5 makes it 6 and leaves empty gaps in between. The element is not placed in the next free slot.

  5. How do you reach the last element of an array arr whatever its length?

    • arr[arr.length]
    • arr[arr.length - 1]
    • arr[-1]
    • arr.last
    Answer and explanation

    Correct answer: arr[arr.length - 1]

    Indexing starts at 0, so the last index is length minus one. arr[arr.length] gives undefined, arr[-1] is not a valid index in JavaScript, and last does not exist.
