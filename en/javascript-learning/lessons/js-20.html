Spread and Rest

Learn how to use ... to copy and gather values with Arrays, Objects, and Functions.

...numbers,
4
];
document.getElementById("jsResult").textContent =
newNumbers.join(", ");

Understanding the code

The ... symbol is used in modern JavaScript in more than one way.

Spread expands the values inside an Array or Object so they can be used elsewhere.

Rest gathers multiple values into a single Array in a function's Parameters.

The difference depends on the context in which the symbol is used.

  1. Which symbol is used in Spread and Rest?

    • ...
    • ***
    • >>>
    • ::
    Answer and explanation

    Correct answer: ...

  2. What does Spread do with an Array?

    • Expands its elements so they can be used in another Array
    • Deletes them
    • Converts them to a String
    • Stops the program
    Answer and explanation

    Correct answer: Expands its elements so they can be used in another Array

  3. What do Rest Parameters do?

    • Gather multiple values into an Array
    • Delete values
    • Create HTML
    • Create CSS
    Answer and explanation

    Correct answer: Gather multiple values into an Array

  4. What does this code print? const a = { x: { n: 1 } }; const b = { ...a }; b.x.n = 2; console.log(a.x.n);

    • 1
    • 2
    • undefined
    • An error
    Answer and explanation

    Correct answer: 2

    Spread makes only a shallow copy, so the inner object x is shared between a and b. Changing b.x.n shows up in a.x.n; use structuredClone for a deep copy.

  5. What does this code print? function f(first, ...rest) { return rest; } console.log(f(1, 2, 3));

    • [1, 2, 3]
    • [1]
    • [2, 3]
    • 3
    Answer and explanation

    Correct answer: [2, 3]

    first takes the first argument, and ...rest gathers the remaining arguments into a real array, [2, 3]. The rest parameter must be last.
