Parameters and Arguments

Learn how functions receive data using Parameters and Arguments.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Code example

JavaScript code

function greet(name) {
return "Hello " + name;
}
document.getElementById("jsResult").textContent =
greet("FAYBIT");

Understanding the code

A Parameter is the variable in the function definition that receives a value.

An Argument is the value we pass when calling the function.

In the example, name is the Parameter.

And "FAYBIT" is the Argument passed to the function.

  2. What is an Argument?

    • The value passed to the function

    • The file name
    • The data type
    Answer and explanation

    Correct answer: The value passed to the function

  3. In greet("FAYBIT"), what is the Argument?

    • "FAYBIT"
    • greet
    • name
    • ()
    Answer and explanation

    Correct answer: "FAYBIT"

  4. What does this code print? function f(a, b = 2) { return a + b; } console.log(f(1), f(1, 5));

    • NaN and 6
    • 3 and 6
    • 3 and 3
    • 1 and 6
    Answer and explanation

    Correct answer: 3 and 6

    The default b = 2 is used only when no argument is passed, so f(1) is 3. Passing 5 replaces the default, giving 6.

  5. What does this code print? function show(a, b) { console.log(b); } show(1);

    • 1
    • An error because an argument is missing
    • null
    • undefined
    Answer and explanation

    Correct answer: undefined

    JavaScript does not require the number of arguments to match the parameters, and a parameter that receives no argument is undefined. No error is thrown and null is not used.
