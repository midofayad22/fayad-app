Functions

Learn how to create reusable functions to organize code and reduce repetition.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Code example

JavaScript code

function greet() {
return "Welcome to FAYBIT";
}
document.getElementById("jsResult").textContent = greet();

Understanding the code

A Function is a set of instructions that can be reused.

A function is defined using the function keyword.

A function can be run by writing its name followed by parentheses.

Using functions makes a program more organized and easier to maintain.

  1. What is a function?

    • A reusable set of instructions
    • An HTML element
    • A CSS property
    • A type of image
    Answer and explanation

    Correct answer: A reusable set of instructions

  2. Which keyword is used to define a traditional function?

    • function
    • def
    • method
    • func
    Answer and explanation

    Correct answer: function

  3. How do you call the greet function?

    • greet()
    • call greet
    • run.greet
    • function.greet
    Answer and explanation

    Correct answer: greet()

  4. What does console.log(typeof greet) print if function greet() {} is defined?

    • string
    • undefined
    • object
    • function
    Answer and explanation

    Correct answer: function

    Writing greet without parentheses refers to the function itself as a value and does not call it, and its type is function. Calling needs parentheses: greet().

  5. What happens? sayHi(); function sayHi() { console.log("Hi"); }

    • It prints Hi because function declarations are hoisted completely
    • A ReferenceError because the call comes before the definition
    • It prints undefined
    • It prints nothing and raises no error
    Answer and explanation

    Correct answer: It prints Hi because function declarations are hoisted completely

    Function declarations are hoisted together with their body, so they can be called before their line. This does not apply to a function stored in const or let.
