Operators

Learn how JavaScript uses arithmetic, comparison, and logical operators to perform operations.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Code example

JavaScript code

const a = 10;
const b = 5;
const result = a + b;
document.getElementById("jsResult").textContent = result;

Understanding the code

Operators are used to perform operations on values.

+ is for addition, - for subtraction, * for multiplication, and / for division.

Comparison operators such as ===, >, and < can also be used.

Operators are a fundamental part of writing program logic.

Test yourself

  1. Which operator is used for addition?

    • +
    • -
    • *
    • /
    Answer and explanation

    Correct answer: +

  2. What is the result of 10 - 4?

    • 6
    • 14
    • 40
    • 2
    Answer and explanation

    Correct answer: 6

  3. Which operator is used for strict comparison?

    • ===
    • =
    • =>
    • !===
    Answer and explanation

    Correct answer: ===

  4. What does console.log(5 + "5", 5 - "5") print?

    • 10 and 0
    • 55 and 0
    • 55 and 55
    • 10 and NaN
    Answer and explanation

    Correct answer: 55 and 0

    With a string, + concatenates, giving 55. The - operator only works on numbers, so it converts the string to a number and gives 0.

  5. What does console.log(0 || 10, 0 ?? 10) print?

    • 10 and 10
    • 0 and 0
    • 0 and 10
    • 10 and 0
    Answer and explanation

    Correct answer: 10 and 0

    || skips any falsy value including 0, so it returns 10. ?? only skips null and undefined, so 0 is kept.
