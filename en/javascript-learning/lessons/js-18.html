Events

Learn how JavaScript responds to user actions such as clicking, typing, and moving the mouse.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Code example

JavaScript code

const button =
document.querySelector("button");
button.addEventListener("click", () => {
document.getElementById("jsResult").textContent =
"The button was clicked";
});

Understanding the code

An Event is something that happens on the page, such as clicking a button.

addEventListener() is used to listen for a specific event.

In the example, we listen for the click event.

When the event occurs, a certain Function runs.

Test yourself

  1. Which Method listens for events?

    • addEventListener()
    • listenEvent()
    • eventClick()
    • watchEvent()
    Answer and explanation

    Correct answer: addEventListener()

  2. What is the name of the event that occurs when a button is clicked?

    • click
    • press
    • button
    • tapOnly
    Answer and explanation

    Correct answer: click

  3. What happens when an Event occurs?

    • A Function attached to it can run
    • The browser stops
    • The HTML is deleted
    • The CSS is deleted
    Answer and explanation

    Correct answer: A Function attached to it can run

  4. What is wrong with this code? btn.addEventListener("click", handle());

    • The event name click is wrong
    • handle() is called immediately and its result is passed; the correct form passes handle without parentheses
    • addEventListener accepts only arrow functions
    • An event cannot be attached to a button
    Answer and explanation

    Correct answer: handle() is called immediately and its result is passed; the correct form passes handle without parentheses

    The parentheses run the function at registration time, so undefined is passed instead of the function and nothing runs on click. Pass the function reference so the browser calls it when the event happens.

  5. Two click listeners are registered on the same button, the first printing A and the second printing B. What happens on a click?

    • Only A is printed because the second replaces it
    • Only B is printed
    • A then B is printed in registration order
    • An error occurs because an event allows only one listener
    Answer and explanation

    Correct answer: A then B is printed in registration order

    addEventListener adds a new listener without replacing the old one, and listeners run in the order they were added. Replacement happens only with the onclick property.
