Array Methods

Learn some of the most important methods for working with Arrays, such as push, pop, map, and filter.

JavaScript code

const numbers = [1, 2, 3];
numbers.push(4);
document.getElementById("jsResult").textContent =
numbers.join(", ");

Understanding the code

JavaScript provides many Array Methods for working with arrays.

push() adds an element to the end of the array.

pop() removes the last element.

map() creates a new Array after applying an operation to the elements.

filter() is used to select the elements that satisfy a certain condition.

    • Removes the first element
    • Deletes the Array

  2. Which Method removes the last element?

    • pop()
    • push()

    Answer and explanation

    Correct answer: pop()

  3. What is a common use of filter()?

    • Selecting the elements that satisfy a condition
    • Always adding an element
    • Deleting all elements
    • Creating HTML
    Answer and explanation

    Correct answer: Selecting the elements that satisfy a condition

  4. What does this code print? const r = [1, 2, 3].forEach(n => n * 2); console.log(r);

    • [2, 4, 6]
    • [1, 2, 3]
    • undefined
    • 12
    Answer and explanation

    Correct answer: undefined

    forEach runs the function for each element but always returns undefined. To get a new array of results, use map.

  5. What does console.log([10, 1, 5].sort()) print?

    • [1, 5, 10]
    • [10, 5, 1]
    • [1, 10, 5]
    • [10, 1, 5]
    Answer and explanation

    Correct answer: [1, 10, 5]

    sort without a compare function orders elements as strings, so "10" comes before "5" because the character 1 comes before 5. For numeric order use sort((a, b) => a - b).
