Return

Learn how to use return to send a value back from a function to where it was called.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Code example

JavaScript code

function add(a, b) {
return a + b;
}
const result = add(5, 3);
document.getElementById("jsResult").textContent = result;

Understanding the code

The return keyword returns a value from a function.

After return runs, the function stops executing any statements after it.

The value returned by the function can be stored in a variable.

This lets you use function results elsewhere in the program.

  1. What does return do?

    • Returns a value from the function
    • Creates a loop
    • Deletes a variable
    • Only changes HTML
    Answer and explanation

    Correct answer: Returns a value from the function

  2. What usually happens after return runs?

    • The function stops executing
    • The loop starts
    • A variable is created
    • CSS runs
    Answer and explanation

    Correct answer: The function stops executing

  3. What is the result of add(5, 3) if the function returns a + b?

    • 8
    • 2
    • 15
    • 53
    Answer and explanation

    Correct answer: 8

  4. What does this code print? function f(a) { a * 2; } console.log(f(4));

    • 8
    • undefined
    • 4
    • NaN
    Answer and explanation

    Correct answer: undefined

    The function computes a * 2 but has no return, and a function that does not return a value explicitly gives undefined. The fix is return a * 2.

  5. What does this code print? function g() { return 1; console.log("x"); return 2; } console.log(g());

    • 1 only
    • x then 1
    • x then 2
    • 2
    Answer and explanation

    Correct answer: 1 only

    return ends the function immediately, so execution never reaches the console.log or the second return. Only 1 is printed.
