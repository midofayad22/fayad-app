The Interpreter: Environment, Variables and Statements

INTERPRETER

How a tree becomes a result and how a language remembers values

Learning objectives

  • Understand how the interpreter walks the tree.
  • Tell an expression from a statement.
  • Understand the environment that stores variables.

Prerequisites

  • The parser and AST lesson (prg-27) and the errors lesson (prg-29).

Expressions and statements

An expression has a value: 3 * (2 + 4) is 18. A statement does something: let area = ... stores a value and print area shows something. Some languages treat everything as an expression, but this distinction keeps our first language simple.

The environment: the language's memory

The environment is a map from variable name to value. let adds a name, reading a variable looks it up, and if it is missing that is a runtime error.

Common mistakes

  • Evaluating a variable before defining it: gives Undefined variable, which is correct behaviour.
  • Forgetting String(...) when producing output, mixing types.
Exercise What does the environment hold after let x = 4 then let x = x * 2?
Show solution

x = 8: the second statement reads x (4), computes 8, then writes the same name again, replacing the old value.

Summary

  • An expression has a value; a statement does something.
  • The interpreter walks the tree recursively from the leaves.
  • The environment stores variables and reports undefined ones.

Core idea

The interpreter walks the tree and keeps variable values in an environment, turning a program from structure into a result.

Worked example

See the idea in code

JavaScript 
const env = new Map();
env.set("a", 2);
env.set("b", env.get("a") * 5);
console.log(Object.fromEntries(env));
Practice

Challenge yourself

Interactive exercise

Write run(ast) that executes an array of statements: {kind:"let",name,value} and {kind:"print",value}, where value is a node {kind:"num",value}, {kind:"var",name} or {kind:"bin",op,left,right} (operators + - * /). Return the outputs as an array of strings. An undefined variable throws Error("Undefined variable 'x'").

Test yourself

  1. What is the environment for?

    • Storing variable names and values
    • Drawing the tree
    • Splitting the text
    • Only printing errors
    Answer and explanation

    Correct answer: Storing variable names and values

    It is a map from name to value.

  2. Which of these is a statement?

    • let a = 5
    • 2 + 3
    • (4)
    • 7
    Answer and explanation

    Correct answer: let a = 5

    It does something (stores a value) rather than merely being a value.

  3. What kind of error is reading an undefined variable?

    • A runtime error
    • A lexical error
    • A syntax error
    • No error
    Answer and explanation

    Correct answer: A runtime error

    The code is valid, but the interpreter could not find the name.

  4. In what order is 3 * (2 + 4) evaluated on the tree?

    • Addition first, then multiplication
    • Multiplication then addition
    • Randomly
    • No order
    Answer and explanation

    Correct answer: Addition first, then multiplication

    The deepest node is evaluated first.

  5. What does the FAY language print? let price = 20, then let qty = 3, then let total = price * qty - 10, then print total

    • 50
    • 10
    • 30
    • 60
    Answer and explanation

    Correct answer: 50

    The environment stores price = 20 and qty = 3, then 20 * 3 = 60 is computed before the subtraction, so 60 - 10 = 50. Reading it as 20 * (3 - 10) would be wrong because multiplication binds tighter.
