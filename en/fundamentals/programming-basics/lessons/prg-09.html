OPERATORS

Make the program perform operations

What is an Operator?

Operators are symbols or words that let us perform operations on values.

Arithmetic

+   -   *   /   %

Comparison

===   !==   >   <

Logical

&&   ||   !

Assignment

=   +=   -=

Arithmetic operators

Addition +, subtraction -, multiplication *, division /, and the remainder % (modulus), which is handy for telling even from odd.

console.log(10 % 3);  // 1  (10 = 3×3 + 1)
console.log(14 % 2);  // 0  -> the number is even
console.log(2 + 3 * 4); // 14 (multiplication first)
console.log((2 + 3) * 4); // 20 (parentheses first)

Comparison operators produce a Boolean

Every comparison returns true or false. Always prefer strict equality ===, which compares value and type together.

console.log(5 === 5);    // true
console.log(5 === "5");  // false (different type)
console.log(5 == "5");   // true  (== converts the type: avoid it)
console.log(7 >= 7);     // true
console.log(3 !== 4);    // true

Logical operators

&& (and): true when both conditions hold. || (or): true when at least one holds. ! (not): flips the value.

const age = 20, hasId = true;
console.log(age >= 18 && hasId);  // true
console.log(age < 18 || hasId);   // true
console.log(!hasId);              // false
Core idea

Operators are the tools that allow a program to calculate, compare, and make decisions.

Worked example

See the idea in code

JavaScript 
const age = 20;
console.log(age >= 18);
console.log(age === 20);

Interactive exercise

The variable n = 14. Create a variable named isEven that is true when n is even, using the remainder operator %.

Test yourself

  1. What is the result of 10 + 5?

    • 15
    • 105
    • 5
    • 10
    Answer and explanation

    Correct answer: 15

    10 + 5 is between two numbers, so they are added and the result is 15. 105 would appear only if one side were a string.

  2. What is 10 % 3?

    • 3
    • 1
    • 0
    • 3.33
    Answer and explanation

    Correct answer: 1

    % returns the remainder: 10 ÷ 3 = 3 with remainder 1.

  3. What is the result of 5 === "5"?

    • true
    • false
    • Error
    • undefined
    Answer and explanation

    Correct answer: false

    === compares value and type. The first is a number and the second a string, so the result is false.

  4. What is true && false?

    • true
    • false
    • null
    • 1
    Answer and explanation

    Correct answer: false

    && is true only when both sides are true. Here the second side is false.

  5. What is x at the end? let x = 5; x += 2; x *= 3;

    • 11
    • 17
    • 21
    • 13
    Answer and explanation

    Correct answer: 21

    x += 2 makes x equal 7, then x *= 3 multiplies it by 3 to give 21. The common mistake is applying both operations to the original 5.
