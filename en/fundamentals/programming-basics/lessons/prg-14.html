SCOPE

Where can a variable be used?

What is Scope?

Scope determines where a variable can be accessed and used.

A variable declared inside a Function usually cannot be accessed from outside it.

Core idea

Scope helps prevent data from interfering and reduces problems caused by using variables in inappropriate places.

Worked example

See the idea in code

JavaScript 
function test() {
let message = "Hello";
console.log(message);
}
test();
Practice

Challenge yourself

Test yourself

  1. What does Scope determine?

    • Where a variable can be accessed
    • Program speed
    • Code color
    • Screen size
    Answer and explanation

    Correct answer: Where a variable can be accessed

  2. What happens? function f() { let secret = 1; } f(); console.log(secret);

    • It prints 1
    • It prints undefined
    • It prints null
    • A ReferenceError, because secret exists only inside the function
    Answer and explanation

    Correct answer: A ReferenceError, because secret exists only inside the function

    A local variable ends with its function and outside code cannot see it. Reading it from outside gives a ReferenceError, not undefined.

  3. What is printed? let x = 1; function f() { let x = 2; return x; } console.log(f(), x);

    • 2 1
    • 2 2
    • 1 1
    • 1 2
    Answer and explanation

    Correct answer: 2 1

    The x inside the function is a separate variable that shadows the outer one only during the call, so the function returns 2. The outer x stays 1 because the function never changed it.

  4. Why are local variables preferred over many global variables?

    • Because they reduce name clashes and accidental changes from other parts
    • Because global variables are not allowed in the language
    • Because local ones are always thousands of times faster
    • Because global ones are deleted automatically after a second
    Answer and explanation

    Correct answer: Because they reduce name clashes and accidental changes from other parts

    Any part of the program can change a global variable, so it is hard to trace who changed it. Local scope limits the effect and makes code easier to understand and test.

  5. What is count at the end? let count = 0; function inc() { count++; } inc(); inc(); console.log(count);

    • 0
    • 1
    • 2
    • An error because the function cannot see count
    Answer and explanation

    Correct answer: 2

    A function can read and modify a variable defined in an outer scope. It was called twice, so count rose from 0 to 2.
