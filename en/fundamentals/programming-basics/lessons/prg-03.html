Learn how to think before learning the language

What is computational thinking?

Computational thinking is an organized way of analyzing problems and breaking them into small parts that can be handled.

Decomposition

Breaking a large problem into smaller problems.

Pattern Recognition

Discovering repeated patterns within problems.

Abstraction

Focusing on the important information and hiding unnecessary details.

Algorithm

Building clear steps to reach the solution.

Core idea

Computational thinking is a skill independent of the programming language; you can use the same way of thinking with JavaScript, Python, or C++.

Worked example

See the idea in code

JavaScript 
const tasks = [
"Open the app",
"Log in",
"Choose a lesson",
"Start learning"
];
console.log(tasks);
Practice

Challenge yourself

Test yourself

  1. What does Decomposition mean?

    • Writing code quickly
    • Breaking a problem into smaller parts
    • Deleting the problem
    • Choosing the programming language
    Answer and explanation

    Correct answer: Breaking a problem into smaller parts

  2. Tea, coffee and hot chocolate recipes all start with heating water, adding a powder and waiting. Which pillar of computational thinking noticed this?

    • Decomposition
    • Pattern recognition
    • Evaluation
    • Debugging
    Answer and explanation

    Correct answer: Pattern recognition

    Noticing similarity between different problems is pattern recognition, and it lets you reuse one solution. Decomposition means splitting a problem into parts, not looking for similarity.

  3. A subway map shows only stations and lines, not real distances or streets. Which concept does it represent?

    • Abstraction: hiding unnecessary details and keeping what matters for the task
    • Breaking into bugs
    • Repeated loops
    • Speed optimization
    Answer and explanation

    Correct answer: Abstraction: hiding unnecessary details and keeping what matters for the task

    Abstraction keeps what is needed to solve the problem, here how stations connect. Street details add clutter and do not help a metro rider.

  4. You want to build a food-delivery app. Which first step best represents decomposition?

    • Write all the code in one file and fix it later
    • Copy an existing app without understanding it
    • Split it into parts such as user accounts, restaurant list, cart, payment and tracking
    • Choose the screen colors first
    Answer and explanation

    Correct answer: Split it into parts such as user accounts, restaurant list, cart, payment and tracking

    A big problem becomes solvable when split into small independent problems you can build and test one by one. Starting with everything at once mixes the problems and makes them hard to trace.

  5. After decomposing, spotting patterns and ignoring details, which pillar produces the ordered steps that solve the problem?

    • Pattern recognition
    • Algorithm design
    • Abstraction
    • Decomposition
    Answer and explanation

    Correct answer: Algorithm design

    Algorithm design is writing clear, ordered steps that end in the solution. The other pillars prepare the problem for this stage but do not write the steps themselves.
