CORE CONCEPT

From the code you write to the result

Code does not go straight to the computer

When you write a program, there are several stages between the text you wrote and the result you see in front of you.

01

You write the instructions using a programming language.

02

The code is analyzed and checked against the language's rules.

03

It is converted or interpreted into executable instructions.

04

The computer executes the instructions and produces the result.

Core idea

Code is the means we use to describe the steps of a solution, and the computer carries out these steps according to the rules defined by the language.

Worked example

See the idea in code

JavaScript 
let x = 10;
let y = 5;
let result = x + y;
console.log(result);
Practice

Challenge yourself

Test yourself

  1. What happens after you write code?

    • The computer executes it randomly
    • It is analyzed and then executed
    • It is deleted automatically
    • It turns into an image
    Answer and explanation

    Correct answer: It is analyzed and then executed

  2. What does this code print? let x = 2; x = x * 3; console.log(x); x = 0;

    • 0
    • 2
    • 6
    • Nothing
    Answer and explanation

    Correct answer: 6

    Statements run top to bottom in order. When console.log runs, x is 6; x = 0 comes after the print, so it cannot affect it.

  3. You edited and saved the code file, but the program that was already running still behaves the old way. What is the most likely explanation?

    • The running program was loaded earlier; you must run it again so it reads the new version
    • The computer does not save files until they are closed
    • New code takes a long time to take effect
    • The translator ignores every edit after the first run
    Answer and explanation

    Correct answer: The running program was loaded earlier; you must run it again so it reads the new version

    The file is just text, and a running program works from a copy already loaded in memory. It will not see your changes until you run it again.

  4. What happens when you run: console.log(total); let total = 5;

    • It prints 5
    • It prints undefined
    • An error, because total is used before execution reaches its declaration
    • It prints 0
    Answer and explanation

    Correct answer: An error, because total is used before execution reaches its declaration

    Execution moves in order, and a let variable cannot be accessed before its declaration line, so a ReferenceError appears. Thinking the computer looks ahead to later lines is the misconception.

  5. A program asks for the user's age and then prints adult or minor. Which part is the processing step?

    • Reading the age from the user
    • Comparing the age with 18 to make the decision
    • Showing the word adult on screen
    • The screen that displays the result
    Answer and explanation

    Correct answer: Comparing the age with 18 to make the decision

    Programs follow input, processing, output. Reading is input and displaying is output; the comparison and decision are the processing.
