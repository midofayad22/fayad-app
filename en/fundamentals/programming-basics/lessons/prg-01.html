What Is Programming?

FOUNDATION

Start by understanding the idea before writing code

Programming is not just writing code

Programming is the process of creating a set of instructions that tell the computer what to do. These instructions are written in a programming language that a compiler or runtime environment can understand.

But the most important part of programming is not memorizing words; it is the ability to turn a problem into clear, logical steps.

How does a programmer think?

1 — The Problem

We identify what we want to solve or build.

2 — Analysis

We understand the data required and the result we want to reach.

3 — The Solution

We turn our thinking into ordered steps.

4 — Implementation

We write the steps using a programming language.

Core idea

A good programmer does not start with code right away; they start by understanding the problem and then build the solution step by step.

Practice

Challenge yourself

Test yourself

  1. What is the main purpose of programming?

    • Writing long texts
    • Giving the computer instructions to perform a task
    • Memorizing language commands
    • Designing images only
    Answer and explanation

    Correct answer: Giving the computer instructions to perform a task

  2. A shop owner wants to send a discount message with each customer's name to 500 customers. Why does programming help here?

    • Because the computer understands the owner's intention without instructions
    • Because programming lets you write the steps once and run them for every customer quickly and accurately
    • Because programming types 500 messages by hand faster than a person
    • Because programming is meant for games only
    Answer and explanation

    Correct answer: Because programming lets you write the steps once and run them for every customer quickly and accurately

    Programming means writing precise instructions once so the computer can repeat them for any number of cases without tiring. A computer cannot guess intentions; it only runs what it was told.

  3. A programmer wanted to add 10% tax to a price but wrote an instruction that multiplies the price by 10 instead of 1.1. What happened?

    • The computer corrected the mistake because it knows what tax means
    • The computer followed the instruction literally, so the price came out ten times larger
    • The computer always refuses to run because the result is not logical
    • The fault is in the computer, not in the instructions
    Answer and explanation

    Correct answer: The computer followed the instruction literally, so the price came out ten times larger

    A computer executes exactly what is written and does not understand what was meant. Accuracy is therefore the programmer's responsibility, which is one of the key lessons of programming.

  4. Which of these tasks is best suited to automating with a program?

    • Choosing a gift that expresses your feelings for a friend
    • Judging the beauty of a painting
    • Calculating the total of 10,000 invoices by the same rule every day
    • Convincing a hesitant customer to buy face to face
    Answer and explanation

    Correct answer: Calculating the total of 10,000 invoices by the same rule every day

    Repetitive tasks with clear rules and large amounts of data are where programs excel. Taste, feelings and persuasion cannot easily be described as exact steps.

  5. Your friend memorized 200 keywords of a language and says: I now know programming. Why is that not enough?

    • Because keywords only work online
    • Because programming needs at least 500 keywords
    • Because memorizing is enough, but he must type quickly
    • Because the core of programming is analyzing a problem and turning it into exact steps; keywords are just a tool to express them
    Answer and explanation

    Correct answer: Because the core of programming is analyzing a problem and turning it into exact steps; keywords are just a tool to express them

    The key skill is thinking through the solution; a language's syntax can be learned and swapped. Someone who memorizes words without solving problems cannot build a useful program.
