DATA STRUCTURES

Store a group of values in one place

What is an Array?

An Array is a data structure that allows storing several values inside a single variable.

Elements can be accessed using an Index, and in JavaScript the Index starts at 0.

Core idea

An Array is suitable when you need to work with a group of related items such as usernames or products.

Worked example

See the idea in code

JavaScript 
const languages = [
"HTML",
"CSS",
"JavaScript"
];
console.log(languages[0]);
console.log(languages[2]);
Practice

Challenge yourself

Test yourself

  1. What is the Index of the first element in an Array?

    • 0
    • 1
    • -1
    • 10
    Answer and explanation

    Correct answer: 0

  2. What is the output? const a = [10, 20, 30]; console.log(a[a.length - 1]);

    • 30
    • 20
    • undefined
    • 3
    Answer and explanation

    Correct answer: 30

    The length is 3 and indexes start at 0, so the last element is at index 2, which is 30. The common mistake a[a.length] gives undefined.

  3. What does the array hold? let a = [1, 2]; a.push(3); a.pop(); a.pop(); console.log(a);

    • [1]
    • [1, 2]
    • []
    • [1, 2, 3]
    Answer and explanation

    Correct answer: [1]

    push adds 3 at the end giving [1,2,3], then the first pop removes 3 and the second removes 2, leaving [1]. pop always removes the last element.

  4. The loop: for (let i = 0; i <= arr.length; i++) { console.log(arr[i]); } on an array with 3 elements. What is the problem?

    • There is no problem
    • i must start at 1
    • The <= condition reads the non-existent index 3 and prints undefined at the end
    • arr.length does not work inside loops
    Answer and explanation

    Correct answer: The <= condition reads the non-existent index 3 and prints undefined at the end

    The valid indexes are 0, 1 and 2, and the condition i <= 3 adds a fourth round. The fix is i < arr.length.

  5. What is the output? const arr = [1, 2, 3]; arr.push(4); console.log(arr);

    • An error because arr is declared with const
    • [1, 2, 3]
    • [4]
    • [1, 2, 3, 4]
    Answer and explanation

    Correct answer: [1, 2, 3, 4]

    const prevents reassigning the variable but not changing the array's contents. push modifies the same array, so it works.
