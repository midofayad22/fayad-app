FUNCTIONS

Write once, use the code many times

What is a Function?

A Function is a block of code designed to perform a specific task and can be called whenever needed.

Using Functions helps organize the project and reduce code repetition.

Reusable

A function can be reused more than once.

Organized

They divide the project into clear parts.

Core idea

A Function groups a set of instructions under a single name, making them easy to use and reuse.

Worked example

See the idea in code

JavaScript 
function greet() {
console.log("Welcome to FAYBIT");
}
greet();
Practice

Challenge yourself

Test yourself

  1. What is the purpose of a Function?

    • Repeating and organizing a set of instructions
    • Changing the screen color
    • Increasing internet speed
    • Deleting the program
    Answer and explanation

    Correct answer: Repeating and organizing a set of instructions

  2. What does the code print? function double(n) { return n * 2; } console.log(double(double(3)));

    • 6
    • 12
    • 9
    • undefined
    Answer and explanation

    Correct answer: 12

    The inner call double(3) returns 6, which is passed to the outer call that returns 12. A returned value can be used directly as the input of the next call.

  3. The function: function add(a, b) { a + b; } then console.log(add(2, 3)). Why does it show undefined?

    • Because the function needs three parameters
    • Because addition does not work inside functions
    • Because the function has no return, so it returns undefined
    • Because the name add is reserved
    Answer and explanation

    Correct answer: Because the function has no return, so it returns undefined

    The function computed the sum but never returned it. Without return, a function always returns undefined no matter what it does inside.

  4. You copied the tax calculation into five places in your program, then the tax rate changed. Why would a function have been better?

    • Because functions make the program five times faster
    • Because the calculation is written once and called where needed, so only one place must change
    • Because functions contain no bugs
    • Because copying is not allowed in JavaScript
    Answer and explanation

    Correct answer: Because the calculation is written once and called where needed, so only one place must change

    A function avoids repetition and keeps changes in one place. Multiple copies leave forgotten outdated versions and cause inconsistent behavior.

  5. What does the code print? function f() { return 1; console.log("x"); } console.log(f());

    • x then 1
    • 1 then x
    • 1 only
    • x only
    Answer and explanation

    Correct answer: 1 only

    return ends the function immediately, so execution never reaches console.log("x"). Only 1 is printed, by the outer call.
