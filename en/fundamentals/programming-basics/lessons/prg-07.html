How do we store information inside a program?

What is a Variable?

A variable is a name we use to refer to a stored value that the program can use while it runs.

In JavaScript you can create variables using let and const.

let

Used when you expect the value to change.

const

Used when you do not want the value to be reassigned.

Choosing a name: rules and convention

A variable name must start with a letter, _ or $, and cannot contain spaces or hyphens. Case matters: score is not Score. The JavaScript convention is camelCase.

let userName = "Sara";   // good: describes the content
let x1 = "Sara";         // valid but says nothing
let user-name = 1;       // error: the hyphen is the minus operator
let 2score = 5;          // error: cannot start with a digit

A good name saves a whole comment: remainingLives is clearer than r.

let or const? A practical rule

Always start with const. Switch to let only when you really need to reassign. This stops accidental changes and tells the reader what can and cannot change.

const pi = 3.14159;   // will not change
let lives = 3;          // changes during the game
lives = lives - 1;      // allowed
pi = 3;                 // TypeError: Assignment to constant variable.

Assignment is not mathematical equality

The = sign means: “calculate the right side, then store the result under the name on the left”. That is why x = x + 1 is a sensible line: take the current value, add 1, and save it again.

let count = 5;
count = count + 1;   // 6
count += 1;          // shorthand: 7
console.log(count);  // 7
Core idea

A variable makes a program's data nameable and usable, instead of handling values in a haphazard way.

Worked example

See the idea in code

JavaScript 
let score = 100;
score = 150;
const username = "FAYBIT";
console.log(username);
console.log(score);
Practice

Challenge yourself

Interactive exercise

Create a variable named name that holds your name (a string) and a variable named age that holds your age (a number), then print both with console.log.

Test yourself

  1. Which keyword is used to declare a variable whose value can change?

    • const
    • let
    • fixed
    • change
    Answer and explanation

    Correct answer: let

    let allows assigning a new value to the same name, while const fixes the assignment. fixed and change are not JavaScript keywords.

  2. What happens when this code runs: const a = 1; a = 2;

    • It prints 2
    • A TypeError is thrown
    • a stays 1 with no error
    • Nothing, the line is ignored
    Answer and explanation

    Correct answer: A TypeError is thrown

    A const binding cannot be reassigned, so JavaScript stops with: Assignment to constant variable.

  3. Which variable name is valid and follows the usual convention?

    • 2score
    • user-name
    • userName
    • let
    Answer and explanation

    Correct answer: userName

    userName is valid and written in camelCase. 2score starts with a digit, user-name contains a hyphen read as minus, and let is a reserved word.

  4. What is x after: let x = 5; x = x + 3;

    • 5
    • 3
    • 8
    • 53
    Answer and explanation

    Correct answer: 8

    The right side is evaluated first (5 + 3 = 8), then the result is stored in x.

  5. What does this code print? let a = 1; let b = a; b = 5; console.log(a, b);

    • 5 5
    • 1 5
    • 1 1
    • 5 1
    Answer and explanation

    Correct answer: 1 5

    With b = a the value 1 is copied into b, so the two are independent. Changing b to 5 does not affect a, which stays 1.
