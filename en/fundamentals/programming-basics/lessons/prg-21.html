RECURSION

A function that calls itself to solve a smaller problem

Learning objectives

  • Understand the base case and the recursive case.
  • Trace a recursive function by hand.
  • Know when a loop is the better choice.

Prerequisites

  • The Functions lesson (prg-12) and the Scope lesson (prg-14).

The idea

Some problems contain a smaller copy of themselves. 5! equals 5 × 4!, and 4! equals 4 × 3!, and so on. Instead of a loop we write a function that solves the smaller case by calling itself. Every recursive function needs two parts:

  • Base case: a simple case answered directly, which stops the recursion.
  • Recursive case: the function calls itself on an input closer to the base case.

What happens in memory?

Each call reserves a new frame on the call stack holding its own n. Calls pile up until the base case is reached, then results return and the frames unwind in reverse order.

A second example: summing an array

Recursion or a loop?

A loop is simpler and faster for linear tasks. Recursion shines when the structure itself is nested: folders inside folders, trees, or splitting in half as in binary search.

Common mistakes

  • Forgetting the base case.
  • Calling the function with the same input so it never gets closer to the end.
  • Forgetting return before the recursive call, so you get undefined.
Exercise What does factorial(0) return in the function above, and why?
Show solution

It returns 1 because n <= 1 holds and the base case runs immediately, which matches the mathematical definition 0! = 1.

Summary

  • A base case plus a smaller recursive case.
  • Every call has a frame on the call stack.
  • Choose loops for linear tasks and recursion for nested structures.

Next step: Next we store data in different shapes: stacks, queues and maps.

Core idea

Recursion solves a problem by solving a smaller copy of it, and stops at the base case.

Worked example

See the idea in code

JavaScript 
function countdown(n) {
if (n === 0) { console.log("Go!"); return; }
console.log(n);
countdown(n - 1);
}
countdown(3);
Practice

Challenge yourself

Interactive exercise

Write a recursive function factorial(n) that returns 1 × 2 × … × n (and 0! = 1).

Test yourself

  1. What is the job of the base case?

    • Stop the recursion at the simplest case
    • Speed up the computer
    • Delete variables
    • Print the result
    Answer and explanation

    Correct answer: Stop the recursion at the simplest case

    Without it the calls continue until the stack is exhausted.

  2. What happens if you remove the base case from factorial?

    • RangeError: stack size exceeded
    • It returns 0
    • It always returns 1
    • Nothing
    Answer and explanation

    Correct answer: RangeError: stack size exceeded

    The calls never end, so the call stack fills up.

  3. Which data structure naturally suits recursion?

    • Trees and nested folders
    • A single number
    • A colour
    • An image
    Answer and explanation

    Correct answer: Trees and nested folders

    Each node contains smaller trees, so a self-repeating solution fits.

  4. What is sum([1,2]) by the function above?

    • 3
    • 2
    • 1
    • undefined
    Answer and explanation

    Correct answer: 3

    1 + sum([2]) = 1 + (2 + sum([])) = 1 + 2 + 0.

  5. What is the output? function pow2(n) { if (n === 0) return 1; return 2 * pow2(n - 1); } console.log(pow2(5));

    • 10
    • 25
    • 32
    • 16
    Answer and explanation

    Correct answer: 32

    The function multiplies by 2 five times before reaching the base case n === 0 that returns 1, so 2*2*2*2*2*1 = 32. 10 would come from adding, not multiplying.
