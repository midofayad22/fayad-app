DEBUGGING

Making mistakes is a natural part of a programmer's life

No programmer escapes Errors

Errors are a natural part of the development process. A professional programmer does not try to avoid all errors, but learns how to read them, identify their cause, and fix them.

Syntax Error

A problem with the rules of writing code.

Runtime Error

An error that happens while the program is running.

Logic Error

The code runs but the result is incorrect.

Debugging

The process of finding and fixing errors.

Core idea

Reading and understanding an error message is a core skill for a programmer, not a sign of failure.

Worked example

See the idea in code

JavaScript 
const age = 20;
if (age > 18) {
console.log("Adult");
}
Practice

Challenge yourself

Test yourself

  1. What does Debugging mean?

    • Writing HTML
    • Finding and fixing errors
    • Designing images
    • Uploading the website
    Answer and explanation

    Correct answer: Finding and fixing errors

  2. A program runs with no error message, but the invoice total is lower than it should be. Which kind of error is most likely?

    • A logic error in the calculation
    • A syntax error
    • An internet connection error
    • An editor installation error
    Answer and explanation

    Correct answer: A logic error in the calculation

    With a syntax error the program would not start, and a runtime error would show a message. No message plus a wrong result points to a logic error.

  3. The message appeared: TypeError: Cannot read properties of undefined (reading 'name'). What does it mean?

    • The word name is reserved in the language
    • You tried to read name from a value that is undefined instead of an object
    • The file cannot be saved
    • A semicolon is missing
    Answer and explanation

    Correct answer: You tried to read name from a value that is undefined instead of an object

    The message gives the type and cause: the value you asked name from is undefined. Tracing which variable may be empty is the place to start debugging.

  4. What does it print? let total = 0; for (let i = 1; i <= 3; i++) { total = i; } console.log(total);

    • 6
    • 3
    • 0
    • 1
    Answer and explanation

    Correct answer: 3

    The assignment total = i replaces the value each round instead of accumulating it, ending at 3. The intent was total += i to get 6, a logic error.

  5. Your function gives a wrong result and you do not know where the problem starts. What is the best strategy?

    • Rewrite the whole program from scratch
    • Print intermediate values with console.log to find the step where a value departs from the expected one
    • Randomly rename variables
    • Ignore it and see if it disappears
    Answer and explanation

    Correct answer: Print intermediate values with console.log to find the step where a value departs from the expected one

    Following values step by step narrows the bug to a small spot instead of guessing. Rewriting wastes time and may reproduce the same bug.
