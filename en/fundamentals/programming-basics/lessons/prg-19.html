DEVELOPER TOOLS

Start by understanding Version Control

What is Git?

Git is a Version Control system that helps developers track the changes that happen in a project.

Repository

The place that contains the project's files and its history.

Commit

Recording a set of changes in the project's history.

Branch

An independent line for developing a feature or experimenting.

GitHub

A popular platform for hosting Git projects and collaborating on them.

Core idea

Git is not a programming language; it is a tool for managing project versions and tracking changes.

Worked example

See the idea in code

JavaScript 
git init
git add .
git commit -m "Initial commit"
Practice

Challenge yourself

Test yourself

  1. What is Git's main function?

    • Designing interfaces
    • Managing and tracking versions of a project
    • Running the internet
    • Creating images
    Answer and explanation

    Correct answer: Managing and tracking versions of a project

  2. You edited a file and want to save a snapshot of it in the project history. What is the right sequence?

    • git commit, then git add
    • git push only
    • git add to stage the changes, then git commit to record them
    • git clone, then git add
    Answer and explanation

    Correct answer: git add to stage the changes, then git commit to record them

    add places the changes in the staging area and commit records them as a snapshot in history. Committing without staging does not include the new edits.

  3. You want to try a risky feature without touching the working main version. What do you do?

    • Create a new branch and work on it
    • Edit main directly and keep a copy on the desktop
    • Delete the project and start over
    • Wait until someone else writes the feature
    Answer and explanation

    Correct answer: Create a new branch and work on it

    A branch isolates the experiment: if it fails you drop the branch without harm, and if it works you merge it. Working on main directly risks breaking it.

  4. What is the difference between commit and push?

    • commit uploads changes to the server and push saves them locally
    • There is no difference
    • commit saves a snapshot in your local repository, and push sends your commits to a remote repository
    • push deletes the history
    Answer and explanation

    Correct answer: commit saves a snapshot in your local repository, and push sends your commits to a remote repository

    A commit is a local operation needing no internet, while push transfers commits to a remote such as GitHub. The reverse in the first option is wrong.

  5. What is the relationship between Git and GitHub?

    • They are two names for the same program
    • Git is a website and GitHub is a command-line tool
    • GitHub is a programming language
    • Git is the version control tool, and GitHub is a service that hosts repositories online
    Answer and explanation

    Correct answer: Git is the version control tool, and GitHub is a service that hosts repositories online

    You can use Git on your machine without GitHub, and GitHub adds hosting and collaboration. People often confuse them because they are used together.
