LOOPS

Repeat instructions without repeating code

Why do we use Loops?

Sometimes we need to perform the same operation several times. Instead of writing the same code dozens of times, we use a Loop.

for

Suitable when you know how many times to repeat.

while

Continues as long as the condition is still true.

The parts of a for loop

It has three parts inside the parentheses: the start runs once, the condition is checked before every round, and the update runs after every round.

for (let i = 1; i <= 3; i++) {
console.log("round", i);
}
// start:     i = 1
// condition: i <= 3 ? yes -> run the block
// update:    i++  -> i = 2 ... until the condition is false

while: when we don't know the number of rounds

Use while when the work repeats “as long as” a condition holds. Make sure something inside the loop eventually changes the condition, otherwise it becomes an infinite loop and the page freezes.

let n = 100, steps = 0;
while (n > 1) {
n = n / 2;     // this line moves the condition toward false
steps++;
}
console.log(steps); // 7

The accumulator pattern

We often start with an initial value and update it every round to build a result, such as the sum of numbers:

let sum = 0;
for (let i = 1; i <= 5; i++) {
sum += i;      // 1, 3, 6, 10, 15
}
console.log(sum); // 15

Trace the loop with pen and paper: write the values of i and sum after each round. It is the fastest way to understand what a loop does and to find bugs.

Core idea

A Loop makes code more efficient and prevents manually repeating instructions.

Worked example

See the idea in code

JavaScript 
for (let i = 1; i <= 5; i++) {
console.log(i);
}
Practice

Challenge yourself

Interactive exercise

Using a for or while loop, calculate the sum of the numbers from 1 to 10 and store it in a variable named sum.

Test yourself

  1. What is the purpose of a Loop?

    • Repeating the execution of instructions
    • Deleting variables
    • Shutting down the computer
    • Changing the language
    Answer and explanation

    Correct answer: Repeating the execution of instructions

    A loop repeats a set of instructions many times without rewriting them, which keeps code short and handles any number of items.

  2. How many times does the loop body run? for (let i = 0; i < 3; i++) { ... }

    • 2
    • 3
    • 4
    • Infinitely
    Answer and explanation

    Correct answer: 3

    i takes the values 0, 1 and 2; when it becomes 3 the condition i < 3 is false. So there are 3 rounds.

  3. What is sum at the end? let sum = 0; for (let i = 1; i <= 4; i++) { sum += i; }

    • 4
    • 10
    • 24
    • 6
    Answer and explanation

    Correct answer: 10

    sum accumulates: 1, then 3, then 6, then 10.

  4. Why does this loop never end? let i = 0; while (i < 5) { console.log(i); }

    • Because console.log does not work
    • Because i never changes inside the loop, so the condition stays true
    • Because while does not accept numbers
    • Because 5 is a big number
    Answer and explanation

    Correct answer: Because i never changes inside the loop, so the condition stays true

    Nothing increases i, so it stays 0 and i < 5 is always true. Fix: add i++ inside the loop.

  5. What does the loop print? for (let i = 10; i > 0; i -= 3) { console.log(i); }

    • 10 7 4 1
    • 10 7 4 1 -2
    • 7 4 1
    • 10 3
    Answer and explanation

    Correct answer: 10 7 4 1

    i starts at 10 and drops by 3 each time: 10, 7, 4, 1; at -2 the condition i > 0 is false so the loop stops before printing.
