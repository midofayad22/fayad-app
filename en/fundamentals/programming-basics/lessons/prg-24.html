PARADIGMS

More than one way to think about code

Learning objectives

  • Distinguish procedural, object-oriented and functional styles.
  • Solve the same problem in three ways.
  • Understand that modern languages mix several paradigms.

Prerequisites

  • The Functions, Arrays and Objects lessons.

What is a paradigm?

A paradigm is a style of organising a program and thinking about a problem; it is not a language. We solve the following task three ways: “add up the squares of the even numbers in a list”.

1) Procedural

A sequence of steps that change variables, organised into functions.

2) Functional

We compose small functions without mutating the original data: filter, then map, then reduce.

3) Object-oriented

We bundle data and behaviour in one object with its own internal state.

ParadigmCore ideaFits
ProceduralSteps and instructionsScripts and simple jobs
FunctionalPure functions and immutable dataData transformation
Object-orientedObjects with state and behaviourLarge models such as games and interfaces

Common mistakes

  • Believing one paradigm is always the “correct” one.
  • Mutating the original array inside map, which breaks the functional style.
Exercise What is a pure function?
Show solution

A function that always gives the same result for the same input and changes nothing outside itself (no globals, no printing, no mutating the array passed in). That makes it easy to test.

Summary

  • A paradigm is a way of thinking, not a language.
  • Procedural is steps, functional is composing functions, object-oriented is data with behaviour.

Next step: Now we open the box: how does a language become execution? Compilers and interpreters.

Core idea

Different paradigms solve the same problem with different organisation, and modern languages blend them.

Worked example

See the idea in code

JavaScript 
const nums = [1, 2, 3, 4, 5, 6];
const result = nums
.filter((n) => n % 2 === 1)
.map((n) => n * 10);
console.log(result);
Practice

Challenge yourself

Interactive exercise

Write sumOddCubes(list) in the functional style (filter, map, reduce) returning the sum of the cubes of the odd numbers. Do not mutate the original list.

Test yourself

  1. Which functions are used together in the functional style to transform a list?

    • filter, map and reduce
    • alert and prompt
    • push and pop only
    • eval
    Answer and explanation

    Correct answer: filter, map and reduce

    They filter, transform and combine without changing the original list.

  2. Which paradigm bundles data and behaviour in an object?

    • Object-oriented
    • Procedural only
    • None
    • Functional only
    Answer and explanation

    Correct answer: Object-oriented

    An object has properties (state) and methods (behaviour).

  3. Which of these is a pure function?

    • (a, b) => a + b
    • A function that changes a global variable
    • A function that prints to the screen
    • A function that depends on Math.random
    Answer and explanation

    Correct answer: (a, b) => a + b

    Same inputs give the same result with no side effects.

  4. Can you use more than one paradigm in JavaScript?

    • Yes
    • No
    • Only in the browser
    • Only in Node
    Answer and explanation

    Correct answer: Yes

    JavaScript is a multi-paradigm language.

  5. What is the difference between the imperative and declarative styles?

    • Imperative describes how to carry out the steps in detail, declarative describes what result is wanted
    • Imperative uses no variables and declarative does
    • Declarative does not work in JavaScript
    • There is no difference except the names
    Answer and explanation

    Correct answer: Imperative describes how to carry out the steps in detail, declarative describes what result is wanted

    A for loop that sums numbers step by step is imperative, while reduce or map states what is wanted. JavaScript lets you mix both styles.
