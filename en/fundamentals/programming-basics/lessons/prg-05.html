LANGUAGES

Why are there so many programming languages?

A programming language is a way to communicate with the computer

There are many languages because each one was designed to suit certain types of projects and problems.

JavaScript

Essential for web development and interactivity inside web pages.

Python

Famous for being easy to learn, and for artificial intelligence and data.

C / C++

Used in systems and high-performance software.

Java

Used in large and varied applications, systems, and projects.

Core idea

There is no single programming language that is best for everything; choosing a language depends on the problem, the platform, and the project requirements.

Worked example

Practice

Challenge yourself

Test yourself

  1. Why are there multiple programming languages?

    • Because all languages are identical
    • Because each language has different uses and features
    • To increase file sizes
    • Because the computer cannot learn
    Answer and explanation

    Correct answer: Because each language has different uses and features

  2. You want a web page to react to visitor clicks inside the browser. Which language is the natural choice?

    • JavaScript
    • C for writing an operating system
    • SQL
    • Assembly
    Answer and explanation

    Correct answer: JavaScript

    Browsers run JavaScript directly, so it is the language for web interactivity. SQL is meant for querying databases, not for browser interfaces.

  3. You know JavaScript well and now learn Python. What transfers over most easily?

    • The exact syntax with all its characters and punctuation
    • The concepts such as variables, conditions, loops and functions
    • Nothing, each language is a separate world
    • The names of the ready-made libraries
    Answer and explanation

    Correct answer: The concepts such as variables, conditions, loops and functions

    Languages differ in syntax but share the core ideas, which is why a second language is much faster to learn than the first.

  4. Why do we write in high-level languages like JavaScript instead of writing machine code directly?

    • Because the processor understands JavaScript directly
    • Because they are closer to human language and a compiler or interpreter converts them to machine code
    • Because machine code is not allowed
    • Because high-level languages need no translation
    Answer and explanation

    Correct answer: Because they are closer to human language and a compiler or interpreter converts them to machine code

    The processor only understands binary instructions, so code must be translated. High-level languages make writing easier and less error-prone.

  5. A team is building an operating system kernel and needs precise memory control and high performance. Which choice fits best?

    • A systems language close to the hardware, such as C or Rust
    • A styling language such as CSS
    • A spreadsheet tool
    • A scripting language that runs only in the browser
    Answer and explanation

    Correct answer: A systems language close to the hardware, such as C or Rust

    The language choice follows the task, and systems languages give control over memory and performance. Browser languages do not reach that level of hardware.
