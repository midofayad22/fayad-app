DATA TYPES

Understand the type of value your program works with

Why do Data Types exist?

Not all data is of the same type. A number is different from text, and a boolean value is different from an Array or Object.

String

Text such as "Hello".

Number

A number such as 25.

Boolean

true or false.

Object

A collection of related data.

The basic types

String

Text inside quotes: "hello"

Number

Whole and decimal numbers: 42 and 3.14

Boolean

Only two values: true and false

undefined / null

undefined: no value has been given yet. null: “nothing”, chosen on purpose.

The type decides the behaviour

The + operator adds numbers but joins strings. Understanding the type explains results that look strange:

console.log(5 + 2);      // 7   (numbers)
console.log("5" + 2);    // "52" (string + number: joined)
console.log("5" * 2);    // 10  (* cannot join, so the string becomes a number)
console.log(typeof "5"); // "string"

A value that comes from an input box or a file is always a string, even if it looks like a number. Convert it with Number("20") before calculating.

Decimal fractions

Computers store decimals in binary, so tiny differences can appear:

console.log(0.1 + 0.2);            // 0.30000000000000004
console.log((0.1 + 0.2).toFixed(2)); // "0.30" (for display only)
Core idea

Knowing the data type matters because the operations you can perform depend on the type of the value.

Worked example

See the idea in code

JavaScript 
const name = "Abdullhamid";
const age = 20;
const isStudent = true;
console.log(typeof name);
console.log(typeof age);
console.log(typeof isStudent);
Practice

Challenge yourself

Interactive exercise

The variable price holds the string "20". Create a variable named total equal to price converted to a number and multiplied by 2.

Test yourself

  1. Which type is used to store true or false?

    • String
    • Number
    • Boolean
    • Array
    Answer and explanation

    Correct answer: Boolean

    The Boolean type holds exactly one of two values, true or false, and it is the basis of decisions inside conditions.

  2. What is the result of: "5" + 2

    • 7
    • "52"
    • Error
    • NaN
    Answer and explanation

    Correct answer: "52"

    When one side of + is a string, JavaScript joins the values as text, so the result is "52".

  3. What does console.log(typeof 42) print?

    • "number"
    • "integer"
    • "string"
    • 42
    Answer and explanation

    Correct answer: "number"

    typeof returns the type name as a string. All numbers, whole or decimal, have the type number.

  4. The variable let city; was given no value. What is its value?

    • null
    • 0
    • undefined
    • ""
    Answer and explanation

    Correct answer: undefined

    A variable declared without a value automatically holds undefined. null is something we write on purpose.

  5. What does this line print? console.log("7" - 2);

    • 72
    • 5
    • NaN
    • An error
    Answer and explanation

    Correct answer: 5

    The minus operator converts the string "7" to the number 7, so the result is 5. Only + concatenates strings, which is why "7" + 2 gives 72.
