DATA STRUCTURES

Organize related data

What is an Object?

An Object is used to group data related to a specific entity using Properties and Values.

For example, a user can be represented using a name, an age, and an email address.

Core idea

Objects make complex data more organized because they link each value to a clear name.

Worked example

See the idea in code

JavaScript 
const user = {
name: "Abdullhamid",
age: 20,
role: "Developer"
};
console.log(user.name);
console.log(user.role);
Practice

Challenge yourself

Test yourself

  1. What does an Object use to store data?

    • Properties and Values
    • Loops only
    • Images only
    • Files
    Answer and explanation

    Correct answer: Properties and Values

  2. What is the output? const p = { name: "Sara", age: 20 }; p.age = 21; console.log(p.age);

    • 20
    • 21
    • An error because p is constant
    • undefined
    Answer and explanation

    Correct answer: 21

    const fixes the name's binding to the object, not the object's contents, so properties can change. An error appears only when you try p = {} again.

  3. What does it print? const p = { name: "Sara" }; console.log(p.email);

    • undefined
    • null
    • An error
    • An empty string
    Answer and explanation

    Correct answer: undefined

    Reading a missing property does not throw; it returns undefined. An error occurs only when you read from undefined itself.

  4. const p = { name: "Sara" }; const key = "name"; Which expression prints Sara?

    • console.log(p.key)
    • console.log(p[name])
    • console.log(p[key])
    • console.log(key.p)
    Answer and explanation

    Correct answer: console.log(p[key])

    Brackets evaluate the variable key so it becomes p["name"]. p.key looks for a property literally named key and gives undefined.

  5. You have a book with a title, an author and a page count. What is the best way to represent it?

    • An array ["JS", "Ali", 300] because order always suffices
    • Three separate variables with random names
    • One string that contains all the values
    • An object { title, author, pages } because each value gets a clear name
    Answer and explanation

    Correct answer: An object { title, author, pages } because each value gets a clear name

    An object ties each value to a descriptive name so the code reads easily (book.pages). An array relies on index numbers that carry no meaning.
