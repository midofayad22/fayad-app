SYNTAX

The language rules you write code with

What does Syntax mean?

Syntax is the set of rules that defines the correct form for writing commands in a programming language.

Just as natural languages have rules, JavaScript and other languages have rules that must be followed.

Syntax errors

If you write code in a way that violates the language rules, you may get a Syntax Error.

Core idea

Syntax defines how you must write the code, while Logic defines whether the code solves the problem in the right way or not.

Worked example

See the idea in code

JavaScript 
const name = "FAYBIT";
console.log(name);
Practice

Challenge yourself

Test yourself

  1. What is meant by Syntax?

    • The rules for writing code
    • Computer speed
    • Program size
    • Processor type
    Answer and explanation

    Correct answer: The rules for writing code

  2. What happens when you run a file containing: console.log("A"); console.log("B"

    • It prints A and then stops at the error
    • It prints A then B
    • Nothing is printed and a SyntaxError appears because the whole file is checked before running
    • It prints B only
    Answer and explanation

    Correct answer: Nothing is printed and a SyntaxError appears because the whole file is checked before running

    Syntax errors are found when the file is parsed, before any execution begins, so no line runs. Thinking the valid lines run first is incorrect.

  3. What happens? let Name = "Sara"; console.log(name);

    • It prints Sara because upper and lower case are the same
    • It prints undefined
    • A ReferenceError, because name and Name are different names
    • A SyntaxError
    Answer and explanation

    Correct answer: A ReferenceError, because name and Name are different names

    JavaScript is case-sensitive, so name differs from Name and is not defined here. The syntax is valid, which is why it is not a SyntaxError.

  4. You wanted to add 5 and 3 but wrote console.log(5 - 3) and got 2. What kind of error is this?

    • A syntax error because a symbol is missing
    • A logic error: the code is valid but does not do what was intended
    • An internet error
    • No error, because the program ran
    Answer and explanation

    Correct answer: A logic error: the code is valid but does not do what was intended

    The syntax is valid so the program ran without an error message, but the result is not what was intended. These errors are harder because the computer does not report them.

  5. You wanted to store He said "hi" in a variable, so you wrote let s = "He said "hi""; and got an error. Which fix is correct?

    • let s = 'He said "hi"';
    • let s = He said "hi";
    • let s = "He said "hi"";;
    • let s = ("He said "hi"");
    Answer and explanation

    Correct answer: let s = 'He said "hi"';

    A double quote inside the text ends the string early. Wrapping with a different quote type, or escaping with a backslash, solves it; extra semicolons or parentheses change nothing.
