FUNCTIONS

Make Functions more flexible

Parameters

A Parameter is a variable that a Function receives so that it can work with different data.

Arguments

An Argument is the actual value we pass to a Function when we call it.

Core idea

Parameters make a Function reusable with different data, instead of writing a new Function for each case.

Worked example

See the idea in code

JavaScript 
function greet(name) {
console.log("Hello " + name);
}
greet("Ali");
greet("Mona");
Practice

Challenge yourself

Test yourself

  1. In the example, what is name?

    • Argument
    • Parameter
    • Operator
    • Loop
    Answer and explanation

    Correct answer: Parameter

  2. What is the output? function greet(name, greeting) { return greeting + ", " + name; } console.log(greet("Ali", "Hi"));

    • Ali, Hi
    • Hi, Ali
    • Hi Ali
    • undefined
    Answer and explanation

    Correct answer: Hi, Ali

    Arguments match parameters by position: "Ali" goes to name and "Hi" to greeting. The concatenation order inside the function gives Hi, Ali.

  3. What does the code print? function f(a, b) { return a + b; } console.log(f(2));

    • 2
    • An error that stops the program
    • 0
    • NaN
    Answer and explanation

    Correct answer: NaN

    The parameter b received no argument so it is undefined, and 2 + undefined gives NaN. JavaScript does not throw an error when arguments are missing.

  4. What is the output? function p(x, y = 10) { return x + y; } console.log(p(1));

    • 11
    • 1
    • NaN
    • 10
    Answer and explanation

    Correct answer: 11

    The default value y = 10 is used when no second argument is passed, so the result is 1 + 10 = 11. NaN would appear only without a default.

  5. What is v? function change(n) { n = 99; } let v = 5; change(v); console.log(v);

    • 99
    • 5
    • undefined
    • An error
    Answer and explanation

    Correct answer: 5

    Numbers are passed as a copy of the value, so changing n inside the function does not change the outer v. It stays 5.
