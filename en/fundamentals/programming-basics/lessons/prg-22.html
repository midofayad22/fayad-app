Data Structures: Stack, Queue, Map and Set

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

DATA STRUCTURES

Pick the storage shape that fits the task

Learning objectives

  • Know the stack and the queue.
  • Use Map and Set in JavaScript.
  • Choose a structure by the operations you need.

Prerequisites

  • The Arrays (prg-15) and Objects (prg-16) lessons.

Why structure matters

A data structure is an organised way of storing data that makes certain operations fast and simple. Arrays are great for lists, but not for every task. Choosing the structure is part of designing the algorithm.

Stack: last in, first out

Like a pile of plates: you add and remove only at the top. Used by the Undo button, the call stack and bracket checking.

Queue: first in, first out

Like a waiting line: items are added at the end and taken from the front. Used for printing, CPU tasks and server requests.

Map and Set

  • Map: key to value pairs with fast lookup by key; any type can be a key.
  • Set: a collection of unique values with no duplicates and fast membership checks.
TaskSuitable structure
Undo / redoStack
Task queueQueue
Counting word frequencyMap
Removing duplicatesSet

Common mistakes

  • Using shift() on a huge array as a queue: it moves every element. For large sizes use a dedicated structure.
  • Confusing Map with a plain object {}: object keys are converted to strings.
Exercise Which structure would you use to know whether a user has visited a page before?
Show solution

A Set storing unique page URLs; has(url) answers immediately.

Summary

  • Stack: last in, first out.
  • Queue: first in, first out.
  • Map for lookup by key, Set for unique values.

Next step: How do we measure the efficiency of our choice? Time complexity.

Core idea

The right structure makes a solution simpler and faster; choose by the operations you need.

Worked example

See the idea in code

JavaScript 
const stack = [];
for (const ch of "abc") stack.push(ch);
let reversed = "";
while (stack.length) reversed += stack.pop();
console.log(reversed);
Practice

Challenge yourself

Interactive exercise

Write isBalanced(text) that returns true when the () brackets are balanced (every opening has a matching closing in the right order), otherwise false. Use a stack.

Test yourself

  1. Which structure gives last-in, first-out order?

    • Stack
    • Queue
    • Set
    • Map
    Answer and explanation

    Correct answer: Stack

    In a stack elements are added and removed at the top.

  2. What is new Set([1,1,2]).size?

    • 2
    • 3
    • 1
    • 0
    Answer and explanation

    Correct answer: 2

    A Set removes duplicates, leaving 1 and 2.

  3. Which structure suits counting how often each word appears?

    • A Map from word to count
    • A single number
    • One long string
    • A stack
    Answer and explanation

    Correct answer: A Map from word to count

    We look the word up by key and increment its counter.

  4. Which operation takes the oldest item from a queue?

    • shift()
    • pop()
    • push()
    • length
    Answer and explanation

    Correct answer: shift()

    shift() removes the first item, while pop() removes the last.

  5. What is the output? const m = new Map(); m.set("a", 1); m.set("a", 2); console.log(m.size, m.get("a"));

    • 2 1
    • 1 2
    • 1 1
    • 2 2
    Answer and explanation

    Correct answer: 1 2

    A Map key is unique, so the second set for "a" replaces the old value instead of adding an entry. Hence the size is 1 and the value is 2.
