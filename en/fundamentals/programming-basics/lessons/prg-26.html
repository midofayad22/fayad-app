TOKENIZER

Splitting text into meaningful tokens

Learning objectives

  • Understand what a token is.
  • Write a tokenizer for arithmetic.
  • Handle whitespace and errors.

Prerequisites

  • The compilers lesson (prg-25) and the Loops and Strings lessons.

What is a token?

When you read 12 + 3*4 you see numbers and operations. The computer sees only a string of characters. The tokenizer groups characters into meaningful units: a number, an operator, a bracket. Each token has a type and a value.

The algorithm

  1. Start at position 0.
  2. Skip whitespace.
  3. If the character is a digit, read all consecutive digits as one number.
  4. If it is an operator or bracket, create a token for it.
  5. Otherwise it is an unknown character: report an error with its position.

A step-by-step trace

We walk through 3 * (2 + 4) one character at a time. The tokenizer keeps a position i and decides at each step what to do:

When it fails: tokenizer errors

The tokenizer does not understand meaning, but it knows the allowed characters. Any character outside the list is a lexical error. Example: 3 $ 4 produces the message below, which names the position so the user can find the problem quickly:

Common mistakes

  • Reading a number one character at a time: 12 becomes 1 and 2.
  • Forgetting to advance the index i, causing an infinite loop.
Exercise How many tokens are in (1+2)*3?
Show solution

Seven: (, 1, +, 2, ), * and 3.

Summary

  • The tokenizer turns characters into units with a type and a value.
  • It skips whitespace and reports unknown characters.

Next step: We turn the token list into a tree: the parser.

Core idea

The tokenizer is the first stage: it turns raw text into symbols the parser can understand.

Worked example

See the idea in code

JavaScript 
const src = "7 * (2 + 1)";
const tokens = src.match(/\d+|[-+*/()]/g);
console.log(tokens);

Write tokenize(src) returning an array of strings: numbers (possibly decimal) and the operators + - * / ( ), skipping whitespace. Example: "12 + 3.5*4" gives ["12","+","3.5","*","4"].

Test yourself

  1. What is a token?

    • A meaningful unit such as a number or operator
    • A password
    • A kind of error
    • A file
    Answer and explanation

    Correct answer: A meaningful unit such as a number or operator

    It has a type and a value and is produced by the lexer.

  2. Why do we read consecutive digits together?

    • So that 12 is one number, not two digits
    • Only to save memory
    • No reason
    • To change the colour
    Answer and explanation

    Correct answer: So that 12 is one number, not two digits

    A number is a single unit of meaning.

  3. What should the tokenizer do with an unknown character such as @?

    • Report an error naming the position
    • Always silently ignore it
    • Delete the program
    • Shut down the machine
    Answer and explanation

    Correct answer: Report an error naming the position

    A clear error is better than a silent wrong result.

  4. How many tokens are in 8/2?

    • 3
    • 2
    • 1
    • 4
    Answer and explanation

    Correct answer: 3

    8, / and 2.

  5. How many tokens does the lexer produce from the text: (10 - 4) * 2?

    • 5
    • 7
    • 9
    • 11
    Answer and explanation

    Correct answer: 7

    The tokens are ( , 10 , - , 4 , ) , * , 2, which is 7. Multi-digit numbers like 10 count as one token and spaces are not counted.
