PARSER

From a list of tokens to a tree that represents structure

Learning objectives

  • Understand an AST.
  • Know why multiplication binds tighter than addition.
  • Read and write a recursive descent parser.

Prerequisites

  • The tokenizer (prg-26) and recursion (prg-21) lessons.

Why is a list not enough?

The list 2 + 3 * 4 does not say which operation runs first. The parser adds structure: it builds an AST (abstract syntax tree) that places multiplication deeper than addition so it is computed first.

Read the tree from the leaves to the root: 3 * 4 = 12 is computed first because it is deeper, then 2 + 12 = 14. Brackets in (2 + 3) * 4 change the shape of the tree itself:

Common mistakes

  • Putting addition and multiplication in one rule, which loses precedence.
  • Forgetting to consume the closing bracket ) after the inner expression.
Exercise Why does the parser put the term rule beneath expression and not the other way round?
Show solution

Because the deeper function finishes first, so multiplications are grouped before additions. The order of the rules is what produces operator precedence.

Summary

  • An AST represents program structure as a tree.
  • The grammar determines precedence.
  • Recursive descent: one function per rule.

Next step: We put everything together in a tiny language.

Core idea

The parser turns tokens into a tree that carries structure and precedence, and evaluating the tree recursively gives the result.

Worked example

See the idea in code

JavaScript 
const ast = { op: "+", left: { num: 2 }, right: { op: "*", left: { num: 3 }, right: { num: 4 } } };
function evaluate(n) {
if (n.num !== undefined) return n.num;
const a = evaluate(n.left), b = evaluate(n.right);
return n.op === "+" ? a + b : a * b;
}
console.log(evaluate(ast));

Test yourself

  1. What is an AST for?

    • It represents program structure and operator precedence
    • It stores images
    • It speeds up the internet
    • It deletes errors
    Answer and explanation

    Correct answer: It represents program structure and operator precedence

    The tree is the representation an interpreter evaluates or a compiler translates.

  2. Where is the multiplication in the tree of 2 + 3 * 4?

    • Deeper than the addition
    • At the root
    • Outside the tree
    • Nowhere
    Answer and explanation

    Correct answer: Deeper than the addition

    The deeper node is evaluated first.

  3. What is the result of evaluating (2 + 3) * 4?

    • 20
    • 14
    • 24
    • 9
    Answer and explanation

    Correct answer: 20

    The brackets push the addition deeper: 5 × 4.

  4. Which programming concept does recursive descent use?

    • Recursion
    • Images
    • Sound
    • Disks
    Answer and explanation

    Correct answer: Recursion

    Functions call each other and themselves for brackets.

  5. What is the root of the AST for 2 * 3 + 4 and what does it evaluate to?

    • The root is * and the value is 14
    • The root is + and the value is 10, with 2 * 3 as its left child
    • The root is + and the value is 9
    • The tree has no root
    Answer and explanation

    Correct answer: The root is + and the value is 10, with 2 * 3 as its left child

    The lowest-precedence operation sits at the top because it runs last, so the root is + with left child 2*3 = 6, and 6 + 4 = 10. Putting * at the root would mean computing (3 + 4) first, a precedence mistake.
