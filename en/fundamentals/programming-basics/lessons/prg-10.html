CONTROL FLOW

Make the program take decisions

Conditional Statements

Conditions allow the program to execute different instructions depending on whether a certain condition is met.

In JavaScript we most often use if and else.

The idea

If the condition is met

Execute the first set of instructions.

If it is not met

Move on to the alternative instructions.

Making a decision, step by step

An if statement runs the block in curly braces only when the condition is true. You can add else if for more conditions and else for everything else. Conditions are checked in order and only the first true block runs.

const score = 72;
if (score >= 90) {
console.log("A");
} else if (score >= 70) {
console.log("B");   // this runs, then checking stops
} else {
console.log("C");
}

Order of conditions matters

If we wrote score >= 50 before score >= 90, a student with 95 would enter the first condition and never reach the second. Start with the most specific condition.

Combining conditions

Use && and || to build one condition out of several:

const age = 17, hasParent = true;
if (age >= 18 || (age >= 15 && hasParent)) {
console.log("allowed");
} else {
console.log("not allowed");
}

Three common mistakes: using = instead of === inside a condition, forgetting the curly braces, and ordering the conditions wrongly.

Core idea

Conditions turn a program from a fixed set of commands into one that can make decisions.

Worked example

See the idea in code

JavaScript 
const score = 85;
if (score >= 50) {
console.log("Passed");
} else {
console.log("Try again");
}
Practice

Challenge yourself

Interactive exercise

The variable score = 72. Create a variable named result with the value "pass" if score ≥ 50, otherwise "fail", using if / else.

Test yourself

  1. What is if used for?

    • Storing images
    • Making a decision based on a condition
    • Only repeating text
    • Creating a file
    Answer and explanation

    Correct answer: Making a decision based on a condition

    if lets the program choose a path based on the result of a condition (true or false), which is what making a decision means.

  2. What is printed? let n = 5; if (n > 10) { console.log("A"); } else if (n > 3) { console.log("B"); } else { console.log("C"); }

    • A
    • B
    • C
    • B then C
    Answer and explanation

    Correct answer: B

    The first condition is false (5 is not greater than 10), the second is true (5 > 3), so block B runs and checking stops.

  3. Which condition holds when age is between 18 and 65 (inclusive)?

    • age >= 18 || age <= 65
    • age >= 18 && age <= 65
    • age > 18 && age < 65
    • age = 18 && age = 65
    Answer and explanation

    Correct answer: age >= 18 && age <= 65

    We need both conditions at once, so we use &&. || would be true for almost any age, and = assigns instead of comparing.

  4. What is wrong with: if (x = 5) { ... }

    • Nothing, it is correct
    • === should be used for comparison instead of =
    • The parentheses must be removed
    • x must be a string
    Answer and explanation

    Correct answer: === should be used for comparison instead of =

    = assigns 5 to x and the result then counts as an always-true condition. Comparison is done with ===

  5. The code: if (n > 3) { console.log("big"); } else if (n > 10) { console.log("huge"); } with n = 20. What is the problem?

    • It prints only big and never huge, because the first condition catches every value above 3
    • It prints huge because 20 is greater than 10
    • It prints big and then huge
    • A syntax error appears
    Answer and explanation

    Correct answer: It prints only big and never huge, because the first condition catches every value above 3

    An else if chain stops at the first true condition, and 20 is greater than 3 so the first branch runs. The most specific condition (n > 10) must come first.
