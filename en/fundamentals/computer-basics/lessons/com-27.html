The Boot Process

Learning objectives

  • Trace the steps from the power button to the desktop.
  • Distinguish BIOS, UEFI and the bootloader.
  • Understand where the first process starts.

Prerequisites

  • Lessons: the motherboard (com-07), storage (com-06) and OS architecture (com-21).

Why is booting complicated?

At power-on RAM is empty and the system sits on disk, so how does the system get loaded? A chain of small programs, each loading a bigger one, until the whole kernel runs. This idea is called bootstrapping.

ComparisonBIOSUEFI
AgeOld (since the 1980s)Modern, replacing BIOS
Partition schemeMBR (up to 2 TB)GPT (huge disks)
SecurityNo verificationSecure Boot verifies the bootloader signature

Common mistakes

  • Disabling Secure Boot without understanding the security impact.
  • Deleting the EFI partition while formatting disks, so the system will not start.
Exercise You installed Windows after Linux and the Linux option vanished at startup. What is the likely explanation?
Show solution

The Windows installer replaced the bootloader with its own, which does not know about Linux. The fix: reinstall GRUB or add a Linux entry in the UEFI settings.

Summary

  • Boot is a chain: firmware, bootloader, kernel, first process.
  • UEFI replaces BIOS and adds Secure Boot.

Next step: Who is allowed to do what? Users and permissions.

Core concept

Booting is a sequence of small programs, each starting a larger one, until the whole system runs.

Hands-on practice

Try it yourself

Find out whether your machine boots via UEFI or BIOS (msinfo32 on Windows, or the path <code>/sys/firmware/efi</code> on Linux) and whether Secure Boot is on.

Test yourself

  1. What is the advantage of an interrupt over polling?

    • The CPU does not waste time asking repeatedly
    • It works without hardware
    • It enlarges the screen
    • It removes the need for drivers
    Answer and explanation

    Correct answer: The CPU does not waste time asking repeatedly

  2. What does a driver do?

    • Translates between a uniform interface the OS knows and the language of specific hardware
    • Enlarges the screen
    • Deletes old files
    • Replaces the CPU
    Answer and explanation

    Correct answer: Translates between a uniform interface the OS knows and the language of specific hardware

    Thanks to it, an app says print and the driver knows how to talk to that exact printer.

  3. What is the benefit of DMA?

    • It replaces interrupts with polling
    • It moves large blocks between a device and RAM without the CPU moving each byte
    • It makes the CPU keep asking the device
    • It encrypts the disk
    Answer and explanation

    Correct answer: It moves large blocks between a device and RAM without the CPU moving each byte

    When done, DMA raises one interrupt, leaving the CPU free for other work.

  4. After a graphics driver update a problem appeared and you kept no earlier version. What common mistake is this?

    • Typing too fast
    • Turning on the device in the morning
    • Updating a driver without a restore point or the old installer
    • Using the screen too long
    Answer and explanation

    Correct answer: Updating a driver without a restore point or the old installer

    Many problems come from incompatible drivers, so keeping the old one makes rollback easy.

  5. Why be careful installing a driver from an untrusted source?

    • Because it uses ink
    • Because it changes the system language
    • There is no risk
    • Because it usually runs with kernel privileges and could give an attacker full control
    Answer and explanation

    Correct answer: Because it usually runs with kernel privileges and could give an attacker full control

    A bug or malicious code in a driver runs with the highest privileges.
