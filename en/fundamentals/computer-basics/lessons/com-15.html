Internet and Networking Basics

Learning objectives

  • Tell a LAN, a WAN and the Internet apart and describe the roles of a Router and a Switch.
  • Explain an IP Address, DNS, a Packet, ports and the Client-Server model.
  • Distinguish Latency from Bandwidth and read ping and nslookup output.

Prerequisites

  • The bits and bytes lesson (com-13) for transfer-speed arithmetic, and the operating-system lesson (com-10).

Introduction: two computers talking

A Network is a group of devices connected to exchange data, by cable or radio waves. As soon as two devices connect, questions arise: how is each identified? how does a message reach only its target? what common language do they use? The answers form the structure of the internet, solved by layers of rules called a Protocol.

Kinds of networks and their parts

  • LAN: a local area network within a small area such as a home, office or school.
  • WAN: a wide area network linking distant sites across cities or countries, often over lines leased from providers.
  • Internet: not one network, but a network of thousands of independent networks interconnected by shared protocols.

The difference: a Switch joins devices inside one network and delivers a message only to the intended device by its hardware MAC Address, whereas a Router joins between networks and chooses the message's next hop by its IP address. At home one box often combines several roles: router, access point and a small switch.

Addresses and DNS

Every device on the network has an IP Address: a number that identifies it and gives its location. In IPv4 the address is 32 bits, written as four numbers from 0 to 255 separated by dots, such as 192.168.1.20. The possible addresses number 2 to the power 32 = 4,294,967,296, not enough for every device on Earth, so IPv6 appeared with 128-bit addresses. Private ranges such as 192.168.x.x are reserved for local networks and reused in many homes, and the router translates between them and your public address through NAT.

People remember names, not numbers, and that is where DNS (Domain Name System) comes in: a distributed system like a phone book that turns a name such as example.com into an IP address. When you type the address in the browser your device asks a DNS server (usually assigned by your provider), which replies with the number, and only then does the browser connect to the numeric address.

Packets, client and server, and ports

Data is not sent in one piece; it is split into small Packets, each with a header carrying the sender and receiver addresses and a sequence number. Each packet follows the best path available, and may arrive late or out of order, so the receiver reorders them and asks for anything lost. That is an advantage: if part of the network fails, packets can take another route. A typical Ethernet packet is about 1500 bytes, of which about 1460 carry content after the headers. So a file of 1,000,000 bytes needs about 685 packets.

Applications communicate in a Client-Server pattern: a Client asks, like the browser on your phone, and a Server is a computer that runs continuously and answers with resources. Because one machine runs many services at once, there is a Port: a number from 0 to 65,535 that identifies which application on the machine is meant, just as an apartment number completes a building's address.

Latency versus bandwidth

Many people confuse the two. Bandwidth is how much data can be moved per second, like a road's width, measured in Mbps. Latency is how long a tiny message takes to arrive, like a road's length, measured in milliseconds, and it is what ping reports. A wider pipe cannot cancel a delay imposed by distance: light in optical fibre covers about 200,000 km/s, so 6,000 km takes 30 ms one way, at least 60 ms round trip.

That is why each matters for different things: downloading a huge file depends on bandwidth, whereas video calls and real-time games depend on latency. Jitter is the fluctuation of latency from one packet to the next, and it is what makes audio stutter.

Real-world applications

  • Troubleshooting: if ping works to a numeric address but not to a name, the problem is probably DNS.
  • Home networks: connecting a game console by cable instead of Wi-Fi lowers and steadies latency.
  • Cloud services: companies place servers near their users to shorten the distance.

Common mistakes

  • “The internet is the web”: the web is a service running on top of the internet, alongside others such as email and calls.
  • “More speed means less delay”: bandwidth and latency are largely independent.
  • “A router and a switch are the same”: a switch works inside a network, a router connects between networks.
  • “Everyone in the world sees my device's IP”: a 192.168.x.x address is local only; websites see the router's public address.
Exercise Calculation: you download a 600 MB file on a 50 Mbps connection. How long does it take in theory? Then what extra delay arises if the file is fetched in 100 small sequential requests with 40 ms latency each?
Show solution

600 MB = 600 × 8 = 4,800 Mb. Time = 4,800 ÷ 50 = 96 seconds. In bytes: 50 ÷ 8 = 6.25 MB/s and 600 ÷ 6.25 = 96 seconds again. 100 sequential requests add 100 × 40 ms = 4,000 ms = 4 seconds of waiting, bringing the total to about 100 seconds. This shows latency matters most when requests are many and small.

Exercise Reasoning: the address http://203.0.113.5 opens in the browser but example.com does not. What is the most likely cause and how do you confirm it?
Show solution

Connectivity is fine since the numeric address works, so the problem is name resolution, that is DNS. To confirm, run nslookup example.com: if it returns no address or an error, the DNS server is down or misconfigured. The fix is to change the DNS server in the network settings to another public one, or restart the router, then test again.

Exercise Hands-on: find your device's local IP address and measure latency to a website.
Show solution

On Windows type ipconfig in the command prompt and look for “IPv4 Address”; on Linux use ip addr. You will usually see the form 192.168.x.x. Then run ping example.com and note the average time. Repeat over Wi-Fi and by cable if you can and compare, then try a site on a distant continent and notice the time grow with distance. Remember that the numbers you see belong to your network and will not match the sample.

Summary

  • A LAN is local, a WAN is wide, and the internet is a network of networks; a switch connects inside one and a router connects between them.
  • An IP address identifies the device, DNS turns names into addresses, packets carry the data and ports pick the application.
  • The client asks and the server responds.
  • Bandwidth is the amount per second, latency is how fast a message arrives, and the two are largely independent.

Test yourself

  1. What is the internet?

    • A single computer
    • A global network of networks
    • A drawing program
    • A type of storage unit
    Answer and explanation

    Correct answer: A global network of networks

  2. What is the difference between a switch and a router?

    • A switch joins networks using IP, a router joins within a network
    • A switch joins devices inside one network by MAC address, a router joins between networks by IP address
    • There is no difference
    • A router stores files
    Answer and explanation

    Correct answer: A switch joins devices inside one network by MAC address, a router joins between networks by IP address

    At home one box often combines the roles of router, access point and a small switch.

  3. What is the job of DNS?

    • Encrypting the connection
    • Speeding up the network
    • Turning a name such as example.com into an IP address
    • Blocking ads
    Answer and explanation

    Correct answer: Turning a name such as example.com into an IP address

    People remember names, not numbers, so your device asks a DNS server and then connects to the numeric address.

  4. Which of the following addresses is in a private range reserved for local networks?

    • 8.8.8.8
    • 300.1.1.1
    • 192.168.1.20
    • 256.256.256.256
    Answer and explanation

    Correct answer: 192.168.1.20

    The 192.168.x.x range is private and reused in many homes; NAT translates it to your public address.

  5. ping shows: 3 packets transmitted, 3 received, time=38.2 ms. What does it mean?

    • No packet loss and a round trip of about 38 ms
    • All packets were lost
    • Download speed is 38 megabits
    • The hop count is 38
    Answer and explanation

    Correct answer: No packet loss and a round trip of about 38 ms

    The time field is the round trip (latency), and 0% packet loss means every packet arrived.
