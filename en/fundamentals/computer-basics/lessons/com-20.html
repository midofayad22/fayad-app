OS Architecture: Kernel, User Space and Kernel Space

Learning objectives

  • Describe the layers of a computer from application to hardware.
  • Explain the difference between the Kernel and User Space, and why the split exists.
  • Compare monolithic kernels with microkernels.

Prerequisites

  • The lessons “Operating Systems” (com-10) and “Hardware and Software”.

Why does an OS need an architecture?

If every program could write to any memory address and talk directly to the disk and the network, a single bug in your browser could bring the whole machine down. So the operating system splits the world into two privilege levels: a small trusted level that owns everything, and an ordinary level where applications run with limits.

User mode and kernel mode

The CPU itself supports at least two modes: User Mode (restricted) and Kernel Mode (full privilege). Sensitive instructions, such as changing memory tables or touching hardware directly, are refused outside kernel mode and raise an exception that the OS handles.

AspectUser SpaceKernel Space
Who runs thereApplications and librariesThe kernel and drivers
Hardware accessIndirect, through the kernelDirect
Effect of a bugUsually only that program crashesCan crash the whole system

Kernel designs

  • Monolithic kernel: most services (files, network, drivers) live inside the kernel. Faster, but a faulty driver can take the system down. Example: Linux.
  • Microkernel: the kernel keeps the minimum (scheduling, memory, inter-process messaging) and other services run as ordinary processes. More isolated, slightly slower. Examples: MINIX and QNX.
  • Hybrid: a practical mix of both, as in Windows NT and macOS.

Common mistakes

  • Confusing “the operating system” with “the kernel”: the kernel is part of the system, not all of it.
  • Believing an application talks to the disk directly; it asks the kernel to do so.
Exercise Why can a faulty driver crash Linux, while a browser crash only closes the browser?
Show solution

A driver runs in Kernel Space with full privilege and shares memory with the kernel, so nothing shields the rest of the system. The browser runs in User Space with memory isolation, so the kernel detects the fault and terminates only that process.

Summary

  • The OS separates restricted User Space from fully privileged Kernel Space.
  • The CPU itself enforces the split through execution modes.
  • Kernel designs differ in how they trade speed for isolation.

Core concept

The kernel is the only trusted part that talks to hardware; applications run in isolation and ask it for services.

Hands-on practice

Try it yourself

Open Task Manager (Windows) or run top (Linux/macOS). Pick one application process and one system process, and write down what distinguishes them.

Test yourself

  1. Which component is primarily responsible for executing program instructions?

    • CPU
    • Monitor
    • Keyboard
    • SSD
    Answer and explanation

    Correct answer: CPU

  2. Which component temporarily stores data at high speed while programs run?

    • RAM
    • The hard disk only
    • The power supply
    • The keyboard
    Answer and explanation

    Correct answer: RAM

    RAM is fast temporary memory and loses its contents without power.

  3. What is the difference between the Internet and the Web?

    • They are two names for the same thing
    • The Web is the cables and the Internet is the browser
    • The Internet is the network of networks and the Web is a service on top of it
    • The Web is older than the Internet
    Answer and explanation

    Correct answer: The Internet is the network of networks and the Web is a service on top of it

    Email and games use the Internet without being part of the Web.

  4. How does a computer ultimately store text, images and sound?

    • As binary numbers made of 0s and 1s
    • As Arabic letters only
    • As tiny drawings inside the CPU
    • Each type in an entirely non-digital system
    Answer and explanation

    Correct answer: As binary numbers made of 0s and 1s

    All data is represented in bits, and programs interpret them as text, images or sound.

  5. Which line best describes the operating system's relation to hardware and applications?

    • It forbids applications from using hardware at all
    • It acts as a go-between, managing hardware and letting applications use it
    • It is part of the motherboard and cannot change
    • It only works when online
    Answer and explanation

    Correct answer: It acts as a go-between, managing hardware and letting applications use it

    The OS manages resources and gives applications a uniform interface.
