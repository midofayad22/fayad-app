Exercise A process is using all of the CPU. What are your steps, in order?
Show solution
  1. Identify the process and PID with top or Get-Process.
  2. Check that it is not an essential system process.
  3. Send a gentle stop request (SIGTERM) before the forceful one (SIGKILL).
  4. Investigate the cause: a stuck program or an infinite loop?

Summary

  • Commands reveal what the system does under the graphical interface.
  • The concepts are the same on Linux and Windows even if names differ.

Hands-on practice

Try it yourself

Complete the three parts, then write a short paragraph summarising what you learned about your machine.

Test yourself

  1. What do permissions 644 mean?

    • Owner read and write, everyone else read only
    • Everyone writes
    • Nobody reads
    • Only the owner executes
    Answer and explanation

    Correct answer: Owner read and write, everyone else read only

  2. A file has permissions -rwxr-x---. What can group members do?

    • Read, write and execute
    • Read and execute only
    • Nothing
    • Write only
    Answer and explanation

    Correct answer: Read and execute only

    The middle part r-x gives the group read and execute without write.

  3. What is the numeric form of rw-r--r--?

    • 755
    • 600
    • 777
    • 644
    Answer and explanation

    Correct answer: 644

    rw-=6, r--=4 and r--=4, giving 644.

  4. A user runs chmod 777 on a file to get rid of Permission denied. Why is this a mistake?

    • Because it opens the file to everyone for read, write and execute
    • Because it deletes the file
    • Because it locks the file for everyone
    • Because it changes the owner's name
    Answer and explanation

    Correct answer: Because it opens the file to everyone for read, write and execute

    Better to find why access was denied and grant the minimum that solves it.

  5. Which case is authentication rather than authorisation?

    • The system stops you editing a file you do not own
    • Scanning your fingerprint to prove who you are
    • Refusing to run a program without permission
    • Setting who may read a folder
    Answer and explanation

    Correct answer: Scanning your fingerprint to prove who you are

    Authentication answers who you are; authorisation answers what you may do.
