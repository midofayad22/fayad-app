Hardware and Software

Learning objectives

  • Distinguish Hardware, Software and Firmware with correct examples.
  • Classify software into system software and application software.
  • Explain how a program reaches the hardware through the operating system and drivers.

Prerequisites

  • The lessons “What is a computer?” and “How a computer works”.

Introduction: the body and the instructions

Imagine a piano with no pianist, or a pianist with no piano: neither makes music. A computer works the same way: hardware can carry out operations but does not know what to do, and software knows what to do but cannot run without hardware. A useful device combines the two.

Hardware: the physical part

Hardware is everything you can touch: the processor, memory, disk, motherboard, screen, keyboard and cables. In practice it divides into internal components (inside the case) and Peripherals that attach from outside, such as a printer or a mouse.

Software: the logical part

Software is a set of instructions and data written in programming languages; it cannot be touched but is stored as files. To tell kinds of software apart we classify them by function:

The operating system manages the hardware and offers services to applications, while a driver is a small program that knows how to talk to one specific device such as a graphics card or a printer. Applications serve the user directly.

Firmware: the middle ground

Firmware is a program stored permanently inside a chip in the device itself, such as UEFI on the motherboard or the program that runs a router or a TV remote. It is software living in a piece of hardware; it can sometimes be updated but it persists when power is cut.

How they cooperate: layers

Real-world applications

  • Phone updates: an update can improve your phone camera without changing the lens, because part of image quality comes from software.
  • Drivers: a new graphics card may perform poorly until you install its correct driver.
  • Smart appliances: TVs, fridges and routers are hardware driven by updatable firmware, which is how security holes get patched.
  • Cloud computing: what looks like a “virtual service” actually runs on physical hardware in data centres.

Common mistakes

  • “The disc a program comes on is software”: the disc is hardware; the program is the content recorded on it.
  • “Updating software always makes hardware faster”: an update may use hardware better but cannot raise its real capability, and it can even slow an old device.
  • “The operating system is hardware because it comes with the device”: it is a program stored on storage and can be replaced.
  • “The cloud needs no hardware”: every cloud service stands on physical servers.
Exercise Classification: classify each of these: Windows, RAM, Chrome, a monitor, UEFI, a printer driver.
Show solution

Windows: system software. RAM: hardware. Chrome: application software. The monitor: hardware (an output device). UEFI: firmware, a program stored in a chip on the motherboard. The printer driver: system software that sits between the operating system and the printer.

Exercise Reasoning: you plugged a new scanner into your computer and it does not appear in the device list although the cable is fine. What is the likely cause and fix?
Show solution

The hardware is fine, but the operating system lacks the program that talks to it, the driver. The fix is to install the driver from the manufacturer or through system updates, then reconnect the device. It shows that hardware alone is not enough.

Exercise Hands-on: open your system settings and the “About” page. Write down the processor name, memory size and operating system version, and classify each.
Show solution

You will find, for example, a processor with a certain number of cores and speed and 8 or 16 GB of memory; these describe hardware. The system name and version (such as Windows 11 or Android 14) describe software. If you see a “firmware version”, that is firmware. Notice that the version can change with an update, while the memory size needs a new part.

Summary

  • Hardware is the physical, software is the instructions, and firmware is a permanent program inside a chip.
  • Software has two main kinds: system and application.
  • An application reaches hardware through the operating system and drivers.

Core concept

Hands-on practice

Try it yourself

Try to classify the following items as Hardware or Software: Windows, RAM, Chrome, CPU, Photoshop.

Test yourself

  1. Which of the following is Software?

    • RAM
    • CPU
    • Windows
    • Motherboard
    Answer and explanation

    Correct answer: Windows

  2. What is firmware?

    • A program stored permanently inside a chip in the device itself
    • A game downloaded from an app store
    • A physical part attached from outside the device
    • A temporary file deleted at shutdown
    Answer and explanation

    Correct answer: A program stored permanently inside a chip in the device itself

    Firmware is software living in a piece of hardware and it persists without power, such as UEFI.

  3. In the printing path, which layer translates the request into commands that this specific printer understands?

    • The application
    • The operating system
    • The driver
    • The paper
    Answer and explanation

    Correct answer: The driver

    A driver is a small program that knows how to talk to one specific device such as a printer or graphics card.

  4. Someone says: "The disc a program comes on is software." What is the correction?

    • The disc is hardware; the program is the content recorded on it
    • The disc is software and the program is hardware
    • Both are hardware
    • Both are firmware
    Answer and explanation

    Correct answer: The disc is hardware; the program is the content recorded on it

    The physical object is hardware, while the instructions recorded on it are the software.

  5. Which of the following is classified as system software rather than an application?

    • A video game
    • Excel
    • Photoshop
    • A backup and compression utility
    Answer and explanation

    Correct answer: A backup and compression utility

    Utilities such as compression and backup tools belong to system software.
