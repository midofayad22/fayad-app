Modern Computing

Learning objectives

  • Explain how much computing moved to the Cloud and data centres, and tell a Virtual Machine from a Container.
  • Compare SaaS, PaaS and IaaS models and pick the right one for a given case.
  • Analyse the trade-offs of modern computing: latency, cost, privacy and energy.

Prerequisites

  • The lessons on the CPU, RAM, storage, networks and the history of computing.

Introduction: the computer is no longer only in front of you

When you order a ride through an app, stream a film or edit a document with colleagues, the device in your hand does a small part of the work, and the larger part runs on distant computers you never see. Modern computing is this distribution: handheld devices, servers in data centres, tiny devices everywhere, all connected. It is not entirely new; everything in it is built from the components you studied, only arranged differently.

Mobile, cloud and data centres

A smartphone is a full computer built around a single chip called a SoC (System on a Chip) that combines the processor, graphics and other parts to save power and space, and it runs on a battery, so everything in it is designed around efficiency. Behind your apps stands a Data Center: a building housing thousands of servers with fast networks, cooling and backup power. The Cloud is renting the capacity of such centres over the internet on demand instead of buying and operating the hardware yourself.

Virtualisation and containers

The cloud does not use a physical server per customer; it divides one server. In Virtualization a program called a Hypervisor runs several virtual machines on one piece of hardware, each with its own complete operating system that believes it has a separate computer. Containers are lighter: they share the same operating system kernel but are isolated from each other in the files, processes and network they can see. A container starts quickly and uses less, but its isolation is weaker than a full virtual machine because the kernel is shared. This difference connects to what we will learn in the operating systems section.

Service models: SaaS, PaaS and IaaS

Cloud services differ in how much you manage and how much the provider does. The closer to SaaS, the less you control and the less you maintain.

IoT and edge computing

IoT (Internet of Things) means everyday devices with a small computer, sensors and connectivity: a smartwatch, a home thermostat, sensors on a farm. They generate huge amounts of data, and sending all of it to the cloud is costly and slow. So Edge Computing appeared: processing part of the data close to its source, on the device itself or on a local server, and sending only the important results. A smart camera detects motion by itself and uploads a short clip instead of streaming hours of video.

AI and machine learning, conceptually

In traditional programming you write the rules; in Machine Learning you give the system many examples and it extracts the pattern by itself: it is trained on thousands of labelled images so it can recognise a new one. Training is heavy work needing graphics processors and large amounts of memory, so it usually happens in data centres. Using a trained model is lighter and may run on a phone. These models predict what resembles the examples they saw, so they can be wrong and need human review in important situations.

Trade-offs: there is no free option

  • Latency: the farther the computer is from you, the longer the response takes; the edge reduces it.
  • Cost: the cloud turns buying hardware into pay-as-you-go, cheap for occasional needs but possibly expensive under constant load.
  • Privacy: your data sits on another party's servers, so you must know where it is stored, who can reach it and how it is encrypted.
  • Energy: data centres use large amounts of electricity and cooling, so efficiency is measured as work done per unit of energy.
  • Dependence on connectivity: if the network drops, services that rely entirely on the cloud stop working.

Real-world applications

  • Online shops: add virtual servers during a sale season and remove them afterwards.
  • Smart farming: sensors measure moisture, decide on watering locally and send a summary to the cloud.
  • Collaboration: a whole team edits one document because the single copy lives in the cloud.
  • Development: programmers wrap their app in a container so it runs the same way on any machine.

Common mistakes

  • “The cloud is a mysterious place with no hardware”: it is real servers in real buildings owned by someone else.
  • “A container is a small virtual machine”: a container shares the host kernel, while a virtual machine carries a full OS.
  • “The cloud is always cheaper and safer”: it depends on workload and setup, and many leaks come from the customer's own misconfiguration.
  • “AI understands as a human does”: a model finds statistical patterns in data and can give a confident but wrong answer.
Exercise Choosing a model: a small company wants (a) email and documents for its staff, (b) to host a web app its developer wrote, (c) to run an old program that needs a specific operating system. Pick SaaS, PaaS or IaaS for each.
Show solution

(a) SaaS, because a finished application is needed and there is no reason to manage servers. (b) PaaS, because the team wants to focus on code while the platform handles running and updates. (c) IaaS, because you need control of the operating system itself, so you rent a virtual machine and install what you need. Rule: choose the highest level that meets your need to reduce maintenance load.

Exercise Trade-off: a surveillance camera records around the clock. Compare sending all the video to the cloud with processing it at the edge in terms of latency, cost and privacy.
Show solution

Sending everything uses large bandwidth and costly storage, adds delay before any alert arrives, and exposes all footage to transport and remote-storage risks. Edge processing detects the event locally, alerts immediately and uploads only a few clips, so cost drops and privacy improves. The price is that the local device needs more processing power plus maintenance and updates, and its model may be less accurate than a larger cloud one. The practical answer is often a mix of both.

Exercise Hands-on: pick three services you use daily (email, video, photo storage). For each: where do the parts run, does it work without internet, and is it SaaS or another type?
Show solution

Most will be SaaS since you use a finished application. Try airplane mode and open each: some will show what was stored earlier on your device (cache and local copies) and others will not work at all. This shows which part runs locally and which in the cloud. Then open the privacy settings and see what is uploaded to the server. Write a small table per service: what is kept locally, what in the cloud, and what a network outage does.

Summary

  • Computing today is spread across mobile devices, data centres, IoT devices and a nearby edge layer.
  • Virtual machines and containers divide hardware; the first with a full OS, the second with a shared kernel.
  • SaaS, PaaS and IaaS differ in how much you manage versus the provider.
  • Every option has a cost in latency, price, privacy and energy.

Try it yourself

Think about the apps you use every day and identify which of them rely on Cloud Computing.

Test yourself

  1. Which concept refers to using computing resources over the internet?

    • Cloud Computing
    • Keyboard
    • RAM
    • BIOS
    Answer and explanation

    Correct answer: Cloud Computing

  2. A company needs a virtual server on which it installs its own OS and software. Which model fits?

    • SaaS
    • IaaS
    • PaaS
    • IoT
    Answer and explanation

    Correct answer: IaaS

    IaaS gives servers, network and storage while you manage the OS and software.

  3. What is the main difference between a container and a virtual machine?

    • A container carries its own full operating system
    • A VM always shares the host kernel
    • A container shares the host kernel so it starts faster and is lighter
    • There is no difference in isolation
    Answer and explanation

    Correct answer: A container shares the host kernel so it starts faster and is lighter

    Sharing the kernel makes a container lighter but its isolation is weaker than a VM.

  4. A smart camera detects motion itself and uploads a short clip instead of streaming hours. What is this pattern?

    • Edge computing
    • Pure cloud computing
    • Hashing
    • Permanent data migration
    Answer and explanation

    Correct answer: Edge computing

    Processing data near its source saves bandwidth and cuts latency.

  5. Which statement about machine learning is correct?

    • The model never makes mistakes
    • It trains on many examples to learn patterns and can be wrong, needing human review
    • The programmer writes every rule by hand
    • Training is lighter than using the model
    Answer and explanation

    Correct answer: It trains on many examples to learn patterns and can be wrong, needing human review

    A model predicts what resembles its examples, so important cases need human review.
