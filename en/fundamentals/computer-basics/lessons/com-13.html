Bits and Bytes

Learning objectives

  • Define a Bit and a Byte and count the values n bits can hold.
  • Distinguish 1000-based units (KB, MB) from 1024-based ones (KiB, MiB) and explain disk-capacity gaps.
  • Estimate an uncompressed file size, convert between Mbps and MB/s and compute download time.

Prerequisites

  • The binary and data lesson (com-12).

Introduction: the language of measurement

When you read “a 5-megabyte photo” or “a 100-megabit connection”, you face units that look alike yet differ greatly. Understanding them lets you compute a drive's capacity, a download time and a video's size instead of guessing. It all starts from the smallest unit: the Bit.

The bit and the byte

A Bit is one place holding 0 or 1, the smallest possible piece of information. Because a single bit is too little to represent anything useful, eight of them are grouped into a Byte, the unit by which a computer addresses its memory. A bit is written with a lowercase b and a byte with an uppercase B, a crucial difference: 8 bits = 1 B.

Every added bit doubles the number of possibilities, so n bits give 2 to the power n values:

BitsValuesExample use
12an on/off switch
416one hex digit
8256an extended ASCII char, or a colour channel
1665,53616-bit CD audio
2416,777,216a full RGB colour
324,294,967,296an IPv4 address
6418,446,744,073,709,551,61664-bit processors

This also explains “32-bit” and “64-bit” processors: the width of the address the processor can use to point at memory locations. Thirty-two bits means 4,294,967,296 addresses, that is at most 4 GiB of memory, which is why modern machines moved to 64 bits.

KB or KiB? The 1000 versus 1024 problem

Binary logic makes 1024 (2 to the power 10) very close to a thousand, so people habitually used “kilo” for both. To end the confusion the international standards define two families: decimal SI units (KB, MB, GB, TB) worth 1000 to the power n, and binary IEC units (KiB, MiB, GiB, TiB) worth 1024 to the power n.

UnitDecimal (SI)Binary (IEC)Gap
KiloKB = 1,000 BKiB = 1,024 B2.4%
MegaMB = 1,000,000 BMiB = 1,048,576 B4.9%
GigaGB = 1,000,000,000 BGiB = 1,073,741,824 B7.4%
TeraTB = 10^12 BTiB = 1,099,511,627,776 B10.0%

The gap grows with each step, which is the secret behind drive-capacity differences: a drive labelled 256 GB holds 256,000,000,000 bytes, and when the system divides by 1,073,741,824 it shows only about 238.4, that is 238.4 GiB. Windows writes GB for what is really GiB, whereas modern macOS and most manufacturers use decimal units.

Estimating file sizes

An uncompressed image's size = width × height × bytes per pixel. A Full HD picture of 1920 × 1080 in RGB (3 bytes per pixel) holds 2,073,600 pixels, so its size is 2,073,600 × 3 = 6,220,800 bytes, about 6.22 MB or 5.93 MiB. A JPG at this resolution may be only a few hundred kilobytes because Compression removes redundancy.

Audio example: a CD takes 44,100 samples per second, each 16 bits, in two channels: 44,100 × 16 × 2 = 1,411,200 bits/s, that is 176,400 bytes/s, so a minute is 10,584,000 bytes ≈ 10.6 MB.

Network speed: Mbps or MB/s?

Internet providers measure speed in Mbps, megabits per second (lowercase b), while the browser shows downloads in MB/s, megabytes per second (uppercase B). The conversion: divide by 8. A 100 Mbps connection gives in theory 100 ÷ 8 = 12.5 MB/s, and 500 Mbps gives 62.5 MB/s. The real speed is somewhat lower because of protocol overhead and congestion.

Real-world applications

  • Buying storage: you can estimate how many photos your phone's memory holds before you buy.
  • Data caps: a 50 GB monthly plan covers a certain number of video hours depending on quality.
  • Choosing quality: understanding bitrate helps you pick recording and streaming settings.

Common mistakes

  • “Mb and MB are the same”: the first is a megabit and the second a megabyte, eight times apart.
  • “My drive is short, the maker is cheating me”: the gap comes from the counting unit (1000 versus 1024), not from lost data.
  • “A JPG has the same pixels so its size equals the raw size”: compression shrinks the size a lot while the dimensions stay the same.
  • “100 Mbps downloads 100 megabytes every second”: it is only 12.5 MB/s in theory.
Exercise Calculation: what is the size of an uncompressed 4000 × 3000 RGB image, and how many fit on a 64 GB (decimal) drive?
Show solution

Pixels = 4000 × 3000 = 12,000,000. Size = 12,000,000 × 3 = 36,000,000 bytes = 36 MB. A 64 GB drive is 64,000 MB, so 64,000 ÷ 36 ≈ 1,777 images (rounded down). In reality the image is compressed to a few megabytes, so far more would fit.

Exercise Reasoning: you bought a 200 Mbps connection. In theory, how long does a 40 GB game take to download?
Show solution

Speed in bytes = 200 ÷ 8 = 25 MB/s. The game = 40 × 1000 = 40,000 MB. Time = 40,000 ÷ 25 = 1,600 seconds ≈ 26.7 minutes. In practice it takes a little longer because of server load, protocol overhead and congestion, and a slow disk can also be a limit.

Exercise Hands-on: find a file's size in bytes on your device, then convert it to KB and KiB and compare.
Show solution

On Windows right-click the file and choose Properties to see its size in bytes. Suppose it is 5,242,880 bytes: in decimal units it is 5,242.88 KB, about 5.24 MB. In binary units it is 5,242,880 ÷ 1,024 = 5,120 KiB = exactly 5 MiB. The difference between the two figures comes from the unit, not from the file. On Linux try ls -l to get the size in bytes.

Summary

  • A bit is the smallest information, a byte is eight bits, and n bits give 2 to the power n values.
  • KB and MB are decimal (1000), KiB and MiB binary (1024), which explains drive capacities.
  • Raw image size = width × height × bytes per pixel, and compression shrinks it a lot.
  • Mbps divided by 8 gives MB/s.

    • 16

    Correct answer: 8

  2. A 256 GB drive shows about 238.4 in Windows. Why?

    • Because it divides by 1,073,741,824 instead of 1,000,000,000 (GiB units)
    • Because the drive is faulty
    • Because of a virus
    • Because the maker cheated
    Answer and explanation

    Correct answer: Because it divides by 1,073,741,824 instead of 1,000,000,000 (GiB units)

    Windows writes GB for what is really GiB, and the gap is 7.4% at the giga level.

  3. Why were 32-bit processors limited to about 4 GiB of memory?

    • Because every machine only had 4 GB
    • Because 32 bits give only 4,294,967,296 addresses
    • Because of clock speed
    • Because of screen size
    Answer and explanation

    Correct answer: Because 32 bits give only 4,294,967,296 addresses

    A 32-bit address width means 2^32 locations, which is 4 GiB.

  4. What is the size of an uncompressed 1920 x 1080 image at 3 bytes per pixel?

    • About 2 MB
    • About 600 KB
    • About 6.22 MB
    • About 62 MB
    Answer and explanation

    Correct answer: About 6.22 MB

    2,073,600 pixels x 3 = 6,220,800 bytes, about 6.22 MB.

  5. An internet connection is 100 Mbps. About how many MB/s is that?

    • 800 MB/s
    • 100 MB/s
    • 50 MB/s
    • 12.5 MB/s
    Answer and explanation

    Correct answer: 12.5 MB/s

    A megabit (lowercase b) is an eighth of a megabyte, so 100 / 8 = 12.5 MB/s.
