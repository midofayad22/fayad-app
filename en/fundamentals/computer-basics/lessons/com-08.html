The Graphics Card (GPU)

Learning objectives

  • Explain how a GPU differs from a CPU in design and in tasks.
  • Distinguish integrated from dedicated graphics and understand the role of VRAM.
  • Calculate pixel counts and the time budget per frame, and know uses of a GPU beyond games.

Prerequisites

  • The CPU (com-04) and motherboard (com-07) lessons.

Introduction: why a second processor?

A Full HD screen holds about two million pixels, and the colour of each must be decided dozens of times per second. If the main processor did that alone it would have no time left for the rest of the system. That is why the GPU (Graphics Processing Unit) exists: a processor specialised in producing the image, working beside the CPU.

A GPU is not a “stronger processor” but one with a different design. A CPU is like a few experts who finish complex tasks one after another; a GPU is like thousands of simple workers each doing the same simple operation at the same time on lots of data.

A design built on parallelism

This works for graphics because the colour of each pixel rarely depends on its neighbour, so all of them can be computed at once. That kind of problem is called Data Parallelism.

How is an image drawn?

These steps are driven through software interfaces called a Graphics API, such as DirectX, Vulkan, OpenGL and Metal, which connect the game to the device's drivers. Developers write small programs called a Shader that run on thousands of cores at once.

Integrated or dedicated? And the role of VRAM

An Integrated GPU is part of the processor chip itself and shares system RAM; it is enough for web browsing, video, office work and light games, and it saves power and heat. A Dedicated GPU is a separate card that plugs into a PCIe slot on the motherboard and has its own VRAM, cooler and power feed; it gives higher performance but uses more power and needs space and cooling.

VRAM holds textures, scene data and the frame buffer. When it fills up the card has to borrow system RAM across the much slower PCIe link, which causes visible stutter. That is why VRAM size matters for high-resolution gaming or large 3D models.

Beyond games: general-purpose GPU computing

Because a GPU runs so many calculations in parallel, it has been put to work on tasks unrelated to drawing, a practice known as GPGPU, through platforms such as CUDA and OpenCL. Its best-known use today is training artificial-intelligence models, since training is built on multiplying huge matrices. It is also used in scientific simulation, video editing, and cryptographic workloads. Most cards also have dedicated circuits for video encoding and decoding that relieve the CPU.

Real-world applications

  • Gaming: the card sets the resolution, frame rate and lighting quality.
  • Design and editing: 3D and video-editing software use the GPU to speed up preview and export.
  • Artificial intelligence: data centres house thousands of GPUs to train models.
  • Phones: the phone chip includes a small GPU that draws the interface and games on minimal power.

Common mistakes

  • “A GPU is just a gaming card”: the desktop interface, web browsing, editing and AI all use it, and every device with a display has some GPU.
  • “A GPU beats a CPU at everything”: a GPU is poor at complex sequential logic and cannot replace the CPU; each complements the other.
  • “More memory means a faster card”: VRAM only prevents stutter when it would otherwise fill up; card speed is set by cores, architecture and memory bandwidth.
  • “Upgrading only the GPU speeds up any computer”: the CPU may become the bottleneck, or the power supply may be too weak.
Exercise Calculation: how many pixels are on a 1920×1080 screen? On a 4K screen at 3840×2160? And how many pixels per second must the GPU produce at 60 frames per second on each?
Show solution

1920 × 1080 = 2,073,600 pixels. 3840 × 2160 = 8,294,400 pixels, exactly four times as many. At 60 frames: 2,073,600 × 60 ≈ 124.4 million pixels per second, and for 4K: 8,294,400 × 60 ≈ 497.7 million pixels per second. This is why raising the resolution burdens the card even when the game does not change.

Exercise Calculation and reasoning: how many milliseconds are available per frame at 60 and at 144 frames per second? And how much memory does one 4K frame need if each pixel is stored in 4 bytes?
Show solution

At 60: 1000 ÷ 60 ≈ 16.7 ms per frame. At 144: 1000 ÷ 144 ≈ 6.9 ms, less than half the time, so the computation must be much faster. A 4K frame: 8,294,400 × 4 = 33,177,600 bytes, about 33 MB. The card keeps several frames alongside the textures, which is why it needs plenty of VRAM.

Exercise Hands-on: find your GPU's name, whether it is integrated or dedicated, how much VRAM it has, and watch its usage while a video plays.
Show solution

On Windows open Task Manager, then Performance, then GPU: you see the name plus dedicated memory (VRAM) and shared memory (from system RAM). If only shared memory appears, it is probably integrated. You can also use dxdiag. On macOS open About This Mac. Play a high-resolution video and watch the Video Decode entry or overall usage: you will see a slight rise because decoding runs on the GPU, while CPU usage stays low.

Summary

  • A GPU is a specialised processor with thousands of simple cores for parallel operations.
  • Integrated GPUs share RAM with the processor; dedicated ones have their own VRAM and a PCIe slot.
  • Resolution and frame rate set the workload, and each increase multiplies the computation.
  • GPUs today serve AI and scientific computing as well as graphics.

Core concept

A GPU specializes in graphics processing and parallel operations; it is not just a second copy of the CPU.

Hands-on practice

Try it yourself

Look up your device's specifications to find the name of the GPU it contains.

Test yourself

  1. Which field is directly associated with the GPU?

    • Graphics
    • Paper printing only
    • File management only
    • The keyboard
    Answer and explanation

    Correct answer: Graphics

  2. What is the main design difference between a GPU and a CPU?

    • A GPU has thousands of simple cores working in parallel, a CPU a few powerful cores
    • A GPU has very few, stronger cores
    • There is no difference
    • A GPU has no memory
    Answer and explanation

    Correct answer: A GPU has thousands of simple cores working in parallel, a CPU a few powerful cores

    Graphics needs a simple operation repeated over huge data, which suits data parallelism.

  3. Which statement describes an integrated GPU?

    • A separate card with its own VRAM
    • Part of the processor chip that shares system RAM
    • It requires its own power supply
    • It works only for artificial intelligence
    Answer and explanation

    Correct answer: Part of the processor chip that shares system RAM

    Integrated graphics saves power and heat and is enough for browsing, office work and light games.

  4. What happens when VRAM fills up in a high-resolution game?

    • Frame rate increases
    • The game always closes
    • The card borrows system RAM over the slower PCIe link, causing stutter
    • It uses the disk as the screen
    Answer and explanation

    Correct answer: The card borrows system RAM over the slower PCIe link, causing stutter

    System RAM is much slower than VRAM, so visible stutter appears.

  5. Ahmed bought a card only because it has more cores than another. What is the mistake?

    • None; more cores always means better performance
    • Core designs differ between vendors and generations, so benchmarks should be used
    • Cores have no effect on performance at all
    • Comparing the box size is the solution
    Answer and explanation

    Correct answer: Core designs differ between vendors and generations, so benchmarks should be used

    Core count alone is not a fair comparison between different cards; look at benchmarks for your workload.
