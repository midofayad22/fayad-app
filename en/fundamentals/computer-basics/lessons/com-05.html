Memory (RAM)

Learning objectives

  • Explain what RAM is and why it is temporary (Volatile) memory.
  • Compare RAM with storage in speed, capacity and persistence.
  • Estimate memory needs roughly and understand what happens when it fills up.

Prerequisites

  • The lessons “How a computer works” and “The CPU”.

Introduction: the workbench

Imagine a huge library (storage) and a workbench in front of you (RAM). You do not work on books inside the library; you bring what you need to the bench, and the bigger the bench the more references you can lay out at once. RAM (Random Access Memory) is that bench: a fast space where the operating system puts the programs and data in use so the processor can reach them quickly.

“Random” does not mean chaotic; it means any location in memory can be reached directly by its address in roughly the same time, without reading everything before it.

Why does RAM lose its contents?

Most computer memory is DRAM: each bit is stored as a tiny electrical charge in a small capacitor, and the charge leaks away within fractions of a second, so it must be refreshed constantly. When power is cut everything vanishes, which is why it is called volatile memory. An SSD or HDD, by contrast, keeps its data without power.

The figures above are approximate and vary by generation and model, but the ratio is what matters: accessing RAM is roughly thousands of times faster than an SSD.

Types and bandwidth

The common generations today are DDR4 and DDR5 (Double Data Rate): they transfer data twice per clock cycle. Speed is measured in MT/s, millions of transfers per second. The memory bus is 64 bits = 8 bytes wide, so DDR4-3200 theoretically moves 3200 × 8 = 25,600 MB per second, about 25.6 GB/s per channel. It roughly doubles with two channels (dual channel) using two matching modules.

What happens when memory fills up?

In this example (illustrative values) “free” memory looks like only 1.1, but the available column shows 8.6 is actually obtainable, because the system uses the rest as a cache and can release it on demand.

Real-world applications

  • Browsing: each browser tab can use hundreds of megabytes, so twenty tabs can take several gigabytes.
  • Video and design work: large files and many layers need more memory; 16 GB or more is often recommended.
  • Servers and databases: they keep the most requested data in RAM to answer quickly.
  • Phones: when an app in the background “reloads” from scratch, the system probably evicted it from memory to make room for another.

Common mistakes

  • “More RAM always means a faster machine”: adding memory only helps if you are running out of what you have; otherwise nothing changes.
  • “Free memory is good and used memory is bad”: unused memory is wasted; a good system fills it with caches and releases them on demand.
  • “RAM is where my files are saved”: files are saved to storage, and what is in RAM is lost unless you save, which is why an unsaved draft disappears in a power cut.
  • “Memory cleaner apps speed up the machine”: emptying memory forces the system to re-read from disk, which usually makes things slower.
Exercise Calculation: a DDR5-5600 module on a single channel. What is the theoretical bandwidth, and roughly how long would it take to read a 4 GB block?
Show solution

5600 × 8 bytes = 44,800 MB/s, about 44.8 GB/s. Reading 4 GB takes theoretically 4 ÷ 44.8 ≈ 0.09 seconds (about 90 ms). In practice the figure is a little lower because of overhead.

Exercise Reasoning: your machine has 8 GB, the system uses 3 GB, and you open 20 tabs at about 300 MB each. Will you have a problem?
Show solution

The tabs: 20 × 300 = 6000 MB, about 6 GB (using 1 GB = 1000 MB for estimation). With the system that totals 9 GB, more than 8, so the system will fall back to virtual memory on disk and you will notice lag when switching tabs. Fixes: close some, use a feature that suspends inactive tabs, or upgrade the memory.

Exercise Hands-on: open Task Manager, the Performance tab, then Memory (or run free -h). Record the used amount before opening several programs, after opening them, and after closing them.
Show solution

The value will rise with each program and drop when you close them, but it will not return exactly to the first number because the system keeps some files cached. The “Cached” figure in Windows or the buff/cache column in Linux is evidence of this behaviour. What matters is whether usage approaches total capacity.

Summary

  • RAM is fast, temporary memory holding the programs and data in use.
  • It is thousands of times faster than storage but smaller, pricier, and loses its contents at power-off.
  • When it fills, the system falls back on the disk and the machine slows down.

Core concept

Hands-on practice

Try it yourself

Watch RAM usage in Task Manager as you open several programs, then close them and notice the difference.

Test yourself

  1. What typically happens to the contents of RAM when the computer is turned off?

    • They always remain
    • They move to the monitor
    • They are lost
    • They turn into a CPU
    Answer and explanation

    Correct answer: They are lost

  2. Why does DRAM lose its contents when power is cut?

    • Each bit is a charge in a tiny capacitor that leaks quickly and needs constant refreshing
    • Because the user's command wipes it automatically
    • Because it is made of spinning platters
    • Because its capacity is too small
    Answer and explanation

    Correct answer: Each bit is a charge in a tiny capacitor that leaks quickly and needs constant refreshing

    The charge leaks within fractions of a second, which is why it is called volatile memory.

  3. free -h shows Free = 1.1Gi but available = 8.6Gi. What can we conclude?

    • Memory is nearly full and the machine will stop
    • The memory is faulty
    • Most of the memory used as cache can be released on demand
    • 8.6 is the disk size
    Answer and explanation

    Correct answer: Most of the memory used as cache can be released on demand

    The system uses spare memory as cache and can release it instantly, so the available column is the accurate one.

  4. When RAM fills up and the system falls back to swap on disk, what is the expected result?

    • The machine gets faster
    • RAM capacity doubles at the same speed
    • Nothing the user would notice changes
    • Noticeable slowdown or freezing because disk is far slower
    Answer and explanation

    Correct answer: Noticeable slowdown or freezing because disk is far slower

    Virtual memory relies on disk, whose access is thousands of times slower than RAM.

  5. What is the theoretical bandwidth of DDR4-3200 per channel? (The bus is 8 bytes wide)

    • 6.4 GB/s
    • 25.6 GB/s
    • 3200 GB/s
    • 256 GB/s
    Answer and explanation

    Correct answer: 25.6 GB/s

    3200 million transfers x 8 bytes = 25,600 MB/s, about 25.6 GB/s.
