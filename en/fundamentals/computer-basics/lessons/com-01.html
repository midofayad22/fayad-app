What Is a Computer?

Learning objectives

  • Define a computer precisely and tell it apart from a simple fixed-function machine.
  • Break any device down into four stages: Input, Processing, Output and Storage.
  • Name the main families of computing devices, from phones to servers and embedded systems.

Prerequisites

  • None; this is the first lesson of the path.

Introduction: a machine that follows instructions

When you tap “like” on a post, pull your card out of an ATM, or change a setting on your smart TV, you are dealing with a Computer. A computer is an electronic device that is programmable: it accepts data, processes it according to instructions stored inside it, and produces a result. The key word is “programmable”. A light switch handles electricity but never changes its behaviour; a computer becomes a word processor, a game or an accounting tool simply by swapping the program it runs.

This idea, that the instructions themselves are kept in memory just like data, is known as the Stored-Program Computer concept. It was worked out by researchers in the 1940s and is still the foundation of every device today.

The processing cycle: four stages

Everything a computer does can be described with four stages. Remember them, because you will use them to analyse any device you meet in the rest of this path.

The stages do not always happen strictly in order; your device stores, processes and displays almost at the same time. Still, the model is useful: everything has an input, some processing, an output, and memory that holds on to results.

Families of computing devices

The families differ not in principle, since they all follow the same cycle, but in size, power and purpose.

  • Personal computers (desktop and laptop): general purpose; you install whatever programs you like.
  • Mobile devices (phones, tablets): built around a single chip that combines several components to save power.
  • Servers: powerful machines that run around the clock and serve thousands of users over a network, such as those hosting websites.
  • Embedded systems: tiny computers dedicated to one job inside a washing machine, a car or a medical device. People use far more of these every day than they use personal computers.

What separates a computer from a calculator?

A basic calculator performs a fixed set of operations built into it. A computer is distinguished by three properties: speed (billions of simple operations per second), accuracy (the same operation always gives the same result) and flexibility (its function changes when the program changes). Be careful, though: a computer does not “understand” or “think”; it does literally what a programmer wrote for it.

Real-world applications

  • Healthcare: MRI scanners process millions of measurements to build a three-dimensional image of the body.
  • Transport: a modern car typically contains dozens of small computers controlling the engine, brakes and airbags.
  • Education: learning platforms store your progress and suggest the next lesson.
  • Finance: a bank transfer is a chain of input, validation and storage operations completed in a fraction of a second.

Common mistakes

  • “The computer is just the box or the screen”: a computer is a whole system of hardware and software; the case is only a shell.
  • “The computer is smart and knows what I mean”: it executes instructions exactly, which is why wrong instructions give a perfectly confident wrong answer.
  • “A phone is not a computer”: a phone is a complete computer with a processor, memory, storage and an operating system, and it outperforms many older desktops.
  • “Storage and processing are the same thing”: storage keeps data, processing transforms it; they are separate components.
Exercise Calculation: if a computer performs one billion simple operations per second, how long do 5 million operations take?
Show solution

Time = 5,000,000 ÷ 1,000,000,000 = 0.005 seconds, i.e. 5 milliseconds, far below what a person notices (roughly 100 ms). That is why computers feel instant on small jobs.

Exercise Reasoning: is a modern elevator a computer? Analyse it with the four stages.
Show solution

Yes, it contains an embedded computer. Input: floor buttons, door sensors and a load sensor. Processing: a program decides which floor to serve first. Output: driving the motor and lighting the buttons. Storage: it remembers pending requests and its settings. It is programmed for one job only, which makes it an embedded system rather than a general-purpose computer.

Exercise Hands-on: pick up your phone and identify one example of each of the four stages while taking a photo.
Show solution

Input: the camera lens and your tap on the screen. Processing: the processor adjusts exposure and focus and compresses the image to JPEG or HEIC. Output: the on-screen preview and the shutter sound. Storage: the file is saved to phone memory, which you can confirm by opening the gallery and then the Files app.

Summary

  • A computer is a programmable electronic device that processes data according to stored instructions.
  • Its work is summarised as Input, Processing, Output and Storage.
  • The families differ in size and purpose but share the same principle.
  • Its strength is speed, accuracy and flexibility, not understanding.

Core concept

A computer does not think like a human; it carries out specific instructions on data according to how it was programmed.

Hands-on practice

Try it yourself

Look at your phone or the computer in front of you and try to identify one example each of Input, Processing, Output, and Storage.

Test yourself

  1. At which stage are operations carried out on the data?

    • Input
    • Processing
    • Output
    • Storage
    Answer and explanation

    Correct answer: Processing

  2. Which key property separates a computer from a light switch?

    • It runs on electricity
    • It has a screen
    • It is programmable, so its behaviour changes when the program changes
    • It only stores files
    Answer and explanation

    Correct answer: It is programmable, so its behaviour changes when the program changes

    A switch handles electricity but never changes behaviour, while a computer becomes a different tool simply by swapping the program.

  3. You typed a message and pressed Save so it survives a shutdown. Which of the four stages did that?

    • Input
    • Processing
    • Output
    • Storage
    Answer and explanation

    Correct answer: Storage

    Writing data to disk so it persists without power is the Storage stage.

  4. Which of the following is an example of an embedded system?

    • A tiny computer dedicated to one job inside a washing machine
    • A desktop PC running many different programs
    • A server hosting thousands of users
    • A gaming laptop
    Answer and explanation

    Correct answer: A tiny computer dedicated to one job inside a washing machine

    Embedded systems are tiny computers dedicated to a single job inside devices such as washing machines and cars.

  5. Which statement about computers is correct?

    • It understands and thinks like a person
    • It does literally what a programmer wrote for it
    • It gives different results for the same operation each time
    • It needs no instructions to work
    Answer and explanation

    Correct answer: It does literally what a programmer wrote for it

    A computer is fast, accurate and flexible, but it does not think; it follows exactly what was written.
