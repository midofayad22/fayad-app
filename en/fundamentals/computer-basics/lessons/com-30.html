Test yourself

  1. Which Linux command shows available disk space?

    • df -h
    • free -h
    • ps aux
    • chmod
    Answer and explanation

    Correct answer: df -h

  2. After ln a.txt b.txt both files show the same inode, and changing a.txt permissions changed b.txt too. Why?

    • Both names point to the same data and the same inode record
    • The system copied the file
    • The disk is faulty
    • Permissions always copy
    Answer and explanation

    Correct answer: Both names point to the same data and the same inode record

    The name lives in the directory, while permissions live in the shared inode.

  3. Which PowerShell command corresponds to ps aux?

    • Get-Volume
    • Get-ChildItem
    • Stop-Process
    • Get-Process
    Answer and explanation

    Correct answer: Get-Process

    Get-Process lists processes, while Get-ChildItem matches ls.

  4. A process uses all the CPU. What is a sensible first step?

    • Kill every process at once
    • Delete the system folder
    • Identify the process and PID with top or Get-Process and check it is not essential
    • Send SIGKILL straight to any process
    Answer and explanation

    Correct answer: Identify the process and PID with top or Get-Process and check it is not essential

    First identify, then try the gentle SIGTERM before the forceful SIGKILL.

  5. Which command matches ls -l in Windows PowerShell, and which shows disk space on Linux?

    • Get-Process and free -h
    • Stop-Process and ps
    • Get-Volume and ls
    • Get-ChildItem and df -h
    Answer and explanation

    Correct answer: Get-ChildItem and df -h

    Get-ChildItem lists files, and df -h shows mounted file systems and free space.
