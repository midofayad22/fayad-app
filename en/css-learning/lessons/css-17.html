Test yourself

  1. Which property controls positioning?

    • position
    • place
    • location
    • element-positioning
    Answer and explanation

    Correct answer: position

  2. Which position value keeps an element attached to the viewport?

    • fixed
    • absolute
    • relative
    • static
    Answer and explanation

    Correct answer: fixed

  3. Which value is commonly used as a reference point for absolutely positioned children?

    • relative
    • static
    • fixed
    • normal
    Answer and explanation

    Correct answer: relative

  4. A badge with position: absolute; top: 0; right: 0 appears in the page corner instead of the card corner. What is the fix?

    • Add position: relative to the card
    • Change the badge to position: fixed
    • Increase the top value
    • Add a margin to the badge
    Answer and explanation

    Correct answer: Add position: relative to the card

    Absolute positioning is calculated from the nearest ancestor with a non-static position, and from the page if none exists. Making the card relative makes it the reference. fixed would pin it to the screen.

  5. What does position: sticky; top: 0 do to a heading?

    • It stays in flow, then sticks to the top when scrolling reaches it
    • It is always fixed to the top of the screen from the start
    • It leaves the flow and follows the mouse
    • It disappears when scrolling
    Answer and explanation

    Correct answer: It stays in flow, then sticks to the top when scrolling reaches it

    sticky is a hybrid: it acts like relative until scrolling reaches the given top offset, then acts like fixed, within the limits of its parent.
