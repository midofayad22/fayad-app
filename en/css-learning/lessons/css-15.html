Test yourself

  1. Which value centers text?

    • center
    • middle
    • horizontal
    • central
    Answer and explanation

    Correct answer: center

  2. Which property controls horizontal text alignment?

    • text-align
    • text-position
    • align-text-property
    • horizontal-text
    Answer and explanation

    Correct answer: text-align

  3. Which value aligns text to the right?

    • right
    • end-text-only
    • east
    • right-align-property
    Answer and explanation

    Correct answer: right

  4. A div is 300px wide with text-align: center. What gets centered?

    • The div itself inside its parent
    • The text and inline content inside the div
    • All block-level children
    • Nothing, because the element is block
    Answer and explanation

    Correct answer: The text and inline content inside the div

    text-align aligns inline content inside the box and does not move the box itself. To center the box use margin: 0 auto.

  5. What does text-align: justify do on a long paragraph?

    • Centers every line
    • Aligns lines to the right only
    • Spreads spacing so both edges line up, except the last line
    • Enlarges the font to fill the width
    Answer and explanation

    Correct answer: Spreads spacing so both edges line up, except the last line

    justify adjusts spacing between words so lines start and end at both edges, and the last line stays start-aligned by default.
