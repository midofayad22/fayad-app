Test yourself

  1. Which selector targets direct children?

    • >
    • +
    • ~
    • *
    Answer and explanation

    Correct answer: >

  2. Which selector targets an element based on an attribute?

    • [attribute]
    • .attribute
    • #attribute
    • :attribute
    Answer and explanation

    Correct answer: [attribute]

  3. What does the + combinator select?

    • The adjacent sibling
    • All children
    • The parent
    • Every element
    Answer and explanation

    Correct answer: The adjacent sibling

  4. With h2 ~ p, after an h2 followed by three paragraphs, how many paragraphs are targeted?

    • Only the first
    • All three
    • Only the last
    • None
    Answer and explanation

    Correct answer: All three

    The ~ combinator targets all following siblings, while + targets only the immediate sibling.

  5. Which elements does a[href^='https'] target?

    • Links whose value ends with https
    • Links containing https anywhere
    • Links whose href value starts with https
    • Links without href
    Answer and explanation

    Correct answer: Links whose href value starts with https

    The ^= operator means starts with, $= means ends with, and *= means contains.
