Test yourself

  1. Which property enables Flexbox?

    • display: flex
    • flex: true
    • layout: flex
    • enable-flex
    Answer and explanation

    Correct answer: display: flex

  2. Which property controls alignment along the main axis?

    • justify-content
    • align-main
    • flex-position
    • main-align
    Answer and explanation

    Correct answer: justify-content

  3. Which property controls alignment on the cross axis?

    • align-items
    • cross-content
    • flex-cross
    • align-main
    Answer and explanation

    Correct answer: align-items

  4. A container has display: flex; flex-direction: column; height: 400px; justify-content: center. How are the items placed?

    • Centered horizontally only
    • Centered vertically inside the container
    • Side by side in a horizontal row
    • Stuck to the top
    Answer and explanation

    Correct answer: Centered vertically inside the container

    justify-content works on the main axis, and with flex-direction: column the main axis is vertical, so the items are centered vertically.

  5. A flex container is 500px wide with three items each 200px wide and no flex-wrap. What happens?

    • The items wrap to a second line
    • The third item overflows rigidly
    • The items shrink to fit on one line
    • The last item is hidden
    Answer and explanation

    Correct answer: The items shrink to fit on one line

    The defaults are flex-wrap: nowrap and flex-shrink: 1, so the items shrink together (about 167px each) to stay on one line. To wrap them you need flex-wrap: wrap.
