Test yourself

  1. Which property controls the font family?

    • font-family
    • font-type
    • font-name
    • typeface
    Answer and explanation

    Correct answer: font-family

  2. Which property controls font size?

    • font-size
    • text-size
    • font-scale
    • size-font
    Answer and explanation

    Correct answer: font-size

  3. What does font-weight control?

    • Font thickness
    • Font color
    • Font family
    • Line spacing
    Answer and explanation

    Correct answer: Font thickness

  4. What does font-family: 'Poppins', sans-serif mean?

    • It layers both fonts on top of each other
    • It tries Poppins and falls back to a generic sans-serif font if unavailable
    • It downloads Poppins from the internet automatically
    • It uses sans-serif first and then Poppins
    Answer and explanation

    Correct answer: It tries Poppins and falls back to a generic sans-serif font if unavailable

    The list is read in order and the first available font is used, with the generic family as a safety net. The declaration does not download the font; that needs @font-face or a font link.

  5. The root html has a font size of 16px and an element has font-size: 1.5rem. What is its font size?

    • 1.5px
    • 16px
    • 24px
    • 32px
    Answer and explanation

    Correct answer: 24px

    The rem unit is relative to the root element's font size, and 1.5 x 16 = 24px.
