Test yourself

  1. What does transition do?

    • Creates smooth changes
    • Creates HTML
    • Deletes an element
    • Creates database tables
    Answer and explanation

    Correct answer: Creates smooth changes

  2. What does 0.3s represent in a transition?

    • Duration
    • Color
    • Width
    • Delay only
    Answer and explanation

    Correct answer: Duration

  3. Which CSS property is often combined with transition for hover effects?

    • transform
    • database
    • position-text
    • html-change
    Answer and explanation

    Correct answer: transform

  4. The button: .btn { background: blue; } .btn:hover { background: red; transition: 0.5s; }. What happens?

    • It changes smoothly on hover and snaps back instantly on leave
    • It changes smoothly in both directions
    • It changes instantly in both directions
    • It never changes
    Answer and explanation

    Correct answer: It changes smoothly on hover and snaps back instantly on leave

    A transition placed in the hover state applies only when entering; on leave the base state has no transition. Put it in the base rule to animate both ways.

  5. Which change will not animate smoothly with transition?

    • opacity from 0 to 1
    • width from 100px to 200px
    • background-color from blue to red
    • display from none to block
    Answer and explanation

    Correct answer: display from none to block

    display is a discrete value with no in-between steps, so it jumps instantly. That is why opacity and similar properties are used for smooth fades.
