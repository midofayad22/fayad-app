Test yourself

  1. What is responsive design?

    • Design that adapts to different screen sizes
    • Design only for phones
    • Design without CSS
    • Design only for desktop
    Answer and explanation

    Correct answer: Design that adapts to different screen sizes

  2. Which CSS feature is commonly used for responsive breakpoints?

    • Media Queries
    • Animations
    • Variables
    • Borders
    Answer and explanation

    Correct answer: Media Queries

  3. What does max-width: 600px mean in a media query?

    • Apply styles when the viewport is 600px or narrower
    • Make the page exactly 600px
    • Make every element 600px wide
    • Set the minimum screen width to 600px
    Answer and explanation

    Correct answer: Apply styles when the viewport is 600px or narrower

  4. Your page is responsive but a phone shows it zoomed out like a desktop page. What is the likely cause?

    • The meta viewport tag is missing from the head
    • Using flexbox
    • Using the rem unit
    • Having many images
    Answer and explanation

    Correct answer: The meta viewport tag is missing from the head

    Without the meta viewport tag, mobile browsers assume a width near 980px and shrink the page, so media queries do not behave as expected. The tag sets the width to the device width.

  5. Why write img { max-width: 100%; height: auto; } in a responsive design?

    • To enlarge all images beyond their original size
    • To stop images overflowing their container while keeping their ratio
    • To hide images on mobile
    • To repeat the image in the background
    Answer and explanation

    Correct answer: To stop images overflowing their container while keeping their ratio

    max-width: 100% stops the width from exceeding the container, and height: auto scales the height proportionally so the image is not distorted.
