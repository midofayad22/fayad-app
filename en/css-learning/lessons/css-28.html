Test yourself

  1. What are media queries commonly used for?

    • Responsive design
    • Database connections
    • HTML structure
    • JavaScript execution
    Answer and explanation

    Correct answer: Responsive design

  2. Which keyword starts a media query?

    • @media
    • @screen
    • @responsive
    • @device
    Answer and explanation

    Correct answer: @media

  3. What does max-width define?

    • A maximum viewport width condition
    • The maximum font size
    • The maximum height of every element
    • The maximum page length
    Answer and explanation

    Correct answer: A maximum viewport width condition

  4. We have p { color: blue; } and inside @media (min-width: 768px) { p { color: red; } }. What is p's color on a 500px screen?

    • Blue
    • Red
    • Green
    • Black
    Answer and explanation

    Correct answer: Blue

    The min-width: 768px condition is false at 500px, so the base rule stays. This is the mobile-first approach.

  5. @media (max-width: 600px) { .a { color: red; } } is written, then .a { color: blue; } after it outside. Why is red never seen on mobile?

    • Because max-width does not work on mobile
    • Because the later rule with equal specificity overrides the one inside the query
    • Because the query needs screen
    • Because red is not supported
    Answer and explanation

    Correct answer: Because the later rule with equal specificity overrides the one inside the query

    A media query does not raise specificity, so the last rule written wins. Put media query rules after the base rules.
