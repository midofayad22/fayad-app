Test yourself

  1. Which four parts make up the CSS box model?

    • Content, padding, border, margin
    • Text, image, button, link
    • Header, main, footer, nav
    • Width, height, color, font
    Answer and explanation

    Correct answer: Content, padding, border, margin

  2. Which part is closest to the actual content?

    • Content
    • Margin
    • Border
    • Outer spacing
    Answer and explanation

    Correct answer: Content

  3. Which part creates space outside the border?

    • Margin
    • Padding
    • Content
    • Width
    Answer and explanation

    Correct answer: Margin

  4. A content-box box has width: 100px; padding: 10px; border: 5px solid; margin: 20px. How wide is the visible box, not counting margin?

    • 100px
    • 120px
    • 130px
    • 170px
    Answer and explanation

    Correct answer: 130px

    Visible width = content + padding + border on both sides: 100 + 20 + 10 = 130px. Margin is outside the visible box; adding it would give 170px.

  5. An element has background-color, padding, border and margin. Which part is not painted with the background color by default?

    • The padding
    • The content
    • The margin
    • The area under the border
    Answer and explanation

    Correct answer: The margin

    The background extends under the content, padding and border, while margin is transparent external space that is never painted.
