What is CSS?

CSS stands for Cascading Style Sheets.

CSS is used to control the visual appearance of HTML elements.

With CSS, you can change colors, sizes, spacing, layouts, fonts, animations, and much more.

KEY IDEA

HTML creates the structure. CSS creates the design.

Think about a house. HTML is the structure of the house, while CSS controls the colors, size, spacing, and overall appearance.

Test yourself

  1. What is CSS mainly used for?

    • Styling the appearance of web pages
    • Creating database tables
    • Running server-side code
    • Creating HTML structure
    Answer and explanation

    Correct answer: Styling the appearance of web pages

  2. What does CSS stand for?

    • Cascading Style Sheets
    • Computer Style System
    • Creative Styling System
    • Coded Style Syntax
    Answer and explanation

    Correct answer: Cascading Style Sheets

  3. Which technology provides the structure of a webpage?

    • HTML
    • CSS
    • JavaScript
    • SQL
    Answer and explanation

    Correct answer: HTML

  4. Which approach lets one stylesheet style many pages at once?

    • Writing a style attribute inside every element on every page
    • Linking one external css file from every page
    • Copying the same rules into every page by hand
    • Using HTML only, because it supports colors
    Answer and explanation

    Correct answer: Linking one external css file from every page

    An external file is written once and linked from every page, so changing one rule updates the whole site. Copying rules or using inline styles forces you to edit every place separately.

  5. The CSS file failed to load because of a wrong link path. What will the page show?

    • A blank white page with no content
    • An error message instead of the page
    • All the content, with the browser's default styling
    • The content with the intended colors and design
    Answer and explanation

    Correct answer: All the content, with the browser's default styling

    CSS only adds appearance; the content comes from HTML. When the file fails to load, the browser renders the elements with its default styles.
