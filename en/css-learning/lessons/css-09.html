Test yourself

  1. Where does padding create space?

    • Inside the element
    • Outside the element
    • Outside the page
    • Inside the margin
    Answer and explanation

    Correct answer: Inside the element

  2. Which property controls space between content and border?

    • padding
    • margin
    • gap-outside
    • content-space
    Answer and explanation

    Correct answer: padding

  3. What does padding: 20px add?

    • 20px of inner space
    • 20px of outer space
    • 20px border
    • 20px height only
    Answer and explanation

    Correct answer: 20px of inner space

  4. A box has width: 200px; padding: 20px, no border, and the default content-box sizing. What is its total width?

    • 200px
    • 220px
    • 240px
    • 160px
    Answer and explanation

    Correct answer: 240px

    In content-box the width applies to the content only, and padding is added on both sides: 200 + 20 + 20 = 240px.

  5. In padding: 10px 20px 30px 40px, what is the left padding?

    • 10px
    • 20px
    • 30px
    • 40px
    Answer and explanation

    Correct answer: 40px

    The order is clockwise: top, right, bottom, left, so the fourth value, 40px, is the left padding.
