CSS Grid

Test yourself

  1. Which property enables CSS Grid?

    • display: grid
    • grid: true
    • layout: grid
    • enable-grid
    Answer and explanation

    Correct answer: display: grid

  2. Which property defines grid columns?

    • grid-template-columns
    • grid-columns-only
    • columns-grid
    • grid-layout-columns
    Answer and explanation

    Correct answer: grid-template-columns

  3. What does gap control in a grid?

    • Space between grid items
    • Grid color
    • Column width only
    • Element height
    Answer and explanation

    Correct answer: Space between grid items

  4. A container has display: grid; grid-template-columns: repeat(3, 1fr) and 6 children. How do they appear?

    • 3 equal-width columns in 2 rows
    • 6 columns in 1 row
    • One column of 6 rows
    • 2 rows of 2 columns
    Answer and explanation

    Correct answer: 3 equal-width columns in 2 rows

    repeat(3, 1fr) creates three columns with equal shares, and the six items flow automatically into two rows.

  5. What does grid-template-columns: 200px 1fr mean?

    • Two columns, each 200px wide
    • A fixed 200px column and a second that takes the remaining space
    • The first column is 1fr and the second is 200px
    • One column 201px wide
    Answer and explanation

    Correct answer: A fixed 200px column and a second that takes the remaining space

    The fr unit divides the space left after fixed columns, so the second column takes all the rest. It is a common pattern for a sidebar layout.
