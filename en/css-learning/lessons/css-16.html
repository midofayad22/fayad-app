Test yourself

  1. Which property controls an element's display behavior?

    • display
    • layout
    • element-type
    • show
    Answer and explanation

    Correct answer: display

  2. Which display value makes an element behave inline while accepting width and height?

    • inline-block
    • inline-only
    • block-inline
    • flex-inline
    Answer and explanation

    Correct answer: inline-block

  3. Which display value creates a block-level element?

    • block
    • section
    • box
    • full-block
    Answer and explanation

    Correct answer: block

  4. A span has width: 200px; height: 100px with no display change. What happens?

    • The width and height are ignored because it is inline
    • It takes both dimensions fully
    • It automatically becomes block
    • The element disappears
    Answer and explanation

    Correct answer: The width and height are ignored because it is inline

    Inline elements ignore width and height. Switch to inline-block or block for them to apply.

  5. What is the difference between display: none and visibility: hidden?

    • none hides but keeps its space, while hidden removes the space
    • There is no difference
    • none removes the element from layout, while hidden hides it but keeps its space
    • hidden deletes the element from the HTML
    Answer and explanation

    Correct answer: none removes the element from layout, while hidden hides it but keeps its space

    display: none makes the element take up no space, while visibility: hidden hides it visually but keeps its space. The element stays in the HTML in both cases.
