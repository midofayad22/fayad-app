Test yourself

  1. What does :hover represent?

    • An element when the mouse is over it
    • An element after clicking
    • An element when hidden
    • An element before loading
    Answer and explanation

    Correct answer: An element when the mouse is over it

  2. Which of these is a pseudo-class?

    • :hover
    • ::after
    • .hover-element
    • #hover
    Answer and explanation

    Correct answer: :hover

  3. Do pseudo-classes usually describe an element's state or part?

    • State
    • HTML structure
    • Database state
    • File type
    Answer and explanation

    Correct answer: State

  4. a:hover is written before a:link with the same specificity. Why does the color not change on hover?

    • Because hover does not work on links
    • Because the later a:link overrides the earlier hover
    • Because color cannot be changed by hover
    • Because the browser needs JavaScript
    Answer and explanation

    Correct answer: Because the later a:link overrides the earlier hover

    With equal specificity the later rule wins, so the later a:link overrides the hover effect. That is why the recommended order is link, visited, hover, active.

  5. Which items does li:nth-child(2n) select?

    • The odd items 1, 3, 5
    • Only the second item
    • The even items 2, 4, 6
    • All items
    Answer and explanation

    Correct answer: The even items 2, 4, 6

    The formula 2n gives multiples of 2, so 2, 4, 6, which is the same as even. The odd items are 2n+1 or odd.
