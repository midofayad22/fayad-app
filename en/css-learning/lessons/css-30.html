Test yourself

  1. Why should CSS be organized?

    • To make code easier to maintain
    • To make HTML unnecessary
    • To remove JavaScript
    • To make CSS stop working
    Answer and explanation

    Correct answer: To make code easier to maintain

  2. Which technique helps avoid repeating the same color value?

    • CSS Variables
    • Extra HTML
    • More IDs
    • Inline JavaScript
    Answer and explanation

    Correct answer: CSS Variables

  3. What is one goal of clean CSS?

    • Easy maintenance and readability
    • Removing all selectors
    • Replacing HTML
    • Avoiding all responsive design
    Answer and explanation

    Correct answer: Easy maintenance and readability

  4. A team adds !important to every rule to make sure it wins. What is the problem?

    • No problem
    • All rules end up equally strong and it becomes a specificity war that is hard to change
    • The browser ignores it
    • It slows down the server
    Answer and explanation

    Correct answer: All rules end up equally strong and it becomes a specificity war that is hard to change

    Overusing !important removes the ability to override later except with another !important. It is better to organize selectors and specificity.

  5. Which class name is best practice?

    • .big-red-left
    • .card-title
    • .x1
    • .div2
    Answer and explanation

    Correct answer: .card-title

    A name should describe purpose rather than appearance, so it stays correct if the design changes. Random names are also hard to understand.
