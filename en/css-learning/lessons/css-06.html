Test yourself

  1. Which property creates a border?

    • border
    • outline-text
    • edge
    • frame
    Answer and explanation

    Correct answer: border

  2. Which property creates rounded corners?

    • border-radius
    • corner
    • radius-border
    • round
    Answer and explanation

    Correct answer: border-radius

  3. What does 2px represent in border: 2px solid?

    • Border width
    • Border color
    • Border radius
    • Element height
    Answer and explanation

    Correct answer: Border width

  4. border: 2px red; was written but no border appears. Why?

    • The color red is not supported
    • 2px is too thin to show
    • The border style is missing and its default is none
    • border must be written inside body
    Answer and explanation

    Correct answer: The border style is missing and its default is none

    A border needs a style such as solid or dashed; without it border-style is none and nothing is drawn regardless of width. The fix is border: 2px solid red.

  5. A box is 100px wide and 100px tall. What does border-radius: 50% do?

    • It turns it into a circle
    • It makes the border 50 percent transparent
    • It shrinks the box to half its size
    • It trims only the top corners by 50px
    Answer and explanation

    Correct answer: It turns it into a circle

    The percentage is relative to the box size, and 50 percent makes the curve half of each side so the corners form a full arc. The size stays the same.
