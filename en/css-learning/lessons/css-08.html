Test yourself

  1. Where does margin create space?

    • Outside the element
    • Inside the element
    • Inside the text
    • Inside the border
    Answer and explanation

    Correct answer: Outside the element

  2. Which property controls the space outside an element?

    • margin
    • padding
    • spacing
    • outside
    Answer and explanation

    Correct answer: margin

  3. What does margin: 30px apply?

    • 30px outside the element
    • 30px inside the content
    • 30px border
    • 30px font size
    Answer and explanation

    Correct answer: 30px outside the element

  4. Two stacked blocks: the first has margin-bottom: 30px and the second has margin-top: 20px. How big is the gap between them?

    • 50px
    • 20px
    • 30px
    • 10px
    Answer and explanation

    Correct answer: 30px

    Vertical margins between adjacent blocks collapse, so the larger one, 30px, is used instead of adding them up.

  5. How do you horizontally center a fixed-width block div inside its parent?

    • margin: 0 auto
    • padding: auto
    • text-align: center on the div itself
    • margin: center
    Answer and explanation

    Correct answer: margin: 0 auto

    When the element has a set width, auto splits the remaining horizontal space equally on both sides, centering it. text-align centers inner content, not the box itself.
