Test yourself

  1. What does border-box include?

    • Padding and border inside the declared size
    • Only the content
    • Only the margin
    • Only the padding
    Answer and explanation

    Correct answer: Padding and border inside the declared size

  2. Which property controls box sizing behavior?

    • box-sizing
    • box-size
    • size-model
    • element-sizing
    Answer and explanation

    Correct answer: box-sizing

  3. Which value is commonly used to make sizing easier to control?

    • border-box
    • content-only
    • margin-box
    • size-box
    Answer and explanation

    Correct answer: border-box

  4. With box-sizing: border-box; width: 300px; padding: 20px; border: 5px solid, how wide is the content area?

    • 250px
    • 300px
    • 340px
    • 260px
    Answer and explanation

    Correct answer: 250px

    In border-box the width includes content, padding and border, so content = 300 - 40 - 10 = 250px, and the whole box stays 300px.

  5. Two columns each have width: 50% and padding: 20px with content-box sizing inside a container. What happens?

    • They fit exactly side by side
    • Together they exceed 100 percent, so one wraps or overflows
    • The padding shrinks automatically
    • The browser ignores the padding
    Answer and explanation

    Correct answer: Together they exceed 100 percent, so one wraps or overflows

    Padding is added on top of 50 percent in content-box, so the combined width is larger than the container. The fix is box-sizing: border-box.
