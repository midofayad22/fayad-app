Test yourself

  1. Which property changes text color?

    • color
    • background
    • font
    • text
    Answer and explanation

    Correct answer: color

  2. What type of color value is #0b5d91?

    • HEX
    • RGB
    • HSL
    • Keyword
    Answer and explanation

    Correct answer: HEX

  3. Which function represents an RGB color?

    • rgb()
    • color()
    • hex()
    • paint()
    Answer and explanation

    Correct answer: rgb()

  4. What does color: rgba(255, 0, 0, 0.5) mean?

    • Red that is 50 percent transparent
    • Red darkened by 50 percent
    • A gray between red and black
    • Full red, because the last value is ignored
    Answer and explanation

    Correct answer: Red that is 50 percent transparent

    The first three values are red, green and blue, and the fourth is alpha, the transparency; 0.5 means half transparent. The last value changes opacity, not the hue.

  5. Which color does the code #0f0 represent?

    • Red
    • Blue
    • Black
    • Green
    Answer and explanation

    Correct answer: Green

    The short form repeats each digit, so #0f0 equals #00ff00: red 0, green full and blue 0, which gives green.
