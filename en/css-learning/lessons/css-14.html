Test yourself

  1. What does line-height control?

    • Vertical space between lines
    • Text color
    • Element width
    • Font family
    Answer and explanation

    Correct answer: Vertical space between lines

  2. Which property changes the space between text lines?

    • line-height
    • line-spacing-css
    • text-height
    • paragraph-gap
    Answer and explanation

    Correct answer: line-height

  3. Does line-height mainly control horizontal or vertical spacing?

    • Vertical
    • Horizontal
    • Diagonal
    • None
    Answer and explanation

    Correct answer: Vertical

  4. An element has font-size: 20px and line-height: 1.6 with no unit. How tall is a line?

    • 1.6px
    • 20px
    • 32px
    • 36px
    Answer and explanation

    Correct answer: 32px

    A unitless number is multiplied by the element's font size: 1.6 x 20 = 32px, so it adapts if the font size changes.

  5. A button is 50px tall and has one line of text. How do you center the text vertically using line-height?

    • line-height: 1
    • line-height: 50px
    • line-height: 0
    • line-height: 100
    Answer and explanation

    Correct answer: line-height: 50px

    When the line height equals the box height, a single line sits in the vertical middle. The unitless 100 would mean 100 times the font size, which is huge.
