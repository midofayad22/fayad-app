Animations

Learn how CSS keyframes create animations.

Code example

Your first CSS code

@keyframes fade {
from {
opacity: 0;
}
to {
opacity: 1;
}
}
.box {
animation: fade 1s ease;
}

Test yourself

  1. Which rule defines animation stages?

    • @keyframes
    • @animation
    • @motion
    • @frames-css
    Answer and explanation

    Correct answer: @keyframes

  2. Which property applies an animation to an element?

    • animation
    • animate
    • keyframe
    • motion
    Answer and explanation

    Correct answer: animation

  3. What does opacity: 0 mean?

    • The element is fully transparent
    • The element is fully visible
    • The element is removed from HTML
    • The element becomes larger
    Answer and explanation

    Correct answer: The element is fully transparent

  4. What is the result of @keyframes spin { to { transform: rotate(360deg); } } with animation: spin 2s linear infinite?

    • One rotation, then it stops
    • Continuous rotation every 2 seconds at constant speed
    • It moves forward and backward
    • Nothing, because from is missing
    Answer and explanation

    Correct answer: Continuous rotation every 2 seconds at constant speed

    infinite repeats forever and linear keeps the speed constant. When from is missing, the browser uses the element's current state as the start.

  5. After a fade-in animation ends, the element suddenly returns to opacity: 0. What is the fix?

    • animation-fill-mode: forwards
    • animation-iteration-count: 0
    • transition: none
    • animation-direction: reverse
    Answer and explanation

    Correct answer: animation-fill-mode: forwards

    After finishing, styles go back to their original state, and forwards keeps the values from the last keyframe.
