Understanding CSS Syntax

A CSS rule contains a selector and a group of declarations.

The selector chooses the HTML element you want to style.

Each declaration contains a property and a value.

Code example

Your first CSS code

h1 {
color: blue;
font-size: 40px;
}

  1. Which part selects the HTML element?

    • Selector
    • Value
    • Property
    • Declaration
    Answer and explanation

    Correct answer: Selector

  2. Which part defines what style is changed?

    • Property
    • Selector
    • HTML
    • Comment
    Answer and explanation

    Correct answer: Property

  3. In color: blue, what is blue?

    • Value
    • Selector
    • Property
    • Element
    Answer and explanation

    Correct answer: Value

  4. What is wrong with this rule? p { color: blue font-size: 20px; }

    • A semicolon is missing after blue to separate the two declarations
    • The unit px must come before the number
    • The element name must go inside the braces
    • A rule cannot hold two declarations
    Answer and explanation

    Correct answer: A semicolon is missing after blue to separate the two declarations

    Each declaration ends with a semicolon. Without it the browser reads blue font-size: 20px as one invalid value and drops the declaration; a rule may hold any number of declarations.

  5. Which rule is written with correct syntax?

    • h1 ( color: red; )
    • h1 { red: color; }
    • h1 { color: red; }
    • h1 { color = red; }
    Answer and explanation

    Correct answer: h1 { color: red; }

    The syntax is a selector followed by curly braces holding property: value; with a colon. Round brackets, an equals sign, or swapping the order are all invalid.
