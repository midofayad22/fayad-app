Test yourself

  1. Which property changes an element's background color?

    • background-color
    • color
    • border-color
    • background-text
    Answer and explanation

    Correct answer: background-color

  2. Which shorthand property can control background styles?

    • background
    • back
    • bg-style
    • background-style-only
    Answer and explanation

    Correct answer: background

  3. Which property is used for a background image?

    • background-image
    • image-background
    • background-picture
    • image
    Answer and explanation

    Correct answer: background-image

  4. A small image is set with background-image on a large box with no other background properties. What happens?

    • The image stretches to fill the box
    • The image tiles repeatedly in both directions
    • It appears once in the center
    • It does not appear until a size is set
    Answer and explanation

    Correct answer: The image tiles repeatedly in both directions

    The default background-repeat is repeat, so the image tiles horizontally and vertically starting from the top-left corner. Use no-repeat to stop the tiling.

  5. What does background-size: cover do?

    • Scales the image to cover the whole box, cropping any excess
    • Always shows the whole image uncropped, leaving gaps
    • Repeats the image until the box is full
    • Hides the image behind the content
    Answer and explanation

    Correct answer: Scales the image to cover the whole box, cropping any excess

    cover keeps the image ratio and scales it until no gap remains, which may crop part of it. The option that shows the whole image with possible gaps is contain.
