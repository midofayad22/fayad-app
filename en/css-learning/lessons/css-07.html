Test yourself

  1. Which property controls an element's width?

    • width
    • size
    • element-width
    • horizontal-size
    Answer and explanation

    Correct answer: width

  2. Which property controls an element's height?

    • height
    • size-height
    • element-height-value
    • vertical
    Answer and explanation

    Correct answer: height

  3. What unit is used in 300px?

    • px
    • em
    • percent
    • rem-only
    Answer and explanation

    Correct answer: px

  4. A div sits inside a parent that is 400px wide and has width: 50%. How wide is the child?

    • 50px
    • 200px
    • 400px
    • 800px
    Answer and explanation

    Correct answer: 200px

    A percentage width is calculated from the parent's width, and 50 percent of 400 is 200px. It is not based on the screen size.

  5. A box has width: 100%; max-width: 600px. How wide is it on a 400px wide screen?

    • 600px
    • 400px
    • 200px
    • 1000px
    Answer and explanation

    Correct answer: 400px

    100 percent of 400 is 400px, which is under the 600px limit, so max-width does not intervene. The cap only applies when the width would exceed 600px.
