Test yourself

  1. What does specificity determine?

    • Which CSS rule has priority
    • The element width
    • The page height
    • The font family
    Answer and explanation

    Correct answer: Which CSS rule has priority

  2. Which usually has higher specificity?

    • ID selector
    • Element selector
    • Universal selector
    • Plain text
    Answer and explanation

    Correct answer: ID selector

  3. Which selector is more specific?

    • .article p
    • p
    • *
    • body
    Answer and explanation

    Correct answer: .article p

  4. Given #a { color: red; } and .a.a.a { color: blue; } on an element with id a and class a, what is the color?

    • Red
    • Blue
    • Purple
    • The default color
    Answer and explanation

    Correct answer: Red

    An id selector outweighs any number of class selectors, since the columns do not carry over: 1,0,0 beats 0,3,0. So red wins.

  5. A p has style='color: blue' and the stylesheet has p { color: red !important; }. What color is it?

    • Blue, because inline is stronger
    • Red, because !important beats normal inline styles
    • Black
    • It varies randomly
    Answer and explanation

    Correct answer: Red, because !important beats normal inline styles

    An !important declaration in a stylesheet beats a normal inline declaration. That is why it should be avoided; it makes later changes harder.
