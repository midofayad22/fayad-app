Test yourself

  1. Which syntax represents a pseudo-element?

    • ::after
    • :after-element
    • pseudo-after
    • .after
    Answer and explanation

    Correct answer: ::after

  2. Which property is commonly required to generate content with ::before or ::after?

    • content
    • generate
    • pseudo-content
    • create
    Answer and explanation

    Correct answer: content

  3. What do pseudo-elements target?

    • Specific parts of an element
    • Only entire pages
    • Database records
    • JavaScript functions
    Answer and explanation

    Correct answer: Specific parts of an element

  4. Why does p::after { color: red; } show nothing?

    • Because ::after does not accept colors
    • Because the content property is missing, so the pseudo-element is not created
    • Because red is not a valid color
    • Because ::after needs only one colon
    Answer and explanation

    Correct answer: Because the content property is missing, so the pseudo-element is not created

    ::before and ::after are only generated when content is set, even an empty string content: ''. So nothing appears no matter what colors are added.

  5. What does p::first-letter { font-size: 2em; } style?

    • The first word of each paragraph
    • Only the first letter of each paragraph
    • The first paragraph on the page
    • All capital letters
    Answer and explanation

    Correct answer: Only the first letter of each paragraph

    ::first-letter targets the first letter of the element's text, commonly used for a large drop-cap effect. It is not a separate element in the HTML.
