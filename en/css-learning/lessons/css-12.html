Test yourself

  1. Which property adds an underline?

    • text-decoration
    • text-style
    • underline-text
    • font-line
    Answer and explanation

    Correct answer: text-decoration

  2. Which property controls spacing between letters?

    • letter-spacing
    • word-spacing-only
    • text-gap
    • font-spacing
    Answer and explanation

    Correct answer: letter-spacing

  3. Which property changes the text color?

    • color
    • text-color-property
    • font-color-only
    • paint
    Answer and explanation

    Correct answer: color

  4. A p element contains the text hello and has text-transform: uppercase. What is displayed?

    • hello
    • Hello
    • HELLO
    • HeLLo
    Answer and explanation

    Correct answer: HELLO

    uppercase turns every letter into a capital in the display only, without changing the original text in the HTML.

  5. In text-shadow: 2px 4px 6px gray, what do the first two values represent?

    • The horizontal then the vertical offset of the shadow
    • The shadow thickness and its opacity
    • The text width and height
    • The blur radius then the color
    Answer and explanation

    Correct answer: The horizontal then the vertical offset of the shadow

    The first two numbers are the shadow's horizontal and vertical offsets, the third is the blur radius, and then comes the color.
