Test yourself

  1. Which syntax creates a CSS variable?

    • --variable-name
    • $variable
    • @variable
    • #variable
    Answer and explanation

    Correct answer: --variable-name

  2. Which function reads a CSS variable?

    • var()
    • get()
    • css-var()
    • value()
    Answer and explanation

    Correct answer: var()

  3. Where are global CSS variables commonly defined?

    • :root
    • :global-css
    • body-root-only
    • #variables
    Answer and explanation

    Correct answer: :root

  4. The variable .card { --gap: 10px; } is defined and var(--gap) is used on body. What happens?

    • It works, because variables are always global
    • It fails, because the variable is only available inside .card and its descendants
    • It works but with the value zero
    • An error breaks the whole page
    Answer and explanation

    Correct answer: It fails, because the variable is only available inside .card and its descendants

    Custom properties are inherited only by descendants of the element where they are defined. Global ones are therefore defined on :root.

  5. What does var(--color, blue) mean?

    • It defines the variable color as blue
    • It always uses blue
    • It uses --color, and if it is not defined it uses blue
    • It blends the two colors
    Answer and explanation

    Correct answer: It uses --color, and if it is not defined it uses blue

    The second argument is a fallback that is used only when the first variable is not defined.
