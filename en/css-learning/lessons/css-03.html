Test yourself

  1. What does a selector do?

    • Selects elements to style
    • Creates HTML elements
    • Runs JavaScript
    • Creates a database
    Answer and explanation

    Correct answer: Selects elements to style

  2. Which selector targets a class named title?

    • .title
    • #title
    • title()
    • class-title
    Answer and explanation

    Correct answer: .title

  3. What does the p selector target?

    • Paragraph elements
    • Elements with an ID
    • Elements with a class
    • Images
    Answer and explanation

    Correct answer: Paragraph elements

  4. A p element has the class note. The rules are .note { color: green; } and p { color: red; }. What is the text color?

    • Green, because a class selector is more specific than an element selector
    • Red, because p is written last
    • A mix of green and red
    • Black, because the two rules conflict and cancel out
    Answer and explanation

    Correct answer: Green, because a class selector is more specific than an element selector

    A class selector is stronger than an element selector, so green wins regardless of order. A conflict does not cancel both rules; the stronger one is chosen.

  5. What does the selector h1, h2 { color: blue; } target?

    • Only h2 elements located inside an h1
    • All h1 elements and all h2 elements
    • An h1 immediately followed by an h2
    • An element named h1,h2
    Answer and explanation

    Correct answer: All h1 elements and all h2 elements

    A comma groups several selectors into one rule so it applies to each separately. Nesting one element inside another requires a space, not a comma.
