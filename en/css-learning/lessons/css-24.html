Test yourself

  1. Which property is used for transformations?

    • transform
    • change
    • motion
    • move-element
    Answer and explanation

    Correct answer: transform

  2. Which transform function moves an element?

    • translate()
    • move-css()
    • position()
    • shift-element()
    Answer and explanation

    Correct answer: translate()

  3. Which transform function changes an element's size?

    • scale()
    • size()
    • resize-css()
    • zoom-element-only
    Answer and explanation

    Correct answer: scale()

  4. What happens to surrounding elements when a card gets transform: translateY(-5px)?

    • They move up with it
    • They are unaffected, because transform does not change the layout
    • They are pushed down 5px
    • They disappear
    Answer and explanation

    Correct answer: They are unaffected, because transform does not change the layout

    A transform changes only the rendering and not the space reserved in layout, so neighbors stay put. That makes it ideal for hover effects.

  5. How do you rotate an element around its top-left corner instead of its center?

    • transform-origin: top left
    • rotate: left
    • transform: top left
    • margin: 0
    Answer and explanation

    Correct answer: transform-origin: top left

    The default origin is the center, and transform-origin changes it to set the pivot of rotation or scaling.
