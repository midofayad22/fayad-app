Data and Reactivity

Data in Vue is not just static values; Vue can watch it and update the interface when it changes.

This idea is called Reactivity, and it is one of Vue's most important concepts.

Data drives the interface

When reactive data changes, Vue updates the interface that depends on it.

Code example

The code


<div id="app">
<h2>Count: {{ count }}</h2>
<button @click="count++">
Increase
</button>
</div>
<script>
const { createApp } = Vue;
createApp({
data() {
return {
count: 0
};
}
}).mount("#app");
</script>
Count: 0

Understanding the code

count lives inside data().

When count++ runs, the data value changes.

Vue notices the change and updates {{ count }} automatically.
