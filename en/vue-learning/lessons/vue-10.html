v-on and Events

Use v-on to listen to Events that occur on page elements.

The common shorthand for v-on:click is @click.

@click handles clicks

You can use @click to run certain logic when the user clicks an element.

Code example

The code


<div id="app">
<p>Clicked {{ count }} times</p>
<button @click="count++">
Click
</button>
</div>
<script>
const { createApp } = Vue;
createApp({
data() {
return {
count: 0
};
}
}).mount("#app");
</script>

Clicked 0 times

Understanding the code

v-on is used to listen to Events.

@click is the shorthand for v-on:click.

When the button is clicked, the code after @click runs.

Test yourself

  1. What is the shorthand for v-on:click?

    • @click
    • :click
    • #click
    • $click
    Answer and explanation

    Correct answer: @click

  2. What is the purpose of v-on?

    • Listening to Events
    • Creating a database
    • Binding images only
    • Changing all of the HTML
    Answer and explanation

    Correct answer: Listening to Events

  3. Which Event occurs when the user clicks a button?

    • click
    • hover-only
    • load-css
    • database
    Answer and explanation

    Correct answer: click

  4. Which form runs save only on button click, not when the page renders?

    • @click="save"
    • click="save"
    • {{ save() }}
    • v-if="save"
    Answer and explanation

    Correct answer: @click="save"

    @click binds the function to the click event; {{ save() }} would run during render and click without @ is just an attribute.

  5. How do we listen for the Enter key in an input?

    • @keyup.enter="submit"
    • @enter="submit"
    • v-enter="submit"
    • @press="enter"
    Answer and explanation

    Correct answer: @keyup.enter="submit"

    Modifiers such as .enter are added after the event name to restrict it to a specific key.
