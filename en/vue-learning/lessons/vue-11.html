v-model

v-model is used to create Two-Way Data Binding between an Input and the data.

When the user types into the Input, the data changes, and when the data changes, that can be reflected in the Input.

v-model for two-way binding

v-model binds an Input's value to the data so that updates flow in both directions.

Code example

The code


<div id="app">
<input v-model="name" placeholder="Type your name">
<h2>Hello {{ name }}</h2>
</div>
<script>
const { createApp } = Vue;
createApp({
data() {
return {
name: ""
};
}
}).mount("#app");
</script>
Hello

Understanding the code

v-model shortens the process of binding an Input's value to the data.

When the user types a new value, name is updated.

Vue then displays the new value inside {{ name }}.
