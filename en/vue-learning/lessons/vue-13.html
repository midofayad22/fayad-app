Components

A component is an independent, reusable piece of the user interface.

Splitting an application into components makes the code better organized and easier to maintain.

Components make the UI reusable

Split the interface into small independent pieces that can be reused in more than one place.

Code example

The code


<div id="app">
<user-card></user-card>
</div>
<script>
const { createApp } = Vue;
const UserCard = {
template: `
<div>
<h2>FAYBIT</h2>
<p>Vue Developer</p>
</div>
`
};
createApp({
components: {
UserCard
}
}).mount("#app");
</script>
FAYBIT

Vue Developer

Understanding the code

UserCard is a reusable component.

We registered it inside components.

After that, it can be used inside the template with <user-card>.

Try it yourself

Test yourself

  1. Why do we use components?

    • To create reusable pieces
    • To replace JavaScript
    • To create an operating system
    • To delete HTML
    Answer and explanation

    Correct answer: To create reusable pieces

  2. What is the benefit of splitting an application into components?

    • Organizing code and reusing pieces
    • Eliminating CSS
    • Preventing JavaScript
    • Deleting data
    Answer and explanation

    Correct answer: Organizing code and reusing pieces

  3. Can a component be used more than once?

    • Yes
    • No
    • Only inside CSS
    • Only inside a database
    Answer and explanation

    Correct answer: Yes

  4. What is wrong with using <Card /> in a template if the component was never registered or imported?

    • There is no error
    • Templates do not accept components
    • Vue will not recognize or render the component
    • The name must contain numbers
    Answer and explanation

    Correct answer: Vue will not recognize or render the component

    A component must be registered or imported before it can be used in a template.

  5. What happens when <Counter /> is placed three times on a page?

    • Only one copy appears
    • Three independent instances are created, each with its own state
    • An error occurs
    • The copies always share the same data
    Answer and explanation

    Correct answer: Three independent instances are created, each with its own state

    Each use creates a separate instance of the component with its own data.
