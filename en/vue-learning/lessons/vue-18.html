watch

watch() is used to observe changes to a specific reactive value.

It is useful when a change in a certain value should trigger a side effect or an additional operation.

Watch data changes

Use watch when you need to run additional logic when a reactive value changes.

Code example

The code


<div id="app">
<input v-model="search">
<p>Search: {{ search }}</p>
</div>
<script>
const { createApp, ref, watch } = Vue;
createApp({
setup() {
const search = ref("");
watch(search, (newValue) => {
console.log("Search:", newValue);
});
return {
search
};
}
}).mount("#app");
</script>

Search:

Understanding the code

watch() tracks a reactive source.

When the value changes, the callback runs.

newValue contains the new value after the change.

Test yourself

  1. What does watch observe?

    • Reactive data changes
    • CSS changes only
    • HTML comments
    • Page images only
    Answer and explanation

    Correct answer: Reactive data changes

  2. When does the watch callback run?

    • When the watched value changes
    • Always only once
    • When the page color changes
    • When the browser closes
    Answer and explanation

    Correct answer: When the watched value changes

  3. What is the main benefit of watch?

    • Running additional logic when data changes
    • Creating components
    • Creating CSS
    • Creating routes only
    Answer and explanation

    Correct answer: Running additional logic when data changes

  4. What does this log when q changes from 'a' to 'ab'? watch(q,(n,o)=>console.log(o,n))

    • ab a
    • a ab
    • a
    • nothing
    Answer and explanation

    Correct answer: a ab

    The callback receives (new, old); we print old a then new ab.

  5. When do we prefer watch over computed?

    • To derive text from other data
    • To run a side effect such as a network request when a value changes
    • To simply show a value in the template
    • To define a click handler
    Answer and explanation

    Correct answer: To run a side effect such as a network request when a value changes

    computed is for derived values, while watch suits side effects triggered by a change.
