v-bind

The v-bind Directive is used to bind an HTML Attribute to a value in Vue data.

You can use the shorthand : instead of writing v-bind:.

Use : to bind Attributes

You can bind src, href, class, style, and other Attributes to Vue data.

Code example

The code


<div id="app">
<img :src="imageUrl" alt="Vue Logo">
</div>
<script>
const { createApp } = Vue;
createApp({
data() {
return {
imageUrl: "https://vuejs.org/images/logo.png"
};
}
}).mount("#app");
</script>

The image source was bound to the data using v-bind.

Understanding the code

:src is shorthand for v-bind:src.

Vue takes the value of imageUrl and puts it inside the src Attribute.

Test yourself

  1. What is the shorthand for v-bind?

    • :
    • @
    • #
    • $
    Answer and explanation

    Correct answer: :

  2. What does v-bind do?

    • Binds an Attribute to Vue data
    • Creates a database
    • Adds JavaScript to the system
    • Deletes the element
    Answer and explanation

    Correct answer: Binds an Attribute to Vue data

  3. Which syntax is correct for binding src?

    • :src="imageUrl"
    • @src="imageUrl"
    • #src="imageUrl"
    • $src="imageUrl"
    Answer and explanation

    Correct answer: :src="imageUrl"

  4. What is wrong with this line if we want to bind the image to the variable imgUrl? <img src="imgUrl">

    • There is no error
    • {{ imgUrl }} must be used inside src
    • The : is missing, so src is just static text
    • Images do not support binding
    Answer and explanation

    Correct answer: The : is missing, so src is just static text

    Without v-bind or :, imgUrl is treated as literal text; the correct form is :src="imgUrl".

  5. Which line binds the disabled attribute to isLocked?

    • <button disabled="isLocked">
    • <button {{ disabled }}>
    • <button v-disabled="isLocked">
    • <button :disabled="isLocked">
    Answer and explanation

    Correct answer: <button :disabled="isLocked">

    We use :attr for a dynamic value; here the button is disabled when isLocked is true.
