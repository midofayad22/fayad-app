Forms and Validation

You can use v-model to bind form values to data.

You can also use methods to validate the data before performing the submit operation.

Validate data before submitting

Bind form fields to data, then validate the values before submitting them or performing the operation.

Code example

The code


<div id="app">
<form @submit.prevent="submitForm">
<input v-model="name" placeholder="Name">
<button type="submit">
Submit
</button>
<p v-if="error">
{{ error }}
</p>
</form>
</div>
<script>
const { createApp } = Vue;
createApp({
data() {
return {
name: "",
error: ""
};
},
methods: {
submitForm() {
if (!this.name.trim()) {
this.error = "Please enter your name";
return;
}
this.error = "";
alert("Submitted");
}
}
}).mount("#app");
</script>

Understanding the code

v-model binds an input to data.

@submit.prevent prevents the form from submitting in the default way.

Inside submitForm(), we validate the data before performing the operation.

Test yourself

  1. What is the benefit of validation in forms?

    • Making sure data is correct before using it
    • Creating CSS
    • Creating components
    • Changing the browser color
    Answer and explanation

    Correct answer: Making sure data is correct before using it

  2. What can be used to bind an input to data?

    • v-model
    • v-route
    • v-check-only
    • v-input-data
    Answer and explanation

    Correct answer: v-model

  3. What does .prevent do with submit?

    • Prevents the browser's default behavior
    • Deletes the form
    • Creates a component
    • Closes the page
    Answer and explanation

    Correct answer: Prevents the browser's default behavior

  4. What is the benefit of @submit.prevent on a form?

    • It stops the page reload and lets our method handle the submit
    • It deletes the fields
    • It prevents typing any data
    • It submits the form twice
    Answer and explanation

    Correct answer: It stops the page reload and lets our method handle the submit

    Without prevent, the browser reloads the page before we can validate the data.

  5. Which validation check suits blocking an empty email from being submitted?

    • if (email) send()
    • if (!email) { error = 'Required'; return }
    • email = ''
    • if (email === email) send()
    Answer and explanation

    Correct answer: if (!email) { error = 'Required'; return }

    We check the value; if empty, we show an error message and stop the submit with return.
