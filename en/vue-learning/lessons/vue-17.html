ref and reactive

Learn the key difference between ref and reactive and how to use them with reactive data.

ref and reactive

ref() is used to create a reactive reference and can handle simple values such as numbers and strings.

reactive() is used to create a reactive object.

ref for values and reactive for objects

Use ref for reactive values and reactive when you need a reactive object.

Code example

The code


<div id="app">
<h2>{{ count }}</h2>
<p>{{ user.name }}</p>
<button @click="increment">
Increase
</button>
</div>
<script>
const { createApp, ref, reactive } = Vue;
createApp({
setup() {
const count = ref(0);
const user = reactive({
name: "FAYBIT"
});
function increment() {
count.value++;
}
return {
count,
user,
increment
};
}
}).mount("#app");
</script>

Understanding the code

ref() creates a reactive reference.

In JavaScript, we access the value using .value.

reactive() makes the object itself reactive.

Inside the template, Vue automatically unwraps refs.

Test yourself

  1. Which function is used to create a reactive reference?

    • ref()
    • stateRef()
    • reactiveValue()
    • reference()
    Answer and explanation

    Correct answer: ref()

  2. Which function is suitable for creating a reactive object?

    • reactive()
    • objectState()
    • makeObject()
    • watchObject()
    Answer and explanation

    Correct answer: reactive()

  3. How do we access a ref's value inside JavaScript?

    • Using .value
    • Using .data
    • Using .state
    • Using .refValue only
    Answer and explanation

    Correct answer: Using .value

  4. What is wrong? const n = ref(0) n++

    • Nothing
    • n.value++ must be used in JavaScript
    • ref does not accept numbers
    • reactive must be used
    Answer and explanation

    Correct answer: n.value++ must be used in JavaScript

    ref wraps the value in an object, so in JavaScript you access it through .value.

  5. How do we display a ref named count in the template?

    • {{ count.value }}
    • {{ ref(count) }}
    • {{ count }}
    • {{ $count }}
    Answer and explanation

    Correct answer: {{ count }}

    The template unwraps refs automatically, so .value is not needed there.
