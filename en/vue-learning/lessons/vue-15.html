Events and Emits

Learn how a child component communicates with its parent using custom events and emits.

Events and Emits

Props are mostly used to pass data from a parent to a child.

When a child needs to tell the parent that something happened, it can fire a custom event using emit.

emit sends events to the parent

A child can fire a custom event, and the parent can listen to it.

Code example

The code


<div id="app">
<button-counter @increase="handleIncrease"></button-counter>
<p>Count: {{ count }}</p>
</div>
<script>
const { createApp } = Vue;
const ButtonCounter = {
emits: ["increase"],
template: `
<button @click="$emit('increase')">
Increase
</button>
`
};
createApp({
components: {
ButtonCounter
},
data() {
return {
count: 0
};
},
methods: {
handleIncrease() {
this.count++;
}
}
}).mount("#app");
</script>

Count: 0

Understanding the code

emits declares the custom events that the component can fire.

$emit("increase") fires an event named increase.

The parent listens to the event using @increase.

Test yourself

  1. What does emit do in Vue?

    • Sends a custom event from the child to the parent
    • Creates CSS
    • Creates a database
    • Changes the URL
    Answer and explanation

    Correct answer: Sends a custom event from the child to the parent

  2. How does reverse communication from child to parent happen?

    • Using events and emits
    • Using CSS
    • Using HTML comments
    • Using images
    Answer and explanation

    Correct answer: Using events and emits

  3. How does the parent listen to a custom event named increase?

    • @increase
    • :increase
    • #increase
    • $increase
    Answer and explanation

    Correct answer: @increase

  4. Which line fires an event named save with the value 5 in the Options API?

    • this.emit('save', 5)
    • this.$emit('save', 5)
    • this.save(5)
    • this.$props.save(5)
    Answer and explanation

    Correct answer: this.$emit('save', 5)

    $emit takes the event name followed by the values to send to the parent.

  5. The child emits 'done' but the parent does not react. What is the most likely cause?

    • The parent did not add @done on the child tag
    • The child has no template
    • emit only works with click events
    • v-model must be used instead
    Answer and explanation

    Correct answer: The parent did not add @done on the child tag

    The parent listens to the custom event with @done="handler" on the child component.
