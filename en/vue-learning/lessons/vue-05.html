Methods

Methods are functions we use to perform operations inside a Vue app.

A Method can be called from the Template when an Event occurs, such as clicking a button.

Methods perform operations

You can put functions inside methods and then call them from the Template.

Code example

The code


<div id="app">
<button @click="sayHello">
Click here
</button>
</div>
<script>
const { createApp } = Vue;
createApp({
methods: {
sayHello() {
alert("Hello Vue!");
}
}
}).mount("#app");
</script>

Understanding the code

We put functions inside methods.

@click="sayHello" calls the function on click.

A Method can read and modify data and perform various operations.

  1. Where do we put Methods in the Options API?

    • methods
    • functions
    • actions
    • events
    Answer and explanation

    Correct answer: methods

  2. How do we call a Method on click?

    • @click
    • @hover
    • @press-only
    • @mouse
    Answer and explanation

    Correct answer: @click

  3. What is the purpose of a Method?

    • Performing a particular operation or logic
    • Automatically creating a database
    • Changing the operating system
    • Deleting HTML
    Answer and explanation

    Correct answer: Performing a particular operation or logic

  4. What is wrong with this code? <button @click="add">+</button> methods: { add: this.count++ }

    • Buttons do not support click
    • add should be a function, not an expression
    • methods must be outside the object
    • There is no error
    Answer and explanation

    Correct answer: add should be a function, not an expression

    Each method must be a function such as add() { this.count++ }, otherwise it cannot be called on click.

  5. How do we access data inside a method in the Options API?

    • Through this, e.g. this.count
    • Through window.count
    • Through document.count
    • It cannot be accessed
    Answer and explanation

    Correct answer: Through this, e.g. this.count

    Inside methods, this refers to the component instance, so we read and change data through it.
