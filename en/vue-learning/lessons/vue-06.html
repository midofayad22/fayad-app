Computed Properties

A Computed Property is a value calculated from other data.

It is useful when we need a result derived from the data we already have.

Computed for derived values

Use Computed when you need to calculate a value based on other data.

Code example

The code


<div id="app">
<h2>{{ fullName }}</h2>
</div>
<script>
const { createApp } = Vue;
createApp({
data() {
return {
firstName: "Abdullhamid",
lastName: "Fayad"
};
},
computed: {
fullName() {
return this.firstName + " " + this.lastName;
}
}
}).mount("#app");
</script>
Abdullhamid Fayad

Understanding the code

computed holds the derived values.

fullName() depends on firstName and lastName.

When the data a Computed depends on changes, Vue recalculates it when needed.

  1. What are Computed Properties used for?

    • Creating values derived from data
    • Creating CSS files
    • Creating images
    • Managing the operating system
    Answer and explanation

    Correct answer: Creating values derived from data

  2. What does a Computed usually depend on?

    • Other Reactive data
    • Images only
    • HTML comments
    • The operating system
    Answer and explanation

    Correct answer: Other Reactive data

  3. Where do we put Computed in the Options API?

    • computed
    • derived
    • calculations
    • values
    Answer and explanation

    Correct answer: computed

  4. What is the practical difference between a computed and a method for fullName?

    • A computed caches its result and recalculates only when its dependencies change
    • There is no difference at all
    • A method always caches the result
    • A computed does not work in templates
    Answer and explanation

    Correct answer: A computed caches its result and recalculates only when its dependencies change

    Caching is the main advantage of computed over methods, which run on every call.

  5. How do we display a computed named total in the template?

    • {{ total() }}
    • {{ total }}
    • {{ computed.total }}
    • {{ this.total() }}
    Answer and explanation

    Correct answer: {{ total }}

    A computed is used like a normal property, without call parentheses.
