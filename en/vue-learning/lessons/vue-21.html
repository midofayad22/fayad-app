Vue Router

Vue Router is the official solution for handling navigation inside Vue applications.

It lets you map different URLs to different components while preserving the nature of a single-page application.

Router controls navigation

Vue Router maps URLs to components and lets the user navigate between different views.

Code example

The code


const routes = [
{
path: "/",
component: Home
},
{
path: "/about",
component: About
}
];

/ → Home

/about → About

Understanding the code

An array named routes contains the application's routes.

path represents the URL.

component specifies the component that will appear for that path.

In real projects, Vue Router is used as a separate package.

Test yourself

  1. What is the primary use of Vue Router?

    • Managing navigation between views
    • Managing databases
    • Designing images
    • Creating CSS
    Answer and explanation

    Correct answer: Managing navigation between views

  2. What does path represent inside a route?

    • The URL or path
    • A CSS class name
    • A database name
    • An image name
    Answer and explanation

    Correct answer: The URL or path

  3. What does component specify inside a route?

    • The component that will appear for the path
    • The page color
    • The database type
    • The browser type
    Answer and explanation

    Correct answer: The component that will appear for the path

  4. Which Vue Router component creates a navigation link without a page reload?

    • <a href>
    • <RouterLink to="/about">
    • <RouterView>
    • <Link src>
    Answer and explanation

    Correct answer: <RouterLink to="/about">

    RouterLink changes the route inside the app without a full page load, while RouterView renders the matched component.

  5. Where does the component matching the current route appear?

    • Inside <RouterView />
    • Inside <head>
    • Inside <RouterLink>
    • In the console
    Answer and explanation

    Correct answer: Inside <RouterView />

    RouterView is the placeholder where the router renders the current page's component.
