v-for

Use v-for to repeat an HTML element for each item in an Array or Collection.

It is one of the most commonly used Directives when building lists.

v-for renders lists

You can use v-for to repeat an HTML element based on the items of an Array.

Code example

The code


<div id="app">
<ul>
<li v-for="item in items">
{{ item }}
</li>
</ul>
</div>
<script>
const { createApp } = Vue;
createApp({
data() {
return {
items: ["HTML", "CSS", "JavaScript"]
};
}
}).mount("#app");
</script>
  • HTML
  • CSS
  • JavaScript

Understanding the code

v-for="item in items" loops over all the items in items.

Each time, a copy of the element inside the Template is created.

When using Arrays with v-for, it is best to use key where appropriate.

    • v-list
    • v-repeat
    • v-loop-html

  2. What does v-for do?

    • Repeats an element based on data
    • Changes the page color
    • Creates a database
    • Runs CSS only
    Answer and explanation

    Correct answer: Repeats an element based on data

  3. If we have an items Array, how do we loop over its elements?

    • v-for="item in items"
    • v-loop="items"
    • v-array="items"
    • v-each="items"
    Answer and explanation

    Correct answer: v-for="item in items"

  4. What is the output? items = ['A','B','C'] <li v-for="x in items">{{ x }}</li>

    • One li element
    • Three li elements showing A, B, and C
    • Nothing
    • An error
    Answer and explanation

    Correct answer: Three li elements showing A, B, and C

    v-for repeats the element once for each item in the array.

  5. Why do we add :key when using v-for?

    • To help Vue track each item and update the list efficiently
    • To change the items' color
    • To prevent repeating items
    • It is required for {{ }} to work
    Answer and explanation

    Correct answer: To help Vue track each item and update the list efficiently

    A unique key lets Vue know which item changed and reuse the rest.
