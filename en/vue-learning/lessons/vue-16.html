Composition API

The Composition API provides a set of functions that help you organize component logic in a more flexible way.

Among its best-known functions are ref(), reactive(), and computed().

Composition API for organizing logic

The Composition API lets you group related logic together in a clear, reusable place.

Code example

The code


<div id="app">
<button @click="increment">
{{ count }}
</button>
</div>
<script>
const { createApp, ref } = Vue;
createApp({
setup() {
const count = ref(0);
function increment() {
count.value++;
}
return {
count,
increment
};
}
}).mount("#app");
</script>

Understanding the code

setup() is the main place to write logic using the Composition API.

ref(0) creates a reactive value.

In JavaScript, we use count.value to access the value.

When you return count and increment, they can be used inside the template.

  4. Where do we call ref and computed when using <script setup>?

    • Inside <script setup> after importing them from vue
    • Inside <style> tags
    • Only inside <template>
    • They never need importing
    Answer and explanation

    Correct answer: Inside <script setup> after importing them from vue

    We import the functions from 'vue' and write the logic in script setup, making it available to the template.

  5. What is the benefit of grouping logic for one feature together in the Composition API?

    • The code becomes harder to read
    • It is easier to organize and reuse
    • It prevents using templates
    • It stops reactivity
    Answer and explanation

    Correct answer: It is easier to organize and reuse

    Grouping by feature keeps large components cleaner and makes it easy to extract reusable functions.
