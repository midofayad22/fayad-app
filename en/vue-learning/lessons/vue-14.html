Props

Props are the primary way to pass data from a parent component to a child component.

Props help make components more flexible and reusable.

Props pass data to child components

A parent can send data to a child through props.

Code example

The code


<div id="app">
<user-card name="FAYBIT"></user-card>
</div>
<script>
const { createApp } = Vue;
const UserCard = {
props: ["name"],
template: `
<h2>Hello {{ name }}</h2>
`
};
createApp({
components: {
UserCard
}
}).mount("#app");
</script>
Hello FAYBIT

Understanding the code

props: ["name"] specifies that the component receives a prop named name.

The parent passes the value using <user-card name="FAYBIT">.

Inside the child, you can use {{ name }}.

Test yourself

  1. What is the primary use of props?

    • Passing data to a child component
    • Creating CSS
    • Creating a database
    • Running a browser
    Answer and explanation

    Correct answer: Passing data to a child component

  2. Where do props usually come from?

    • From the parent component
    • From the operating system
    • From CSS
    • Only from the browser
    Answer and explanation

    Correct answer: From the parent component

  3. Can the child use a prop's value?

    • Yes
    • No
    • Only in CSS
    • Only in a database
    Answer and explanation

    Correct answer: Yes

  4. How does a parent pass the text 'Ali' to a prop named name?

    • <Child name="Ali" />
    • <Child {{ name }} />
    • <Child @name="Ali" />
    • <Child v-on:name="Ali" />
    Answer and explanation

    Correct answer: <Child name="Ali" />

    A static string is passed as a normal attribute; to pass a variable we use :name.

  5. Why should a child not modify a prop directly?

    • Because it cannot be read
    • Because data flows from parent to child and the parent owns it
    • Because Vue deletes props
    • There is no problem modifying it
    Answer and explanation

    Correct answer: Because data flows from parent to child and the parent owns it

    One-way data flow keeps the app easy to follow; to change it, the child emits an event to the parent.
