What Is Vue.js?

Learn what Vue.js is, what it is for, and why it is used to build interactive user interfaces.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

Vue.js is a JavaScript Framework used to build modern, interactive user interfaces.

Vue is easy to learn and flexible, and it can be used to build small apps as well as large, complex ones.

Vue is based on the idea of binding data to the interface, so that the interface updates automatically when the data changes.

Vue binds data to the interface

When the data in the app changes, Vue can automatically update the right part of the interface.

Code example

The code


<div id="app">
<h1>{{ message }}</h1>
</div>
<script>
const { createApp } = Vue;
createApp({
data() {
return {
message: "Hello Vue!"
};
}
}).mount("#app");
</script>
Hello Vue!

Understanding the code

createApp() is used to create a new Vue app.

data() returns the data the app will use.

{{ message }} displays the value of message inside the Template.

mount("#app") attaches the Vue app to the element whose id is app.

  1. What is the main use of Vue.js?

    • Building interactive user interfaces
    • Creating databases only
    • Designing images only
    • Managing the operating system
    Answer and explanation

    Correct answer: Building interactive user interfaces

  2. What is Vue.js fundamentally built with?

    • JavaScript
    • SQL
    • Python only
    • C++ only
    Answer and explanation

    Correct answer: JavaScript

  3. What important idea does Vue provide?

    • Binding data to the interface
    • Eliminating HTML
    • Replacing the operating system
    • Creating PDF files only
    Answer and explanation

    Correct answer: Binding data to the interface

  4. Which of these is a benefit of binding data to the interface in Vue?

    • Manually refreshing the page after each change
    • The interface updates automatically when data changes
    • Preventing the user from interacting with the page
    • Removing the need for HTML entirely
    Answer and explanation

    Correct answer: The interface updates automatically when data changes

    With binding, Vue watches the data and updates the affected part of the page for you.

  5. A team wants a small app now and to grow it into a large one later. Why might Vue suit them?

    • Because it only works for small projects
    • Because it does not support scaling
    • Because it requires an entirely new programming language
    • Because it is easy to learn, flexible, and fits both sizes
    Answer and explanation

    Correct answer: Because it is easy to learn, flexible, and fits both sizes

    Vue is easy to start with and can be used for both small and large, complex apps.
