v-if and v-else

Use v-if to display an element when the condition is true.

You can use v-else to display an alternative element when the condition is false.

v-if controls rendering

Use v-if and v-else to show different elements depending on the state of the data.

Code example

The code


<div id="app">
<p v-if="isLoggedIn">
Welcome back!
</p>
<p v-else>
Please log in.
</p>
</div>
<script>
const { createApp } = Vue;
createApp({
data() {
return {
isLoggedIn: true
};
}
}).mount("#app");
</script>

Welcome back!

Understanding the code

v-if tests the condition.

If the value is true, the element is displayed.

v-else is used for the other branch when the condition is false.

Test yourself

  1. Which Directive is used for Conditional Rendering?

    • v-if
    • v-condition
    • v-show-text
    • v-check
    Answer and explanation

    Correct answer: v-if

  2. When does v-else apply?

    • When the v-if condition is false
    • Always
    • When the CSS changes
    • When the image loads
    Answer and explanation

    Correct answer: When the v-if condition is false

  3. What does v-if control?

    • Rendering an element based on a condition
    • Only the text color
    • The size of the database
    • The page title
    Answer and explanation

    Correct answer: Rendering an element based on a condition

  4. What is wrong here? <p v-if="ok">Yes</p> <span>divider</span> <p v-else>No</p>

    • v-else must come directly after the v-if element
    • p cannot be used with v-if
    • v-else does not accept text
    • There is no error
    Answer and explanation

    Correct answer: v-else must come directly after the v-if element

    v-else must immediately follow a v-if or v-else-if element, or Vue will not recognize it.

  5. If the v-if condition is false, what happens to the element?

    • It is only hidden with display:none
    • It turns gray
    • It is not rendered in the DOM
    • It is rendered twice
    Answer and explanation

    Correct answer: It is not rendered in the DOM

    v-if adds or removes the element in the DOM based on the condition, not just a visual hide.
