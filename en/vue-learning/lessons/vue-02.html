Vue App Structure

Learn the basic way to create a Vue app and attach it to an HTML element.

Open the interactive lesson (editor + quiz + progress)The exercise, quiz and progress tracking run on the interactive page.

A Vue app usually starts with createApp().

After creating the app, we use mount() to specify the HTML element the app will run inside.

createApp starts the app

We use createApp to create a Vue app, then mount to attach it to an HTML element.

Code example

The code


<div id="app">
<h1>{{ title }}</h1>
</div>
<script>
const { createApp } = Vue;
createApp({
data() {
return {
title: "My Vue App"
};
}
}).mount("#app");
</script>
My Vue App

Understanding the code

createApp() creates a Vue app.

data() holds the data used inside the app.

mount("#app") makes Vue control the element with id="app".

  1. What is the main job of createApp()?

    • Creating a Vue app
    • Creating a database
    • Changing the operating system
    • Creating a CSS file
    Answer and explanation

    Correct answer: Creating a Vue app

  2. Which method attaches a Vue app to an HTML element?

    • mount()
    • attach()
    • connect()
    • link()
    Answer and explanation

    Correct answer: mount()

  3. What does mount() usually specify?

    • The element the Vue app will run inside
    • The page color
    • The database name
    • The browser type
    Answer and explanation

    Correct answer: The element the Vue app will run inside

  4. What happens with this code if no #app element exists on the page? createApp({}).mount('#app')

    • The app appears at the top of the page
    • The app is not rendered because there is no element to attach to
    • Vue creates the #app element automatically
    • The whole page becomes a Vue app
    Answer and explanation

    Correct answer: The app is not rendered because there is no element to attach to

    mount needs an existing element matching the selector; otherwise Vue has nowhere to render the app.

  5. What is the correct order to start a Vue app?

    • mount, then createApp
    • createApp, then mount
    • The order does not matter
    • mount only, without createApp
    Answer and explanation

    Correct answer: createApp, then mount

    First you need the app object from createApp, then call mount on it to attach it to an HTML element.
