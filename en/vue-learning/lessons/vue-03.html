Template Syntax

Vue uses a simple way to display data inside HTML, using double curly braces {{ }}.

This technique is called Interpolation, and it lets you display data values directly inside the Template.

Use {{ }} to display data

Interpolation lets you display JavaScript values inside a Vue Template.

Code example

The code


<div id="app">
<h1>{{ name }}</h1>
<p>{{ message }}</p>
</div>
<script>
const { createApp } = Vue;
createApp({
data() {
return {
name: "FAYBIT",
message: "Welcome to Vue!"
};
}
}).mount("#app");
</script>
FAYBIT

Welcome to Vue!

Understanding the code

{{ name }} displays the value of the variable name.

{{ message }} displays the value of message.

Vue watches this data and updates the interface when it changes.
