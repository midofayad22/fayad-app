Binding Class and Style

Vue lets you bind CSS classes and inline styles to data.

This is useful when you want to change an element's appearance based on a certain state.

Control appearance with data

You can change a class or style dynamically based on data.

Code example

The code


<div id="app">
<p :class="{ active: isActive }">
Element status
</p>
</div>
<script>
const { createApp } = Vue;
createApp({
data() {
return {
isActive: true
};
}
}).mount("#app");
</script>

Element status — Active

Understanding the code

:class is used to bind a CSS class to data.

In the example, a class named active is applied when isActive is true.

You can also use :style to bind inline styles.

Try it yourself

Bind a class named active so that it is added when isActive is true.

Test yourself

  1. How do we bind a CSS class dynamically?

    • :class
    • @class
    • #class
    • v-css-only
    Answer and explanation

    Correct answer: :class

  2. When does active appear in the example?

    • When isActive is true
    • Always
    • When the CSS is deleted
    • When the page title changes
    Answer and explanation

    Correct answer: When isActive is true

  3. Which directive is used to bind an inline style?

    • :style
    • @style
    • #style
    • v-css
    Answer and explanation

    Correct answer: :style

  4. What class results? <div :class="{ red: isRed, big: isBig }"> isRed=true, isBig=false

    • red big
    • big
    • red
    • none
    Answer and explanation

    Correct answer: red

    In object syntax, only class names whose value is true are added.

  5. How do we write a hyphenated CSS property such as font-size in :style?

    • :style="{ font-size: size }"
    • :style="{ fontSize: size + 'px' }"
    • :style="font-size=size"
    • style="{{ size }}"
    Answer and explanation

    Correct answer: :style="{ fontSize: size + 'px' }"

    In a JavaScript object we use camelCase like fontSize, or quote the hyphenated name.
