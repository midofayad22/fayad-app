LESSON 01

Introduction to JavaScript

Learn what JavaScript is, why we use it, and how it makes websites interactive.

What is JavaScript?

JavaScript is a programming language used to add behavior and interaction to websites.

HTML creates the structure. CSS controls the appearance. JavaScript adds behavior and logic.

For example, JavaScript can make a button respond when the user clicks it.

KEY IDEA

JavaScript makes websites interactive

Think of a website as a human body. HTML is the skeleton, CSS is the appearance, and JavaScript is the behavior.
