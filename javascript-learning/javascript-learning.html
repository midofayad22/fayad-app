مقدمة إلى JavaScript

تعرّف على JavaScript، وما وظيفتها، ولماذا تُستخدم، وكيف تضيف التفاعل والسلوك إلى صفحات الويب.

ما هي JavaScript؟

JavaScript هي لغة برمجة تُستخدم لإضافة السلوك والتفاعل إلى صفحات ومواقع الويب.

تُستخدم HTML لبناء هيكل الصفحة، وتُستخدم CSS للتحكم في المظهر والتصميم، بينما تُستخدم JavaScript لإضافة المنطق والتفاعل والسلوك.

على سبيل المثال، يمكن استخدام JavaScript لجعل الزر يستجيب عند الضغط عليه، أو تغيير محتوى الصفحة، أو التحقق من البيانات التي يدخلها المستخدم.

الفكرة الأساسية

JavaScript تجعل صفحات الويب تفاعلية

يمكنك التفكير في موقع الويب على أنه جسم الإنسان: HTML تمثل الهيكل، CSS تمثل المظهر، وJavaScript تمثل السلوك والحركة والتفاعل.
