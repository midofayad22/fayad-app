فهم الكود

String تُستخدم للنصوص مثل "FAYBIT".

Number تُستخدم للأرقام مثل 20.

Boolean تحتوي على قيمتين فقط: true أو false.

اختيار نوع البيانات المناسب يساعد البرنامج على التعامل مع المعلومات بشكل صحيح.

    NaN اختصار Not a Number لكنه قيمة من النوع number، ويظهر عند عمليات حسابية غير صالحة مثل 0 / 0. لذلك typeof يعيد number.
