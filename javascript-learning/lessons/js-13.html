الكائنات Objects

تعلّم كيف تخزن Objects البيانات المرتبطة باستخدام Properties وValues.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

مثال برمجي

كود JavaScript

const user = {
name: "FAYBIT",
age: 20,
student: true
};
document.getElementById("jsResult").textContent =
user.name;

فهم الكود

Object يستخدم لتجميع البيانات المرتبطة داخل بنية واحدة.

يحتوي Object على Properties، ولكل Property قيمة.

في المثال name وage وstudent هي Properties.

يمكن الوصول إلى Property باستخدام النقطة مثل user.name.
