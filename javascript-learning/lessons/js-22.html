JavaScript غير المتزامنة

تعرّف على مفهوم Asynchronous JavaScript وكيفية التعامل مع المهام التي تستغرق وقتًا.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

مثال برمجي

كود JavaScript

document.getElementById("jsResult").textContent =
"ابدأ";
setTimeout(() => {
document.getElementById("jsResult").textContent =
"اكتملت المهمة";
}, 1000);

فهم الكود

Asynchronous JavaScript تسمح للبرنامج بالتعامل مع مهام لا تنتهي فورًا.

من أمثلة ذلك طلب البيانات من Server أو الانتظار باستخدام Timer.

setTimeout() تسمح بتأجيل تنفيذ Function لمدة محددة.

الهدف هو التعامل مع المهام التي تحتاج إلى وقت دون تجميد تجربة المستخدم.

اختبر نفسك

  1. ماذا يعني Asynchronous؟

    • تنفيذ المهام بطريقة لا تتطلب الانتظار لكل شيء قبل الاستمرار
    • إيقاف البرنامج
    • حذف HTML
    • تغيير CSS
    الإجابة والشرح

    الإجابة الصحيحة: تنفيذ المهام بطريقة لا تتطلب الانتظار لكل شيء قبل الاستمرار

  2. أي Function تستخدم لتأخير التنفيذ؟

    • setTimeout()
    • delayCode()
    • waitJS()
    • pauseScript()
    الإجابة والشرح

    الإجابة الصحيحة: setTimeout()

  3. أين تظهر الحاجة إلى Async JavaScript كثيرًا؟

    • طلبات الشبكة والعمليات التي تستغرق وقتًا
    • كتابة CSS فقط
    • كتابة HTML فقط
    • تغيير الخطوط فقط
    الإجابة والشرح

    الإجابة الصحيحة: طلبات الشبكة والعمليات التي تستغرق وقتًا

  4. ما ترتيب الطباعة؟ console.log(1); setTimeout(() => console.log(2), 0); console.log(3);

    • 1 ثم 2 ثم 3
    • 2 ثم 1 ثم 3
    • 1 ثم 3 ثم 2
    • 3 ثم 2 ثم 1
    الإجابة والشرح

    الإجابة الصحيحة: 1 ثم 3 ثم 2

    دالة setTimeout تؤجل callback حتى ينتهي الكود المتزامن حتى لو كان التأخير صفراً. لذلك تُطبع 1 و 3 أولاً ثم 2.

  5. جُدول setTimeout بتأخير 100ms ثم setTimeout بتأخير 0ms. أيهما يُنفَّذ أولاً؟

    • الأول لأنه جُدول أولاً
    • الثاني لأن مدة انتظاره أقصر
    • يعملان معاً في اللحظة نفسها
    • يتوقف البرنامج 100ms ثم يعمل الاثنان
    الإجابة والشرح

    الإجابة الصحيحة: الثاني لأن مدة انتظاره أقصر

    الترتيب يحدده زمن انتهاء المؤقت وليس ترتيب الكتابة، والانتظار لا يوقف بقية البرنامج. لذلك ينفذ المؤقت ذو 0ms أولاً.
