مقدمة إلى DOM

تعلّم كيف تمثل JavaScript صفحة HTML من خلال Document Object Model وكيف تتعامل معها.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

مثال برمجي

كود JavaScript

const title =
document.getElementById("lessonTitle");
document.getElementById("jsResult").textContent =
title.textContent;

فهم الكود

DOM اختصار لـ Document Object Model.

يقوم المتصفح بتمثيل مستند HTML كهيكل من العناصر والكائنات.

JavaScript تستطيع الوصول إلى هذه العناصر وتغييرها والتفاعل معها.

الـDOM هو الأساس الذي يسمح لـJavaScript بالتعامل مع واجهة الصفحة.

  4. ماذا يحدث لملف HTML الأصلي عندما ينفذ JavaScript تعديلاً على عنصر في DOM؟

    • يتغير الملف على الخادم أيضاً
    • يتغير الملف المحفوظ على جهاز المستخدم
    • يتغير ما يعرضه المتصفح في الذاكرة فقط، وعند إعادة التحميل يعود كما كان
    • لا يتغير شيء لأن DOM للقراءة فقط
    الإجابة والشرح

    الإجابة الصحيحة: يتغير ما يعرضه المتصفح في الذاكرة فقط، وعند إعادة التحميل يعود كما كان

    DOM تمثيل حي في ذاكرة المتصفح لبنية الصفحة، وتعديله يغير العرض فقط. ملف HTML على الخادم لا يتأثر، ولذلك تضيع التغييرات عند إعادة تحميل الصفحة ما لم تُحفظ بطريقة أخرى.

  5. أي كائن هو نقطة البداية للوصول إلى عناصر الصفحة من JavaScript؟

    • window.html
    • document
    • console
    • navigator
    الإجابة والشرح

    الإجابة الصحيحة: document

    document يمثل الصفحة المحمّلة ويوفر طرق البحث عن العناصر مثل querySelector. console للتسجيل و navigator لمعلومات المتصفح، وليس لهما علاقة بعناصر الصفحة.
