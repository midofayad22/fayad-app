المصفوفات Arrays

تعلّم كيف تخزن المصفوفات عدة قيم داخل متغير واحد وكيف تصل إلى عناصرها.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

مثال برمجي

كود JavaScript

const fruits = [
"Apple",
"Banana",
"Orange"
];
document.getElementById("jsResult").textContent =
fruits[0];

فهم الكود

Array هي بنية بيانات تسمح بتخزين عدة قيم داخل متغير واحد.

العناصر داخل Array لها ترتيب رقمي يبدأ من 0.

للوصول إلى أول عنصر نستخدم array[0].

المصفوفات مهمة جدًا عند التعامل مع مجموعات البيانات.

  3. كيف تصل إلى أول عنصر في fruits؟

    • fruits[0]
    • fruits[1]
    • fruits.first
    • fruits()
    الإجابة والشرح

    الإجابة الصحيحة: fruits[0]

  4. ما ناتج الكود؟ const a = [1, 2, 3]; a[5] = 9; console.log(a.length);

    • 4
    • 3
    • 6
    • 5
    الإجابة والشرح

    الإجابة الصحيحة: 6

    length يساوي أكبر index زائد واحد، والإسناد إلى index 5 يجعل الطول 6 ويترك فجوات فارغة في المنتصف. لا يضيف العنصر في المكان التالي مباشرة.

  5. كيف نصل إلى آخر عنصر في المصفوفة arr مهما كان طولها؟

    • arr[arr.length]
    • arr[arr.length - 1]
    • arr[-1]
    • arr.last
    الإجابة والشرح

    الإجابة الصحيحة: arr[arr.length - 1]

    الفهرسة تبدأ من 0 لذلك آخر index هو length ناقص واحد. arr[arr.length] يعطي undefined، و arr[-1] ليست index صالحاً في JavaScript، و last غير موجودة.
