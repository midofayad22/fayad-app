اختيار العناصر

تعلّم الطرق الأساسية لاختيار عناصر HTML باستخدام JavaScript.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

مثال برمجي

كود JavaScript

const title =
document.querySelector("h1");
document.getElementById("jsResult").textContent =
title.textContent;

فهم الكود

querySelector() تختار أول عنصر يطابق CSS Selector معين.

getElementById() تختار عنصرًا باستخدام قيمة ID.

اختيار العناصر هو الخطوة الأولى قبل تعديلها أو التعامل معها.

يمكن استخدام Selectors مثل h1 و.class و#id.

اختبر نفسك

  1. أي Method تستخدم CSS Selector لاختيار عنصر؟

    • querySelector()
    • selectElement()
    • getCSS()
    • findCSS()

    الإجابة الصحيحة: querySelector()

  2. ما الذي يستخدمه getElementById()؟

    • ID العنصر
    • اسم CSS
    • اسم الملف
    • اسم المتصفح
    الإجابة والشرح

    الإجابة الصحيحة: ID العنصر

  3. ماذا يعيد querySelector() عند وجود أكثر من عنصر مطابق؟

    • أول عنصر مطابق
    • كل العناصر
    • آخر عنصر فقط
    • لا شيء
    الإجابة والشرح

    الإجابة الصحيحة: أول عنصر مطابق

  4. ما الخطأ في هذا الكود؟ document.getElementById("#title")

    • لا شيء، فالعلامة # مطلوبة دائماً
    • getElementById تتطلب CSS Selector كاملاً
    • تعيد مصفوفة بدل عنصر
    • getElementById تأخذ الـ id فقط بدون #، لذلك تعيد null
    الإجابة والشرح

    الإجابة الصحيحة: getElementById تأخذ الـ id فقط بدون #، لذلك تعيد null

    getElementById تبحث عن id مطابق نصاً، ولا يوجد id يبدأ بـ # فتعيد null. العلامة # تُستخدم مع querySelector فقط.

  5. في الصفحة ثلاثة عناصر لها class باسم item. ماذا يعيد document.querySelectorAll(".item").length؟

    • 3
    • 1
    • undefined
    • 0
    الإجابة والشرح

    الإجابة الصحيحة: 3

    querySelectorAll تعيد NodeList بكل العناصر المطابقة، وله خاصية length فتكون 3. أما querySelector فتعيد أول عنصر مطابق فقط.
