Fetch API

تعلّم كيف تستخدم Fetch API لإرسال طلبات HTTP والحصول على البيانات من Server أو API.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

مثال برمجي

كود JavaScript

fetch("https://example.com/data")
.then(response => response.json())
.then(data => {
console.log(data);
})
.catch(error => {
console.error(error);
});

فهم الكود

Fetch API توفر طريقة حديثة لإرسال HTTP Requests من JavaScript.

يمكن استخدامها لجلب بيانات من API أو Server.

النتيجة الأولية تكون Response ويمكن تحويلها إلى JSON باستخدام response.json().

عادةً يتم التعامل مع النتيجة باستخدام Promises أو async/await.

  4. ما المشكلة في هذا الكود؟ const data = fetch(url).json();

    • fetch تعيد promise لا يملك json()، والصحيح انتظار fetch ثم استدعاء json() على response
    • json() تعمل مع POST فقط
    • يجب إضافة new قبل fetch
    • url يجب أن يكون كائناً وليس نصاً
    الإجابة والشرح

    الإجابة الصحيحة: fetch تعيد promise لا يملك json()، والصحيح انتظار fetch ثم استدعاء json() على response

    fetch تعيد Promise وليس response مباشرة، ولذلك استدعاء json() عليه يرمي TypeError. نكتب const res = await fetch(url); const data = await res.json().

  5. يعيد الخادم الحالة 404 عند طلب fetch. ماذا يحدث للـ promise؟

    • يُرفض ويذهب إلى catch تلقائياً
    • يتحقق عادة ونفحص response.ok لاكتشاف الخطأ
    • يبقى معلقاً pending إلى الأبد
    • تعاد المحاولة تلقائياً
    الإجابة والشرح

    الإجابة الصحيحة: يتحقق عادة ونفحص response.ok لاكتشاف الخطأ

    fetch ترفض الـ promise فقط عند فشل الشبكة نفسها، أما حالات HTTP مثل 404 و 500 فتصل كـ response عادي. لذلك نفحص response.ok أو status ونرمي الخطأ بأنفسنا.
