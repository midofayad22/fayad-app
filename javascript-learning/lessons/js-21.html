Modules

تعلّم كيف تقسّم JavaScript إلى ملفات مستقلة باستخدام export وimport.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

مثال برمجي

كود JavaScript

// math.js
export function add(a, b) {
return a + b;
}
// app.js
import { add } from "./math.js";
document.getElementById("jsResult").textContent =
add(5, 3);

فهم الكود

Modules تسمح بتقسيم البرنامج إلى ملفات منفصلة ومنظمة.

export تجعل قيمة أو Function متاحة لملفات أخرى.

import تستخدم لاستيراد ما تم تصديره من Module أخرى.

استخدام Modules يساعد في تنظيم المشاريع الكبيرة.

    • export

    الإجابة والشرح

    الإجابة الصحيحة: export

  3. أي كلمة تستخدم لاستيراد قيمة؟

    • import
    • include
    • requireOnly
    • load
    الإجابة والشرح

    الإجابة الصحيحة: import

  4. الملف يحتوي export default add;. أي استيراد صحيح؟

    • import { add } from "./math.js";
    • import add from "./math.js";
    • import * add from "./math.js";
    • require add from "./math.js";
    الإجابة والشرح

    الإجابة الصحيحة: import add from "./math.js";

    الـ default export يُستورد دون أقواس معقوفة وباسم نختاره. الأقواس المعقوفة مخصصة للتصدير المسمى named export.

  5. عرّفنا const secret = 1 في ملف module دون export. هل يمكن لملف آخر قراءتها؟

    • نعم، لأنها متغير عام
    • نعم إذا كتبنا import secret فقط
    • نعم لكن للقراءة فقط
    • لا، فكل ما في الـ module خاص به إلا ما يُصدَّر بـ export
    الإجابة والشرح

    الإجابة الصحيحة: لا، فكل ما في الـ module خاص به إلا ما يُصدَّر بـ export

    للـ module نطاق خاص به، فلا تتسرب متغيراته إلى النطاق العام. لا يراه غيره إلا بالتصدير الصريح، وهذه إحدى فوائد الـ modules.
