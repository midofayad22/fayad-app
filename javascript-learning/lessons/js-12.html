دوال المصفوفات

تعلّم بعض أهم الدوال المستخدمة للتعامل مع Arrays مثل push وpop وmap وfilter.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

مثال برمجي

كود JavaScript

const numbers = [1, 2, 3];
numbers.push(4);
document.getElementById("jsResult").textContent =
numbers.join(", ");

فهم الكود

JavaScript توفر العديد من Array Methods للتعامل مع المصفوفات.

push() تضيف عنصرًا إلى نهاية المصفوفة.

pop() تحذف آخر عنصر.

map() تنشئ Array جديدة بعد تطبيق عملية على العناصر.

filter() تستخدم لاختيار العناصر التي تحقق شرطًا معينًا.

  3. ما الاستخدام الشائع لـ filter()؟

    • اختيار العناصر التي تحقق شرطًا
    • إضافة عنصر دائمًا

    الإجابة والشرح

    الإجابة الصحيحة: اختيار العناصر التي تحقق شرطًا

  4. ما ناتج الكود؟ const r = [1, 2, 3].forEach(n => n * 2); console.log(r);

    • [2, 4, 6]
    • [1, 2, 3]
    • undefined
    • 12
    الإجابة والشرح

    الإجابة الصحيحة: undefined

    forEach تنفذ الدالة لكل عنصر لكنها تعيد undefined دائماً. إذا أردنا مصفوفة جديدة من النتائج نستخدم map.

  5. ما ناتج console.log([10, 1, 5].sort())؟

    • [1, 5, 10]
    • [10, 5, 1]
    • [1, 10, 5]
    • [10, 1, 5]
    الإجابة والشرح

    الإجابة الصحيحة: [1, 10, 5]

    sort بدون دالة مقارنة ترتب العناصر كنصوص، فيأتي "10" قبل "5" لأن الحرف 1 يسبق 5. للترتيب الرقمي نستخدم sort((a, b) => a - b).
