معالجة الأخطاء

تعلّم كيف تتعامل مع الأخطاء باستخدام try وcatch وfinally.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

مثال برمجي

كود JavaScript

try {
const result = unknownVariable;
document.getElementById("jsResult").textContent =
result;
} catch (error) {
document.getElementById("jsResult").textContent =
"حدث خطأ";
}

فهم الكود

الأخطاء يمكن أن تحدث أثناء تشغيل JavaScript لأسباب مختلفة.

try تحتوي على الكود الذي قد ينتج عنه خطأ.

catch تستقبل الخطأ وتسمح لنا بالتعامل معه بدلًا من ترك البرنامج يتوقف بشكل غير متوقع.

finally يمكن استخدامها لتنفيذ كود سواء حدث خطأ أم لا.

  4. ماذا يطبع الكود؟ try { JSON.parse("{bad"); } catch (e) { console.log("err"); } finally { console.log("done"); }

    • done فقط
    • err فقط
    • done ثم err
    • err ثم done
    الإجابة والشرح

    الإجابة الصحيحة: err ثم done

    JSON.parse يرمي خطأً لأن النص غير صالح، فينفذ catch ثم يعمل finally دائماً في النهاية. الترتيب إذاً err ثم done.

  5. ماذا يطبع الكود؟ function f() { try { return 1; } finally { console.log("f"); } } console.log(f());

    • 1 فقط
    • f ثم 1
    • 1 ثم f
    • f فقط
    الإجابة والشرح

    الإجابة الصحيحة: f ثم 1

    finally تعمل حتى مع وجود return داخل try، وتنفذ قبل أن تغادر الدالة. لذلك يطبع f أولاً ثم تُطبع القيمة المعادة 1.
