Parameters و Arguments

تعلّم كيف تستقبل الدوال البيانات باستخدام Parameters وArguments.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

مثال برمجي

كود JavaScript

function greet(name) {
return "مرحبًا " + name;
}
document.getElementById("jsResult").textContent =
greet("FAYBIT");

فهم الكود

Parameter هو المتغير الموجود داخل تعريف الدالة لاستقبال قيمة.

Argument هي القيمة التي نمررها عند استدعاء الدالة.

في المثال name هو Parameter.

أما "FAYBIT" فهي Argument تم تمريرها إلى الدالة.

    القيمة الافتراضية b = 2 تُستخدم فقط عند عدم تمرير argument، فيكون f(1) يساوي 3. عند تمرير 5 تحل محل الافتراضية فيكون الناتج 6.

  5. ما ناتج الكود؟ function show(a, b) { console.log(b); } show(1);

    • 1
    • خطأ لأن عدد arguments ناقص
    • null
    • undefined
    الإجابة والشرح

    الإجابة الصحيحة: undefined

    JavaScript لا تشترط تطابق عدد arguments مع parameters، والـ parameter الذي لا يصله argument يكون undefined. لا يُرمى خطأ ولا تستخدم null.
