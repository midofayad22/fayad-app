دوال الكائنات

تعلّم كيف يمكن للكائنات أن تحتوي على Functions تُعرف باسم Methods.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

مثال برمجي

كود JavaScript

const user = {
name: "FAYBIT",
greet() {
return "Hello " + this.name;
}
};
document.getElementById("jsResult").textContent =
user.greet();

فهم الكود

Method هي Function مرتبطة بكائن Object.

يمكن تعريف Method داخل Object.

الكلمة المفتاحية this تشير في هذا السياق إلى الكائن الذي ينتمي إليه الـMethod.

Methods تسمح للكائن بتجميع البيانات والسلوك معًا.

  4. ما ناتج الكود؟ const c = { count: 0, inc() { this.count++; } }; c.inc(); c.inc(); console.log(c.count);

    • 0
    • 1
    • 2

    الإجابة والشرح

    الإجابة الصحيحة: 2

    عند استدعاء c.inc() يشير this إلى الكائن c، فيزيد count في كل استدعاء. بعد استدعاءين تصبح القيمة 2.

  5. ما المشكلة؟ const c = { count: 0, inc() { count++; } }; c.inc();

    • نسيان this فيبحث الكود عن متغير count منفصل غير موجود فيرمي ReferenceError
    • لا يمكن استخدام ++ داخل method
    • لا يمكن تعريف method داخل كائن بهذه الصيغة
    • count خاصية للقراءة فقط
    الإجابة والشرح

    الإجابة الصحيحة: نسيان this فيبحث الكود عن متغير count منفصل غير موجود فيرمي ReferenceError

    خصائص الكائن لا تصبح متغيرات داخل الـ method، ويجب الوصول إليها عبر this.count. بدون this يُبحث عن متغير count في النطاق فلا يوجد.
