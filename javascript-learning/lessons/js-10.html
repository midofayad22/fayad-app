Arrow Functions

تعلّم الصيغة الحديثة لكتابة الدوال باستخدام Arrow Functions.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

مثال برمجي

كود JavaScript

const add = (a, b) => {
return a + b;
};
document.getElementById("jsResult").textContent =
add(5, 3);

فهم الكود

Arrow Function هي صيغة مختصرة وحديثة لكتابة الدوال.

يتم استخدام الرمز => بين Parameters وجسم الدالة.

يمكن اختصار الدالة أكثر إذا كانت تحتوي على تعبير واحد.

Arrow Functions شائعة جدًا في JavaScript الحديثة.

اختبر نفسك

  1. أي رمز يستخدم في Arrow Function؟

    • =>
    • ->
    • ::
    • ==>
    الإجابة والشرح

    الإجابة الصحيحة: =>

  2. أي صيغة صحيحة؟

    • const add = (a, b) => a + b;
    • const add => (a, b)
    • arrow add(a, b)
    • function => add
    الإجابة والشرح

    الإجابة الصحيحة: const add = (a, b) => a + b;

  3. ما فائدة Arrow Functions؟

    • كتابة الدوال بصيغة حديثة ومختصرة
    • إنشاء HTML
    • تغيير ألوان CSS
    • إدارة قواعد البيانات فقط
    الإجابة والشرح

    الإجابة الصحيحة: كتابة الدوال بصيغة حديثة ومختصرة

  4. ما ناتج الكود؟ const f = () => { a: 1 }; console.log(f());

    • { a: 1 }
    • 1
    • undefined
    • خطأ في الصياغة
    الإجابة والشرح

    الإجابة الصحيحة: undefined

    الأقواس المعقوفة بعد السهم تُفسَّر كجسم دالة وليست كائناً، و a: 1 تصبح label، ولا يوجد return. لإعادة كائن نضعه بين أقواس عادية: () => ({ a: 1 }).

  5. ما ناتج الكود؟ const sq = n => n * n; console.log([1, 2, 3].map(sq));

    • [1, 4, 9]
    • [1, 2, 3]
    • 14
    • [2, 4, 6]
    الإجابة والشرح

    الإجابة الصحيحة: [1, 4, 9]

    الدالة السهمية بدون أقواس معقوفة تعيد نتيجة التعبير تلقائياً، و map تطبقها على كل عنصر وتعيد مصفوفة جديدة بمربعاتها.
