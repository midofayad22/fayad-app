العوامل Operators

تعلّم كيف تستخدم JavaScript العوامل الحسابية والمقارنة والمنطقية لتنفيذ العمليات.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

مثال برمجي

كود JavaScript

const a = 10;
const b = 5;
const result = a + b;
document.getElementById("jsResult").textContent = result;

فهم الكود

العوامل Operators تُستخدم لتنفيذ عمليات على القيم.

+ للجمع، - للطرح، * للضرب، و/ للقسمة.

يمكن أيضًا استخدام عوامل المقارنة مثل === و> و<.

العوامل جزء أساسي من كتابة المنطق البرمجي.

  4. ما ناتج console.log(5 + "5", 5 - "5")؟

    • 10 و 0
    • 55 و 0
    • 55 و 55
    • 10 و NaN
    الإجابة والشرح

    الإجابة الصحيحة: 55 و 0

    عند وجود نص مع + تُدمج القيم كنصوص فيصبح الناتج 55. أما - فتعمل على الأرقام فقط، فتحول النص إلى رقم والناتج 0.

  5. ما ناتج console.log(0 || 10, 0 ?? 10)؟

    • 10 و 10
    • 0 و 0
    • 0 و 10
    • 10 و 0
    الإجابة والشرح

    الإجابة الصحيحة: 10 و 0

    || يتجاوز أي قيمة falsy ومنها 0 فيعيد 10. أما ?? فيتجاوز null و undefined فقط، فيبقى 0 كما هو.
