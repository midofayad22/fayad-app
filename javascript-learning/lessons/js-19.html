Destructuring

تعلّم كيف تستخرج القيم من Arrays وObjects بطريقة مختصرة ومنظمة.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

مثال برمجي

كود JavaScript

const user = {
name: "FAYBIT",
age: 20
};
const { name, age } = user;
document.getElementById("jsResult").textContent =
name + " - " + age;

فهم الكود

Destructuring تسمح باستخراج القيم من Object أو Array داخل متغيرات.

بدلًا من كتابة user.name وuser.age عدة مرات يمكن استخراج القيم مباشرة.

يُستخدم Destructuring بكثرة في JavaScript الحديثة.

يمكن استخدامه مع Objects وArrays.

    • نعم

    الإجابة والشرح

    الإجابة الصحيحة: نعم

  4. ما ناتج الكود؟ const [x, y = 5] = [1]; const { name, age = 30 } = { name: "Z" }; console.log(x, y, name, age);

    • 1 undefined Z undefined
    • 1 5 Z 30
    • 1 5 Z undefined
    • خطأ لأن المصفوفة أقصر من المتغيرات
    الإجابة والشرح

    الإجابة الصحيحة: 1 5 Z 30

    القيم الافتراضية في destructuring تُستخدم عندما تكون القيمة المقابلة undefined أو غير موجودة. لذلك y تصبح 5 و age تصبح 30.

  5. ما الذي تفعله هذه العبارة؟ [a, b] = [b, a];

    • تنسخ a إلى b فقط
    • تبدّل قيمتي المتغيرين دون متغير مؤقت
    • ترمي خطأ لأن المصفوفة لا تُسند
    • تنشئ مصفوفة جديدة فقط دون تغيير المتغيرات
    الإجابة والشرح

    الإجابة الصحيحة: تبدّل قيمتي المتغيرين دون متغير مؤقت

    الطرف الأيمن يبني مصفوفة بالقيم الحالية أولاً، ثم يفككها destructuring إلى a و b بالترتيب المعكوس. هكذا يتم التبديل دون متغير ثالث.
