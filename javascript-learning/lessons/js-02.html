المتغيرات

تعلّم كيف تخزن المتغيرات القيم والبيانات داخل برنامج JavaScript.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

مثال برمجي

كود JavaScript

let name = "FAYBIT";
let age = 20;
document.getElementById("jsResult").textContent =
name + " - " + age;

فهم الكود

let تُستخدم لإنشاء متغير يمكن تغيير قيمته لاحقًا.

name يخزن قيمة نصية.

age يخزن قيمة رقمية.

يمكن إعادة إسناد قيمة جديدة للمتغير الذي تم إنشاؤه باستخدام let.

  4. ما ناتج الكود التالي؟ const user = { n: 1 }; user.n = 2; console.log(user.n);

    • 1
    • 2
    • خطأ TypeError لأن user معرّف بـ const
    • undefined
    الإجابة والشرح

    الإجابة الصحيحة: 2

    const يمنع إعادة إسناد المتغير نفسه إلى قيمة جديدة، لكنه لا يمنع تعديل خصائص الكائن الذي يشير إليه. لذلك يطبع 2 دون خطأ.

  5. ما الخطأ في هذا الكود؟ const total = 0; total = total + 5;

    • لا يمكن إعادة إسناد متغير معرّف بـ const، ويجب استخدام let هنا
    • لا يمكن جمع رقم مع نفسه
    • يجب كتابة اسم المتغير بحروف كبيرة
    • الصفر ليس قيمة صالحة للمتغيرات
    الإجابة والشرح

    الإجابة الصحيحة: لا يمكن إعادة إسناد متغير معرّف بـ const، ويجب استخدام let هنا

    الإسناد الثاني يحاول تغيير ارتباط const فيرمي TypeError. عندما نعرف أن القيمة ستتغير نستخدم let.
