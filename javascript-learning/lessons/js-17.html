تغيير المحتوى

تعلّم كيف تغيّر JavaScript النصوص والمحتوى الموجود داخل عناصر HTML.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

مثال برمجي

كود JavaScript

const title =
document.querySelector("h1");
title.textContent = "مرحبًا من JavaScript";
document.getElementById("jsResult").textContent =
title.textContent;

فهم الكود

textContent تسمح بقراءة أو تغيير النص الموجود داخل العنصر.

يمكن استخدامها لتحديث محتوى الصفحة بناءً على تفاعل المستخدم أو البيانات.

عند إسناد قيمة جديدة إلى textContent يتم تحديث النص في الصفحة مباشرة.

هذه من أكثر عمليات DOM استخدامًا.

اختبر نفسك

  1. أي Property تغيّر النص داخل العنصر؟

    • textContent
    • textChange
    • contentText
    • changeText
    الإجابة والشرح

    الإجابة الصحيحة: textContent

  2. ماذا يحدث عند كتابة element.textContent = "Hello"؟

    • يتغير النص داخل العنصر
    • يتم حذف JavaScript
    • يتغير CSS فقط
    • يتم إنشاء Array
    الإجابة والشرح

    الإجابة الصحيحة: يتغير النص داخل العنصر

  3. هل يمكن استخدام textContent لقراءة النص؟

    • نعم
    • لا
    • فقط داخل CSS
    • فقط داخل HTML
    الإجابة والشرح

    الإجابة الصحيحة: نعم

  4. تضع في textContent نصاً يحتوي على علامات HTML مثل عنصر b. كيف يظهر في الصفحة؟

    • كنص حرفي كما كُتب، فتظهر العلامات نفسها
    • كنص بخط عريض
    • لا يظهر شيء
    • يرمي خطأ في الصياغة
    الإجابة والشرح

    الإجابة الصحيحة: كنص حرفي كما كُتب، فتظهر العلامات نفسها

    textContent يعامل القيمة كنص عادي ولا يحللها كـ HTML، لذلك تظهر العلامات كما هي. هذا يجعله أكثر أماناً عند عرض نصوص قادمة من المستخدم.

  5. ما الخطأ في هذا الكود؟ document.querySelector("#msg").textContent("Hi");

    • textContent خاصية وليست دالة، والصحيح textContent = "Hi"
    • يجب استخدام getElementById فقط
    • لا يمكن كتابة نص داخل عنصر
    • علامة # ممنوعة في querySelector
    الإجابة والشرح

    الإجابة الصحيحة: textContent خاصية وليست دالة، والصحيح textContent = "Hi"

    textContent خاصية نسندها بعلامة = ، واستدعاؤها بأقواس يرمي TypeError لأنها ليست دالة. علامة # صحيحة مع querySelector.
