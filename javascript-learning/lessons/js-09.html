Return

تعلّم كيف تستخدم return لإرجاع قيمة من الدالة إلى المكان الذي تم استدعاؤها منه.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

مثال برمجي

كود JavaScript

function add(a, b) {
return a + b;
}
const result = add(5, 3);
document.getElementById("jsResult").textContent = result;

فهم الكود

الكلمة المفتاحية return تُرجع قيمة من الدالة.

بعد تنفيذ return تتوقف الدالة عن تنفيذ التعليمات الموجودة بعدها.

يمكن تخزين القيمة التي أعادتها الدالة داخل متغير.

هذا يسمح باستخدام نتائج الدوال في أماكن أخرى من البرنامج.

  4. ما ناتج الكود؟ function f(a) { a * 2; } console.log(f(4));

    الإجابة والشرح

    الإجابة الصحيحة: undefined

    الدالة تحسب a * 2 لكنها لا تستخدم return، والدالة التي لا تعيد قيمة صراحة تعيد undefined. الحل أن نكتب return a * 2.

  5. ما ناتج الكود؟ function g() { return 1; console.log("x"); return 2; } console.log(g());

    • 1 فقط
    • x ثم 1
    • x ثم 2
    • 2
    الإجابة والشرح

    الإجابة الصحيحة: 1 فقط

    return ينهي تنفيذ الدالة فوراً، فلا يصل التنفيذ إلى console.log ولا إلى return الثانية. لذلك يطبع 1 فقط.
