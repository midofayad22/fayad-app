Promises

تعلّم كيف تمثل Promises نتيجة عملية غير متزامنة قد تنجح أو تفشل.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

مثال برمجي

كود JavaScript

const promise = new Promise((resolve) => {
resolve("نجحت العملية");
});
promise.then((result) => {
document.getElementById("jsResult").textContent =
result;
});

فهم الكود

Promise تمثل نتيجة مستقبلية لعملية غير متزامنة.

يمكن أن تكون العملية في حالة Pending أو Fulfilled أو Rejected.

resolve تستخدم للإشارة إلى نجاح العملية.

then() تستخدم للتعامل مع النتيجة عند نجاح Promise.

  4. ما ناتج الكود؟ Promise.resolve(1).then(v => v + 1).then(v => console.log(v));
