الحلقات Loops

تعلّم كيف تكرر JavaScript تنفيذ مجموعة من الأوامر باستخدام الحلقات.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

مثال برمجي

كود JavaScript

let result = "";
for (let i = 1; i <= 5; i++) {
result += i + " ";
}
document.getElementById("jsResult").textContent = result;

فهم الكود

الحلقات Loops تسمح بتكرار تنفيذ مجموعة من التعليمات.

حلقة for تتكون عادةً من البداية والشرط والتغيير.

في المثال تبدأ قيمة i من 1 وتستمر حتى تصل إلى 5.

الحلقات تقلل الحاجة إلى كتابة نفس الكود عدة مرات.

  4. ماذا يطبع الكود؟ for (let i = 0; i !== 5; i++) { if (i === 2) continue; if (i === 4) break; console.log(i); }

    • 0 1 3
    • 0 1 2 3
    • 0 1
    • 0 1 3 4
    الإجابة والشرح

    الإجابة الصحيحة: 0 1 3

    continue يتخطى دورة i = 2 فقط، و break يوقف الحلقة بالكامل عند i = 4 قبل طباعته. لذلك المطبوع 0 و 1 و 3.

  5. ما المشكلة في هذا الكود؟ let i = 0; while (i !== 3) { console.log(i); }

    • while لا تقبل الشرط !==
    • الحلقة لا تعمل أبداً لأن i يساوي 0
    • لا شيء يزيد i فتصبح الحلقة لا نهائية
    • يجب استخدام const بدل let
    الإجابة والشرح

    الإجابة الصحيحة: لا شيء يزيد i فتصبح الحلقة لا نهائية

    الشرط i !== 3 يبقى صحيحاً دائماً لأن قيمة i لا تتغير داخل الحلقة. نحتاج مثلاً إلى i++ حتى تصل إلى 3 وتتوقف.
