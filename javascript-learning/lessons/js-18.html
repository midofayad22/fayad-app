الأحداث Events

تعلّم كيف تستجيب JavaScript لأفعال المستخدم مثل الضغط والكتابة وتحريك الماوس.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

مثال برمجي

كود JavaScript

const button =
document.querySelector("button");
button.addEventListener("click", () => {
document.getElementById("jsResult").textContent =
"تم الضغط على الزر";
});

فهم الكود

Event هو حدث يحدث داخل الصفحة مثل الضغط على زر.

addEventListener() تُستخدم للاستماع إلى حدث معين.

في المثال نستمع إلى حدث click.

عند حدوث الحدث يتم تنفيذ Function معينة.

اختبر نفسك

  1. أي Method تستمع إلى الأحداث؟

    • addEventListener()
    • listenEvent()
    • eventClick()
    • watchEvent()
    الإجابة والشرح

    الإجابة الصحيحة: addEventListener()

  2. ما اسم الحدث الذي يحدث عند الضغط على زر؟

    • click
    • press
    • button
    • tapOnly
    الإجابة والشرح

    الإجابة الصحيحة: click

  3. ماذا يحدث عند وقوع Event؟

    • يمكن تنفيذ Function مرتبطة به
    • يتوقف المتصفح
    • يُحذف HTML
    • يتم حذف CSS
    الإجابة والشرح

    الإجابة الصحيحة: يمكن تنفيذ Function مرتبطة به

  4. ما الخطأ في هذا الكود؟ btn.addEventListener("click", handle());

    • اسم الحدث click خاطئ
    • handle() تُستدعى فوراً ويُمرَّر ناتجها، والصحيح تمرير handle بدون أقواس
    • addEventListener تقبل دوال سهمية فقط
    • لا يمكن ربط الحدث بزر
    الإجابة والشرح

    الإجابة الصحيحة: handle() تُستدعى فوراً ويُمرَّر ناتجها، والصحيح تمرير handle بدون أقواس

    الأقواس تنفذ الدالة لحظة تسجيل المستمع، فيُمرَّر undefined بدل الدالة ولا تعمل عند الضغط. نمرر مرجع الدالة لينفذها المتصفح عند وقوع الحدث.

  5. سُجّل مستمعان لحدث click على الزر نفسه، الأول يطبع A والثاني يطبع B. ماذا يحدث عند الضغط؟

    • يطبع A فقط لأن الثاني يستبدله
    • يطبع B فقط
    • يطبع A ثم B بترتيب التسجيل
    • يحدث خطأ لأن الحدث له مستمع واحد فقط
    الإجابة والشرح

    الإجابة الصحيحة: يطبع A ثم B بترتيب التسجيل

    addEventListener تضيف مستمعاً جديداً ولا تستبدل القديم، وتُنفذ المستمعات بترتيب إضافتها. الاستبدال يحدث مع الخاصية onclick فقط.
