القيم الاعتباطية Arbitrary Values

عندما لا يكفي المقياس الجاهز: w-[17rem] وbg-[#...] وخصائص كاملة.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

الأقواس المربعة

w-[17rem] top-[117px] bg-[#0b6b78] grid-cols-[1fr_2fr] (الشرطة السفلية تعني مسافة). للمتغيرات في v4: w-(--sidebar-width).

خصائص اعتباطية و variants

[mask-type:luminance] خاصية CSS كاملة. وvariants اعتباطية: [&>p]:mt-2 و[@media(min-width:900px)]:flex. استخدمها باعتدال: إن تكررت القيمة فأضفها إلى @theme.

القيمة المتكررة مكانها @theme، والاعتباطية للحالات الاستثنائية.

مثال برمجي

كود HTML

<div class="space-y-3 p-4" style="--sidebar-width: 12rem">
<div id="w" class="w-[17rem] rounded bg-[#0b6b78] p-2 text-white">w-[17rem] bg-[#0b6b78]</div>
<div class="w-(--sidebar-width) rounded bg-slate-200 p-2">w-(--sidebar-width)</div>
<div class="grid grid-cols-[1fr_2fr] gap-2"><div class="bg-amber-100 p-2">1fr</div><div class="bg-amber-200 p-2">2fr</div></div>
<div class="[&>p]:mt-2 rounded border p-2"><p>فقرة أولى</p><p>فقرة ثانية</p></div>
</div>

فهم الكود

الأقواس تتيح قيمًا غير موجودة في المقياس. الصيغة w-(--sidebar-width) تقرأ متغير CSS مباشرة (v4).
