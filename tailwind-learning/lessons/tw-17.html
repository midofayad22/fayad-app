التخصيص بـ @theme

عرّف ألوانك وخطوطك ونقاطك الفاصلة كمتغيرات تُولّد فئات تلقائيًا.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

من config إلى CSS

في v4 يتم التخصيص داخل CSS عبر @theme: --color-brand: #0b6b78; يولّد bg-brand وtext-brand وborder-brand تلقائيًا. كذلك --font-display و--breakpoint-3xl و--spacing و--radius-card.

ألوان بدرجات

عرّف --color-brand-500 و--color-brand-700 لتحصل على فئات بدرجات. لإلغاء لوحة الألوان الافتراضية: --color-*: initial;.

كل متغير في @theme يولّد فئات الأدوات المقابلة له تلقائيًا.

مثال برمجي

كود HTML

<style type="text/tailwindcss">
@theme {
--color-brand-500: #0b6b78;
--color-brand-700: #095561;
--radius-card: 1.25rem;
--breakpoint-3xl: 100rem;
}
</style>
<div class="p-4">
<button id="b" class="rounded-card bg-brand-500 px-5 py-2 font-semibold text-white hover:bg-brand-700">زر بلون العلامة</button>
<p class="mt-3 text-brand-700">نص بلون العلامة الداكن.</p>
</div>

فهم الكود

المتغيرات --color-brand-* ولّدت فئات bg-brand-500 وtext-brand-700 وhover:bg-brand-700، والمتغير --radius-card ولّد rounded-card.
