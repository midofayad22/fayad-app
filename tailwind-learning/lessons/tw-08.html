التموضع والـ container وترتيب الطبقات

relative وabsolute وsticky وinset وz-index والتجاوز.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

Position

relative absolute fixed sticky مع inset-0 top-0 start-0 end-4 (المنطقية). العنصر المطلق يتمركز بالنسبة لأقرب أب relative.

z-index والتجاوز

z-10 z-50 لترتيب الطبقات. overflow-hidden وoverflow-auto لقص أو تمرير المحتوى. container يحدد أقصى عرض حسب النقطة الفاصلة، ويُستخدم عادة مع mx-auto px-4.

اجعل الأب relative قبل وضع عنصر absolute بداخله.

مثال برمجي

كود HTML

<div class="container mx-auto px-4 py-6">
<div id="wrap" class="relative h-32 overflow-hidden rounded-xl bg-slate-200">
<span class="absolute end-3 top-3 rounded-full bg-rose-500 px-2 py-1 text-xs font-bold text-white">جديد</span>
<div class="absolute inset-x-0 bottom-0 bg-black/60 p-2 text-sm text-white">شريط سفلي</div>
</div>
<div class="sticky top-0 z-10 mt-4 bg-white p-2 shadow">شريط لاصق (sticky)</div>
</div>

فهم الكود

الشارة والشريط السفلي مطلقان داخل الأب النسبي. inset-x-0 يمدّد الشريط أفقيًا. overflow-hidden يقص ما يخرج عن الزوايا الدائرية.
