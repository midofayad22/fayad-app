@apply و @layer وإعادة الاستخدام

متى نستخرج مكونًا، وكيف نكتب فئات مخصصة مع @apply.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

الأفضل: مكوّنات

أول حل للتكرار هو مكوّن (قالب أو دالة في إطار عملك) لا فئة CSS جديدة. عندما لا يتوفر مكوّن (مثل HTML خام) استخدم @layer components مع @apply.

الصيغة

@layer components { .btn { @apply rounded-lg px-4 py-2 font-semibold; } }. حافظ على قلة هذه الفئات وإلا فقدت فائدة Utility-First.

استخدم @apply بحذر: المكوّنات أولًا ثم الفئات المخصصة للضرورة.

مثال برمجي

كود HTML

<style type="text/tailwindcss">
@layer components {
.btn {
@apply rounded-lg px-4 py-2 font-semibold transition;
}
.btn-primary {
@apply bg-sky-600 text-white hover:bg-sky-700;
}
}
</style>
<div class="flex gap-3 p-4">
<button id="x" class="btn btn-primary">أساسي</button>
<button class="btn bg-slate-200 text-slate-800 hover:bg-slate-300">ثانوي</button>
</div>

فهم الكود

الفئتان btn وbtn-primary جمعتا أدوات Tailwind في اسم واحد. ويمكن تجاوزها بفئات أدوات مباشرة عند الحاجة كما في الزر الثاني.
