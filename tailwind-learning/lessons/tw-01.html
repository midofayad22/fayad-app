مقدمة: فلسفة Utility-First وطرق الإعداد

ما هو Tailwind CSS، ولماذا نكتب الفئات الصغيرة مباشرة في HTML، وكيف نبدأ.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

Utility-First

بدل كتابة ملف CSS وتسمية الفئات، تركّب الواجهة من فئات صغيرة بغرض واحد: p-4 حشوة، text-lg حجم خط، bg-sky-600 خلفية. كل فئة تقابل خاصية CSS واحدة تقريبًا، فتبقى التصاميم متسقة دون مغادرة ملف HTML.

كيف نبدأ (الإصدار 4)

هذا الكورس مبني على Tailwind CSS v4 (المثبت في المعاينة 4.3.3). في المشاريع الحقيقية تثبّت Tailwind وتضيف في ملف CSS السطر @import "tailwindcss"; (عبر إضافة Vite أو واجهة الأوامر). أما هنا فالمعاينة تستخدم نسخة المتصفح التي تحوّل الفئات إلى CSS لحظيًا، وهي للتجربة والتعلم فقط، لا للإنتاج.

فئة صغيرة لكل غرض، وتركّبها في HTML. الإصدار 4 يبدأ بـ @import "tailwindcss".

مثال برمجي

كود HTML

<div id="card" class="m-6 max-w-sm rounded-xl bg-white p-6 shadow-lg">
<h1 class="text-xl font-bold text-slate-900">أول بطاقة Tailwind</h1>
<p class="mt-2 text-slate-600">بدون أي سطر CSS مكتوب يدويًا.</p>
<button class="mt-4 rounded-lg bg-sky-600 px-4 py-2 font-semibold text-white">ابدأ</button>
</div>

فهم الكود

p-6 حشوة 1.5rem، rounded-xl زوايا دائرية، shadow-lg ظل كبير، mt-2 هامش علوي، وpx-4 py-2 حشوة أفقية ورأسية للزر.

اختبر نفسك

  1. ما فكرة Utility-First؟

    • تركيب الواجهة من فئات صغيرة بغرض واحد
    • كتابة CSS ضخم لكل صفحة
    • استخدام JavaScript لكل نمط
    • تجنب HTML
    الإجابة والشرح

    الإجابة الصحيحة: تركيب الواجهة من فئات صغيرة بغرض واحد

  2. ما السطر الذي يبدأ به Tailwind v4 في ملف CSS؟

    • @import "tailwindcss";
    • @tailwind base;
    • import tailwind
    • <tailwind>
    الإجابة والشرح

    الإجابة الصحيحة: @import "tailwindcss";

  3. لماذا نسخة المتصفح مناسبة للتعلم فقط؟

    • تحوّل الفئات داخل المتصفح لحظيًا وهو غير مثالي للأداء في الإنتاج
    • لأنها لا تعمل أبدًا
    • لأنها مدفوعة
    • لأنها بدون ألوان
    الإجابة والشرح

    الإجابة الصحيحة: تحوّل الفئات داخل المتصفح لحظيًا وهو غير مثالي للأداء في الإنتاج

  4. أي فئة تعطي خلفية زرقاء سماوية بدرجة 600؟

    • bg-sky-600
    • text-sky-600
    • sky-600-bg
    • background-sky:600
    الإجابة والشرح

    الإجابة الصحيحة: bg-sky-600

    الصيغة bg-{اللون}-{الدرجة}.

  5. لماذا يبقى التصميم متسقاً مع فئات Tailwind؟

    • لأن Tailwind يمنع تغيير الألوان
    • لأن كل فئة تقابل خاصية واحدة تقريباً وقيمها من مقياس موحد
    • لأن كل صفحة تحتاج ملف CSS مختلف
    • لأن الفئات تُكتب بأسماء عشوائية
    الإجابة والشرح
