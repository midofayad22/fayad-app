ارتفاع السطر Line Height

تعلم كيف يتحكم line-height في المسافة الرأسية بين أسطر النص.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

مثال برمجي

أول كود CSS لك

p {
line-height: 1.8;
}
جرّب بنفسك

اكتب CSS وشاهد النتيجة

غيّر الكود الموجود بالأسفل ثم شغّله لترى النتيجة.

اختبر نفسك

  1. ماذا يتحكم line-height؟

    • المسافة الرأسية بين الأسطر
    • لون النص
    • عرض العنصر
    • نوع الخط
    الإجابة والشرح

    الإجابة الصحيحة: المسافة الرأسية بين الأسطر

  2. أي خاصية تغير المسافة بين أسطر النص؟

    • line-height
    • line-spacing-css
    • text-height
    • paragraph-gap
    الإجابة والشرح

    الإجابة الصحيحة: line-height

  3. هل يتحكم line-height بشكل أساسي في مسافة أفقية أم رأسية؟

    • رأسية
    • أفقية
    • مائلة
    • لا يتحكم في المسافات
    الإجابة والشرح

    الإجابة الصحيحة: رأسية

  4. عنصر font-size: 20px وline-height: 1.6 (بدون وحدة). كم ارتفاع السطر؟

    • 1.6px
    • 20px
    • 32px
    • 36px
    الإجابة والشرح

    الإجابة الصحيحة: 32px

    الرقم بدون وحدة يُضرب في حجم خط العنصر: 1.6 × 20 = 32px، وهذا يجعله يتكيف إذا تغير حجم الخط.

  5. زر ارتفاعه 50px ونصه سطر واحد. كيف تُوسّط النص عمودياً بخاصية line-height؟

    • line-height: 1
    • line-height: 50px
    • line-height: 0
    • line-height: 100
    الإجابة والشرح

    الإجابة الصحيحة: line-height: 50px

    عندما يساوي ارتفاع السطر ارتفاع الصندوق يقع السطر الواحد في المنتصف عمودياً. القيمة 100 بدون وحدة تعني 100 ضعف حجم الخط وهي ضخمة.
