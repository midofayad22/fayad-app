الحشو Padding

تعلم كيف ينشئ Padding مساحة داخل العنصر.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

مثال برمجي

أول كود CSS لك

.box {
padding: 30px;
background: #eaf3f8;
}
جرّب بنفسك

اكتب CSS وشاهد النتيجة

غيّر الكود الموجود بالأسفل ثم شغّله لترى النتيجة.

اختبر نفسك

  1. أين ينشئ الـ Padding المساحة؟

    • داخل العنصر
    • خارج العنصر
    • خارج الصفحة
    • داخل الـ Margin
    الإجابة والشرح

    الإجابة الصحيحة: داخل العنصر

  2. أي خاصية تتحكم في المسافة بين المحتوى والـ Border؟

    • padding
    • margin
    • gap-outside
    • content-space
    الإجابة والشرح

    الإجابة الصحيحة: padding

  3. ماذا يضيف padding: 20px؟

    • مساحة داخلية مقدارها 20px
    • مساحة خارجية مقدارها 20px
    • Border بحجم 20px
    • ارتفاع فقط بمقدار 20px
    الإجابة والشرح

    الإجابة الصحيحة: مساحة داخلية مقدارها 20px

  4. صندوق width: 200px; padding: 20px بدون إطار، والحجم الافتراضي content-box. ما عرضه الكلي؟

    • 200px
    • 220px
    • 240px
    • 160px
    الإجابة والشرح

    الإجابة الصحيحة: 240px

    في content-box العرض يخص المحتوى فقط، ويُضاف الحشو من الجانبين: 200 + 20 + 20 = 240px.

  5. في padding: 10px 20px 30px 40px، كم حشو الجانب الأيسر؟

    • 10px
    • 20px
    • 30px
    • 40px
    الإجابة والشرح

    الإجابة الصحيحة: 40px

    الترتيب مع عقارب الساعة: أعلى ثم يمين ثم أسفل ثم يسار، فالقيمة الرابعة 40px هي لليسار.
