المحددات Selectors

تعلم كيف تستخدم محددات CSS لاستهداف عناصر HTML.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

مثال برمجي

أول كود CSS لك

p {
color: #0b5d91;
}
.title {
color: #0f807a;
}
جرّب بنفسك

اكتب CSS وشاهد النتيجة

غيّر الكود الموجود بالأسفل ثم شغّله لترى النتيجة.

اختبر نفسك

  1. ماذا يفعل الـ Selector؟

    • يحدد العناصر التي نريد تنسيقها
    • ينشئ عناصر HTML
    • يشغل JavaScript
    • ينشئ قاعدة بيانات
    الإجابة والشرح

    الإجابة الصحيحة: يحدد العناصر التي نريد تنسيقها

  2. أي Selector يستهدف Class باسم title؟

    • .title
    • #title
    • title()
    • class-title
    الإجابة والشرح

    الإجابة الصحيحة: .title

  3. ماذا يستهدف الـ p Selector؟

    • عناصر الفقرات Paragraph
    • العناصر التي لها ID
    • العناصر التي لها Class
    • الصور
    الإجابة والشرح

    الإجابة الصحيحة: عناصر الفقرات Paragraph

  4. العنصر p يحمل الصنف note. القواعد: .note { color: green; } و p { color: red; }. ما لون النص؟

    • أخضر لأن محدد الصنف أخص من محدد العنصر
    • أحمر لأن p مكتوبة أخيراً
    • مزيج من الأخضر والأحمر
    • أسود لأن القاعدتين تتعارضان وتلغيان بعضهما
    الإجابة والشرح

    الإجابة الصحيحة: أخضر لأن محدد الصنف أخص من محدد العنصر

    محدد الصنف أقوى من محدد العنصر، فيفوز الأخضر بغض النظر عن الترتيب. التعارض لا يلغي القاعدتين، بل تُختار الأقوى.

  5. ماذا يستهدف المحدد h1, h2 { color: blue; }؟

    • كل h2 الموجودة داخل h1 فقط
    • كل عناصر h1 وكل عناصر h2
    • أول h1 يتبعه h2 مباشرة
    • عنصراً اسمه h1,h2
    الإجابة والشرح

    الإجابة الصحيحة: كل عناصر h1 وكل عناصر h2

    الفاصلة تجمع عدة محددات في قاعدة واحدة، فتنطبق القاعدة على كل منها منفصلاً. وجود عنصر داخل آخر يحتاج مسافة وليس فاصلة.
