صيغة كتابة CSS

تعلم البنية الأساسية لقاعدة CSS وافهم المحددات والخصائص والقيم.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

فهم صيغة كتابة CSS

تحتوي قاعدة CSS على Selector ومجموعة من Declarations.

يحدد الـ Selector عنصر HTML الذي تريد تنسيقه.

كل Declaration تحتوي على Property وValue.

مثال برمجي

أول كود CSS لك

h1 {
color: blue;
font-size: 40px;
}
جرّب بنفسك

اكتب CSS وشاهد النتيجة

غيّر الكود الموجود بالأسفل ثم شغّله لترى النتيجة.

اختبر نفسك

  1. أي جزء يحدد عنصر HTML الذي نريد تنسيقه؟

    • Selector — المحدد
    • Value — القيمة
    • Property — الخاصية
    • Declaration — التصريح
    الإجابة والشرح

    الإجابة الصحيحة: Selector — المحدد

  2. أي جزء يحدد نوع التنسيق الذي سيتم تغييره؟

    • Property — الخاصية
    • Selector — المحدد
    • HTML
    • Comment — التعليق
    الإجابة والشرح

    الإجابة الصحيحة: Property — الخاصية

  3. في color: blue، ماذا تمثل blue؟

    • Value — القيمة
    • Selector — المحدد
    • Property — الخاصية
    • Element — العنصر
    الإجابة والشرح

    الإجابة الصحيحة: Value — القيمة

  4. ما الخطأ في هذه القاعدة؟ p { color: blue font-size: 20px; }

    • نقص فاصلة منقوطة بعد blue تفصل بين التصريحين
    • يجب كتابة الوحدة px قبل الرقم
    • يجب وضع اسم العنصر داخل الأقواس
    • لا يجوز وضع تصريحين في قاعدة واحدة
    الإجابة والشرح

    الإجابة الصحيحة: نقص فاصلة منقوطة بعد blue تفصل بين التصريحين

    كل تصريح ينتهي بفاصلة منقوطة. بدونها يقرأ المتصفح blue font-size: 20px كقيمة واحدة غير صالحة فيتجاهل التصريحين، ويجوز وضع أي عدد من التصريحات داخل القاعدة.

  5. أي قاعدة مكتوبة بصيغة صحيحة؟

    • h1 ( color: red; )
    • h1 { red: color; }
    • h1 { color: red; }
    • h1 { color = red; }
    الإجابة والشرح

    الإجابة الصحيحة: h1 { color: red; }

    الصيغة هي محدد ثم أقواس معقوفة تحوي property: value; بالنقطتين. الأقواس العادية وعلامة المساواة وعكس الترتيب كلها غير صالحة.
