Animations

تعلم كيف تستخدم CSS Keyframes لإنشاء الحركات Animation.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

مثال برمجي

أول كود CSS لك

@keyframes fade {
from {
opacity: 0;
}
to {
opacity: 1;
}
}
.box {
animation: fade 1s ease;
}
جرّب بنفسك

اكتب CSS وشاهد النتيجة

غيّر الكود الموجود بالأسفل ثم شغّله لترى النتيجة.

اختبر نفسك

  1. أي قاعدة تحدد مراحل الـ Animation؟

    • @keyframes
    • @animation
    • @motion
    • @frames-css
    الإجابة والشرح

    الإجابة الصحيحة: @keyframes

  2. أي خاصية تطبق Animation على العنصر؟

    • animation
    • animate
    • keyframe
    • motion
    الإجابة والشرح

    الإجابة الصحيحة: animation

  3. ماذا يعني opacity: 0؟

    • العنصر شفاف بالكامل
    • العنصر ظاهر بالكامل
    • العنصر يتم حذفه من HTML
    • العنصر يصبح أكبر
    الإجابة والشرح

    الإجابة الصحيحة: العنصر شفاف بالكامل

  4. ما نتيجة: @keyframes spin { to { transform: rotate(360deg); } } مع animation: spin 2s linear infinite؟

    • دورانة واحدة ثم يتوقف
    • دوران مستمر كل ثانيتين بسرعة ثابتة
    • يتحرك للأمام ثم للخلف
    • لا شيء لأن from مفقودة
    الإجابة والشرح

    الإجابة الصحيحة: دوران مستمر كل ثانيتين بسرعة ثابتة

    infinite يكرر بلا نهاية، وlinear يجعل السرعة ثابتة. وعند غياب from يستخدم المتصفح الحالة الحالية للعنصر كبداية.

  5. بعد انتهاء حركة الظهور يعود العنصر إلى opacity: 0 فجأة. ما الحل؟

    • animation-fill-mode: forwards
    • animation-iteration-count: 0
    • transition: none
    • animation-direction: reverse
    الإجابة والشرح

    الإجابة الصحيحة: animation-fill-mode: forwards

    بعد الانتهاء تعود الأنماط إلى حالتها الأصلية، وforwards يُبقي القيم من آخر إطار.
