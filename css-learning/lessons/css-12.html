تنسيق النصوص

تعلم كيفية التحكم في لون النص وتزيينه والمسافات والمظهر.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

مثال برمجي

أول كود CSS لك

p {
color: #0b5d91;
text-decoration: underline;
letter-spacing: 1px;
}
جرّب بنفسك

اكتب CSS وشاهد النتيجة

غيّر الكود الموجود بالأسفل ثم شغّله لترى النتيجة.

اختبر نفسك

  1. أي خاصية تضيف خطًا أسفل النص؟

    • text-decoration
    • text-style
    • underline-text
    • font-line
    الإجابة والشرح

    الإجابة الصحيحة: text-decoration

  2. أي خاصية تتحكم في المسافة بين الحروف؟

    • letter-spacing
    • word-spacing-only
    • text-gap
    • font-spacing
    الإجابة والشرح

    الإجابة الصحيحة: letter-spacing

  3. أي خاصية تغير لون النص؟

    • color
    • text-color-property
    • font-color-only
    • paint
    الإجابة والشرح

    الإجابة الصحيحة: color

  4. العنصر p يحوي النص hello وقاعدته text-transform: uppercase. ماذا يظهر؟

    • hello
    • Hello
    • HELLO
    • HeLLo
    الإجابة والشرح

    الإجابة الصحيحة: HELLO

    uppercase يحول كل الحروف إلى كبيرة في العرض فقط، دون تغيير النص الأصلي في HTML.

  5. في text-shadow: 2px 4px 6px gray، ماذا تمثل القيمتان الأوليان؟

    • الإزاحة الأفقية ثم العمودية للظل
    • سماكة الظل وشفافيته
    • عرض وارتفاع النص
    • نصف قطر التمويه ثم اللون
    الإجابة والشرح

    الإجابة الصحيحة: الإزاحة الأفقية ثم العمودية للظل

    أول رقمين هما إزاحة الظل أفقياً ثم عمودياً، والثالث نصف قطر التمويه، ثم اللون.
