الحدود Borders

تعلم كيفية إنشاء حدود حول عناصر HTML.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

مثال برمجي

أول كود CSS لك

.card {
border: 2px solid #0f807a;
border-radius: 12px;
}
جرّب بنفسك

اكتب CSS وشاهد النتيجة

غيّر الكود الموجود بالأسفل ثم شغّله لترى النتيجة.

اختبر نفسك

  1. أي خاصية تنشئ Border حول العنصر؟

    • border
    • outline-text
    • edge
    • frame
    الإجابة والشرح

    الإجابة الصحيحة: border

  2. أي خاصية تجعل زوايا العنصر مستديرة؟

    • border-radius
    • corner
    • radius-border
    • round
    الإجابة والشرح

    الإجابة الصحيحة: border-radius

  3. ماذا تمثل 2px في border: 2px solid؟

    • سمك الـ Border
    • لون الـ Border
    • استدارة الـ Border
    • ارتفاع العنصر
    الإجابة والشرح

    الإجابة الصحيحة: سمك الـ Border

  4. كُتبت border: 2px red; ولا يظهر أي إطار. ما السبب؟

    • اللون red غير مدعوم
    • السماكة 2px صغيرة جداً لتظهر
    • نمط الإطار مفقود وقيمته الافتراضية none
    • يجب كتابة border داخل عنصر body
    الإجابة والشرح

    الإجابة الصحيحة: نمط الإطار مفقود وقيمته الافتراضية none

    الإطار يحتاج نمطاً مثل solid أو dashed، وبدونه يكون border-style هو none فلا يُرسم شيء مهما كانت السماكة. الصحيح border: 2px solid red.

  5. مربع عرضه وارتفاعه 100px. ما أثر border-radius: 50%؟

    • يحوّله إلى دائرة
    • يجعل الإطار شفافاً بنسبة 50 بالمئة
    • يصغّر المربع إلى نصف حجمه
    • يقص الزوايا الأربع بمقدار 50px فقط من الأعلى
    الإجابة والشرح

    الإجابة الصحيحة: يحوّله إلى دائرة

    النسبة تُحسب من أبعاد الصندوق، و50 بالمئة تجعل الانحناء نصف الضلع فتتحول الزوايا إلى قوس كامل. ويبقى الحجم كما هو.
