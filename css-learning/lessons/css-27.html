Specificity

افهم كيف يحدد CSS أي قاعدة لها الأولوية عند تعارض القواعد.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

مثال برمجي

أول كود CSS لك

p {
color: blue;
}
.article p {
color: #0f807a;
}
جرّب بنفسك

اكتب CSS وشاهد النتيجة

غيّر الكود الموجود بالأسفل ثم شغّله لترى النتيجة.

اختبر نفسك

  1. ماذا تحدد Specificity؟

    • أي قاعدة CSS لها الأولوية
    • عرض العنصر
    • ارتفاع الصفحة
    • نوع الخط
    الإجابة والشرح

    الإجابة الصحيحة: أي قاعدة CSS لها الأولوية

  2. أي Selector يمتلك عادة Specificity أعلى؟

    • ID Selector
    • Element Selector
    • Universal Selector
    • النص العادي
    الإجابة والشرح

    الإجابة الصحيحة: ID Selector

  3. أي Selector أكثر تحديدًا؟

    • .article p
    • p
    • *
    • body
    الإجابة والشرح

    الإجابة الصحيحة: .article p

  4. القاعدتان: #a { color: red; } و .a.a.a { color: blue; } على عنصر id a وclass a. ما اللون؟

    • أحمر
    • أزرق
    • بنفسجي
    • الافتراضي
    الإجابة والشرح

    الإجابة الصحيحة: أحمر

    محدد id أقوى من أي عدد من محددات الصنف، فالأعمدة لا تُرحّل: 1,0,0 أكبر من 0,3,0. لذلك يفوز الأحمر.

  5. العنصر p له style='color: blue' والستايل شيت يحوي p { color: red !important; }. ما اللون؟

    • أزرق لأن inline أقوى
    • أحمر لأن !important تتغلب على الـ inline العادي
    • أسود
    • يتغير بشكل عشوائي
    الإجابة والشرح

    الإجابة الصحيحة: أحمر لأن !important تتغلب على الـ inline العادي

    تصريح !important في ورقة الأنماط يتفوق على تصريح inline غير مهم. ولهذا يجب تجنبه لأنه يصعّب التعديل لاحقاً.
