العرض والارتفاع

تعلم كيفية التحكم في عرض وارتفاع العناصر.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

مثال برمجي

أول كود CSS لك

.box {
width: 300px;
height: 150px;
background: #0b5d91;
}
جرّب بنفسك

اكتب CSS وشاهد النتيجة

غيّر الكود الموجود بالأسفل ثم شغّله لترى النتيجة.

اختبر نفسك

  1. أي خاصية تتحكم في عرض العنصر؟

    • width
    • size
    • element-width
    • horizontal-size
    الإجابة والشرح

    الإجابة الصحيحة: width

  2. أي خاصية تتحكم في ارتفاع العنصر؟

    • height
    • size-height
    • element-height-value
    • vertical
    الإجابة والشرح

    الإجابة الصحيحة: height

  3. ما الوحدة المستخدمة في 300px؟

    • px
    • em
    • percent
    • rem-only
    الإجابة والشرح

    الإجابة الصحيحة: px

  4. div داخل عنصر أب عرضه 400px، وقاعدة الابن width: 50%. كم عرض الابن؟

    • 50px
    • 200px
    • 400px
    • 800px
    الإجابة والشرح

    الإجابة الصحيحة: 200px

    النسبة المئوية للعرض تُحسب من عرض الأب، و50 بالمئة من 400 تساوي 200px. وليست من حجم الشاشة.

  5. صندوق قاعدته width: 100%; max-width: 600px. ما عرضه على شاشة عرضها 400px؟

    • 600px
    • 400px
    • 200px
    • 1000px
    الإجابة والشرح

    الإجابة الصحيحة: 400px

    100 بالمئة من 400 هي 400px وهي أقل من الحد 600px فلا يتدخل max-width. الحد يعمل فقط عندما يتجاوز العرض 600px.
