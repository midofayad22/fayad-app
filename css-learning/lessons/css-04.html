الألوان

تعلم كيفية استخدام أسماء الألوان وHEX وRGB وغيرها من طرق تحديد الألوان.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

مثال برمجي

أول كود CSS لك

h1 {
color: #0b5d91;
}
p {
color: rgb(15, 128, 122);
}

اختبر نفسك

  1. أي خاصية تغير لون النص؟

    • color
    • background
    • font
    • text
    الإجابة والشرح

    الإجابة الصحيحة: color

  2. ما نوع قيمة اللون #0b5d91؟

    • HEX
    • RGB
    • HSL
    • Keyword
    الإجابة والشرح

    الإجابة الصحيحة: HEX

  3. أي دالة تستخدم لكتابة لون بصيغة RGB؟

    • rgb()
    • color()
    • hex()
    • paint()
    الإجابة والشرح

    الإجابة الصحيحة: rgb()

  4. ما معنى color: rgba(255, 0, 0, 0.5)؟

    • أحمر شبه شفاف بنسبة 50 بالمئة
    • أحمر داكن بنسبة 50 بالمئة
    • لون رمادي بين الأحمر والأسود
    • أحمر كامل لأن القيمة الأخيرة تُهمل
    الإجابة والشرح

    الإجابة الصحيحة: أحمر شبه شفاف بنسبة 50 بالمئة

    القيم الثلاث الأولى هي الأحمر والأخضر والأزرق، والرابعة هي alpha أي الشفافية، و0.5 تعني نصف شفاف. القيمة الأخيرة لا تغير درجة اللون بل شفافيته.

  5. أي لون يمثله الرمز #0f0؟

    • أحمر
    • أزرق
    • أسود
    • أخضر
    الإجابة والشرح

    الإجابة الصحيحة: أخضر

    الصيغة المختصرة تكرر كل خانة، فـ #0f0 تساوي #00ff00، أي الأحمر 0 والأخضر كامل والأزرق 0، والناتج أخضر.
