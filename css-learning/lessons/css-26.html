متغيرات CSS

تعلم كيف تجعل المتغيرات المخصصة CSS أسهل في التنظيم والصيانة.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

مثال برمجي

أول كود CSS لك

:root {
--primary: #0f807a;
}
button {
background: var(--primary);
}

غيّر الكود الموجود بالأسفل ثم شغّله لترى النتيجة.

اختبر نفسك

  1. أي صيغة تستخدم لإنشاء CSS Variable؟

    • --variable-name
    • $variable
    • @variable
    • #variable
    الإجابة والشرح

    الإجابة الصحيحة: --variable-name

  2. أي دالة تستخدم لقراءة قيمة CSS Variable؟

    • var()
    • get()
    • css-var()
    • value()
    الإجابة والشرح

    الإجابة الصحيحة: var()

  3. أين يتم تعريف CSS Variables العامة غالبًا؟

    • :root
    • :global-css
    • body-root-only
    • #variables
    الإجابة والشرح

    الإجابة الصحيحة: :root

  4. عُرّف .card { --gap: 10px; } ثم استُخدم var(--gap) في body. ماذا يحدث؟

    • تعمل لأن المتغيرات عامة دائماً
    • لا تعمل لأن المتغير متاح فقط داخل .card وأبنائه
    • تعمل لكن بقيمة صفر
    • يحدث خطأ في الصفحة كلها
    الإجابة والشرح

    الإجابة الصحيحة: لا تعمل لأن المتغير متاح فقط داخل .card وأبنائه

    المتغيرات تُورَّث لأبناء العنصر الذي عُرّفت فيه فقط. لذلك نعرّف العامة في :root.

  5. ماذا تعني var(--color, blue)؟

    • يعرّف المتغير color بقيمة blue
    • يستخدم blue دائماً
    • يستخدم --color، وإذا لم يكن معرفاً يستخدم blue
    • يدمج اللونين
    الإجابة والشرح

    الإجابة الصحيحة: يستخدم --color، وإذا لم يكن معرفاً يستخدم blue

    الوسيط الثاني قيمة احتياطية تُستخدم فقط عندما لا يوجد المتغير الأول.
