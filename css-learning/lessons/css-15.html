محاذاة النص

تعلم كيفية محاذاة النص أفقيًا.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

مثال برمجي

أول كود CSS لك

.title {
text-align: center;
}
جرّب بنفسك

اكتب CSS وشاهد النتيجة

غيّر الكود الموجود بالأسفل ثم شغّله لترى النتيجة.

اختبر نفسك

  1. أي قيمة تجعل النص في المنتصف؟

    • center
    • middle
    • horizontal
    • central
    الإجابة والشرح

    الإجابة الصحيحة: center

  2. أي خاصية تتحكم في محاذاة النص أفقيًا؟

    • text-align
    • text-position
    • align-text-property
    • horizontal-text
    الإجابة والشرح

    الإجابة الصحيحة: text-align

  3. أي قيمة تجعل النص بمحاذاة اليمين؟

    • right
    • end-text-only
    • east
    • right-align-property
    الإجابة والشرح

    الإجابة الصحيحة: right

  4. div عرضه 300px وعليه text-align: center. ماذا يتوسط؟

    • الـ div نفسه داخل أبيه
    • النص والمحتوى المضمن داخل الـ div
    • كل الأبناء من نوع block
    • لا شيء لأن العنصر block
    الإجابة والشرح

    الإجابة الصحيحة: النص والمحتوى المضمن داخل الـ div

    text-align يحاذي المحتوى المضمن داخل الصندوق، ولا يحرك الصندوق نفسه. لتوسيط الصندوق نستخدم margin: 0 auto.

  5. ماذا يفعل text-align: justify على فقرة طويلة؟

    • يوسّط كل الأسطر
    • يحاذي الأسطر إلى اليمين فقط
    • يوزع المسافات لتتساوى حافتا الأسطر، عدا السطر الأخير
    • يكبّر الخط ليملأ العرض
    الإجابة والشرح

    الإجابة الصحيحة: يوزع المسافات لتتساوى حافتا الأسطر، عدا السطر الأخير

    justify يضبط المسافات بين الكلمات لتبدأ الأسطر وتنتهي عند الحافتين، ويُترك السطر الأخير محاذياً للبداية افتراضياً.
