أفضل ممارسات CSS

تعلم كيفية تنظيم CSS وكتابته بطريقة أنظف وأسهل في الصيانة.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

مثال برمجي

أول كود CSS لك

:root {
--primary: #0f807a;
}
.button {
background: var(--primary);
border-radius: 10px;
}

    • تبطئ الخادم

    الإفراط في !important يسلب القدرة على التغلب لاحقاً إلا بـ !important أخرى. الأفضل تنظيم المحددات وقوتها.
