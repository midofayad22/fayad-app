الخلفيات

تعلم كيفية التحكم في ألوان وصور خلفيات العناصر.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

مثال برمجي

أول كود CSS لك

body {
background-color: #eaf3f8;
}
.card {
background: white;
}
جرّب بنفسك

اكتب CSS وشاهد النتيجة

غيّر الكود الموجود بالأسفل ثم شغّله لترى النتيجة.

اختبر نفسك

  1. أي خاصية تغير لون خلفية العنصر؟

    • background-color
    • color
    • border-color
    • background-text
    الإجابة والشرح

    الإجابة الصحيحة: background-color

  2. أي خاصية مختصرة يمكنها التحكم في إعدادات الخلفية؟

    • background
    • back
    • bg-style
    • background-style-only
    الإجابة والشرح

    الإجابة الصحيحة: background

  3. أي خاصية تستخدم لإضافة صورة للخلفية؟

    • background-image
    • image-background
    • background-picture
    • image
    الإجابة والشرح

    الإجابة الصحيحة: background-image

  4. صورة صغيرة وُضعت بـ background-image على صندوق كبير بدون أي خصائص خلفية أخرى. ماذا يحدث؟

    • تتمدد الصورة لتملأ الصندوق
    • تتكرر الصورة كالبلاط في الاتجاهين
    • تظهر مرة واحدة في المنتصف
    • لا تظهر الصورة حتى نحدد الحجم
    الإجابة والشرح

    الإجابة الصحيحة: تتكرر الصورة كالبلاط في الاتجاهين

    القيمة الافتراضية لـ background-repeat هي repeat فتتكرر الصورة أفقياً وعمودياً، وتبدأ من الزاوية العلوية اليسرى. نستخدم no-repeat لمنع التكرار.

  5. ماذا يفعل background-size: cover؟

    • يكبّر الصورة لتغطي الصندوق كله مع قص الزائد
    • يعرض الصورة كاملة دائماً دون أي قص مع ترك فراغ
    • يكرر الصورة حتى يمتلئ الصندوق
    • يخفي الصورة خلف المحتوى
    الإجابة والشرح

    الإجابة الصحيحة: يكبّر الصورة لتغطي الصندوق كله مع قص الزائد

    cover يحافظ على نسبة الصورة ويكبرها حتى لا يبقى فراغ، وقد يقص جزءاً منها. الخيار الذي يعرض الصورة كاملة مع فراغ هو contain.
