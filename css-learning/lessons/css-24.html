Transforms

تعلم كيف تستخدم transform لتحريك العناصر وتكبيرها وتدويرها وميلها.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

مثال برمجي

أول كود CSS لك

.card:hover {
transform: translateY(-5px) scale(1.02);
}

  3. أي دالة تغير حجم العنصر؟

    الإجابة والشرح

    الإجابة الصحيحة: scale()

  4. ماذا يحدث لباقي العناصر عند transform: translateY(-5px) على بطاقة؟

    • تتحرك للأعلى معها
    • لا تتأثر لأن transform لا يغير التخطيط
    • تُدفع للأسفل 5px
    • تختفي
    الإجابة والشرح

    الإجابة الصحيحة: لا تتأثر لأن transform لا يغير التخطيط

    التحويل يغير الرسم فقط ولا يغير المساحة المحجوزة في التخطيط، لذلك لا تتحرك الجوار. وهذا يجعله مناسباً لتأثيرات hover.

  5. كيف تدوّر عنصراً حول زاويته العلوية اليسرى بدل مركزه؟

    • transform-origin: top left
    • rotate: left
    • transform: top left
    • margin: 0
    الإجابة والشرح

    الإجابة الصحيحة: transform-origin: top left

    نقطة الأصل الافتراضية هي المركز، وtransform-origin يغيّرها لتصبح محور الدوران أو التحجيم.
