Display

تعلم كيف تتحكم خاصية display في طريقة ظهور وترتيب العناصر.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

مثال برمجي

أول كود CSS لك

.box {
display: inline-block;
}
جرّب بنفسك

اكتب CSS وشاهد النتيجة

غيّر الكود الموجود بالأسفل ثم شغّله لترى النتيجة.

اختبر نفسك

  1. أي خاصية تتحكم في طريقة عرض العنصر؟

    • display
    • layout
    • element-type
    • show
    الإجابة والشرح

    الإجابة الصحيحة: display

  2. أي قيمة تجعل العنصر يتصرف كـ inline مع إمكانية تحديد العرض والارتفاع؟

    • inline-block
    • inline-only
    • block-inline
    • flex-inline
    الإجابة والشرح

    الإجابة الصحيحة: inline-block

  3. أي قيمة تجعل العنصر Block-level؟

    • block
    • section
    • box
    • full-block
    الإجابة والشرح

    الإجابة الصحيحة: block

  4. span مكتوب له width: 200px; height: 100px بدون تغيير display. ماذا يحدث؟

    • يُتجاهل العرض والارتفاع لأنه inline
    • يأخذ المقاسين كاملين
    • يصبح block تلقائياً
    • يختفي العنصر
    الإجابة والشرح

    الإجابة الصحيحة: يُتجاهل العرض والارتفاع لأنه inline

    العناصر inline لا تقبل width و height. نغير إلى inline-block أو block لتطبيقهما.

  5. ما الفرق بين display: none و visibility: hidden؟

    • none يخفي مع إبقاء مكانه، وhidden يزيل المكان
    • لا فرق بينهما
    • none يزيل العنصر من التخطيط، وhidden يخفيه ويبقي مساحته
    • hidden يحذف العنصر من HTML
    الإجابة والشرح

    الإجابة الصحيحة: none يزيل العنصر من التخطيط، وhidden يخفيه ويبقي مساحته

    display: none يجعل العنصر لا يشغل أي مساحة، أما visibility: hidden فيخفيه بصرياً مع بقاء مساحته. والعنصر يبقى في HTML في الحالتين.
