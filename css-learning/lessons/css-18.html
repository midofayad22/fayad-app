Flexbox

تعلم كيف يساعدك Flexbox على إنشاء تخطيطات مرنة أحادية الاتجاه.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

مثال برمجي

أول كود CSS لك

.container {
display: flex;
justify-content: center;
align-items: center;
}
جرّب بنفسك

اكتب CSS وشاهد النتيجة

غيّر الكود الموجود بالأسفل ثم شغّله لترى النتيجة.

اختبر نفسك

  1. أي خاصية تقوم بتفعيل Flexbox؟

    • display: flex
    • flex: true
    • layout: flex
    • enable-flex
    الإجابة والشرح

    الإجابة الصحيحة: display: flex

  2. أي خاصية تتحكم في المحاذاة على الـ Main Axis؟

    • justify-content
    • align-main
    • flex-position
    • main-align
    الإجابة والشرح

    الإجابة الصحيحة: justify-content

  3. أي خاصية تتحكم في المحاذاة على الـ Cross Axis؟

    • align-items
    • cross-content
    • flex-cross
    • align-main
    الإجابة والشرح

    الإجابة الصحيحة: align-items

  4. حاوية فيها display: flex; flex-direction: column; height: 400px; justify-content: center. كيف تتوزع العناصر؟

    • متوسطة أفقياً فقط
    • متوسطة عمودياً داخل الحاوية
    • متجاورة في صف أفقي
    • ملتصقة بالأعلى
    الإجابة والشرح

    الإجابة الصحيحة: متوسطة عمودياً داخل الحاوية

    justify-content يعمل على المحور الرئيسي، وعند flex-direction: column يصبح المحور الرئيسي عمودياً، فيتوسط المحتوى عمودياً.

  5. حاوية flex عرضها 500px فيها ثلاثة عناصر عرض كل منها 200px بدون flex-wrap. ماذا يحدث؟

    • تنزل العناصر إلى سطر ثانٍ
    • يفيض العنصر الثالث خارج الحاوية بثبات
    • تتقلص العناصر لتناسب السطر الواحد
    • يُخفى العنصر الأخير
    الإجابة والشرح

    الإجابة الصحيحة: تتقلص العناصر لتناسب السطر الواحد

    الافتراضي flex-wrap: nowrap وflex-shrink: 1، فتتقلص العناصر معاً (حوالي 167px لكل منها) لتبقى في سطر واحد. لكي تنزل نحتاج flex-wrap: wrap.
