Transitions

تعلم كيف تجعل Transitions التغييرات بين الحالات أكثر سلاسة.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

مثال برمجي

أول كود CSS لك

button {
transition: 0.3s ease;
}
button:hover {
transform: translateY(-3px);
}

اختبر نفسك

  1. ماذا تفعل transition؟

    • تنشئ تغييرات وانتقالات سلسة
    • تنشئ HTML
    • تحذف عنصرًا
    • تنشئ جداول قواعد البيانات
    الإجابة والشرح

    الإجابة الصحيحة: تنشئ تغييرات وانتقالات سلسة

  2. ماذا تمثل 0.3s في transition؟

    • مدة الانتقال
    • اللون
    • العرض
    • التأخير فقط
    الإجابة والشرح

    الإجابة الصحيحة: مدة الانتقال

  3. أي خاصية تستخدم كثيرًا مع transition لإنشاء تأثيرات Hover؟

    • transform
    • database
    • position-text
    • html-change
    الإجابة والشرح

    الإجابة الصحيحة: transform

  4. الزر: .btn { background: blue; } .btn:hover { background: red; transition: 0.5s; }. ماذا يحدث؟

    • يتغير بسلاسة عند المرور ويرجع فوراً عند الخروج
    • يتغير بسلاسة في الاتجاهين
    • يتغير فوراً في الاتجاهين
    • لا يتغير أبداً
    الإجابة والشرح

    الإجابة الصحيحة: يتغير بسلاسة عند المرور ويرجع فوراً عند الخروج

    الانتقال المكتوب في حالة hover يُطبق عند الدخول فقط، وعند الخروج تعود الحالة الأساسية بلا transition. نكتبه في القاعدة الأساسية ليعمل في الاتجاهين.

  5. أي تغيير لن يتحرك بسلاسة عبر transition؟

    • opacity من 0 إلى 1
    • width من 100px إلى 200px
    • background-color من أزرق إلى أحمر
    • display من none إلى block
    الإجابة والشرح

    الإجابة الصحيحة: display من none إلى block

    display قيمة منفصلة لا تقبل القيم الوسيطة فتقفز فوراً. لذلك نستخدم opacity وغيرها للتلاشي والحركة السلسة.
