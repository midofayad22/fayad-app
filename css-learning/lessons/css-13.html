الخطوط Fonts

تعلم كيفية التحكم في نوع الخط وحجمه ووزنه وشكله.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

مثال برمجي

أول كود CSS لك

h1 {
font-family: Arial, sans-serif;
font-size: 42px;
font-weight: 700;
}
جرّب بنفسك

اكتب CSS وشاهد النتيجة

غيّر الكود الموجود بالأسفل ثم شغّله لترى النتيجة.

اختبر نفسك

  1. أي خاصية تتحكم في نوع الخط؟

    • font-family
    • font-type
    • font-name
    • typeface
    الإجابة والشرح

    الإجابة الصحيحة: font-family

  2. أي خاصية تتحكم في حجم الخط؟

    • font-size
    • text-size
    • font-scale
    • size-font
    الإجابة والشرح

    الإجابة الصحيحة: font-size

  3. ماذا تتحكم font-weight؟

    • سمك الخط
    • لون الخط
    • نوع الخط
    • المسافة بين الأسطر
    الإجابة والشرح

    الإجابة الصحيحة: سمك الخط

  4. ماذا تعني font-family: 'Poppins', sans-serif؟

    • يستخدم الخطين معاً فوق بعضهما
    • يجرب Poppins وإن لم يتوفر يستخدم خط sans-serif عام
    • يحمّل Poppins من الإنترنت تلقائياً
    • يستخدم sans-serif أولاً ثم Poppins
    الإجابة والشرح

    الإجابة الصحيحة: يجرب Poppins وإن لم يتوفر يستخدم خط sans-serif عام

    القائمة تُقرأ بالترتيب، فيُستخدم أول خط متاح. الخط العام في النهاية شبكة أمان. ولا يحمّل التصريح الخط بنفسه بل يحتاج @font-face أو رابط خط.

  5. الجذر html بحجم خط 16px والعنصر له font-size: 1.5rem. ما حجم خطه؟

    • 1.5px
    • 16px
    • 24px
    • 32px
    الإجابة والشرح

    الإجابة الصحيحة: 24px

    الوحدة rem نسبة إلى حجم خط العنصر الجذر، و1.5 × 16 = 24px.
