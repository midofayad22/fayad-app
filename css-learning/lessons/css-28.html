Media Queries

تعلم كيف تطبق Media Queries تنسيقات مختلفة بناءً على ظروف الشاشة.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

مثال برمجي

أول كود CSS لك

@media (max-width: 768px) {
body {
font-size: 14px;
}
}
جرّب بنفسك

اكتب CSS وشاهد النتيجة

غيّر الكود الموجود بالأسفل ثم شغّله لترى النتيجة.

اختبر نفسك

  1. فيما تستخدم Media Queries غالبًا؟

    • التصميم المتجاوب
    • الاتصال بقواعد البيانات
    • بنية HTML
    • تشغيل JavaScript
    الإجابة والشرح

    الإجابة الصحيحة: التصميم المتجاوب

  2. أي كلمة تبدأ بها Media Query؟

    • @media
    • @screen
    • @responsive
    • @device
    الإجابة والشرح

    الإجابة الصحيحة: @media

  3. ماذا يحدد max-width؟

    • شرطًا لأقصى عرض للـ viewport
    • أقصى حجم للخط
    • أقصى ارتفاع لكل العناصر
    • أقصى طول للصفحة
    الإجابة والشرح

    الإجابة الصحيحة: شرطًا لأقصى عرض للـ viewport

  4. لدينا p { color: blue; } وداخل @media (min-width: 768px) { p { color: red; } }. ما لون p على شاشة 500px؟

    • أزرق
    • أحمر
    • أخضر
    • أسود
    الإجابة والشرح

    الإجابة الصحيحة: أزرق

    الشرط min-width: 768px لا يتحقق على 500px فتبقى القاعدة الأساسية. هذا أسلوب mobile-first.

  5. كُتب @media (max-width: 600px) { .a { color: red; } } ثم بعده .a { color: blue; } خارجه. لماذا لا يظهر الأحمر على الجوال؟

    • لأن max-width لا يعمل على الجوال
    • لأن القاعدة المتأخرة بنفس القوة تتغلب على القاعدة داخل الاستعلام
    • لأن الاستعلام يحتاج screen
    • لأن red غير مدعوم
    الإجابة والشرح

    الإجابة الصحيحة: لأن القاعدة المتأخرة بنفس القوة تتغلب على القاعدة داخل الاستعلام

    الاستعلام لا يرفع قوة القاعدة، فيفوز الأخير كتابة. لذا نضع قواعد الاستعلام بعد القواعد الأساسية.
