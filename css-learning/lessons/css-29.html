المحددات المتقدمة

تعلم المحددات المتقدمة مثل Child وSibling وAttribute وDescendant Selectors.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

مثال برمجي

أول كود CSS لك

nav > a {
color: #0b5d91;
}
input[type="text"] {
border-color: #0f807a;
}

اكتب CSS وشاهد النتيجة

غيّر الكود الموجود بالأسفل ثم شغّله لترى النتيجة.

اختبر نفسك

  1. أي Selector يستهدف العناصر الأبناء المباشرة؟

    • >
    • +
    • ~
    • *
    الإجابة والشرح

    الإجابة الصحيحة: >

  2. أي Selector يستهدف عنصرًا بناءً على Attribute؟

    • [attribute]
    • .attribute
    • #attribute
    • :attribute
    الإجابة والشرح

    الإجابة الصحيحة: [attribute]

  3. ماذا يحدد الـ + Combinator؟

    • العنصر الشقيق المباشر التالي
    • كل العناصر الأبناء
    • العنصر الأب
    • كل العناصر
    الإجابة والشرح

    الإجابة الصحيحة: العنصر الشقيق المباشر التالي

  4. h2 ~ p بعد h2 يتبعه ثلاث فقرات. كم فقرة تستهدف؟

    • الأولى فقط
    • الثلاث كلها
    • الأخيرة فقط
    • لا شيء
    الإجابة والشرح

    الإجابة الصحيحة: الثلاث كلها

    المقرن ~ يستهدف كل الأشقاء التالين، بينما + يستهدف الشقيق المباشر فقط.

  5. أي عناصر يستهدفها a[href^='https']؟

    • الروابط التي تنتهي قيمتها بـ https
    • الروابط التي تحتوي https في أي موضع
    • الروابط التي تبدأ قيمة href فيها بـ https
    • الروابط بدون href
    الإجابة والشرح

    الإجابة الصحيحة: الروابط التي تبدأ قيمة href فيها بـ https

    العلامة ^= تعني يبدأ بـ، و$= تعني ينتهي بـ، و*= تعني يحتوي.
