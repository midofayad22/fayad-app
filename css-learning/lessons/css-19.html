CSS Grid

تعلم كيف ينشئ CSS Grid تخطيطات قوية ثنائية الاتجاه.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

مثال برمجي

أول كود CSS لك

.container {
display: grid;
grid-template-columns: repeat(3, 1fr);
gap: 20px;
}
جرّب بنفسك

اكتب CSS وشاهد النتيجة

غيّر الكود الموجود بالأسفل ثم شغّله لترى النتيجة.

اختبر نفسك

  1. أي خاصية تقوم بتفعيل CSS Grid؟

    • display: grid
    • grid: true
    • layout: grid
    • enable-grid
    الإجابة والشرح

    الإجابة الصحيحة: display: grid

  2. أي خاصية تحدد أعمدة الـ Grid؟

    • grid-template-columns
    • grid-columns-only
    • columns-grid
    • grid-layout-columns
    الإجابة والشرح

    الإجابة الصحيحة: grid-template-columns

  3. ماذا تتحكم gap في الـ Grid؟

    • المسافة بين عناصر الـ Grid
    • لون الـ Grid
    • عرض الأعمدة فقط
    • ارتفاع العنصر
    الإجابة والشرح

    الإجابة الصحيحة: المسافة بين عناصر الـ Grid

  4. حاوية فيها display: grid; grid-template-columns: repeat(3, 1fr) وبداخلها 6 عناصر. كيف تظهر؟

    • 3 أعمدة متساوية العرض في صفين
    • 6 أعمدة في صف واحد
    • عمود واحد من 6 صفوف
    • صفان من عمودين لكل منهما
    الإجابة والشرح

    الإجابة الصحيحة: 3 أعمدة متساوية العرض في صفين

    repeat(3, 1fr) يصنع ثلاثة أعمدة بحصص متساوية، وتتوزع العناصر الستة تلقائياً على صفين.

  5. ماذا يعني grid-template-columns: 200px 1fr؟

    • عمودان بعرض 200px لكل منهما
    • عمود ثابت 200px والثاني يأخذ المساحة المتبقية
    • العمود الأول 1fr والثاني 200px
    • عمود واحد بعرض 201px
    الإجابة والشرح

    الإجابة الصحيحة: عمود ثابت 200px والثاني يأخذ المساحة المتبقية

    الوحدة fr تقسم المساحة المتاحة بعد خصم الأعمدة الثابتة، فيأخذ العمود الثاني كل الباقي. هذا نمط شائع للشريط الجانبي.
