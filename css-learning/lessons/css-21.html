Pseudo-classes

تعلم كيف تستخدم Pseudo-classes لتنسيق العناصر في حالات معينة.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

مثال برمجي

أول كود CSS لك

button:hover {
background: #0f807a;
}
جرّب بنفسك

اكتب CSS وشاهد النتيجة

غيّر الكود الموجود بالأسفل ثم شغّله لترى النتيجة.

اختبر نفسك

  1. ماذا يمثل :hover؟

    • العنصر عندما يكون مؤشر الماوس فوقه
    • العنصر بعد الضغط عليه
    • العنصر عندما يكون مخفيًا
    • العنصر قبل تحميله
    الإجابة والشرح

    الإجابة الصحيحة: العنصر عندما يكون مؤشر الماوس فوقه

  2. أي مما يلي يعتبر Pseudo-class؟

    • :hover
    • ::after
    • .hover-element
    • #hover
    الإجابة والشرح

    الإجابة الصحيحة: :hover

  3. هل تصف Pseudo-classes عادة حالة العنصر أم جزءًا منه؟

    • حالة العنصر
    • هيكل HTML
    • حالة قاعدة البيانات
    • نوع الملف
    الإجابة والشرح

    الإجابة الصحيحة: حالة العنصر

  4. a:hover كُتبت قبل a:link بنفس القوة. لماذا لا يتغير اللون عند المرور؟

    • لأن hover لا يعمل على الروابط
    • لأن a:link المتأخرة تتغلب على hover السابقة
    • لأن اللون لا يمكن تغييره بـ hover
    • لأن المتصفح يحتاج JavaScript
    الإجابة والشرح

    الإجابة الصحيحة: لأن a:link المتأخرة تتغلب على hover السابقة

    عند تساوي القوة يفوز الأخير كتابة، فتلغي a:link المتأخرة أثر hover. لذلك الترتيب الموصى به link ثم visited ثم hover ثم active.

  5. أي عناصر تستهدفها li:nth-child(2n)؟

    • العناصر الفردية 1 و3 و5
    • العنصر الثاني فقط
    • العناصر الزوجية 2 و4 و6
    • كل العناصر
    الإجابة والشرح

    الإجابة الصحيحة: العناصر الزوجية 2 و4 و6

    الصيغة 2n تعطي مضاعفات 2 أي 2 و4 و6 وهي مرادفة لـ even. أما الفردية فهي 2n+1 أو odd.
