Pseudo-elements

تعلم كيف تستخدم Pseudo-elements لتنسيق أجزاء محددة من العناصر.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

مثال برمجي

أول كود CSS لك

h1::after {
content: "";
display: block;
height: 3px;
background: #0f807a;
}
جرّب بنفسك

اكتب CSS وشاهد النتيجة

غيّر الكود الموجود بالأسفل ثم شغّله لترى النتيجة.

اختبر نفسك

  1. أي صيغة تمثل Pseudo-element؟

    • ::after
    • :after-element
    • pseudo-after
    • .after
    الإجابة والشرح

    الإجابة الصحيحة: ::after

  2. أي خاصية تستخدم عادة مع ::before أو ::after لإنشاء المحتوى؟

    • content
    • generate
    • pseudo-content
    • create
    الإجابة والشرح

    الإجابة الصحيحة: content

  3. ماذا تستهدف Pseudo-elements؟

    • أجزاء محددة من العنصر
    • الصفحات بالكامل فقط
    • سجلات قواعد البيانات
    • دوال JavaScript
    الإجابة والشرح

    الإجابة الصحيحة: أجزاء محددة من العنصر

  4. لماذا لا يظهر شيء من p::after { color: red; }؟

    • لأن ::after لا يقبل الألوان
    • لأن الخاصية content غير مكتوبة فلا يُنشأ العنصر
    • لأن اللون red غير صالح
    • لأن ::after تحتاج نقطة واحدة فقط
    الإجابة والشرح

    الإجابة الصحيحة: لأن الخاصية content غير مكتوبة فلا يُنشأ العنصر

    الكيان ::before و::after لا يُولَّد إلا إذا وُجدت content ولو كانت نصاً فارغاً content: ''. لذلك لا يظهر شيء ولو أضفنا ألواناً.

  5. ماذا يطبّق p::first-letter { font-size: 2em; }؟

    • أول كلمة في كل فقرة
    • أول حرف فقط في كل فقرة
    • أول فقرة في الصفحة
    • كل الحروف الكبيرة
    الإجابة والشرح

    الإجابة الصحيحة: أول حرف فقط في كل فقرة

    ::first-letter جزء من نص العنصر هو حرفه الأول، وتُستخدم عادة لعمل حرف استهلالي كبير. ليس عنصراً مستقلاً في HTML.
