نموذج الصندوق Box Model

افهم أجزاء نموذج الصندوق: المحتوى والـ Padding والـ Border والـ Margin.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

مثال برمجي

أول كود CSS لك

.box {
width: 200px;
padding: 20px;
border: 5px solid #0f807a;
margin: 20px;
}
جرّب بنفسك

اكتب CSS وشاهد النتيجة

غيّر الكود الموجود بالأسفل ثم شغّله لترى النتيجة.

اختبر نفسك

  1. ما الأجزاء الأربعة التي يتكون منها CSS Box Model؟

    • المحتوى، Padding، Border، Margin
    • النص، الصورة، الزر، الرابط
    • Header، Main، Footer، Nav
    • العرض، الارتفاع، اللون، الخط
    الإجابة والشرح

    الإجابة الصحيحة: المحتوى، Padding، Border، Margin

  2. أي جزء يكون الأقرب إلى المحتوى نفسه؟

    • Content — المحتوى
    • Margin
    • Border
    • المساحة الخارجية
    الإجابة والشرح

    الإجابة الصحيحة: Content — المحتوى

  3. أي جزء ينشئ مساحة خارج الـ Border؟

    • Margin
    • Padding
    • Content
    • Width
    الإجابة والشرح

    الإجابة الصحيحة: Margin

  4. صندوق content-box: width: 100px; padding: 10px; border: 5px solid; margin: 20px. كم عرضه المرئي بدون الهامش؟

    • 100px
    • 120px
    • 130px
    • 170px
    الإجابة والشرح

    الإجابة الصحيحة: 130px

    المرئي = المحتوى + الحشو + الإطار من الجانبين: 100 + 20 + 10 = 130px. الهامش خارج الصندوق المرئي، وإضافته تعطي 170px.

  5. عنصر له background-color وpadding وborder وmargin. أي جزء لا يُلوَّن بلون الخلفية افتراضياً؟

    • الحشو
    • المحتوى
    • الهامش
    • المنطقة تحت الإطار
    الإجابة والشرح

    الإجابة الصحيحة: الهامش

    الخلفية تمتد تحت المحتوى والحشو والإطار، أما الهامش فهو مسافة خارجية شفافة لا تُلوَّن.
