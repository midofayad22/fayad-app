Position

تعلم كيفية عمل relative وabsolute وfixed وsticky.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

مثال برمجي

أول كود CSS لك

.box {
position: relative;
top: 20px;
}

    الإجابة والشرح

  3. أي قيمة تستخدم غالبًا كنقطة مرجعية لعناصر absolute الداخلية؟

    • relative
    • static
    • fixed

    الإجابة والشرح

    الإجابة الصحيحة: relative

  4. شارة badge بقاعدة position: absolute; top: 0; right: 0 تظهر في زاوية الصفحة بدل زاوية البطاقة. ما الحل؟

    • إضافة position: relative إلى البطاقة
    • تغيير الشارة إلى position: fixed
    • زيادة قيمة top
    • إضافة margin إلى الشارة
    الإجابة والشرح

    الإجابة الصحيحة: إضافة position: relative إلى البطاقة

    الموضع المطلق يُحسب نسبة إلى أقرب سلف له position غير static، وإن لم يوجد فنسبة إلى الصفحة. جعل البطاقة relative يجعلها المرجع. fixed سيثبتها على الشاشة.

  5. ماذا يفعل position: sticky; top: 0 على عنوان؟

    • يبقى مكانه في التدفق ثم يلتصق بأعلى الإطار عند وصول التمرير إليه
    • يثبت دائماً بأعلى الشاشة من أول لحظة
    • يُزال من التدفق ويتحرك مع الماوس
    • يختفي عند التمرير
    الإجابة والشرح

    الإجابة الصحيحة: يبقى مكانه في التدفق ثم يلتصق بأعلى الإطار عند وصول التمرير إليه

    sticky هجين: يتصرف كـ relative حتى يصل إلى حد top المحدد أثناء التمرير فيتصرف كـ fixed، وذلك داخل حدود أبيه.
