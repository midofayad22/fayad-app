حساب حجم الصندوق Box Sizing

تعلم كيف تغير خاصية box-sizing طريقة حساب العرض والارتفاع.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

مثال برمجي

أول كود CSS لك

* {
box-sizing: border-box;
}
.box {
width: 300px;
padding: 30px;
}
جرّب بنفسك

اكتب CSS وشاهد النتيجة

غيّر الكود الموجود بالأسفل ثم شغّله لترى النتيجة.

اختبر نفسك

  1. ماذا يتضمن border-box؟

    • الـ Padding والـ Border داخل الحجم المحدد
    • المحتوى فقط
    • الـ Margin فقط
    • الـ Padding فقط
    الإجابة والشرح

    الإجابة الصحيحة: الـ Padding والـ Border داخل الحجم المحدد

  2. أي خاصية تتحكم في طريقة حساب حجم الصندوق؟

    • box-sizing
    • box-size
    • size-model
    • element-sizing
    الإجابة والشرح

    الإجابة الصحيحة: box-sizing

  3. أي قيمة تستخدم غالبًا لتسهيل التحكم في أحجام العناصر؟

    • border-box
    • content-only
    • margin-box
    • size-box
    الإجابة والشرح

    الإجابة الصحيحة: border-box

  4. box-sizing: border-box; width: 300px; padding: 20px; border: 5px solid. كم عرض منطقة المحتوى؟

    • 250px
    • 300px
    • 340px
    • 260px
    الإجابة والشرح

    الإجابة الصحيحة: 250px

    في border-box يشمل العرض المحتوى والحشو والإطار، فالمحتوى = 300 - 40 - 10 = 250px، والصندوق كله يبقى 300px.

  5. عمودان كل منهما width: 50% وpadding: 20px بحجم content-box داخل حاوية. ماذا يحدث؟

    • يتسعان تماماً بجانب بعضهما
    • يتجاوز مجموعهما 100 بالمئة فينزل أحدهما أو يفيض
    • يتقلص الحشو تلقائياً
    • يتجاهل المتصفح الحشو
    الإجابة والشرح

    الإجابة الصحيحة: يتجاوز مجموعهما 100 بالمئة فينزل أحدهما أو يفيض

    الحشو يُضاف فوق 50 بالمئة في content-box فيصبح مجموع العرضين أكبر من الحاوية. الحل box-sizing: border-box.
