مقدمة إلى CSS

تعرف على ماهية CSS ولماذا نستخدمه وكيف يتحكم في مظهر عناصر HTML.

ما هو CSS؟

CSS اختصار لـ Cascading Style Sheets أي أوراق الأنماط المتتالية.

يُستخدم CSS للتحكم في المظهر المرئي لعناصر HTML.

باستخدام CSS يمكنك تغيير الألوان والأحجام والمسافات والتخطيطات والخطوط والحركات وغير ذلك الكثير.

الفكرة الأساسية

HTML ينشئ الهيكل، وCSS ينشئ التصميم.

تخيل أنك تبني منزلًا. HTML يمثل هيكل المنزل، بينما CSS يتحكم في الألوان والحجم والمسافات والمظهر العام.

مثال على الكود

أول كود CSS لك

h1 {
  color: #0f807a;
  font-size: 40px;
}

p {
  color: #536777;
}
