LESSON 01

Introduction to CSS

Learn what CSS is, why we use it, and how it controls the appearance of HTML elements.

What is CSS?

CSS stands for Cascading Style Sheets.

CSS is used to control the visual appearance of HTML elements.

With CSS, you can change colors, sizes, spacing, layouts, fonts, animations, and much more.

KEY IDEA

HTML creates the structure. CSS creates the design.

Think about a house. HTML is the structure of the house, while CSS controls the colors, size, spacing, and overall appearance.

CODE EXAMPLE

Your first CSS code

  color: #0f807a;
  font-size: 40px;

Understanding CSS Syntax

A CSS rule contains a selector and a group of declarations.

The selector chooses the HTML element you want to style.

Each declaration contains a property and a value.
