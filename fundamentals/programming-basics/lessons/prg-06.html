Syntax

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

SYNTAX

قواعد اللغة التي تكتب بها الكود

ما معنى Syntax؟

Syntax هي مجموعة القواعد التي تحدد الشكل الصحيح لكتابة الأوامر في لغة البرمجة.

كما أن اللغة الطبيعية لها قواعد، فإن JavaScript وغيرها من اللغات لها قواعد يجب اتباعها.

خطأ Syntax

إذا كتبت الكود بطريقة تخالف قواعد اللغة، فقد تحصل على Syntax Error.

الفكرة الأساسية

Syntax تحدد كيف يجب أن تكتب الكود، بينما Logic تحدد هل الكود يحل المشكلة بالطريقة الصحيحة أم لا.

مثال عملي

شاهد الفكرة في كود

JavaScript 
const name = "FAYBIT";
console.log(name);

اختبر نفسك

  1. ما المقصود بـ Syntax؟

    • قواعد كتابة الكود
    • سرعة الكمبيوتر
    • حجم البرنامج
    • نوع المعالج
    الإجابة والشرح

    الإجابة الصحيحة: قواعد كتابة الكود

  2. ما الذي يحدث عند تشغيل ملف فيه: console.log("A"); console.log("B"

    • يطبع A ثم يتوقف عند الخطأ
    • يطبع A ثم B
    • لا يطبع شيئاً ويظهر SyntaxError لأن الملف يُفحص كله قبل التنفيذ
    • يطبع B فقط
    الإجابة والشرح

    الإجابة الصحيحة: لا يطبع شيئاً ويظهر SyntaxError لأن الملف يُفحص كله قبل التنفيذ

    أخطاء الصياغة تُكتشف عند قراءة الملف قبل بدء التنفيذ، فلا يعمل أي سطر. الظن أن الأسطر الصحيحة تعمل أولاً غير صحيح.

  3. ما الذي يحدث؟ let Name = "Sara"; console.log(name);

    • يطبع Sara لأن الحروف الكبيرة والصغيرة سواء
    • يطبع undefined
    • يظهر ReferenceError لأن name و Name اسمان مختلفان
    • يظهر SyntaxError
    الإجابة والشرح

    الإجابة الصحيحة: يظهر ReferenceError لأن name و Name اسمان مختلفان

    JavaScript حساسة لحالة الأحرف، فـ name تختلف عن Name وهي غير معرّفة هنا. الصياغة سليمة لذلك لا يكون الخطأ SyntaxError.

  4. أردت جمع 5 و 3 لكن كتبت console.log(5 - 3) فظهر 2. أي نوع من الأخطاء هذا؟

    • خطأ صياغة لأن الرمز ناقص
    • خطأ منطقي: الكود صحيح الصياغة لكنه لا يفعل المطلوب
    • خطأ في الإنترنت
    • لا يوجد خطأ لأن البرنامج عمل
    الإجابة والشرح

    الإجابة الصحيحة: خطأ منطقي: الكود صحيح الصياغة لكنه لا يفعل المطلوب

    الصياغة سليمة فعمل البرنامج بلا رسالة خطأ، لكن النتيجة ليست المقصودة. هذه الأخطاء أصعب لأن الحاسوب لا يبلغك بها.

  5. أردت تخزين: He said "hi" في متغير، فكتبت let s = "He said "hi""; فظهر خطأ. أي إصلاح صحيح؟

    • let s = 'He said "hi"';
    • let s = He said "hi";
    • let s = "He said "hi"";;
    • let s = ("He said "hi"");
    الإجابة والشرح

    الإجابة الصحيحة: let s = 'He said "hi"';

    علامة الاقتباس المزدوجة داخل النص تُنهي السلسلة مبكراً. استخدام نوع اقتباس مختلف للإحاطة أو الهروب بـ \ يحل المشكلة، أما إضافة فواصل أو أقواس فلا تغيّر ذلك.
