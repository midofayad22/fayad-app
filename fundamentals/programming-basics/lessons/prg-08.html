النوع يحدد السلوك

العامل + يجمع الأرقام لكنه يدمج النصوص. لذلك فهم النوع يفسّر نتائج تبدو غريبة:

console.log(5 + 2);      // 7   (أرقام)
console.log("5" + 2);    // "52" (نص + رقم: دمج)
console.log("5" * 2);    // 10  (* لا يدمج، فيحوّل النص لرقم)
console.log(typeof "5"); // "string"

القيمة التي تأتي من مربع إدخال أو من ملف تكون نصًا دائمًا حتى لو بدت رقمًا. حوّلها بـ Number("20") قبل الحساب.

الكسور العشرية

الحاسوب يخزّن الأعداد العشرية بالنظام الثنائي، لذا قد تظهر فروق صغيرة:

console.log(0.1 + 0.2);            // 0.30000000000000004
console.log((0.1 + 0.2).toFixed(2)); // "0.30" (للعرض فقط)
الفكرة الأساسية

اختبر نفسك

  1. أي نوع يستخدم لتخزين true أو false؟

    • String
    • Number
    • Boolean
    • Array
    الإجابة والشرح

    الإجابة الصحيحة: Boolean

    النوع Boolean يحمل إحدى قيمتين فقط: true أو false، وهو الأساس في اتخاذ القرارات داخل الشروط.

  2. ما ناتج: "5" + 2

    • 7
    • "52"
    • Error
    • NaN
    الإجابة والشرح

    الإجابة الصحيحة: "52"

    عندما يكون أحد طرفي + نصًا، تدمج JavaScript القيمتين كنصين فتصبح النتيجة "52".

  3. ماذا يطبع: console.log(typeof 42)

    • "number"
    • "integer"
    • "string"
    • 42
    الإجابة والشرح

    الإجابة الصحيحة: "number"

    typeof يُرجع اسم النوع كنص. كل الأعداد، صحيحة أو عشرية، من النوع number.

  4. المتغير let city; لم نعطه قيمة. ما قيمته؟

    • null
    • 0
    • undefined
    • ""
    الإجابة والشرح

    الإجابة الصحيحة: undefined

    المتغير الذي يُعرَّف دون قيمة يحمل القيمة undefined تلقائيًا. أما null فنكتبه نحن عمدًا.

  5. ما ناتج هذا السطر؟ console.log("7" - 2);

    • 72
    • 5
    • NaN
    • خطأ
    الإجابة والشرح

    الإجابة الصحيحة: 5

    عامل الطرح يحوّل النص "7" إلى الرقم 7 فتكون النتيجة 5. أما + فيدمج النصوص، ولهذا "7" + 2 تعطي 72.
