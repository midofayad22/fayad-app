DEVELOPER TOOLS

ابدأ بفهم Version Control

ما هو Git؟

Git هو نظام Version Control يساعد المطورين على تتبع التغييرات التي تحدث في المشروع.

Repository

المكان الذي يحتوي على ملفات المشروع وتاريخه.

Commit

تسجيل مجموعة من التغييرات في تاريخ المشروع.

Branch

مسار مستقل لتطوير ميزة أو تجربة.

GitHub

منصة شهيرة لاستضافة مشاريع Git والتعاون عليها.

الفكرة الأساسية

Git ليس لغة برمجة؛ هو أداة لإدارة إصدارات المشروع وتتبع التغييرات.

مثال عملي

شاهد الفكرة في كود

JavaScript 
git init
git add .
git commit -m "Initial commit"
تطبيق

تحدَّ نفسك

اختبر نفسك

  1. ما وظيفة Git الأساسية؟

    • تصميم واجهات
    • إدارة وتتبع إصدارات المشروع
    • تشغيل الإنترنت
    • إنشاء صور
    الإجابة والشرح

    الإجابة الصحيحة: إدارة وتتبع إصدارات المشروع

  2. عدّلت ملفاً وتريد حفظ لقطة منه في تاريخ المشروع. ما التسلسل الصحيح؟

    • git commit ثم git add
    • git push فقط
    • git add لتجهيز التغييرات ثم git commit لتسجيلها
    • git clone ثم git add
    الإجابة والشرح

    الإجابة الصحيحة: git add لتجهيز التغييرات ثم git commit لتسجيلها

    add تضع التغييرات في منطقة التجهيز، وcommit تسجلها كلقطة في التاريخ. الـ commit بدون تجهيز لا يتضمن التعديلات الجديدة.

  3. تريد تجربة ميزة محفوفة بالمخاطر دون المساس بالنسخة الرئيسية العاملة. ماذا تفعل؟

    • أنشئ فرعاً جديداً (branch) وأعمل عليه
    • أعدّل الفرع الرئيسي مباشرة وأحتفظ بنسخة في سطح المكتب
    • أحذف المشروع وأبدأ من جديد
    • أنتظر حتى يكتب غيري الميزة
    الإجابة والشرح

    الإجابة الصحيحة: أنشئ فرعاً جديداً (branch) وأعمل عليه

    الفرع يتيح عزل التجربة، فإذا فشلت يُترك الفرع بلا ضرر وإذا نجحت تُدمج. العمل على الرئيسي مباشرة يعرّضه للكسر.

  4. ما الفرق بين commit و push؟

    • commit يرفع التغييرات إلى الخادم و push تحفظها محلياً
    • لا فرق بينهما
    • commit يحفظ لقطة في مستودعك المحلي، و push يرسل التزاماتك إلى مستودع بعيد
    • push يحذف التاريخ
    الإجابة والشرح

    الإجابة الصحيحة: commit يحفظ لقطة في مستودعك المحلي، و push يرسل التزاماتك إلى مستودع بعيد

    الـ commit عملية محلية لا تحتاج إنترنت، أما push فتنقل الالتزامات إلى مستودع مثل GitHub. العكس الذي في الخيار الأول خاطئ.

  5. ما العلاقة بين Git و GitHub؟

    • الاسمان لنفس البرنامج
    • Git موقع و GitHub أداة سطر أوامر
    • GitHub لغة برمجة
    • Git أداة إدارة الإصدارات، و GitHub خدمة تستضيف المستودعات على الإنترنت
    الإجابة والشرح

    الإجابة الصحيحة: Git أداة إدارة الإصدارات، و GitHub خدمة تستضيف المستودعات على الإنترنت

    يمكنك استخدام Git على جهازك بدون GitHub، وGitHub يضيف الاستضافة والتعاون. الخلط بينهما شائع لتقاربهما في الاستخدام.
