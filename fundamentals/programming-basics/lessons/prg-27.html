المحلل النحوي Parser وشجرة AST

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

PARSER

من قائمة رموز إلى شجرة تمثل البنية

أهداف الدرس

  • تفهم شجرة AST.
  • تعرف لماذا تسبق الضرب الجمع.
  • تقرأ وتكتب Recursive Descent Parser.

المتطلبات السابقة

  • درس Tokenizer (prg-26) ودرس Recursion (prg-21).

لماذا لا تكفي القائمة؟

القائمة 2 + 3 * 4 لا تقول أي عملية تُنفَّذ أولًا. الـ Parser يضيف البنية: يبني AST (Abstract Syntax Tree) تضع الضرب أعمق من الجمع فيُحسب أولًا.

اقرأ الشجرة من الأوراق إلى الجذر: يُحسب 3 * 4 = 12 أولًا لأنه أعمق، ثم 2 + 12 = 14. أما الأقواس في (2 + 3) * 4 فتغيّر شكل الشجرة نفسها:

عرض الحل

لأن الدالة الأعمق تُنهي عملها أولًا، فتُجمَّع عمليات الضرب قبل الجمع. ترتيب القواعد هو الذي يُنتج أولوية العوامل.

الخلاصة

  • AST تمثل بنية البرنامج كشجرة.
  • قواعد النحو تحدد الأولوية.
  • Recursive Descent: دالة لكل قاعدة.

الخطوة التالية: نجمع كل شيء في لغة مصغّرة.

الفكرة الأساسية

الـ Parser يحوّل الرموز إلى شجرة تحمل البنية والأولوية، وتقييم الشجرة بالـ Recursion يعطي النتيجة.

مثال عملي

شاهد الفكرة في كود

JavaScript 
const ast = { op: "+", left: { num: 2 }, right: { op: "*", left: { num: 3 }, right: { num: 4 } } };
function evaluate(n) {
if (n.num !== undefined) return n.num;
const a = evaluate(n.left), b = evaluate(n.right);
return n.op === "+" ? a + b : a * b;
}
console.log(evaluate(ast));

تمرين تفاعلي

اكتب evaluate(node) تقيّم شجرة AST التي لها الشكل {num} أو {op,left,right} وتدعم + - * /.

اختبر نفسك

  1. ما فائدة شجرة AST؟

    • تمثل بنية البرنامج وأولوية العمليات
    • تخزن الصور
    • تسرّع الإنترنت
    • تحذف الأخطاء
    الإجابة والشرح

    الإجابة الصحيحة: تمثل بنية البرنامج وأولوية العمليات

    الشجرة هي التمثيل الذي يقيّمه المفسّر أو يترجمه المترجم.

  2. أين تقع عملية الضرب في شجرة 2 + 3 * 4؟

    • أعمق من الجمع
    • في الجذر
    • خارج الشجرة
    • بلا مكان
    الإجابة والشرح

    الإجابة الصحيحة: أعمق من الجمع

    الأعمق يُقيَّم أولًا.

  3. ما ناتج تقييم (2 + 3) * 4؟

    • 20
    • 14
    • 24
    • 9
    الإجابة والشرح

    الإجابة الصحيحة: 20

    الأقواس ترفع الجمع إلى مستوى أعمق: 5 × 4.

  4. أي مفهوم برمجي يستخدمه Recursive Descent؟

    • Recursion
    • الصور
    • الأصوات
    • القرص
    الإجابة والشرح

    الإجابة الصحيحة: Recursion

    الدوال تنادي بعضها وتنادي نفسها عند الأقواس.

  5. ما الجذر (root) في شجرة AST للتعبير 2 * 3 + 4 وما قيمته عند التقييم؟

    • الجذر * وقيمته 14
    • الجذر + وقيمته 10، ويكون الضرب 2 * 3 ابنه الأيسر
    • الجذر + وقيمته 9
    • لا جذر للشجرة
    الإجابة والشرح

    الإجابة الصحيحة: الجذر + وقيمته 10، ويكون الضرب 2 * 3 ابنه الأيسر

    العملية الأقل أولوية تكون أعلى الشجرة لأنها تُنفذ أخيراً، فالجذر + وابنه الأيسر 2*3 = 6 ثم 6 + 4 = 10. وضع * كجذر يعني (3 + 4) أولاً وهو خطأ في الأولوية.
