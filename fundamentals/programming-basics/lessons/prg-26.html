المحلل المعجمي Tokenizer

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

TOKENIZER

تقطيع النص إلى رموز ذات معنى

أهداف الدرس

  • تفهم ما هو Token.
  • تكتب Tokenizer لعمليات حسابية.
  • تتعامل مع المسافات والأخطاء.

المتطلبات السابقة

  • درس المترجم والمفسّر (prg-25) ودرس Loops والـ Strings.

ما الـ Token؟

حين تقرأ 12 + 3*4 ترى أرقامًا وعمليات. الحاسوب يرى أحرفًا متتالية فقط. الـ Tokenizer يجمع الأحرف في وحدات لها معنى: عدد، عامل، قوس. كل Token له نوع وقيمة.

الخوارزمية

  1. ابدأ عند الموضع 0.
  2. تجاهل المسافات.
  3. إذا كان الحرف رقمًا فاقرأ كل الأرقام المتتالية كعدد واحد.
  4. إذا كان عاملًا أو قوسًا فأنشئ Token له.
  5. غير ذلك فهو حرف غير معروف: أبلغ بخطأ يذكر الموضع.

حين يفشل: أخطاء الـ Tokenizer

الـ Tokenizer لا يفهم المعنى، لكنه يعرف الأحرف المسموحة. أي حرف خارج القائمة هو خطأ معجمي. مثال: 3 $ 4 ينتج الرسالة التالية التي تذكر الموضع، وهذا ما يسمح للمستخدم بالوصول إلى الخطأ بسرعة:

أخطاء شائعة

  • قراءة رقم من حرف واحد: 12 يصبح 1 و2.
  • نسيان زيادة المؤشر i فتدخل حلقة لا نهائية.
تمرين ما عدد الـ Tokens في (1+2)*3؟
عرض الحل

سبعة: ( و1 و+ و2 و) و* و3.

الخلاصة

  • الـ Tokenizer يحوّل الأحرف إلى وحدات ذات نوع وقيمة.
  • يتجاهل المسافات ويُبلغ عن الأحرف غير المعروفة.

الخطوة التالية: نحوّل قائمة الـ Tokens إلى شجرة: الـ Parser.

الفكرة الأساسية

الـ Tokenizer هو أول مرحلة: يحوّل نصًا خامًا إلى رموز يستطيع الـ Parser فهمها.

مثال عملي

شاهد الفكرة في كود

JavaScript 
const src = "7 * (2 + 1)";
const tokens = src.match(/\d+|[-+*/()]/g);
console.log(tokens);

تحدَّ نفسك

تمرين تفاعلي

اكتب tokenize(src) تعيد مصفوفة نصوص: الأعداد (قد تكون عشرية) والعوامل + - * / ( ) بعد تجاهل المسافات. مثال: "12 + 3.5*4" ← ["12","+","3.5","*","4"].

    • كلمة مرور
    • نوع من الأخطاء
    • ملف

    • بلا سبب
    • لتغيير اللون
