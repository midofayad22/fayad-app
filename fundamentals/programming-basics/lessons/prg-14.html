Scope

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

SCOPE

أين يمكن استخدام المتغير؟

ما هو Scope؟

Scope يحدد المكان الذي يمكن فيه الوصول إلى المتغير واستخدامه.

المتغير الذي يتم تعريفه داخل Function لا يمكن الوصول إليه عادةً من خارجها.

الفكرة الأساسية

Scope يساعد على منع تداخل البيانات وتقليل المشاكل الناتجة عن استخدام المتغيرات في أماكن غير مناسبة.

مثال عملي

شاهد الفكرة في كود

JavaScript 
function test() {
let message = "Hello";
console.log(message);
}
test();
تطبيق

تحدَّ نفسك

اختبر نفسك

  1. ماذا يحدد Scope؟

    • مكان إمكانية الوصول إلى المتغير
    • سرعة البرنامج
    • لون الكود
    • حجم الشاشة
    الإجابة والشرح

    الإجابة الصحيحة: مكان إمكانية الوصول إلى المتغير

  2. ماذا يحدث؟ function f() { let secret = 1; } f(); console.log(secret);

    • يطبع 1
    • يطبع undefined
    • يطبع null
    • يظهر ReferenceError لأن secret موجود داخل الدالة فقط
    الإجابة والشرح

    الإجابة الصحيحة: يظهر ReferenceError لأن secret موجود داخل الدالة فقط

    المتغير المحلي ينتهي عمره بانتهاء الدالة ولا يراه الكود خارجها. محاولة قراءته من الخارج تنتج ReferenceError لا undefined.

  3. ما الذي يُطبع؟ let x = 1; function f() { let x = 2; return x; } console.log(f(), x);

    • 2 1
    • 2 2
    • 1 1
    • 1 2
    الإجابة والشرح

    الإجابة الصحيحة: 2 1

    x داخل الدالة متغير مستقل يُخفي الخارجي أثناء الاستدعاء فقط، فتعيد الدالة 2. المتغير الخارجي يبقى 1 لأن الدالة لم تغيّره.

  4. لماذا يُفضَّل استخدام متغيرات محلية بدل كثير من المتغيرات العامة؟

    • لأنها تقلل تعارض الأسماء والتعديل غير المقصود من أجزاء أخرى
    • لأن المتغيرات العامة غير مسموحة في اللغة
    • لأن المحلية أسرع بآلاف المرات دائماً
    • لأن العامة تُحذف تلقائياً بعد ثانية
    الإجابة والشرح

    الإجابة الصحيحة: لأنها تقلل تعارض الأسماء والتعديل غير المقصود من أجزاء أخرى

    المتغير العام يستطيع أي جزء من البرنامج تغييره، فيصعب تتبع من غيّر قيمته. النطاق المحلي يحصر الأثر ويسهل الفهم والاختبار.

  5. ما قيمة count في النهاية؟ let count = 0; function inc() { count++; } inc(); inc(); console.log(count);

    • 0
    • 1
    • 2
    • خطأ لأن الدالة لا ترى count
    الإجابة والشرح

    الإجابة الصحيحة: 2

    الدالة تستطيع قراءة وتعديل المتغير الخارجي المعرّف في نطاق أعلى. استُدعيت مرتين فزادت count من 0 إلى 2.
