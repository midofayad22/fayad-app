هياكل البيانات: Stack وQueue وMap وSet

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

DATA STRUCTURES

اختر طريقة التخزين المناسبة للمهمة

أهداف الدرس

  • تعرف المكدس Stack والطابور Queue.
  • تستخدم Map وSet في JavaScript.
  • تختار البنية حسب العمليات المطلوبة.

المتطلبات السابقة

  • درس Arrays (prg-15) ودرس Objects (prg-16).

لماذا تهم البنية؟

Data Structure هي طريقة منظمة لتخزين البيانات تجعل عمليات معينة سريعة وبسيطة. المصفوفة ممتازة للقوائم، لكن لا تناسب كل مهمة. اختيار البنية جزء من تصميم الخوارزمية.

Stack: آخر داخل أول خارج

كأكوام الأطباق: تضيف وتأخذ من الأعلى فقط. يُستخدم في زر «تراجع» وفي Call Stack وفي فحص الأقواس.

Queue: أول داخل أول خارج

كطابور الانتظار: تُضاف العناصر في النهاية وتُؤخذ من البداية. يُستخدم في الطباعة ومهام المعالج وطلبات الخادم.

Map وSet

  • Map: أزواج مفتاح ← قيمة مع بحث سريع بالمفتاح، ويقبل أي نوع كمفتاح.
  • Set: مجموعة قيم فريدة، لا تكرار فيها، والتحقق من وجود قيمة سريع.
المهمةالبنية المناسبة
تراجع/إعادةStack
طابور مهامQueue
عدّ تكرار الكلماتMap
إزالة التكرارSet

أخطاء شائعة

  • استخدام shift() على مصفوفة ضخمة كطابور: يحرّك كل العناصر. للأحجام الكبيرة استخدم بنية مخصصة.
  • الخلط بين Map والكائن العادي {}: المفاتيح في الكائن تتحول إلى نصوص.
تمرين أي بنية تستخدم لمعرفة هل زار المستخدم صفحة من قبل؟
عرض الحل

Set يحفظ عناوين الصفحات الفريدة، وhas(url) يجيب فورًا.

الخلاصة

  • Stack: آخر داخل أول خارج.
  • Queue: أول داخل أول خارج.
  • Map للبحث بالمفتاح، Set للقيم الفريدة.

الخطوة التالية: كيف نقيس كفاءة اختيارنا؟ التعقيد الزمني.

الفكرة الأساسية

البنية المناسبة تجعل الحل أبسط وأسرع؛ اختر حسب العمليات التي تحتاجها.

مثال عملي

شاهد الفكرة في كود

JavaScript 
const stack = [];
for (const ch of "abc") stack.push(ch);
let reversed = "";
while (stack.length) reversed += stack.pop();
console.log(reversed);
