اجعل البرنامج ينفذ العمليات

ما هو Operator؟

Operators هي رموز أو كلمات تسمح لنا بتنفيذ عمليات على القيم.

Arithmetic

+   -   *   /   %

Comparison

===   !==   >   <

Logical

&&   ||   !

Assignment

=   +=   -=

عوامل الحساب

الجمع +، الطرح -، الضرب *، القسمة /، وباقي القسمة % (Modulus) وهو مفيد لمعرفة الزوجي والفردي.

console.log(10 % 3);  // 1  (10 = 3×3 + 1)
console.log(14 % 2);  // 0  -> العدد زوجي
console.log(2 + 3 * 4); // 14 (الضرب أولًا)
console.log((2 + 3) * 4); // 20 (الأقواس أولًا)

عوامل المقارنة تُنتج Boolean

كل مقارنة تُرجع true أو false. استخدم دائمًا المساواة الصارمة === لأنها تقارن القيمة والنوع معًا.

console.log(5 === 5);    // true
console.log(5 === "5");  // false (النوع مختلف)
console.log(5 == "5");   // true  (== يحوّل النوع: تجنّبه)
console.log(7 >= 7);     // true
console.log(3 !== 4);    // true

العوامل المنطقية

&& (و): صحيحة إذا تحقق الشرطان. || (أو): صحيحة إذا تحقق أحدهما. ! (ليس): تعكس القيمة.

const age = 20, hasId = true;
console.log(age >= 18 && hasId);  // true
console.log(age < 18 || hasId);   // true
console.log(!hasId);              // false
الفكرة الأساسية

Operators هي الأدوات التي تسمح للبرنامج بإجراء الحساب والمقارنة واتخاذ القرارات.

مثال عملي

شاهد الفكرة في كود

JavaScript 
const age = 20;
console.log(age >= 18);
console.log(age === 20);

تمرين تفاعلي

المتغير n = 14. أنشئ متغيرًا باسم isEven قيمته true إذا كان n زوجيًا، مستخدمًا عامل باقي القسمة %.

اختبر نفسك

  1. ما نتيجة 10 + 5؟

    • 15
    • 105
    • 5
    • 10
    الإجابة والشرح

    الإجابة الصحيحة: 15

    10 + 5 بين رقمين فتُجمع القيمتان وتكون النتيجة 15. النتيجة 105 كانت ستظهر لو كان أحد الطرفين نصًا.

  2. ما ناتج 10 % 3؟

    • 3
    • 1
    • 0
    • 3.33
    الإجابة والشرح

    الإجابة الصحيحة: 1

    % يُرجع باقي القسمة: 10 ÷ 3 = 3 والباقي 1.

  3. ما ناتج 5 === "5"؟

    • true
    • false
    • Error
    • undefined
    الإجابة والشرح

    الإجابة الصحيحة: false

    === تقارن القيمة والنوع. الأول number والثاني string، لذا النتيجة false.

  4. ما ناتج: true && false

    • true
    • false
    • null
    • 1
    الإجابة والشرح

    الإجابة الصحيحة: false

    && لا تُرجع true إلا إذا كان الطرفان true. هنا الطرف الثاني false.

  5. ما قيمة x في النهاية؟ let x = 5; x += 2; x *= 3;

    • 11
    • 17
    • 21
    • 13
    الإجابة والشرح

    الإجابة الصحيحة: 21

    x += 2 تجعل x تساوي 7 ثم x *= 3 تضربها بـ 3 فتصبح 21. الخطأ الشائع هو إجراء العمليتين على القيمة الأصلية 5.
