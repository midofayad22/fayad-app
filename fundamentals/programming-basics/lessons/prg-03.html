PROBLEM SOLVING

تعلم طريقة التفكير قبل تعلم اللغة

ما هو التفكير البرمجي؟

التفكير البرمجي هو طريقة منظمة لتحليل المشكلات وتقسيمها إلى أجزاء صغيرة يمكن التعامل معها.

Decomposition

تقسيم المشكلة الكبيرة إلى مشاكل أصغر.

Pattern Recognition

اكتشاف الأنماط المتكررة داخل المشكلات.

Abstraction

التركيز على المعلومات المهمة وإخفاء التفاصيل غير الضرورية.

Algorithm

بناء خطوات واضحة للوصول إلى الحل.

الفكرة الأساسية

التفكير البرمجي مهارة مستقلة عن لغة البرمجة؛ يمكنك استخدام نفس طريقة التفكير مع JavaScript أو Python أو C++.

مثال عملي

شاهد الفكرة في كود

JavaScript 
const tasks = [
"فتح التطبيق",
"تسجيل الدخول",
"اختيار الدرس",
"بدء التعلم"
];
console.log(tasks);

  2. وصفة الشاي والقهوة والشوكولاتة الساخنة كلها تبدأ بتسخين الماء ثم إضافة المسحوق ثم الانتظار. أي ركيزة من التفكير الحاسوبي لاحظت ذلك؟

    • Decomposition
    • Pattern Recognition

    الإجابة والشرح

    الإجابة الصحيحة: Pattern Recognition

    ملاحظة التشابه بين مسائل مختلفة هي التعرف على الأنماط، وتتيح إعادة استخدام نفس الحل. التفكيك يعني تقسيم المشكلة إلى أجزاء لا البحث عن التشابه.

  3. خريطة المترو لا تعرض المسافات الحقيقية ولا الشوارع بل المحطات والخطوط فقط. أي مفهوم تمثّله؟

    • التجريد: إخفاء التفاصيل غير الضرورية وإبقاء المهم للمهمة
    • التفكيك إلى أخطاء
    • الحلقات المتكررة
    • تحسين السرعة
    الإجابة والشرح

    الإجابة الصحيحة: التجريد: إخفاء التفاصيل غير الضرورية وإبقاء المهم للمهمة

    التجريد يحتفظ بما يلزم لحل المشكلة، وهنا الاتصال بين المحطات. تفاصيل الشوارع تزيد الازدحام ولا تفيد مسافر المترو.

  4. تريد بناء تطبيق توصيل طعام. أي خطوة أولى تمثل التفكيك بشكل أفضل؟

    • كتابة الكود كله في ملف واحد ثم إصلاحه
    • نسخ تطبيق موجود دون فهمه
    • تقسيمه إلى أجزاء مثل حسابات المستخدمين وقائمة المطاعم والسلة والدفع والتتبع
    • اختيار ألوان الشاشات أولاً
    الإجابة والشرح

    الإجابة الصحيحة: تقسيمه إلى أجزاء مثل حسابات المستخدمين وقائمة المطاعم والسلة والدفع والتتبع

    المشكلة الكبيرة تصبح قابلة للحل حين تُقسم إلى مسائل صغيرة مستقلة يمكن بناء كل منها واختباره. البدء بكل شيء معاً يخلط المشاكل ويصعب تتبعها.

  5. بعد التفكيك وملاحظة الأنماط وتجاهل التفاصيل، ما الركيزة التي تنتج الخطوات المرتبة لحل المشكلة؟

    • Pattern Recognition
    • Algorithm Design
    • Abstraction
    • Decomposition
    الإجابة والشرح

    الإجابة الصحيحة: Algorithm Design

    تصميم الخوارزمية هو كتابة خطوات واضحة ومرتبة تنتهي بالحل. الركائز الأخرى تجهز المشكلة لهذه المرحلة ولا تكتب الخطوات نفسها.
