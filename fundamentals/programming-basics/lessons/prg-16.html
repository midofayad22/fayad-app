نظم البيانات المرتبطة ببعضها

ما هو Object؟

Object يستخدم لتجميع بيانات مرتبطة بكيان معين باستخدام Properties وValues.

على سبيل المثال يمكن تمثيل مستخدم باستخدام الاسم والعمر والبريد الإلكتروني.

الفكرة الأساسية

Objects تجعل البيانات المعقدة أكثر تنظيمًا لأنها تربط كل قيمة باسم واضح.

مثال عملي

شاهد الفكرة في كود

JavaScript 
const user = {
name: "Abdullhamid",
age: 20,
role: "Developer"
};
console.log(user.name);
console.log(user.role);

اختبر نفسك

  1. ما الذي يستخدمه Object لتخزين البيانات؟

    • Properties وValues
    • Loops فقط
    • صور فقط
    • Files
    الإجابة والشرح

    الإجابة الصحيحة: Properties وValues

  2. ما الناتج؟ const p = { name: "Sara", age: 20 }; p.age = 21; console.log(p.age);

    • 20
    • 21
    • خطأ لأن p ثابت
    • undefined
    الإجابة والشرح

    الإجابة الصحيحة: 21

    const تثبّت ارتباط الاسم بالكائن لا محتوى الكائن، فيمكن تعديل خصائصه. الخطأ يظهر فقط عند محاولة p = {} من جديد.

  3. ماذا يطبع؟ const p = { name: "Sara" }; console.log(p.email);

    • undefined
    • null
    • خطأ
    • سلسلة فارغة
    الإجابة والشرح

    الإجابة الصحيحة: undefined

    قراءة خاصية غير موجودة لا ترمي خطأ بل تعيد undefined. الخطأ يحدث فقط عند القراءة من undefined نفسها.

  4. const p = { name: "Sara" }; const key = "name"; أي تعبير يطبع Sara؟

    • console.log(p.key)
    • console.log(p[name])
    • console.log(p[key])
    • console.log(key.p)
    الإجابة والشرح

    الإجابة الصحيحة: console.log(p[key])

    الأقواس تقيّم المتغير key فتصبح p["name"]. أما p.key فتبحث عن خاصية اسمها key حرفياً وتعطي undefined.

  5. لديك كتاب له عنوان ومؤلف وعدد صفحات. ما أفضل تمثيل له؟

    • مصفوفة ["JS", "Ali", 300] لأن الترتيب يكفي دائماً
    • ثلاثة متغيرات منفصلة بأسماء عشوائية
    • نص واحد يضم كل القيم
    • كائن { title, author, pages } لأن لكل قيمة اسماً واضحاً
    الإجابة والشرح

    الإجابة الصحيحة: كائن { title, author, pages } لأن لكل قيمة اسماً واضحاً

    الكائن يربط كل قيمة باسم يصف معناها فتُقرأ الشيفرة بسهولة (book.pages). المصفوفة تعتمد على أرقام الفهارس التي لا تعبّر عن المعنى.
