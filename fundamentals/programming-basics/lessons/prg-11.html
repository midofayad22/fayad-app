LOOPS

كرر التعليمات بدون تكرار الكود

لماذا نستخدم Loops؟

أحيانًا نحتاج لتنفيذ نفس العملية عدة مرات. بدل كتابة الكود نفسه عشرات المرات، نستخدم Loop.

for

مناسبة عندما تعرف عدد مرات التكرار.

while

تستمر طالما الشرط ما زال صحيحًا.

أجزاء حلقة for

تتكون من ثلاثة أجزاء داخل الأقواس: البداية تُنفَّذ مرة واحدة، الشرط يُفحص قبل كل دورة، والتحديث يُنفَّذ بعد كل دورة.

for (let i = 1; i <= 3; i++) {
console.log("دورة", i);
}
// البداية: i = 1
// الشرط:   i <= 3 ؟ نعم -> نفّذ الكتلة
// التحديث: i++  -> i = 2 ... حتى يصبح الشرط false

while: عندما لا نعرف عدد الدورات

استخدم while حين تتكرر العملية «ما دام» الشرط صحيحًا. تأكد أن شيئًا داخل الحلقة يغيّر الشرط في النهاية، وإلا ستصبح حلقة لا نهائية وتتجمد الصفحة.

let n = 100, steps = 0;
while (n > 1) {
n = n / 2;     // هذا السطر يقرّب الشرط من false
steps++;
}
console.log(steps); // 7

نمط المُجمِّع Accumulator

كثيرًا ما نبدأ بقيمة ابتدائية ونحدّثها في كل دورة لنصل إلى نتيجة، مثل مجموع الأعداد:

let sum = 0;
for (let i = 1; i <= 5; i++) {
sum += i;      // 1, 3, 6, 10, 15
}
console.log(sum); // 15

تتبّع الحلقة بقلم وورقة: اكتب قيمة i وsum بعد كل دورة. هذه أسرع طريقة لفهم ما تفعله الحلقة واكتشاف الأخطاء.

تمرين تفاعلي

باستخدام حلقة for أو while، احسب مجموع الأعداد من 1 إلى 10 وخزّنه في متغير باسم sum.

اختبر نفسك

  1. ما الهدف من Loop؟

    • تكرار تنفيذ تعليمات
    • حذف المتغيرات
    • إيقاف الكمبيوتر
    • تغيير اللغة
    الإجابة والشرح

    الإجابة الصحيحة: تكرار تنفيذ تعليمات

    الحلقة (Loop) تكرر تنفيذ مجموعة تعليمات عدة مرات دون كتابتها من جديد، فتختصر الكود وتتعامل مع أي عدد من العناصر.

  2. كم مرة تُنفَّذ كتلة الحلقة؟ for (let i = 0; i < 3; i++) { ... }

    • 2
    • 3
    • 4
    • لا نهائية
    الإجابة والشرح

    الإجابة الصحيحة: 3

    تأخذ i القيم 0 ثم 1 ثم 2، وعندما تصبح 3 يصبح الشرط i < 3 خاطئًا. إذن 3 دورات.

  3. ما قيمة sum في النهاية؟ let sum = 0; for (let i = 1; i <= 4; i++) { sum += i; }

    • 4
    • 10
    • 24
    • 6
    الإجابة والشرح

    الإجابة الصحيحة: 10

    sum تتراكم: 1 ثم 3 ثم 6 ثم 10.

  4. ما سبب أن هذه الحلقة لا تنتهي؟ let i = 0; while (i < 5) { console.log(i); }

    • لأن console.log لا تعمل
    • لأن i لا تتغير داخل الحلقة فيبقى الشرط صحيحًا
    • لأن while لا تقبل أرقامًا
    • لأن 5 رقم كبير
    الإجابة والشرح

    الإجابة الصحيحة: لأن i لا تتغير داخل الحلقة فيبقى الشرط صحيحًا

    لا شيء يزيد i، فتبقى 0 والشرط i < 5 صحيحًا دائمًا. الحل: أضف i++ داخل الحلقة.

  5. ما الذي تطبعه الحلقة؟ for (let i = 10; i > 0; i -= 3) { console.log(i); }

    • 10 7 4 1
    • 10 7 4 1 -2
    • 7 4 1
    • 10 3
    الإجابة والشرح

    الإجابة الصحيحة: 10 7 4 1

    تبدأ i بـ 10 وتنقص 3 في كل دورة: 10 ثم 7 ثم 4 ثم 1، وعند -2 يصبح الشرط i > 0 خاطئاً فتتوقف قبل الطباعة.
