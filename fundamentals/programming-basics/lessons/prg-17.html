DEBUGGING

الخطأ جزء طبيعي من حياة المبرمج

لا يوجد مبرمج لا يواجه Errors

الأخطاء جزء طبيعي من عملية التطوير. المبرمج المحترف لا يحاول تجنب جميع الأخطاء، بل يتعلم كيف يقرأها ويحدد سببها ويصلحها.

Syntax Error

مشكلة في قواعد كتابة الكود.

Runtime Error

خطأ يحدث أثناء تشغيل البرنامج.

Logic Error

الكود يعمل لكن النتيجة غير صحيحة.

Debugging

عملية اكتشاف الأخطاء وإصلاحها.

الفكرة الأساسية

قراءة رسالة الخطأ وفهمها مهارة أساسية للمبرمج، وليست علامة على الفشل.

مثال عملي

شاهد الفكرة في كود

JavaScript 
const age = 20;
if (age > 18) {
console.log("Adult");
}
تطبيق

تحدَّ نفسك

اختبر نفسك

  1. ما معنى Debugging؟

    • كتابة HTML
    • اكتشاف الأخطاء وإصلاحها
    • تصميم الصور
    • رفع الموقع
    الإجابة والشرح

    الإجابة الصحيحة: اكتشاف الأخطاء وإصلاحها

  2. برنامج يعمل بلا أي رسالة خطأ لكن إجمالي الفاتورة أقل من الصحيح. أي نوع من الأخطاء المرجح؟

    • خطأ منطقي في الحساب
    • خطأ صياغة
    • خطأ في الاتصال بالإنترنت
    • خطأ في تثبيت المحرر
    الإجابة والشرح

    الإجابة الصحيحة: خطأ منطقي في الحساب

    لو كانت الصياغة خاطئة لما بدأ البرنامج أصلاً، ولو كان خطأ تشغيل لظهرت رسالة. غياب الرسائل مع نتيجة خاطئة يدل على خطأ منطقي.

  3. ظهرت الرسالة: TypeError: Cannot read properties of undefined (reading 'name'). ماذا تعني؟

    • الكلمة name محجوزة في اللغة
    • حاولت قراءة name من قيمة هي undefined بدل كائن
    • الملف لا يُحفظ
    • مفقودة فاصلة منقوطة
    الإجابة والشرح

    الإجابة الصحيحة: حاولت قراءة name من قيمة هي undefined بدل كائن

    الرسالة تذكر النوع والسبب: القيمة التي طلبت منها name هي undefined. تتبع المتغير الذي قد يكون فارغاً هو نقطة بدء التصحيح.

  4. ماذا يطبع؟ let total = 0; for (let i = 1; i <= 3; i++) { total = i; } console.log(total);

    • 6
    • 3
    • 0
    • 1
    الإجابة والشرح

    الإجابة الصحيحة: 3

    الإسناد total = i يستبدل القيمة في كل دورة بدل جمعها، فتنتهي عند 3. كان المقصود total += i للحصول على 6، وهو خطأ منطقي.

  5. دالتك تعطي ناتجاً خاطئاً ولا تعرف من أين يبدأ الخطأ. ما أفضل استراتيجية؟

    • إعادة كتابة البرنامج كله من الصفر
    • طباعة القيم الوسيطة بـ console.log لتجد الخطوة التي تنحرف فيها القيمة عن المتوقع
    • تغيير أسماء المتغيرات عشوائياً
    • تجاهل المشكلة والنظر هل تختفي
    الإجابة والشرح

    الإجابة الصحيحة: طباعة القيم الوسيطة بـ console.log لتجد الخطوة التي تنحرف فيها القيمة عن المتوقع

    تتبع القيم خطوة بخطوة يحصر الخطأ في موضع صغير بدل التخمين. إعادة الكتابة تهدر الوقت وقد تعيد نفس الخطأ.
