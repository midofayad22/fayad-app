تطبيق

تحدَّ نفسك

اختبر نفسك

  1. ما أهم شيء يجب أن تخرج به من هذا المسار؟

    • حفظ كل Syntax
    • التفكير المنطقي وحل المشكلات
    • حفظ أسماء اللغات
    • كتابة أكبر عدد من الأسطر
    الإجابة والشرح

    الإجابة الصحيحة: التفكير المنطقي وحل المشكلات

  2. ما الناتج؟ function sumTo(n) { let s = 0; for (let i = 1; i <= n; i++) { s += i; } return s; } console.log(sumTo(4) + sumTo(2));

    • 13
    • 10
    • 16
    • 9
    الإجابة والشرح

    الإجابة الصحيحة: 13

    sumTo(4) = 1+2+3+4 = 10 و sumTo(2) = 1+2 = 3، ومجموعهما 13. كل استدعاء له متغير s خاص به يبدأ من الصفر.

  3. ما الناتج؟ const items = [3, 8, 5]; let max = items[0]; for (const x of items) { if (x > max) max = x; } console.log(max);

    • 3
    • 16
    • 8
    • 5
    الإجابة والشرح

    الإجابة الصحيحة: 8

    max تبدأ بـ 3 وتصبح 8 عند العنصر الثاني، أما 5 فليس أكبر من 8 فتبقى 8. الحلقة تجمع الشرط والمصفوفة في نمط البحث عن الأكبر.

  4. function isAdult(age) { if (age > 18) return true; return false; } مستخدم عمره 18 بالضبط يُرفض. ما الإصلاح؟

    • استبدال > بـ >= ليشمل 18
    • استبدال return بـ console.log
    • تغيير 18 إلى 17.5 ثم حذف الدالة
    • إضافة حلقة داخل الدالة
    الإجابة والشرح

    الإجابة الصحيحة: استبدال > بـ >= ليشمل 18

    المقارنة > تستثني 18 نفسه، وهو خطأ منطقي على الحد. >= تجعل الشرط صحيحاً لكل من هم 18 فأكثر.

  5. تريد بناء ميزة جديدة في مشروعك. أي ترتيب يطبّق ما تعلمته في المسار؟

    • كتابة كل الكود ثم الاختبار في اليوم الأخير ثم حفظ النسخة
    • فهم المطلوب، تقسيمه، كتابة جزء صغير، اختباره، تصحيحه، ثم commit
    • commit أولاً ثم التفكير
    • حذف الاختبارات حتى لا تظهر الأخطاء
    الإجابة والشرح

    الإجابة الصحيحة: فهم المطلوب، تقسيمه، كتابة جزء صغير، اختباره، تصحيحه، ثم commit

    العمل بأجزاء صغيرة مع اختبار متكرر يكشف الأخطاء مبكراً حين يكون سببها قريباً. الاختبار المتأخر يجمّع أخطاء كثيرة يصعب فصلها.
