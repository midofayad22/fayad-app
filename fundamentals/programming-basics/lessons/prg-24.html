PARADIGMS

أكثر من طريقة واحدة للتفكير في الكود

أهداف الدرس

  • تفرّق بين البرمجة الإجرائية والكائنية والوظيفية.
  • تحل المسألة نفسها بثلاث طرق.
  • تفهم أن اللغات الحديثة تجمع أكثر من نموذج.

المتطلبات السابقة

  • دروس Functions وArrays وObjects.

ما هو الـ Paradigm؟

Paradigm هو أسلوب في تنظيم البرنامج وطريقة التفكير في حل المشكلة، وليس لغة. نحلّ المسألة التالية بثلاثة أساليب: «اجمع مربعات الأعداد الزوجية في قائمة».

1) إجرائي Procedural

سلسلة خطوات تعدّل متغيرات، وتنظّم بدوال.

2) وظيفي Functional

نركّب دوالًا صغيرة بلا تعديل للبيانات الأصلية: filter ثم map ثم reduce.

3) كائني Object-Oriented

نجمع البيانات والسلوك في كائن واحد له حالة داخلية.

أخطاء شائعة

  • الاعتقاد أن نموذجًا واحدًا هو «الصحيح» دائمًا.
  • تعديل المصفوفة الأصلية داخل map وهو ما يخالف الأسلوب الوظيفي.
تمرين ما الدالة النقية Pure Function؟
عرض الحل

دالة تعطي دائمًا النتيجة نفسها للمدخلات نفسها ولا تغيّر شيئًا خارجها (لا متغيرات عامة ولا طباعة ولا تعديل للمصفوفة الممرّرة). هذا يجعلها سهلة الاختبار.

الخلاصة

  • النموذج أسلوب تفكير وليس لغة.
  • الإجرائي خطوات، الوظيفي تركيب دوال، الكائني بيانات مع سلوك.

الخطوة التالية: نفتح الصندوق: كيف تتحول اللغة إلى تنفيذ؟ المترجم والمفسّر.

الفكرة الأساسية

النماذج المختلفة تحل المشكلة نفسها بأساليب تنظيم مختلفة، واللغات الحديثة تجمعها.

مثال عملي

شاهد الفكرة في كود

JavaScript 
const nums = [1, 2, 3, 4, 5, 6];
const result = nums
.filter((n) => n % 2 === 1)
.map((n) => n * 10);
console.log(result);

    الإجابة الصحيحة: filter وmap وreduce

    تصفّي ثم تحوّل ثم تجمع، دون تعديل القائمة الأصلية.

    • الكائني

    • الوظيفي فقط

    الإجابة الصحيحة: الكائني

    الكائن له خصائص (حالة) ودوال (سلوك).

  3. أي ما يلي دالة نقية؟

    • (a, b) => a + b
    • دالة تغيّر متغيرًا عامًا

    الإجابة الصحيحة: (a, b) => a + b

    نفس المدخلات تعطي نفس النتيجة بلا آثار جانبية.

  4. هل يمكن استخدام أكثر من نموذج في JavaScript؟

    • نعم
    • لا
    • فقط في المتصفح
    • فقط في Node
    الإجابة والشرح

    الإجابة الصحيحة: نعم

    JavaScript لغة متعددة النماذج.

  5. ما الفرق بين الأسلوب الأمري (imperative) والتصريحي (declarative)؟

    • الأمري يصف كيف تنفَّذ الخطوات بالتفصيل، والتصريحي يصف ما المطلوب من النتيجة
    • الأمري لا يستخدم متغيرات والتصريحي يستخدمها
    • التصريحي لا يعمل في JavaScript
    • لا فرق إلا في الأسماء
    الإجابة والشرح

    الإجابة الصحيحة: الأمري يصف كيف تنفَّذ الخطوات بالتفصيل، والتصريحي يصف ما المطلوب من النتيجة

    الحلقة for التي تجمع الأرقام خطوة خطوة أمرية، بينما reduce أو map تعبّر عن المطلوب أكثر. يمكن الجمع بين الأسلوبين في JavaScript.
