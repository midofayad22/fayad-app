Arrays

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

DATA STRUCTURES

خزن مجموعة من القيم في مكان واحد

ما هي Array؟

Array هي بنية بيانات تسمح بتخزين عدة قيم داخل متغير واحد.

يمكن الوصول إلى العناصر باستخدام Index، ويبدأ الـ Index في JavaScript من الرقم 0.

الفكرة الأساسية

Array مناسبة عندما تحتاج إلى التعامل مع مجموعة عناصر مرتبطة ببعضها مثل أسماء المستخدمين أو المنتجات.

مثال عملي

شاهد الفكرة في كود

JavaScript 
const languages = [
"HTML",
"CSS",
"JavaScript"
];
console.log(languages[0]);
console.log(languages[2]);
تطبيق

تحدَّ نفسك

اختبر نفسك

  1. ما هو Index أول عنصر في Array؟

    • 0
    • 1
    • -1
    • 10
    الإجابة والشرح

    الإجابة الصحيحة: 0

  2. ما الناتج؟ const a = [10, 20, 30]; console.log(a[a.length - 1]);

    • 30
    • 20
    • undefined
    • 3
    الإجابة والشرح

    الإجابة الصحيحة: 30

    الطول 3 والفهرس يبدأ من 0، فآخر عنصر في الفهرس 2 وهو 30. الخطأ الشائع هو a[a.length] الذي يعطي undefined.

  3. ما محتوى المصفوفة؟ let a = [1, 2]; a.push(3); a.pop(); a.pop(); console.log(a);

    • [1]
    • [1, 2]
    • []
    • [1, 2, 3]
    الإجابة والشرح

    الإجابة الصحيحة: [1]

    push تضيف 3 إلى النهاية فتصبح [1,2,3]، ثم pop الأولى تزيل 3 والثانية تزيل 2، فيبقى [1]. pop تُزيل دائماً آخر عنصر.

  4. الحلقة: for (let i = 0; i <= arr.length; i++) { console.log(arr[i]); } على مصفوفة بها 3 عناصر. ما المشكلة؟

    • لا مشكلة
    • يجب أن يبدأ i من 1
    • الشرط <= يجعلها تقرأ الفهرس 3 غير الموجود فتطبع undefined في النهاية
    • arr.length لا يعمل داخل الحلقات
    الإجابة والشرح

    الإجابة الصحيحة: الشرط <= يجعلها تقرأ الفهرس 3 غير الموجود فتطبع undefined في النهاية

    الفهارس الصحيحة 0 و 1 و 2، والشرط i <= 3 يضيف دورة رابعة. الحل هو استخدام i < arr.length.

  5. ما الناتج؟ const arr = [1, 2, 3]; arr.push(4); console.log(arr);

    • خطأ لأن arr معرّف بـ const
    • [1, 2, 3]
    • [4]
    • [1, 2, 3, 4]
    الإجابة والشرح

    الإجابة الصحيحة: [1, 2, 3, 4]

    const تمنع إعادة إسناد المتغير لكنها لا تمنع تعديل محتوى المصفوفة. push تعدّل المصفوفة نفسها فتنجح العملية.
