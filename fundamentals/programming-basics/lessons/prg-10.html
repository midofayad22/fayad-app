Conditional Statements

الشروط تسمح للبرنامج بتنفيذ تعليمات مختلفة بناءً على تحقق شرط معين.

في JavaScript نستخدم غالبًا if و else.

الفكرة

إذا تحقق الشرط

نفذ مجموعة التعليمات الأولى.

إذا لم يتحقق

انتقل إلى التعليمات البديلة.

القرار خطوة بخطوة

جملة if تنفّذ الكتلة التي بين الأقواس المعقوفة فقط إذا كان الشرط true. ويمكن إضافة else if لشروط أخرى وelse لما عداها. تُفحص الشروط بالترتيب وتُنفَّذ أول كتلة صحيحة فقط.

const score = 72;
if (score >= 90) {
console.log("A");
} else if (score >= 70) {
console.log("B");   // هذه تُنفَّذ، ثم يتوقف الفحص
} else {
console.log("C");
}

ترتيب الشروط مهم

لو كتبنا score >= 50 قبل score >= 90 فسيدخل صاحب 95 في الشرط الأول ولن يصل إلى الثاني أبدًا. ابدأ بالشرط الأكثر تحديدًا.

دمج الشروط

استخدم && و|| لبناء شرط واحد من عدة شروط:

const age = 17, hasParent = true;
if (age >= 18 || (age >= 15 && hasParent)) {
console.log("مسموح");
} else {
console.log("غير مسموح");
}

ثلاثة أخطاء شائعة: استخدام = بدل === داخل الشرط، ونسيان الأقواس المعقوفة، وترتيب الشروط بشكل خاطئ.

الفكرة الأساسية

الشروط تحول البرنامج من مجموعة أوامر ثابتة إلى برنامج يستطيع اتخاذ قرارات.

تطبيق

تحدَّ نفسك

تمرين تفاعلي

المتغير score = 72. أنشئ متغيرًا باسم result بالقيمة "pass" إذا كان score ≥ 50، وإلا "fail"، مستخدمًا if / else.

اختبر نفسك

  1. ما الذي تستخدمه if؟

    • لتخزين الصور
    • لاتخاذ قرار بناءً على شرط
    • لتكرار النص فقط
    • لإنشاء ملف
    الإجابة والشرح

    الإجابة الصحيحة: لاتخاذ قرار بناءً على شرط

    if تجعل البرنامج يختار مسارًا بحسب نتيجة شرط (true أو false)، وهذا هو معنى اتخاذ القرار.

  2. ما الذي يُطبع؟ let n = 5; if (n > 10) { console.log("A"); } else if (n > 3) { console.log("B"); } else { console.log("C"); }

    • A
    • B
    • C
    • B ثم C
    الإجابة والشرح

    الإجابة الصحيحة: B

    الشرط الأول خاطئ (5 ليست أكبر من 10)، والثاني صحيح (5 > 3) فتُنفَّذ كتلة B ويتوقف الفحص.

  3. أي شرط يتحقق عندما تكون age بين 18 و65 (شاملة)؟

    • age >= 18 || age <= 65
    • age >= 18 && age <= 65
    • age > 18 && age < 65
    • age = 18 && age = 65
    الإجابة والشرح

    الإجابة الصحيحة: age >= 18 && age <= 65

    نحتاج تحقق الشرطين معًا فنستخدم &&. أما || فتكون صحيحة لأي عمر تقريبًا، وعلامة = تُسند ولا تقارن.

  4. ما الخطأ في: if (x = 5) { ... }

    • لا شيء، هو صحيح
    • يجب استخدام === للمقارنة بدل =
    • يجب حذف الأقواس
    • x يجب أن يكون نصًا
    الإجابة والشرح

    الإجابة الصحيحة: يجب استخدام === للمقارنة بدل =

    = تُسند القيمة 5 إلى x ثم تُعتبر النتيجة شرطًا صحيحًا دائمًا. المقارنة تكون بـ ===.

  5. الكود: if (n > 3) { console.log("big"); } else if (n > 10) { console.log("huge"); } مع n = 20. ما المشكلة؟

    • يطبع big فقط ولن يطبع huge أبداً لأن الشرط الأول يلتقط كل القيم الأكبر من 3
    • يطبع huge لأن 20 أكبر من 10
    • يطبع big ثم huge
    • يظهر خطأ صياغة
    الإجابة والشرح

    الإجابة الصحيحة: يطبع big فقط ولن يطبع huge أبداً لأن الشرط الأول يلتقط كل القيم الأكبر من 3

    سلسلة else if تتوقف عند أول شرط صحيح، و20 أكبر من 3 فينفذ الفرع الأول. يجب وضع الشرط الأكثر تحديداً أولاً (n > 10).
