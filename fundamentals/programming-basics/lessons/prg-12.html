FUNCTIONS

اكتب مرة واستخدم الكود عدة مرات

ما هي Function؟

Function هي كتلة من الكود مصممة لتنفيذ مهمة محددة ويمكن استدعاؤها عند الحاجة.

استخدام Functions يساعد على تنظيم المشروع وتقليل تكرار الكود.

Reusable

يمكن إعادة استخدام الدالة أكثر من مرة.

Organized

تجعل المشروع مقسمًا إلى أجزاء واضحة.

الفكرة الأساسية

Function تجمع مجموعة تعليمات تحت اسم واحد لتصبح سهلة الاستخدام وإعادة الاستخدام.

مثال عملي

شاهد الفكرة في كود

JavaScript 
function greet() {
console.log("Welcome to FAYBIT");
}
greet();

تحدَّ نفسك

اختبر نفسك

  1. ما فائدة Function؟

    • تكرار وتنظيم مجموعة تعليمات
    • تغيير لون الشاشة
    • زيادة سرعة الإنترنت
    • حذف البرنامج
    الإجابة والشرح

    الإجابة الصحيحة: تكرار وتنظيم مجموعة تعليمات

  2. ما الذي يطبعه الكود؟ function double(n) { return n * 2; } console.log(double(double(3)));

    • 6
    • 12
    • 9
    • undefined
    الإجابة والشرح

    الإجابة الصحيحة: 12

    الاستدعاء الداخلي double(3) يعيد 6 ثم يُمرر إلى الاستدعاء الخارجي فيعيد 12. القيمة المُعادة تستخدم مباشرة كمدخل للاستدعاء التالي.

  3. الدالة: function add(a, b) { a + b; } ثم console.log(add(2, 3)). لماذا تظهر undefined؟

    • لأن الدالة تحتاج ثلاثة معاملات
    • لأن الجمع لا يعمل داخل الدوال
    • لأن الدالة لا تحتوي على return فتعيد undefined
    • لأن اسم add محجوز
    الإجابة والشرح

    الإجابة الصحيحة: لأن الدالة لا تحتوي على return فتعيد undefined

    الدالة حسبت الجمع لكنها لم تُرجعه. بدون return تُعيد الدالة undefined دائماً مهما كانت العمليات داخلها.

  4. نسخت حساب الضريبة في خمسة أماكن من برنامجك، ثم تغيّر معدل الضريبة. لماذا كانت الدالة أفضل؟

    • لأن الدوال تجعل البرنامج أسرع بخمس مرات
    • لأن الحساب يكتب مرة واحدة ويُستدعى حيث يلزم، فيكفي تعديل مكان واحد
    • لأن الدوال لا تحتوي على أخطاء
    • لأن النسخ غير مسموح في JavaScript
    الإجابة والشرح

    الإجابة الصحيحة: لأن الحساب يكتب مرة واحدة ويُستدعى حيث يلزم، فيكفي تعديل مكان واحد

    الدالة تمنع التكرار وتجعل التعديل في مكان واحد. النسخ المتعدد يترك نسخاً قديمة منسية فيظهر سلوك غير متسق.

  5. ماذا يطبع الكود؟ function f() { return 1; console.log("x"); } console.log(f());

    • x ثم 1
    • 1 ثم x
    • 1 فقط
    • x فقط
    الإجابة والشرح

    الإجابة الصحيحة: 1 فقط

    return ينهي تنفيذ الدالة فوراً، فلا يصل التنفيذ إلى سطر console.log("x") أبداً. يُطبع 1 فقط من الاستدعاء الخارجي.
