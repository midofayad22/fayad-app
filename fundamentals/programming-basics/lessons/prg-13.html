Parameters & Arguments

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

FUNCTIONS

اجعل Functions أكثر مرونة

Parameters

Parameter هو متغير تستقبله Function لكي تتمكن من التعامل مع بيانات مختلفة.

Arguments

Argument هي القيمة الفعلية التي نرسلها إلى Function عند استدعائها.

الفكرة الأساسية

Parameters تجعل Function قابلة لإعادة الاستخدام مع بيانات مختلفة بدل كتابة Function جديدة لكل حالة.

مثال عملي

شاهد الفكرة في كود

JavaScript 
function greet(name) {
console.log("Hello " + name);
}
greet("Ali");
greet("Mona");

اختبر نفسك

    الإجابة الصحيحة: Parameter

  2. ما الناتج؟ function greet(name, greeting) { return greeting + ", " + name; } console.log(greet("Ali", "Hi"));

    • Ali, Hi
    • Hi, Ali
    • Hi Ali
    • undefined
    الإجابة والشرح

    الإجابة الصحيحة: Hi, Ali

    الوسائط تُطابق المعاملات بالترتيب: "Ali" إلى name و "Hi" إلى greeting. ترتيب الدمج داخل الدالة يعطي Hi, Ali.

  3. ماذا يطبع الكود؟ function f(a, b) { return a + b; } console.log(f(2));

    • 2
    • خطأ يوقف البرنامج
    • 0
    • NaN
    الإجابة والشرح

    الإجابة الصحيحة: NaN

    المعامل b لم يستلم وسيطاً فقيمته undefined، و 2 + undefined تعطي NaN. JavaScript لا ترمي خطأ عند نقص الوسائط.

  4. ما الناتج؟ function p(x, y = 10) { return x + y; } console.log(p(1));

    • 11
    • 1
    • NaN
    • 10
    الإجابة والشرح

    الإجابة الصحيحة: 11

    القيمة الافتراضية y = 10 تُستخدم عندما لا يُمرَّر وسيط ثانٍ، فيكون الناتج 1 + 10 = 11. الناتج NaN يظهر فقط بدون قيمة افتراضية.

  5. ما قيمة v؟ function change(n) { n = 99; } let v = 5; change(v); console.log(v);

    • 99
    • 5
    • undefined
    • خطأ
    الإجابة والشرح

    الإجابة الصحيحة: 5

    الأرقام تُمرَّر كنسخة من القيمة، فتعديل n داخل الدالة لا يغيّر v الخارجي. لذلك تبقى v تساوي 5.
