ما هو Variable؟

المتغير هو اسم نستخدمه للإشارة إلى قيمة مخزنة يمكن للبرنامج استخدامها أثناء التنفيذ.

في JavaScript يمكنك إنشاء المتغيرات باستخدام let و const.

let

تستخدم عندما تتوقع أن تتغير القيمة.

const

تستخدم عندما لا تريد إعادة إسناد القيمة.

اختيار الاسم: القواعد والعُرف

اسم المتغير يجب أن يبدأ بحرف أو _ أو $، ولا يحتوي مسافات أو شرطات، وحالة الأحرف مهمة: score غير Score. العُرف في JavaScript هو camelCase.

let userName = "Sara";   // جيد: يصف المحتوى
let x1 = "Sara";         // صالح لكنه لا يعبّر
let user-name = 1;       // خطأ: الشرطة عامل طرح
let 2score = 5;          // خطأ: لا يبدأ برقم

الاسم الجيد يوفّر عليك تعليقًا كاملًا: remainingLives أوضح من r.

let أم const؟ قاعدة عملية

ابدأ دائمًا بـ const. حوّلها إلى let فقط إذا احتجت فعلًا إلى إعادة الإسناد. هذا يمنعك من تغيير قيمة بالخطأ، ويُعلِم من يقرأ الكود بما يتغير وما لا يتغير.

const pi = 3.14159;   // لن تتغير
let lives = 3;          // ستتغير أثناء اللعبة
lives = lives - 1;      // مسموح
pi = 3;                 // TypeError: Assignment to constant variable.

الإسناد ليس مساواة رياضية

علامة = تعني: «احسب الطرف الأيمن ثم خزّن النتيجة في الاسم الذي على اليسار». لذلك x = x + 1 سطر منطقي: خذ القيمة الحالية، أضف 1، واحفظها مجددًا.

let count = 5;
count = count + 1;   // 6
count += 1;          // اختصار: 7
console.log(count);  // 7

تمرين تفاعلي

أنشئ متغيرًا باسم name يحتوي اسمك (نص) ومتغيرًا باسم age يحتوي عمرك (رقم)، ثم اطبع الاثنين بـ console.log.

اختبر نفسك

  1. أي كلمة تستخدم لتعريف متغير يمكن تغيير قيمته؟

    • const
    • let
    • fixed
    • change
    الإجابة والشرح

    الإجابة الصحيحة: let

    let تسمح بإعادة إسناد قيمة جديدة لنفس الاسم، أما const فتثبّت الإسناد. fixed و change ليستا كلمتين محجوزتين في JavaScript.

  2. ماذا يحدث عند تنفيذ الكود: const a = 1; a = 2;

    • يطبع 2
    • يظهر خطأ TypeError
    • يبقى a يساوي 1 دون أي خطأ
    • لا شيء، السطر يُتجاهل
    الإجابة والشرح

    الإجابة الصحيحة: يظهر خطأ TypeError

    المتغير المعرّف بـ const لا يقبل إعادة الإسناد، فتتوقف JavaScript وتُظهر: Assignment to constant variable.

  3. أي اسم متغير صالح ويتبع العُرف المتبع؟

    • 2score
    • user-name
    • userName
    • let
    الإجابة والشرح

    الإجابة الصحيحة: userName

    userName صالح ومكتوب بنمط camelCase. 2score يبدأ برقم، وuser-name فيه شرطة تُفهم كعامل طرح، وlet كلمة محجوزة.

  4. ما قيمة x بعد: let x = 5; x = x + 3;

    • 5
    • 3
    • 8
    • 53
    الإجابة والشرح

    الإجابة الصحيحة: 8

    يُحسب الطرف الأيمن أولًا (5 + 3 = 8) ثم تُخزَّن النتيجة في x.

  5. ما الذي يطبعه هذا الكود؟ let a = 1; let b = a; b = 5; console.log(a, b);

    • 5 5
    • 1 5
    • 1 1
    • 5 1
    الإجابة والشرح

    الإجابة الصحيحة: 1 5

    عند b = a تُنسخ القيمة 1 إلى b، فيصبحان مستقلين. تغيير b إلى 5 لا يؤثر على a الذي يبقى 1.
