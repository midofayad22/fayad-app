التكرار الذاتي Recursion

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

RECURSION

دالة تستدعي نفسها لحل مشكلة أصغر

أهداف الدرس

  • تفهم الحالة الأساسية والحالة التكرارية.
  • تتتبع تنفيذ دالة تكرارية على الورق.
  • تعرف متى تفضّل الحلقة على Recursion.

المتطلبات السابقة

  • درس Functions (prg-12) ودرس Scope (prg-14).

الفكرة

بعض المشكلات تحوي نسخة أصغر من نفسها. حاصل 5! يساوي 5 × 4!، وحاصل 4! يساوي 4 × 3! وهكذا. فبدل حلقة، نكتب دالة تحل الحالة الأصغر بنفسها. لكل دالة تكرارية جزءان لا غنى عنهما:

  • الحالة الأساسية Base Case: حالة بسيطة تُحل مباشرة وتوقف التكرار.
  • الحالة التكرارية Recursive Case: تنادي الدالة نفسها على مدخل أقرب إلى الحالة الأساسية.

ماذا يحدث داخل الذاكرة؟

كل استدعاء يحجز إطارًا جديدًا في Call Stack يحمل قيمة n الخاصة به. الاستدعاءات تتراكم حتى نصل إلى الحالة الأساسية، ثم تعود النتائج وتُفكّ الإطارات بالترتيب العكسي.

مثال ثانٍ: جمع عناصر مصفوفة

Recursion أم حلقة؟

الحلقة أبسط وأسرع في المسائل الخطية. تتفوق Recursion حين تكون البنية نفسها متداخلة: المجلدات داخل مجلدات، أو الأشجار، أو التقسيم إلى نصفين كما في البحث الثنائي.

أخطاء شائعة

  • نسيان الحالة الأساسية.
  • استدعاء الدالة بنفس المدخل فلا تقترب من النهاية.
  • نسيان return أمام الاستدعاء التكراري فتعود undefined.
تمرين ما ناتج factorial(0) في الدالة أعلاه ولماذا؟
عرض الحل

يعود 1 لأن الشرط n <= 1 يتحقق فيعمل الحالة الأساسية مباشرة، وهو يوافق التعريف الرياضي 0! = 1.

الخلاصة

  • حالة أساسية + حالة تكرارية أصغر.
  • كل استدعاء له إطار في Call Stack.
  • اختر الحلقة للمسائل الخطية وRecursion للبنى المتداخلة.

الخطوة التالية: نخزّن البيانات بأشكال مختلفة: Stack وQueue وMap.

الفكرة الأساسية

Recursion تحل المشكلة بحلّ نسخة أصغر منها، وتتوقف عند الحالة الأساسية.

مثال عملي

شاهد الفكرة في كود

JavaScript 
function countdown(n) {
if (n === 0) { console.log("Go!"); return; }
console.log(n);
countdown(n - 1);
}
countdown(3);

تحدَّ نفسك

تمرين تفاعلي

اكتب دالة تكرارية factorial(n) تعيد حاصل ضرب 1 × 2 × … × n (و 0! = 1).

اختبر نفسك

  1. ما وظيفة الحالة الأساسية؟

    • إيقاف التكرار عند أبسط حالة
    • تسريع الكمبيوتر
    • حذف المتغيرات
    • طباعة النتيجة
    الإجابة والشرح

    الإجابة الصحيحة: إيقاف التكرار عند أبسط حالة

    بدونها تستمر الاستدعاءات حتى ينفد المكدس.

  2. ماذا يحدث عند حذف الحالة الأساسية من factorial؟

    • RangeError: تجاوز حجم المكدس
    • يعود 0
    • يعود 1 دائمًا
    • لا شيء
    الإجابة والشرح

    الإجابة الصحيحة: RangeError: تجاوز حجم المكدس

    الاستدعاءات لا تنتهي فيمتلئ Call Stack.

  3. أي بنية بيانات تناسب Recursion طبيعيًا؟

    • الأشجار والمجلدات المتداخلة
    • رقم واحد
    • لون
    • صورة
    الإجابة والشرح

    الإجابة الصحيحة: الأشجار والمجلدات المتداخلة

    كل عقدة تحوي أشجارًا أصغر، فيناسبها حل يكرر نفسه.

  4. ما sum([1,2]) بحسب الدالة؟

    • 3
    • 2
    • 1
    • undefined
    الإجابة والشرح

    الإجابة الصحيحة: 3

    1 + sum([2]) = 1 + (2 + sum([])) = 1 + 2 + 0.

  5. ما الناتج؟ function pow2(n) { if (n === 0) return 1; return 2 * pow2(n - 1); } console.log(pow2(5));

    • 10
    • 25
    • 32
    • 16
    الإجابة والشرح

    الإجابة الصحيحة: 32

    الدالة تضرب 2 في نفسها خمس مرات قبل أن تصل للحالة الأساسية n === 0 التي تعيد 1، أي 2*2*2*2*2*1 = 32. القيمة 10 تنتج عن الجمع لا الضرب.
