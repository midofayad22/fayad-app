التعقيد الزمني Big-O

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

COMPLEXITY

كيف يتغير الزمن عندما تكبر البيانات؟

أهداف الدرس

  • تفهم ماذا يعني O(n) وO(n²).
  • تقارن بين حلّين لنفس المشكلة.
  • تحسّن حلًا بطيئًا باستخدام بنية مناسبة.

المتطلبات السابقة

  • درس Loops (prg-11) ودرس هياكل البيانات (prg-22).

لا نقيس بالثواني

زمن التنفيذ بالثواني يتغير بحسب الجهاز. لذلك نصف الخوارزمية بكيفية نموّ عدد الخطوات مع حجم المدخل n. هذا هو Big-O: يعطي الحد الأعلى التقريبي للنمو ويتجاهل الثوابت.

الرمزالاسممثال
O(1)ثابتالوصول لعنصر بفهرسه list[3]
O(log n)لوغاريتميالبحث الثنائي
O(n)خطيالمرور على كل عنصر مرة
O(n²)تربيعيحلقة داخل حلقة على نفس البيانات

مثال: البحث عن تكرار

مع 1000 عنصر يفحص الحل الأول نحو نصف مليون مقارنة، والثاني ألف خطوة فقط. ومع مليون عنصر يصبح الأول غير عملي (نحو 500 مليار مقارنة) بينما يبقى الثاني سريعًا.

أخطاء شائعة

  • تحسين الشيفرة قبل قياس المشكلة (Premature Optimization).
  • الاعتقاد أن O(n²) سيئ دائمًا؛ مع بيانات صغيرة جدًا قد يكون كافيًا وأوضح.
تمرين ما تعقيد حلقتين متتاليتين (لا متداخلتين) كل منهما على n عنصر؟
عرض الحل

O(n): نجمع n + n = 2n، والثابت 2 يُتجاهل في Big-O.

الخلاصة

  • Big-O يصف نمو الخطوات لا الثواني.
  • حلقة داخل حلقة غالبًا O(n²).
  • البنية المناسبة قد تحوّل O(n²) إلى O(n).

الخطوة التالية: أساليب التفكير المختلفة في البرمجة: Paradigms.

الفكرة الأساسية

الخوارزمية الجيدة هي التي يبقى زمنها مقبولًا حين تكبر البيانات.

مثال عملي

شاهد الفكرة في كود

JavaScript 
const data = Array.from({ length: 5 }, (_, i) => i * 2);
let steps = 0;
for (const x of data) { steps++; }
console.log("n =", data.length, "steps =", steps);

تحدَّ نفسك

تمرين تفاعلي

اكتب hasDuplicate(arr) بتعقيد O(n) باستخدام Set. سيُختبر على 200 ألف عنصر، والحل التربيعي سيتجاوز الزمن.

اختبر نفسك

  1. ما تعقيد حلقة for واحدة تمر على n عنصر؟

    • O(n)
    • O(1)
    • O(n²)
    • O(log n)
    الإجابة والشرح

    الإجابة الصحيحة: O(n)

    عدد الخطوات يتناسب طرديًا مع n.

  2. ما تعقيد حلقتين متداخلتين على n عنصر؟

    • O(n²)
    • O(n)
    • O(1)
    • O(2n)
    الإجابة والشرح

    الإجابة الصحيحة: O(n²)

    لكل عنصر في الحلقة الخارجية نمر على n في الداخلية.

  3. لماذا نتجاهل الثوابت في Big-O؟

    • لأن ما يهم هو شكل النمو عند الأحجام الكبيرة
    • لأنها خاطئة
    • لأن الحاسوب لا يعدّها
    • لا سبب
    الإجابة والشرح

    الإجابة الصحيحة: لأن ما يهم هو شكل النمو عند الأحجام الكبيرة

    عند n الكبير يطغى شكل النمو على الثابت.

  4. ما فائدة Set في hasDuplicateFast؟

    • يجعل التحقق من وجود قيمة سريعًا
    • يرتّب المصفوفة
    • يحذف المصفوفة
    • يطبع النتيجة
    الإجابة والشرح

    الإجابة الصحيحة: يجعل التحقق من وجود قيمة سريعًا

    has() لا تمسح كل العناصر.

  5. ما تعقيد هذا الكود بالنسبة لـ n؟ for (const x of arr) { f(x); } ثم بعده مباشرة (وليس بداخله) for (const y of arr) { g(y); }

    • O(n)
    • O(n squared)
    • O(1)
    • O(log n)
    الإجابة والشرح

    الإجابة الصحيحة: O(n)

    الحلقتان متتاليتان فيكون الجهد n + n = 2n، وبحذف الثابت يصبح O(n). التربيع يحدث فقط عند تداخل الحلقات.
