لغات البرمجة

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

LANGUAGES

لماذا توجد لغات برمجة كثيرة؟

لغة البرمجة هي وسيلة للتواصل مع الكمبيوتر

توجد لغات كثيرة لأن كل لغة صممت لتناسب أنواعًا معينة من المشاريع والمشكلات.

JavaScript

أساسية لتطوير الويب والتفاعل داخل صفحات الويب.

Python

مشهورة بالتعلم السهل والذكاء الاصطناعي والبيانات.

C / C++

تستخدم في الأنظمة والبرمجيات عالية الأداء.

Java

تستخدم في تطبيقات وأنظمة ومشاريع كبيرة ومتنوعة.

الفكرة الأساسية

لا توجد لغة برمجة واحدة هي الأفضل لكل شيء؛ اختيار اللغة يعتمد على المشكلة والمنصة ومتطلبات المشروع.

تطبيق

تحدَّ نفسك

اختبر نفسك

  1. لماذا توجد لغات برمجة متعددة؟

    • لأن كل اللغات متطابقة
    • لأن لكل لغة استخدامات وخصائص مختلفة
    • لزيادة حجم الملفات
    • لأن الكمبيوتر لا يستطيع التعلم
    الإجابة والشرح

    الإجابة الصحيحة: لأن لكل لغة استخدامات وخصائص مختلفة

  2. تريد جعل صفحة ويب تتفاعل مع ضغطات الزائر داخل المتصفح. أي لغة هي الخيار الطبيعي؟

    • JavaScript
    • C لكتابة نظام تشغيل
    • SQL
    • Assembly
    الإجابة والشرح

    الإجابة الصحيحة: JavaScript

    المتصفحات تشغّل JavaScript مباشرة، فهي اللغة المخصصة للتفاعل في الويب. SQL مخصصة للاستعلام عن قواعد البيانات لا لواجهات المتصفح.

  3. تعلمت JavaScript جيداً وتريد الآن تعلم Python. ما الذي ينتقل معك بسهولة؟

    • الصياغة بحروفها وفواصلها بالضبط
    • المفاهيم مثل المتغيرات والشروط والحلقات والدوال
    • لا شيء، كل لغة عالم مستقل
    • أسماء المكتبات الجاهزة
    الإجابة والشرح

    الإجابة الصحيحة: المفاهيم مثل المتغيرات والشروط والحلقات والدوال

    اللغات تختلف في الصياغة لكن الأفكار الأساسية مشتركة. لذلك تعلم لغة ثانية أسرع بكثير من الأولى.

  4. لماذا نكتب بلغات عالية المستوى مثل JavaScript بدل كتابة لغة الآلة مباشرة؟

    • لأن المعالج يفهم JavaScript مباشرة
    • لأنها أقرب إلى لغة البشر ويتولى مترجم أو مفسّر تحويلها إلى لغة الآلة
    • لأن لغة الآلة ممنوعة قانونياً
    • لأن اللغات العالية لا تحتاج أي ترجمة
    الإجابة والشرح

    الإجابة الصحيحة: لأنها أقرب إلى لغة البشر ويتولى مترجم أو مفسّر تحويلها إلى لغة الآلة

    المعالج لا يفهم إلا تعليمات ثنائية، لذا لا بد من ترجمة الشيفرة. اللغات العالية المستوى تجعل الكتابة أسهل وأقل أخطاء.

  5. فريق يبني نواة نظام تشغيل ويحتاج تحكماً دقيقاً في الذاكرة وأداءً عالياً. أي اختيار أنسب؟

    • لغة نظم قريبة من العتاد مثل C أو Rust
    • لغة تنسيق مثل CSS
    • أداة جداول بيانات
    • لغة نصوص تُشغَّل داخل المتصفح فقط
    الإجابة والشرح

    الإجابة الصحيحة: لغة نظم قريبة من العتاد مثل C أو Rust

    اختيار اللغة يتبع المهمة، وتتيح لغات النظم التحكم بالذاكرة والأداء. لغات المتصفح لا تصل إلى هذا المستوى من العتاد.
