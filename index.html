02 / UNDERSTAND

قبل أن تتعلم الكود

ما هو Web Development؟

قبل أن تبدأ في حفظ Tags أو Properties أو JavaScript Methods، لازم تفهم الصورة الكبيرة: كيف يعمل الويب؟ وأين يوجد دورك كمطور؟

THE BIG PICTURE

الموقع الذي تراه أمامك نتيجة تعاون أكثر من جزء.

عندما تفتح موقعًا في المتصفح، هناك Browser يعرض الواجهة، وFrontend يبني الجزء الذي تتفاعل معه، وBackend يتعامل مع البيانات والمنطق والخدمات في الخلفية.

01

Browser

البرنامج الذي يستخدمه المستخدم للوصول إلى صفحات الويب وتشغيل HTML وCSS وJavaScript.

02

Frontend

كل ما يراه المستخدم ويتفاعل معه مباشرة داخل الموقع.

HTML CSS JavaScript
03

Backend

الجزء الذي يعمل خلف الكواليس ويتعامل مع البيانات، السيرفر، قواعد البيانات والخدمات.

04 / THE CORE

تقنيات الويب الأساسية

كل تقنية لها وظيفة.

لا تتعلم HTML وCSS وJavaScript كأنها ثلاث لغات منفصلة. افهم كيف تعمل معًا لبناء واجهة واحدة.

01
STRUCTURE

HTML

يبني هيكل الصفحة ويعطي المحتوى معناه.

<h1> Hello World </h1>
02
PRESENTATION

CSS

يتحكم في شكل الصفحة، layout، الألوان، والمساحات.

.button { display: flex; }
03
BEHAVIOR

JavaScript

يضيف المنطق، التفاعل، البيانات والسلوك الديناميكي.

button .addEventListener ("click", ...)

HTML يبني الهيكل → CSS ينسق المظهر → JavaScript يضيف السلوك.

06 / FRAMEWORKS

بعد الأساسيات

What is a Framework؟

Framework ليس اختصارًا لتعلم الأساسيات. هو مجموعة أدوات وقواعد تساعدك على بناء تطبيقات أكبر بطريقة منظمة.

CHOOSE BY PURPOSE

لا يوجد Framework واحد هو الأفضل للجميع.

React

Library
  • Flexible
  • Huge ecosystem
  • Component-based

Vue

Progressive Framework
  • Beginner-friendly
  • Simple learning curve
  • Flexible

Angular

Full Framework
  • Full ecosystem
  • Structured architecture
  • Large applications
