المسار التعليمي

المسار التعليمي

أربع مراحل مرتّبة. اتبعها بالترتيب، أو ابدأ من المرحلة التي تناسبك.

الأساسيات

افهم كيف يعمل الحاسوب وكيف يفكر المبرمج قبل أي لغة.

  • CS Computer Fundamentals من العتاد والمعالج والذاكرة إلى أنظمة التشغيل والشبكات والأمن السيبراني.
  • { } Programming Fundamentals المتغيرات والشروط والحلقات والدوال والمصفوفات والكائنات وحل المشكلات.

أساسيات الويب

ابنِ الصفحة وصمّمها وأضف التفاعل: HTML وCSS وJavaScript.

  • HTML HTML بنية الصفحة والنصوص والروابط والجداول والنماذج والعناصر الدلالية وإمكانية الوصول.
  • CSS CSS المحددات ونموذج الصندوق وFlexbox وGrid والتصميم المتجاوب والحركة.
  • JS JavaScript أساسيات اللغة وDOM والأحداث والوحدات وPromises وFetch.

تعمّق وأدوات

JavaScript المتقدم، وأطر CSS الجاهزة لتسريع العمل.

  • +JS Advanced JavaScript النطاق والـ Closures والـ prototypes وProxy والمولدات وحلقة الأحداث والـ async وأنماط التصميم.
  • BS Bootstrap 5 الشبكة والأدوات المساعدة والنماذج والمكونات التفاعلية والوضع الداكن وRTL (Bootstrap 5.3).
  • TW Tailwind CSS فلسفة Utility-First والتخطيط والتجاوب والحالات والوضع الداكن والتخصيص بـ @theme (Tailwind v4).

أطر العمل

ابنِ واجهات كاملة بإطار حديث: اختر React أو Vue أو Angular.

  • Re React المكونات وJSX وProps وState وHooks والتوجيه وبنية التطبيق.
  • Vue Vue القوالب والتفاعلية والمكونات وComposition API وVue Router.
  • Ng Angular المكونات والقوالب والتوجيهات والخدمات والتوجيه والنماذج وRxJS.
