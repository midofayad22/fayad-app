حلقة الأحداث: Microtasks و Macrotasks

افهم ترتيب تنفيذ الكود المتزامن واللامتزامن بدقة.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

Call Stack وطوابير المهام

JavaScript تنفذ على خيط واحد. الكود المتزامن يعمل أولًا على الـ Call Stack. عند فراغه تنفذ الـ Event Loop كل Microtasks (Promise.then وqueueMicrotask) ثم مهمة واحدة من Macrotasks (setTimeout وأحداث DOM) وتكرر.

Microtasks تنفذ كلها قبل أي Macrotask، حتى لو كان setTimeout بصفر.

مثال برمجي

كود JavaScript

console.log("1 sync");
setTimeout(() => console.log("5 timeout"), 0);
Promise.resolve().then(() => console.log("3 promise"));
queueMicrotask(() => console.log("4 microtask"));
(async () => {
console.log("2 inside async (sync part)");
await null;
console.log("4b after await");
})();
console.log("2b sync end");
1 sync
2 inside async (sync part)
2b sync end
3 promise
4 microtask
4b after await
5 timeout

فهم الكود

الجزء الأول من دالة async ينفذ فورًا. كل ما بعد await ينتقل إلى طابور الـ microtasks، وتنفذ كلها قبل أن يصل الدور إلى setTimeout.

  3. أين يستأنف الكود بعد await؟

    • كـ Microtask

    الإجابة والشرح

    الإجابة الصحيحة: كـ Microtask

  4. ما ترتيب الطباعة؟ console.log("1"); setTimeout(() => console.log("2")); Promise.resolve().then(() => console.log("3")); console.log("4");

    • 1 ثم 2 ثم 3 ثم 4
    • 1 ثم 4 ثم 2 ثم 3
    • 1 ثم 3 ثم 4 ثم 2
    • 1 ثم 4 ثم 3 ثم 2
    الإجابة والشرح

    الإجابة الصحيحة: 1 ثم 4 ثم 3 ثم 2

    الكود المتزامن يعمل أولاً فتُطبع 1 و 4، ثم تُفرغ طابور microtasks فتُطبع 3، وأخيراً تأتي macrotask الخاصة بالمؤقت فتُطبع 2.

  5. ما ترتيب الطباعة؟ async function f() { console.log("a"); await null; console.log("b"); } f(); console.log("c");

    • a ثم c ثم b
    • a ثم b ثم c
    • c ثم a ثم b
    • a ثم c فقط
    الإجابة والشرح

    الإجابة الصحيحة: a ثم c ثم b

    الدالة async تعمل بشكل متزامن حتى أول await فتطبع a، ثم تتوقف ويعود التحكم للمستدعي فتُطبع c. الجزء بعد await يُجدول كـ microtask فيطبع b أخيراً.
