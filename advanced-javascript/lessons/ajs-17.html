أنماط async/await العملية

التنفيذ المتسلسل مقابل المتوازي، وإعادة المحاولة، والمهلة، ومعالجة الأخطاء الصحيحة.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

تسلسلي أم متوازٍ؟

استخدام await داخل حلقة ينفذ العمليات واحدة بعد أخرى. إن كانت مستقلة فابدأها كلها ثم انتظرها معًا بـ Promise.all لتوفير الوقت.

إعادة المحاولة والمهلة

كثير من العمليات الشبكية تفشل مؤقتًا. اكتب دالة retry بعدد محاولات محدد، وسباقًا مع مؤقت لفرض مهلة.

لا تضع await داخل حلقة إذا كانت العمليات مستقلة.

مثال برمجي

كود JavaScript

const wait = (ms, v) => new Promise((r) => setTimeout(() => r(v), ms));
async function retry(fn, times) {
let lastError;
for (let i = 1; i <= times; i++) {
try { return await fn(i); }
catch (e) { lastError = e; console.log("attempt", i, "failed"); }
}
throw lastError;
}
const withTimeout = (p, ms) =>
Promise.race([p, new Promise((_, j) => setTimeout(() => j(new Error("timeout")), ms))]);
(async () => {
const v = await retry(async (n) => { if (n < 3) throw new Error("flaky"); return "ok on " + n; }, 5);
console.log(v);
const t0 = Date.now();
await Promise.all([wait(40), wait(40), wait(40)]);
console.log("parallel under 110ms:", Date.now() - t0 < 110);
try { await withTimeout(wait(100), 10); } catch (e) { console.log(e.message); }
})();
attempt 1 failed
attempt 2 failed
ok on 3
parallel under 110ms: true
timeout

فهم الكود

ثلاث عمليات انتظار 40ms تنتهي في ~40ms معًا لا 120ms لأنها بدأت في وقت واحد. دالة retry تحتفظ بآخر خطأ وترميه إذا استنفدت المحاولات.

جرّب بنفسك

اختبر نفسك

  1. لماذا نستخدم Promise.all للعمليات المستقلة؟

    • لتنفيذها بالتوازي وتقليل الزمن الكلي
    • لتقليل عدد الأخطاء
    • لأنها تحذف await
    • لتشفيرها
    الإجابة والشرح

    الإجابة الصحيحة: لتنفيذها بالتوازي وتقليل الزمن الكلي

  2. كيف نفرض مهلة على وعد؟

    • Promise.race مع وعد يرفض بعد المهلة
    • setTimeout فقط
    • console.log
    • typeof
    الإجابة والشرح

    الإجابة الصحيحة: Promise.race مع وعد يرفض بعد المهلة

  3. ما الغرض من retry؟

    • إعادة محاولة العملية عند الفشل المؤقت
    • تسريع المتصفح
    • حذف الأخطاء
    • إنشاء Promise جديد دائمًا
    الإجابة والشرح

    الإجابة الصحيحة: إعادة محاولة العملية عند الفشل المؤقت

  4. ما ترتيب الطباعة؟ [1, 2].forEach(async n => { await null; console.log(n); }); console.log("end");

    • 1 ثم 2 ثم end
    • end ثم 1 ثم 2
    • end فقط
    • 1 ثم end ثم 2
    الإجابة والشرح

    الإجابة الصحيحة: end ثم 1 ثم 2

    forEach لا تنتظر الـ promises التي تعيدها دوال async، فتكمل فوراً وتُطبع end أولاً. للانتظار الحقيقي نستخدم for...of مع await أو Promise.all مع map.

  5. ماذا يطبع الكود؟ async function f() { try { return Promise.reject(new Error("x")); } catch { return "caught"; } } f().catch(e => console.log(e.message));

    • caught
    • x
    • لا شيء
    • undefined
    الإجابة والشرح

    الإجابة الصحيحة: x

    return دون await يمرر الـ promise المرفوض للخارج قبل أن يلتقطه try، فلا يعمل catch الداخلي. لو كتبنا return await لالتقطه catch وطبعنا caught.
