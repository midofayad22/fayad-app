Prototypes وسلسلة الوراثة

كيف تعمل الوراثة فعلًا في JavaScript من خلال الكائنات النموذجية.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

Prototype Chain

لكل كائن رابط داخلي إلى كائن آخر هو prototype. عند قراءة خاصية غير موجودة يبحث المحرك في السلسلة حتى Object.prototype ثم null.

أدوات

  • Object.create(proto) ينشئ كائنًا برابط مباشر.
  • Object.getPrototypeOf(obj) لقراءة الرابط.
  • hasOwn للتمييز بين الخاصية الخاصة والموروثة.

الوراثة في JavaScript تفويض عبر السلسلة، لا نسخ للخصائص.

مثال برمجي

كود JavaScript

const animal = {
speak() { return this.name + " makes a sound"; },
};
const dog = Object.create(animal);
dog.name = "Rex";
console.log(dog.speak());
console.log(Object.hasOwn(dog, "speak"), "speak" in dog);
console.log(Object.getPrototypeOf(dog) === animal);
function Person(name) { this.name = name; }
Person.prototype.hi = function () { return "hi " + this.name; };
const p = new Person("Mona");
console.log(p.hi(), p instanceof Person);
Rex makes a sound
false true
true
hi Mona true

فهم الكود

speak غير موجودة على dog نفسه لذا hasOwn ترجع false لكن عامل in يبحث في السلسلة فيرجع true. الدوال المنشئة تضع الأساليب على prototype لمشاركتها بين كل الكائنات.

اختبر نفسك

  1. كيف يبحث المحرك عن خاصية غير موجودة على الكائن؟

    • يتتبع سلسلة prototype حتى null
    • يرمي خطأ فورًا
    • يبحث في النطاق العام فقط
    • ينشئها تلقائيًا
    الإجابة والشرح

    الإجابة الصحيحة: يتتبع سلسلة prototype حتى null

  2. ماذا تفعل Object.hasOwn؟

    • تتحقق أن الخاصية موجودة على الكائن نفسه لا الموروثة
    • تحذف الخاصية
    • تنسخ الكائن
    • تبحث في السلسلة كلها
    الإجابة والشرح

    الإجابة الصحيحة: تتحقق أن الخاصية موجودة على الكائن نفسه لا الموروثة

  3. أين تُوضع الأساليب المشتركة في الدوال المنشئة؟

    • على Constructor.prototype
    • داخل كل كائن
    • في النطاق العام
    • في localStorage
    الإجابة والشرح

    الإجابة الصحيحة: على Constructor.prototype

  4. ما ناتج الكود؟ function A() {} A.prototype.hi = function () {}; const a = new A(); console.log(a.hasOwnProperty("hi"), "hi" in a);

    • true true
    • false true
    • true false
    • false false
    الإجابة والشرح

    الإجابة الصحيحة: false true

    الدالة hi موجودة على A.prototype وليست خاصية ذاتية للكائن a، فتعيد hasOwnProperty قيمة false. أما عامل in فيبحث في سلسلة prototype أيضاً فيعيد true.

  5. ما ناتج console.log("toString" in Object.create(null))؟

    • true لأن كل كائن يرث toString
    • undefined
    • خطأ TypeError
    • false لأن الكائن بلا prototype فلا يرث شيئاً
    الإجابة والشرح

    الإجابة الصحيحة: false لأن الكائن بلا prototype فلا يرث شيئاً

    Object.create(null) ينشئ كائناً بدون prototype، فلا تصله خصائص Object.prototype مثل toString. لذلك هو مناسب كقاموس خالٍ من الخصائص الموروثة.
