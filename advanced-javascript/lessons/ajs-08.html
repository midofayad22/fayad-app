الوراثة بين الكلاسات و Mixins

extends وsuper وتعدد السلوكيات عبر Mixins وتفضيل التركيب على الوراثة.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

extends و super

extends تربط prototype الكلاس الابن بالأب. super() في الـ constructor إلزامية قبل استخدام this، وsuper.method() تستدعي نسخة الأب.

التركيب أولًا

سلاسل الوراثة العميقة تصبح هشة. عندما تحتاج سلوكًا مشتركًا من أكثر من مصدر استخدم Mixins أو مرّر الاعتماديات (Composition).

فضّل التركيب (has-a) على الوراثة (is-a) إلا عند علاقة حقيقية.

مثال برمجي

كود JavaScript

class Shape {
constructor(name) { this.name = name; }
area() { return 0; }
describe() { return this.name + " area=" + this.area().toFixed(1); }
}
class Circle extends Shape {
constructor(r) { super("circle"); this.r = r; }
area() { return Math.PI * this.r ** 2; }
describe() { return super.describe() + "!"; }
}
console.log(new Circle(2).describe());
const Serializable = (Base) => class extends Base {
toJSON() { return { type: this.name }; }
};
class Tagged extends Serializable(Shape) {}
console.log(JSON.stringify(new Tagged("tag")));
console.log(new Circle(1) instanceof Shape);
circle area=12.6!

true

فهم الكود

Serializable دالة تأخذ كلاسًا وتُرجع كلاسًا جديدًا يرثه، وهكذا نضيف سلوكًا دون تعقيد التسلسل الهرمي.

    • لأن الكائن لا يُنشأ إلا بعد تنفيذ constructor الأب
    • للسرعة
    • اختياري
    • لأنها تحذف الأب

    • إضافة سلوك مشترك دون سلسلة وراثة عميقة
    • حذف الكلاسات
    • تسريع الشبكة
    • تشفير البيانات

    • بناء الكائنات من أجزاء مستقلة بدل التوسع في الهرم
    • عدم استخدام الكلاسات
    • استخدام var
    • عدم كتابة اختبارات
    الإجابة والشرح

    الإجابة الصحيحة: بناء الكائنات من أجزاء مستقلة بدل التوسع في الهرم

  4. ما ناتج الكود؟ class A { hi() { return "A"; } } class B extends A { hi() { return super.hi() + "B"; } } console.log(new B().hi());

    • B
    • A
    • AB
    • BA
    الإجابة والشرح

    الإجابة الصحيحة: AB

    super.hi() يستدعي نسخة الأب فتعيد A، ثم تضيف الابنة B فتصبح AB. override لا يلغي الأب بل يسمح بالبناء عليه.

  5. ما ناتج الكود؟ const Fly = Base => class extends Base { fly() { return "fly"; } }; class Bird extends Fly(Object) {} console.log(new Bird().fly(), new Bird() instanceof Bird);

    • fly true
    • fly false
    • undefined true
    • خطأ لأن الكلاس لا يعاد من دالة
    الإجابة والشرح

    الإجابة الصحيحة: fly true

    الكلاس قيمة عادية في JavaScript فيمكن لدالة أن تنشئ كلاساً يمتد من Base الممرر، وهذا نمط mixin. Bird يرث fly عبر السلسلة ويبقى instanceof لنفسه صحيحاً.
