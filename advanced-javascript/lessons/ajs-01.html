النطاق والرفع و TDZ

افهم كيف يبحث المحرك عن المتغيرات، وما الذي يحدث فعلًا عند الرفع (Hoisting)، ولماذا يوجد Temporal Dead Zone.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

Scope Chain

كل دالة وكل كتلة { } (مع let و const) تنشئ نطاقًا. عند قراءة متغير يبحث المحرك في النطاق الحالي ثم في النطاق الأب وهكذا حتى النطاق العام، وتسمى هذه السلسلة Scope Chain.

الرفع و TDZ

تُرفع التصريحات إلى أعلى نطاقها لكن بحالات مختلفة: var تبدأ بقيمة undefined، أما let و const فتبقى غير مهيأة حتى سطر التصريح، وأي وصول قبله يرمي ReferenceError. هذه الفترة تسمى Temporal Dead Zone.

var ترتفع بقيمة undefined، و let/const ترتفع لكنها غير قابلة للاستخدام قبل سطر التصريح.

مثال برمجي

كود JavaScript

console.log(typeof hoisted);
var hoisted = 1;
console.log(hoisted);
try {
console.log(late);
} catch (e) {
console.log(e.name);
}
let late = 2;
const x = "global";
function outer() {
const x = "outer";
function inner() {
return x;
}
return inner();
}
console.log(outer());
undefined
1
ReferenceError
outer

فهم الكود

المتغير hoisted موجود قبل سطره بقيمة undefined. أما late فقراءته قبل التصريح ترمي ReferenceError. وinner ترى x الخاص بـ outer لأنه أقرب نطاق في السلسلة.

اختبر نفسك

  1. ما قيمة var المرفوعة قبل سطر التصريح؟

    • undefined
    • null
    • ReferenceError
    • 0
    الإجابة والشرح

    الإجابة الصحيحة: undefined

  2. ماذا يحدث عند قراءة let قبل تصريحها؟

    • يُرمى ReferenceError
    • تكون undefined
    • تكون null
    • تُنشأ تلقائيًا
    الإجابة والشرح

    الإجابة الصحيحة: يُرمى ReferenceError

  3. ما المقصود بـ Scope Chain؟

    • سلسلة النطاقات التي يبحث فيها المحرك عن المتغير من الأقرب للأبعد
    • ترتيب تنفيذ الدوال
    • قائمة الأخطاء
    • ترتيب الملفات
    الإجابة والشرح

    الإجابة الصحيحة: سلسلة النطاقات التي يبحث فيها المحرك عن المتغير من الأقرب للأبعد

  4. ما ناتج الكود؟ console.log(typeof f, typeof g); function f() {} var g = function () {};

    • undefined undefined
    • function function
    • خطأ ReferenceError عند g
    • function undefined
    الإجابة والشرح

    الإجابة الصحيحة: function undefined

    تصريح الدالة f يُرفع مع جسمها كاملاً فيكون نوعها function. أما g فمتغير var يُرفع التصريح فقط بقيمة undefined، ولا تُسند الدالة إلا عند وصول التنفيذ إلى السطر.

  5. ماذا يحدث؟ let x = 1; { console.log(x); let x = 2; }

    • يطبع 1 لأنه يستخدم x الخارجي
    • يطبع undefined
    • يرمي ReferenceError لأن x الداخلية في TDZ حتى سطر تعريفها
    • يطبع 2
    الإجابة والشرح

    الإجابة الصحيحة: يرمي ReferenceError لأن x الداخلية في TDZ حتى سطر تعريفها

    let داخل البلوك تظلل x الخارجي من بداية البلوك كله، لكنها غير قابلة للقراءة قبل تصريحها، وهذه هي TDZ. لذلك لا يُستخدم x الخارجي ولا تكون القيمة undefined.
