Closures

الدالة التي تتذكر النطاق الذي وُلدت فيه: أساس الخصوصية والحالة المخبأة في JavaScript.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

ما هو Closure؟

الـ Closure هو دالة مع إشارة إلى بيئتها المعجمية (المتغيرات المحيطة بها وقت تعريفها). تبقى هذه المتغيرات حيّة ما دامت الدالة قابلة للاستدعاء حتى بعد انتهاء الدالة الخارجية.

استخدامات عملية

  • عدادات وحالة خاصة لا يمكن الوصول إليها من الخارج.
  • مصانع الدوال (Function Factories).
  • معالجات الأحداث التي تحتاج بيانات من وقت الإنشاء.

كل استدعاء للدالة الخارجية ينشئ بيئة جديدة مستقلة، والدوال الداخلية تحتفظ بها.

مثال برمجي

كود JavaScript

function makeCounter(start = 0) {
let count = start;
return {
inc: () => ++count,
value: () => count,
};
}
const a = makeCounter();
const b = makeCounter(10);
a.inc();
a.inc();
b.inc();
console.log(a.value(), b.value());
const fns = [];
for (var i = 0; i < 3; i++) fns.push(() => i);
console.log(fns.map((f) => f()));
const fns2 = [];
for (let j = 0; j < 3; j++) fns2.push(() => j);
console.log(fns2.map((f) => f()));
2 11
[ 3, 3, 3 ]
[ 0, 1, 2 ]

فهم الكود

كل عداد له count خاص به. مع var توجد نسخة واحدة من i يشاركها الجميع فتصبح 3. مع let تُنشأ نسخة جديدة لكل دورة.

جرّب بنفسك

اختبر نفسك

  1. لماذا تعطي حلقة var مع دوال مؤجلة نفس القيمة؟

    • لأن هناك متغيرًا واحدًا مشتركًا في نطاق الدالة
    • لأن var أبطأ
    • لأن الدوال لا تتذكر شيئًا
    • بسبب خطأ في المحرك
    الإجابة والشرح

    الإجابة الصحيحة: لأن هناك متغيرًا واحدًا مشتركًا في نطاق الدالة

  2. ماذا يضمن الـ Closure؟

    • بقاء المتغيرات المحيطة متاحة للدالة
    • تنفيذ الدالة مرتين
    • منع الأخطاء
    • تسريع الكود
    الإجابة والشرح

    الإجابة الصحيحة: بقاء المتغيرات المحيطة متاحة للدالة

  3. كيف نخفي حالة داخلية عن الخارج؟

    • بتعريفها داخل دالة وإرجاع دوال تستخدمها فقط
    • بتسميتها بحرف كبير
    • باستخدام console.log
    • لا يمكن
    الإجابة والشرح

    الإجابة الصحيحة: بتعريفها داخل دالة وإرجاع دوال تستخدمها فقط

  4. ما ناتج الكود؟ const mk = () => { let c = 0; return () => ++c; }; const a = mk(), b = mk(); a(); a(); console.log(a(), b());

    • 3 و 1
    • 3 و 3
    • 1 و 1
    • 2 و 1
    الإجابة والشرح

    الإجابة الصحيحة: 3 و 1

    كل استدعاء لـ mk ينشئ نطاقاً جديداً بمتغير c مستقل تحتفظ به الدالة المعادة. لذلك a تعد وحدها حتى 3، و b تبدأ من 1.

  5. ما ناتج الكود؟ let n = 1; const f = () => n; n = 2; console.log(f());

    • 1 لأن الدالة نسخت القيمة عند إنشائها
    • 2 لأن closure تحتفظ بالمتغير نفسه لا بنسخة من قيمته
    • undefined
    • خطأ لأن n تغيرت بعد الإنشاء
    الإجابة والشرح

    الإجابة الصحيحة: 2 لأن closure تحتفظ بالمتغير نفسه لا بنسخة من قيمته

    الـ closure تلتقط الربط بالمتغير وليس قيمته وقت الإنشاء، فترى التغييرات اللاحقة. لذلك تُقرأ القيمة الحالية 2 عند الاستدعاء.
