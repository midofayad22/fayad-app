AbortController والـ Async Iterators

إلغاء العمليات الجارية وقراءة التدفقات اللامتزامنة بـ for await...of.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

إلغاء العمليات

AbortController ينتج signal تمرره إلى العملية (مثل fetch). استدعاء abort() يجعل العملية ترفض بخطأ AbortError وتتوقف.

Async Iterators

المولد اللامتزامن async function* ينتج قيمًا عبر الزمن، ونقرؤه بـ for await...of. مناسب للتدفقات والصفحات المتتابعة.

مرّر signal وتحقق منه، وتعامل مع الإلغاء كحالة عادية لا خطأ مفاجئ.

مثال برمجي

كود JavaScript

const sleep = (ms, signal) => new Promise((resolve, reject) => {
const t = setTimeout(resolve, ms);
signal?.addEventListener("abort", () => {
clearTimeout(t);
reject(signal.reason);
});
});
(async () => {
const ctrl = new AbortController();
setTimeout(() => ctrl.abort(new Error("cancelled")), 10);
try { await sleep(200, ctrl.signal); }
catch (e) { console.log(e.message); }
async function* pages() {
for (let p = 1; p <= 3; p++) {
await sleep(5);
yield [p * 10, p * 10 + 1];
}
}
const all = [];
for await (const items of pages()) all.push(...items);
console.log(all);
})();
cancelled
[ 10, 11, 20, 21, 30, 31 ]

فهم الكود

الإلغاء يمنع الانتظار الكامل (200ms). المولد اللامتزامن يسلّم صفحات متتابعة، وfor await تنتظر كل صفحة قبل الانتقال للتالية.

  4. ما الناتج؟ const c = new AbortController(); c.signal.addEventListener("abort", () => console.log("ab")); c.abort(); c.abort(); console.log(c.signal.aborted);

    • ab ثم ab ثم true
    • ab ثم true
    • true فقط

    الإجابة والشرح

    الإجابة الصحيحة: ab ثم true

    الإلغاء يحدث مرة واحدة فقط، والاستدعاءات التالية لـ abort لا تفعل شيئاً ولا تُطلق الحدث ثانية. وبعده تصبح signal.aborted تساوي true.

  5. ماذا يُطبع؟ async function* g() { try { yield 1; yield 2; } finally { console.log("cleanup"); } } (async () => { for await (const x of g()) { console.log(x); break; } })();

    • 1 فقط
    • 1 ثم 2 ثم cleanup
    • 1 ثم cleanup
    • cleanup ثم 1
    الإجابة والشرح

    الإجابة الصحيحة: 1 ثم cleanup

    الخروج المبكر من for await بـ break يستدعي return للمولد، فتنفذ كتلة finally فتُطبع cleanup بعد 1. لذلك نضع التنظيف في finally ليعمل حتى عند التوقف المبكر.
