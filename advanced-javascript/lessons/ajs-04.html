Higher-Order Functions

الدالة عالية المرتبة تأخذ دالة كوسيط أو تُرجع دالة. map وfilter وreduce أمثلة معروفة، ويمكنك بناء أدواتك.

Currying والتركيب

Currying تحويل دالة متعددة الوسائط إلى سلسلة دوال بوسيط واحد. Pipe تمرر النتيجة من دالة لأخرى من اليسار لليمين.

ابنِ الدوال الصغيرة النقية ثم ركّبها بدل كتابة دالة ضخمة واحدة.

مثال برمجي

كود JavaScript

const curry = (fn) => function curried(...args) {
return args.length >= fn.length
? fn(...args)
: (...more) => curried(...args, ...more);
};
const add3 = curry((a, b, c) => a + b + c);
console.log(add3(1)(2)(3), add3(1, 2)(3));
const pipe = (...fns) => (x) => fns.reduce((v, f) => f(v), x);
const slugify = pipe(
(s) => s.trim(),
(s) => s.toLowerCase(),
(s) => s.replace(/\s+/g, "-"),
);
console.log(slugify("  Advanced JS Course "));

فهم الكود

fn.length هو عدد الوسائط المعلنة، فنستمر في جمع الوسائط حتى تكتمل. pipe تستخدم reduce لتمرير القيمة عبر سلسلة التحويلات.

اختبر نفسك

  1. ما الدالة عالية المرتبة؟

    • دالة تأخذ دالة أو تُرجع دالة
    • دالة بأكثر من 5 وسائط
    • دالة داخل كائن
    • دالة async
    الإجابة والشرح

    الإجابة الصحيحة: دالة تأخذ دالة أو تُرجع دالة

  2. ما هو Currying؟

    • تحويل دالة متعددة الوسائط إلى دوال بوسيط واحد متتالية
    • نسخ الدوال
    • حذف الدوال
    • تسريع الحلقات
    الإجابة والشرح

    الإجابة الصحيحة: تحويل دالة متعددة الوسائط إلى دوال بوسيط واحد متتالية

  3. بماذا تختلف pipe عن compose؟

    • pipe من اليسار لليمين و compose من اليمين لليسار
    • لا فرق إطلاقًا
    • pipe للأرقام فقط
    • compose غير موجودة
    الإجابة والشرح

    الإجابة الصحيحة: pipe من اليسار لليمين و compose من اليمين لليسار

  4. ما ناتج الكود؟ const add = a => b => a + b; console.log([1, 2].map(add(10)));

    • [11, 12]
    • [10, 10]
    • [1, 2]
    • [NaN, NaN]
    الإجابة والشرح

    الإجابة الصحيحة: [11, 12]

    add(10) تعيد دالة تنتظر b وتتذكر a = 10، و map تمرر لها كل عنصر. هذا مثال على currying وتطبيق جزئي.

  5. إذا كانت inc = x => x + 1 و dbl = x => x * 2، فما ناتج compose(inc, dbl)(5) و pipe(inc, dbl)(5) على الترتيب؟

    • 12 و 12
    • 11 و 12
    • 12 و 11
    • 11 و 11
    الإجابة والشرح

    الإجابة الصحيحة: 11 و 12

    compose تطبق الدوال من اليمين: dbl(5) = 10 ثم inc = 11. pipe تطبقها من اليسار: inc(5) = 6 ثم dbl = 12.
