Promise.all و allSettled و race و any

نسّق عدة عمليات لا متزامنة بالاستراتيجية الصحيحة لكل حالة.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

المقارنة

  • all: تنتظر الجميع وتفشل عند أول فشل.
  • allSettled: تنتظر الجميع وتعيد حالة كل واحد.
  • race: أول واحد ينتهي (نجاحًا أو فشلًا).
  • any: أول نجاح، وتفشل فقط إذا فشل الجميع.

اختر all عندما تحتاج كل النتائج، وallSettled عندما يجوز أن يفشل بعضها.

مثال برمجي

كود JavaScript

const ok = (v, ms) => new Promise((r) => setTimeout(() => r(v), ms));
const fail = (m, ms) => new Promise((_, j) => setTimeout(() => j(new Error(m)), ms));
(async () => {
console.log(await Promise.all([ok("a", 20), ok("b", 5)]));
try { await Promise.all([ok("a", 20), fail("boom", 5)]); }
catch (e) { console.log("all failed:", e.message); }
const settled = await Promise.allSettled([ok("x", 5), fail("no", 5)]);
console.log(settled.map((s) => s.status));
console.log(await Promise.race([ok("slow", 30), ok("fast", 5)]));
console.log(await Promise.any([fail("e1", 5), ok("winner", 15)]));
})();
[ 'a', 'b' ]
all failed: boom
[ 'fulfilled', 'rejected' ]
fast
winner

فهم الكود

ترتيب النتائج في all يطابق ترتيب المدخلات لا ترتيب الانتهاء. any تتجاهل الفشل المبكر وتنتظر أول نجاح.

  3. ماذا تعيد Promise.any عند فشل الجميع؟

    • ترفض بـ AggregateError
    • تنجح بمصفوفة فارغة
    • تعيد undefined

    الإجابة والشرح

  4. ما ناتج الكود؟ Promise.allSettled([Promise.resolve(1), Promise.reject("x")]).then(r => console.log(r.map(i => i.status)));

    • ["fulfilled", "rejected"]
    • ["fulfilled"]
    • لا شيء، ويظهر خطأ غير معالج
    • [1, "x"]
    الإجابة والشرح

    الإجابة الصحيحة: ["fulfilled", "rejected"]

    allSettled لا ترفض أبداً بسبب أحد العناصر، وتعيد كائناً لكل promise فيه status و value أو reason. لذلك يعمل then وتظهر الحالتان.

  5. promise يُرفض بعد 10ms وآخر يتحقق بعد 50ms. ما نتيجة Promise.race عليهما، وما نتيجة Promise.any؟

    • race تتحقق بنتيجة الثاني و any ترفض
    • race و any كلاهما يرفضان
    • race و any كلاهما يتحققان بنتيجة الثاني
    • race ترفض لأن الأول انتهى أولاً و any تتحقق بنتيجة الثاني
    الإجابة والشرح

    الإجابة الصحيحة: race ترفض لأن الأول انتهى أولاً و any تتحقق بنتيجة الثاني

    race تتبع أول promise ينتهي سواء بنجاح أو رفض، وهنا الرفض عند 10ms. any تتجاهل الرفض وتنتظر أول نجاح فتتحقق بالقيمة الثانية.
