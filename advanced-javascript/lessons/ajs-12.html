function* و yield

الدالة المولدة function* ترجع Iterator. عند yield تتوقف وتسلم قيمة، ويكمل الاستدعاء التالي من نفس المكان بحالتها المحفوظة.

كسل وتدفقات

لا تُحسب القيمة إلا عند طلبها، لذا يمكن تعريف تسلسل لا نهائي وأخذ الجزء المطلوب منه فقط. ويمكن تمرير قيم إلى المولد عبر next(value).

yield يوقف التنفيذ ويحفظ الحالة، وnext(value) يعيد قيمة إلى داخل المولد.

مثال برمجي

كود JavaScript

function* naturals() {
let n = 1;
while (true) yield n++;
}
function* take(iter, count) {
let i = 0;
for (const v of iter) {
if (i++ >= count) return;
yield v;
}
}
console.log([...take(naturals(), 5)]);
function* conversation() {
const name = yield "name?";
const lang = yield "language?";
return name + " likes " + lang;
}
const g = conversation();
console.log(g.next().value);
console.log(g.next("Sara").value);
console.log(g.next("JS"));
[ 1, 2, 3, 4, 5 ]
name?
language?
{ value: 'Sara likes JS', done: true }

فهم الكود

التسلسل naturals لا نهائي لكنه لا يعلّق البرنامج لأن take تطلب 5 قيم فقط. في المحادثة تُرسل الإجابات عبر next.

اختبر نفسك

  1. ماذا يحدث عند yield؟

    • تتوقف الدالة وتسلم القيمة وتحفظ حالتها
    • تنتهي الدالة نهائيًا
    • ترمي خطأ
    • تتكرر من البداية
    الإجابة والشرح

    الإجابة الصحيحة: تتوقف الدالة وتسلم القيمة وتحفظ حالتها

  2. لماذا يمكن تعريف تسلسل لا نهائي بمولد؟

    • لأن القيم تُحسب عند الطلب فقط
    • لأن الذاكرة لا نهائية
    • لأن المولد ينسخ المصفوفات
    • لا يمكن
    الإجابة والشرح

    الإجابة الصحيحة: لأن القيم تُحسب عند الطلب فقط

  3. ماذا يفعل next('x')؟

    • يعيد 'x' كنتيجة لتعبير yield المتوقف
    • يحذف المولد
    • يضيف عنصرًا للمصفوفة
    • يغير اسم الدالة
    الإجابة والشرح

    الإجابة الصحيحة: يعيد 'x' كنتيجة لتعبير yield المتوقف

  4. ما ناتج الكود؟ function* g() { yield 1; yield 2; return 3; } console.log([...g()]);

    • [1, 2, 3]
    • [1, 2]
    • [3]
    • [1, 2, undefined]
    الإجابة والشرح

    الإجابة الصحيحة: [1, 2]

    الـ spread والحلقات تتوقف عندما تصبح done تساوي true ولا تأخذ قيمة return. لذلك تظهر القيم المنتجة بـ yield فقط.

  5. مع نفس المولد function* g() { yield 1; yield 2; return 3; } و it = g() و it.next() مرة، ماذا تعيد الاستدعاءات الثلاثة التالية على الترتيب؟

    • {value:2,done:false} ثم {value:3,done:true} ثم {value:undefined,done:true}
    • {value:2,done:false} ثم {value:3,done:false} ثم {value:undefined,done:true}
    • {value:2,done:true} ثم {value:3,done:true} ثم خطأ
    • {value:2,done:false} ثم {value:undefined,done:true} ثم {value:undefined,done:true}
    الإجابة والشرح

    الإجابة الصحيحة: {value:2,done:false} ثم {value:3,done:true} ثم {value:undefined,done:true}

    return تعيد قيمتها مع done: true مرة واحدة، وبعدها يبقى المولد منتهياً فيعيد value غير معرّفة. لذلك ظهرت 3 مع done صحيحة ثم undefined.
