Proxy و Reflect

اعترض العمليات على الكائنات لبناء التحقق والتسجيل والقيم الافتراضية.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

Proxy

new Proxy(target, handler) يغلف كائنًا ويعترض عمليات مثل get وset وhas وdeleteProperty عبر دوال تسمى traps.

Reflect

Reflect يوفر نفس العمليات الافتراضية كدوال، فتستدعيها داخل الـ trap للحفاظ على السلوك الأصلي.

ارجع دائمًا بـ Reflect.set/get داخل الـ traps للحفاظ على السلوك الصحيح.

مثال برمجي

كود JavaScript

const validator = {
set(target, key, value, receiver) {
if (key === "age" && !Number.isInteger(value)) {
throw new TypeError("age must be an integer");
}
return Reflect.set(target, key, value, receiver);
},
get(target, key, receiver) {
return key in target ? Reflect.get(target, key, receiver) : "n/a";
},
};
const person = new Proxy({}, validator);
person.age = 30;
console.log(person.age, person.name);
try { person.age = "x"; } catch (e) { console.log(e.message); }
const logs = [];
const tracked = new Proxy({ n: 1 }, {
set(t, k, v) { logs.push(k + "=" + v); t[k] = v; return true; },
});
tracked.n = 2; tracked.m = 3;
console.log(logs);
30 n/a
age must be an integer
[ 'n=2', 'm=3' ]

فهم الكود

الـ Proxy الأول يتحقق من القيم قبل الكتابة ويعيد قيمة افتراضية للمفاتيح غير الموجودة. الثاني يسجل كل تعديل دون تغيير الكائن الأصلي.

اختبر نفسك

  1. ما الـ trap؟

    • دالة في handler تعترض عملية على الكائن
    • نوع من الأخطاء
    • حلقة
    • مكتبة خارجية
    الإجابة والشرح

    الإجابة الصحيحة: دالة في handler تعترض عملية على الكائن

  2. لماذا نستخدم Reflect داخل الـ traps؟

    • لتنفيذ السلوك الافتراضي بشكل صحيح
    • لإبطاء الكود
    • لتعطيل Proxy
    • لإنشاء كلاسات
    الإجابة والشرح

    الإجابة الصحيحة: لتنفيذ السلوك الافتراضي بشكل صحيح

  3. أي مما يلي استخدام مناسب للـ Proxy؟

    • التحقق من القيم وتسجيل التغييرات
    • تلوين الصفحة
    • تحميل الصور
    • تشفير كلمات المرور
    الإجابة والشرح

    الإجابة الصحيحة: التحقق من القيم وتسجيل التغييرات

  4. ما ناتج الكود؟ const p = new Proxy({}, { set(t, k, v) { t[k] = v * 2; return true; } }); p.x = 5; console.log(p.x);

    • 5
    • undefined
    • خطأ لأن set لا تعدل القيمة
    • 10
    الإجابة والشرح

    الإجابة الصحيحة: 10

    الـ trap المسمى set يعترض عملية الإسناد ويحدد ما يُخزّن في الهدف، فيخزن 10. القراءة p.x لا تملك trap فتمر إلى الهدف مباشرة.

  5. ما ناتج الكود؟ const p = new Proxy({}, { get: (t, k) => (k in t ? t[k] : 0) }); console.log(p.a, p.b + 1);

    • 0 و 1
    • undefined و NaN
    • 0 و NaN
    • 0 و 0
    الإجابة والشرح

    الإجابة الصحيحة: 0 و 1

    الـ trap المسمى get يعيد 0 لأي مفتاح غير موجود بدل undefined، فتكون p.a تساوي 0 و p.b + 1 تساوي 1. هذا يوضح كيف يغير Proxy سلوك القراءة.
