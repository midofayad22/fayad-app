Memoization و Debounce و Throttle

تقنيات عملية للأداء: التخزين المؤقت للنتائج وضبط عدد الاستدعاءات.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

Memoization

تخزين نتيجة دالة نقية لكل مدخل حتى لا تُحسب مرتين. المفتاح عادةً من المدخلات.

Debounce و Throttle

Debounce ينفذ الدالة بعد توقف الاستدعاءات لمدة محددة (مثل البحث أثناء الكتابة). Throttle ينفذها بحد أقصى مرة كل فترة (مثل التمرير).

Memoization للدوال النقية فقط، وDebounce يؤخر بينما Throttle يحدّ.

مثال برمجي

كود JavaScript

const memo = (fn) => {
const cache = new Map();
return (n) => {
if (cache.has(n)) return cache.get(n);
const v = fn(n);
cache.set(n, v);
return v;
};
};
let calls = 0;
const square = memo((n) => { calls++; return n * n; });
square(4); square(4); square(5);
console.log("calls:", calls);
const debounce = (fn, ms) => {
let t;
return (...a) => {
clearTimeout(t);
t = setTimeout(() => fn(...a), ms);
};
};
const log = debounce((v) => console.log("saved", v), 20);
log("a"); log("b"); log("c");
calls: 2
saved c

فهم الكود

الاستدعاء الثاني لـ square(4) جاء من الـ cache فلم يزد العداد. في debounce كل استدعاء يلغي المؤقت السابق فلا ينفذ إلا الأخير.

اختبر نفسك

  1. متى تكون Memoization آمنة؟

    • مع الدوال النقية التي لا تعتمد على حالة خارجية
    • مع أي دالة
    • مع الدوال غير المتزامنة فقط
    • لا تكون آمنة أبدًا
    الإجابة والشرح

    الإجابة الصحيحة: مع الدوال النقية التي لا تعتمد على حالة خارجية

  2. ماذا يفعل Debounce؟

    • يؤخر التنفيذ حتى تتوقف الاستدعاءات
    • ينفذ كل استدعاء فورًا
    • يمنع الدالة نهائيًا
    • يكرر الدالة
    الإجابة والشرح

    الإجابة الصحيحة: يؤخر التنفيذ حتى تتوقف الاستدعاءات

  3. أي تقنية تناسب حدث scroll المتكرر؟

    • Throttle
    • Memoization
    • Currying
    • Hoisting
    الإجابة والشرح

    الإجابة الصحيحة: Throttle

  4. memoize تخزن النتيجة بمفتاح args[0] فقط. ما المشكلة عند استخدامها مع دالة add(a, b)؟

    • add(1, 2) ثم add(1, 5) يعيد الثانية نتيجة الأولى الخاطئة 3 من الذاكرة
    • لا تعمل الذاكرة مع دوال بوسيطين
    • تصبح الدالة أبطأ دائماً
    • لا مشكلة لأن الوسيط الأول يكفي دائماً
    الإجابة والشرح

    الإجابة الصحيحة: add(1, 2) ثم add(1, 5) يعيد الثانية نتيجة الأولى الخاطئة 3 من الذاكرة

    مفتاح التخزين يجب أن يمثل كل المدخلات التي تؤثر في النتيجة، وإلا تتشابه المفاتيح وتعود نتائج قديمة خاطئة. نبني المفتاح من كل args مثلاً JSON.stringify(args).

  5. دالة debounce بانتظار 200ms استُدعيت عند الزمن 0 و 50 و 100ms. متى وكم مرة تُنفذ الدالة الأصلية؟

    • ثلاث مرات عند 200 و 250 و 300
    • مرة واحدة عند 200ms
    • مرة واحدة عند 300ms
    • مرتان عند 0 و 100
    الإجابة والشرح

    الإجابة الصحيحة: مرة واحدة عند 300ms

    كل استدعاء جديد يلغي المؤقت السابق ويبدأ انتظاراً جديداً. آخر استدعاء كان عند 100ms فتُنفذ الدالة مرة واحدة بعد 200ms منه أي عند 300ms.
