Classes: الخصوصية والـ static

بناء كلاسات حديثة بخصائص خاصة وأساليب ثابتة وGetters وSetters.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

السكر النحوي فوق Prototypes

الـ class طريقة أوضح لكتابة نفس نظام الـ prototypes. الأساليب تذهب إلى prototype تلقائيًا.

Private و Static

الحقول التي تبدأ بـ # خاصة فعليًا ولا يمكن الوصول إليها من خارج الكلاس. أعضاء static تنتمي للكلاس نفسه لا للنسخ.

استخدم #private لحماية الحالة، وgetter/setter للتحقق من القيم.

مثال برمجي

كود JavaScript

class Account {
#balance = 0;
static count = 0;
constructor(owner) {
this.owner = owner;
Account.count++;
}
get balance() { return this.#balance; }
deposit(n) {
if (n <= 0) throw new RangeError("amount must be positive");
this.#balance += n;
return this;
}
static compare(a, b) { return a.balance - b.balance; }
}
const a = new Account("Ali").deposit(50).deposit(25);
const b = new Account("Noor").deposit(10);
console.log(a.balance, Account.count);
console.log([a, b].sort(Account.compare).map((x) => x.owner));
console.log(a.balance = 5, a.balance);
try { a.deposit(-1); } catch (e) { console.log(e.name + ": " + e.message); }
75 2
[ 'Noor', 'Ali' ]
5 75
RangeError: amount must be positive

فهم الكود

لا يوجد setter للـ balance لذا الإسناد لا يغير شيئًا (يتجاهل بصمت خارج الوضع الصارم). الحقل #balance لا يمكن الوصول إليه إلا من داخل الكلاس.

اختبر نفسك

  1. ماذا يعني الحقل الذي يبدأ بـ #؟

    • خاص ولا يُقرأ من خارج الكلاس
    • ثابت فقط
    • مؤقت
    • عام
    الإجابة والشرح

    الإجابة الصحيحة: خاص ولا يُقرأ من خارج الكلاس

  2. على ماذا تنتمي أعضاء static؟

    • على الكلاس نفسه لا على النسخ
    • على كل نسخة
    • على prototype فقط
    • على window
    الإجابة والشرح

    الإجابة الصحيحة: على الكلاس نفسه لا على النسخ

  3. ما فائدة getter؟

    • قراءة قيمة محسوبة كأنها خاصية
    • حذف الخاصية
    • تجميد الكائن
    • تكرار الكائن
    الإجابة والشرح

    الإجابة الصحيحة: قراءة قيمة محسوبة كأنها خاصية

  4. ما ناتج الكود؟ class A { #x = 1; } const a = new A(); console.log(a.x, Object.keys(a));

    • 1 و ["x"]
    • 1 و []
    • undefined و []
    • undefined و ["#x"]
    الإجابة والشرح

    الإجابة الصحيحة: undefined و []

    الحقل الخاص #x ليس خاصية عادية اسمها x ولا يظهر في المفاتيح، فتعطي a.x القيمة undefined. لا يُوصل إليه إلا من داخل الكلاس بـ this.#x.

  5. ما ناتج الكود؟ class C { static n = 0; constructor() { C.n++; } } new C(); new C(); console.log(C.n);

    • 0
    • 1
    • 2
    • undefined
    الإجابة والشرح

    الإجابة الصحيحة: 2

    الحقل static ينتمي إلى الكلاس نفسه ويوجد منه نسخة واحدة مشتركة، وكل استدعاء للـ constructor يزيدها. بعد إنشاء كائنين تصبح 2.
