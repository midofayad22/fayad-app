Map و Set و WeakMap و WeakRef

اختر بنية البيانات المناسبة، وافهم المراجع الضعيفة ومتى تفيد في منع تسرب الذاكرة.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

Map و Set

Map يقبل أي نوع مفتاح ويحافظ على ترتيب الإدخال. Set مجموعة قيم فريدة. كلاهما أسرع وأوضح من الكائنات في كثير من الحالات.

المراجع الضعيفة

WeakMap وWeakSet تمسكان بمفاتيح كائنات دون منع جامع القمامة من حذفها. مناسبة لربط بيانات خاصة بكائن دون تسريب ذاكرة. مفاتيحها كائنات فقط ولا يمكن تعدادها.

WeakMap لا تمنع حذف المفتاح من الذاكرة، ولا يمكن المرور على عناصرها.

مثال برمجي

كود JavaScript

const counts = new Map();
for (const w of "to be or not to be".split(" ")) {
counts.set(w, (counts.get(w) ?? 0) + 1);
}
console.log([...counts].filter(([, n]) => n > 1));
const unique = [...new Set([3, 1, 3, 2, 1])];
console.log(unique);
const keyObj = { id: 1 };
const m = new Map([[keyObj, "object key"], [NaN, "nan key"]]);
console.log(m.get(keyObj), m.get(NaN), m.size);
const meta = new WeakMap();
const el = {};
meta.set(el, { clicks: 0 });
meta.get(el).clicks++;
console.log(meta.get(el), meta.has({}));
[ [ 'to', 2 ], [ 'be', 2 ] ]
[ 3, 1, 2 ]
object key nan key 2
{ clicks: 1 } false

فهم الكود

الـ Map يقبل كائنًا وNaN كمفتاح، وهو ما لا تقدمه الكائنات العادية. WeakMap تربط بيانات بالكائن، وتختفي البيانات تلقائيًا إذا اختفى الكائن.

اختبر نفسك

  1. أي بنية تقبل كائنًا كمفتاح مع إمكانية التعداد؟

    • Map
    • Object العادي
    • Array
    • JSON
    الإجابة والشرح

    الإجابة الصحيحة: Map

  2. ما ميزة WeakMap؟

    • لا تمنع جامع القمامة من حذف المفتاح
    • أسرع من Map دائمًا
    • تقبل أي نوع مفتاح
    • قابلة للتعداد
    الإجابة والشرح

    الإجابة الصحيحة: لا تمنع جامع القمامة من حذف المفتاح

  3. كيف تزيل التكرار من مصفوفة بسرعة؟

    • [...new Set(arr)]
    • arr.unique()
    • arr.deleteDuplicates()
    • Object.keys(arr)
    الإجابة والشرح

    الإجابة الصحيحة: [...new Set(arr)]

  4. ما ناتج الكود؟ console.log(new Map([[{}, 1]]).get({}));

    • 1
    • undefined
    • null
    • خطأ
    الإجابة والشرح

    الإجابة الصحيحة: undefined

    مفاتيح Map المأخوذة من كائنات تُقارن بالهوية وليس بالمحتوى، و {} الثانية كائن جديد مختلف عن الأول. لذلك لا يُعثر على المفتاح ونحصل على undefined.

  5. ما ناتج الكود؟ console.log(new Set([{ a: 1 }, { a: 1 }]).size, new Set([NaN, NaN]).size);

    • 1 و 1
    • 1 و 2
    • 2 و 2
    • 2 و 1
    الإجابة والشرح

    الإجابة الصحيحة: 2 و 1

    الكائنان المتشابهان شكلاً مرجعان مختلفان فيبقيان معاً فيكون الحجم 2. أما Set فتعتبر NaN مساوياً لنفسه عكس ===، فيبقى عنصر واحد.
