Symbols والـ Tagged Templates

مفاتيح فريدة غير قابلة للتصادم، وقوالب نصية يمكنك معالجتها بدالة خاصة.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

Symbol

كل Symbol() قيمة فريدة تمامًا. تصلح كمفاتيح خصائص لا تتصادم مع غيرها ولا تظهر في for...in أو Object.keys.

Tagged Templates

عند كتابة tag`نص ${قيمة}` تستدعى الدالة tag بمصفوفة الأجزاء النصية ثم القيم. تُستخدم لتهريب HTML وبناء استعلامات آمنة ولغات مخصصة.

Symbols للمفاتيح الفريدة، والـ tagged templates تتيح معالجة القيم المدرجة قبل بناء النص.

مثال برمجي

كود JavaScript

const id = Symbol("id");
const user = { name: "Lina", [id]: 101 };
console.log(Object.keys(user), user[id]);
console.log(Symbol("a") === Symbol("a"), Symbol.for("a") === Symbol.for("a"));
const escapeHtml = (s) => String(s).replace(/[&<>"']/g, (c) => ({ "&": "&amp;", "<": "&lt;", ">": "&gt;", '"': "&quot;", "'": "&#39;" }[c]));
const html = (strings, ...values) =>
strings.reduce((out, s, i) => out + s + (i < values.length ? escapeHtml(values[i]) : ""), "");
const input = "<script>alert(1)</script>";
console.log(html`<p>${input}</p>`);
[ 'name' ] 101
false true
<p>&lt;script&gt;alert(1)&lt;/script&gt;</p>

فهم الكود

المفتاح id لم يظهر في keys. دالة html تهرّب كل قيمة مدرجة تلقائيًا، فيصبح بناء HTML من مدخلات المستخدم أكثر أمانًا.
