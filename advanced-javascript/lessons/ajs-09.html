Property Descriptors والتجميد

تحكم في قابلية الخاصية للتعديل والعد، وافهم الفرق بين freeze وseal وبين النسخ السطحي والعميق.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

Descriptors

كل خاصية لها صفات: writable وenumerable وconfigurable (أو get/set). تتحكم بها عبر Object.defineProperty.

freeze و structuredClone

Object.freeze سطحي: يمنع تعديل الخصائص المباشرة فقط. للنسخ العميق استخدم structuredClone (لا يدعم الدوال).

freeze سطحي. الكائنات المتداخلة تبقى قابلة للتعديل ما لم تجمدها أيضًا.

مثال برمجي

كود JavaScript

"use strict";
const cfg = {};
Object.defineProperty(cfg, "id", { value: 7, enumerable: false });
console.log(cfg.id, Object.keys(cfg));
try { cfg.id = 8; } catch (e) { console.log(e.name); }
const state = Object.freeze({ user: { name: "A" }, n: 1 });
try { state.n = 2; } catch (e) { console.log("frozen"); }
state.user.name = "B";
console.log(state.user.name);
const deep = structuredClone({ d: new Date(0), list: [1, { x: 2 }] });
console.log(deep.list[1].x, deep.d.getTime());
7 []
TypeError
frozen
B

فهم الكود

الخاصية المعرفة بـ defineProperty بدون writable للقراءة فقط وغير مرئية في keys. التجميد لم يمنع تغيير state.user.name لأنه كائن متداخل.

اختبر نفسك

  1. ماذا تمنع Object.freeze؟

    • تعديل وإضافة وحذف الخصائص المباشرة
    • قراءة الخصائص
    • استخدام الكائن في الحلقات
    • التحويل إلى JSON
    الإجابة والشرح

    الإجابة الصحيحة: تعديل وإضافة وحذف الخصائص المباشرة

  2. ما حد freeze؟

    • سطحي ولا يجمد الكائنات المتداخلة
    • يجمد كل شيء عميقًا
    • يعمل على الأرقام فقط
    • لا يمنع شيئًا
    الإجابة والشرح

    الإجابة الصحيحة: سطحي ولا يجمد الكائنات المتداخلة

  3. ما الذي لا يدعمه structuredClone؟

    • الدوال
    • المصفوفات
    • التواريخ
    • الكائنات المتداخلة
    الإجابة والشرح

    الإجابة الصحيحة: الدوال

  4. ما ناتج الكود؟ const o = {}; Object.defineProperty(o, "id", { value: 1 }); console.log(Object.keys(o), o.id, Object.getOwnPropertyDescriptor(o, "id").writable);

    • ["id"] 1 true
    • [] 1 false
    • ["id"] 1 false
    • [] undefined false
    الإجابة والشرح

    الإجابة الصحيحة: [] 1 false

    عند التعريف بـ defineProperty تكون الخصائص writable و enumerable و configurable مساوية false افتراضياً. لذلك الخاصية غير قابلة للتعديل ولا تظهر في Object.keys لكن قيمتها تُقرأ.

  5. ما ناتج الكود؟ const o = Object.freeze({ list: [1] }); o.list.push(2); console.log(o.list);

    • [1] لأن الكائن مجمّد
    • [1, 2] لأن freeze سطحي ولا يشمل المصفوفة الداخلية
    • خطأ TypeError
    • [2]
    الإجابة والشرح

    الإجابة الصحيحة: [1, 2] لأن freeze سطحي ولا يشمل المصفوفة الداخلية

    freeze يجمّد خصائص الكائن المباشرة فقط، فلا يمكن استبدال list بمصفوفة أخرى. لكن المصفوفة نفسها كائن غير مجمّد فيمكن تعديلها بـ push.
