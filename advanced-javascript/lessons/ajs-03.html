this و call / apply / bind

قواعد تحديد قيمة this في كل حالة، وكيف تتحكم فيها يدويًا.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

القواعد

قيمة this تُحدد وقت الاستدعاء لا وقت التعريف (باستثناء الدوال السهمية):

  1. obj.method(): this هو obj.
  2. استدعاء عادي fn(): undefined في الوضع الصارم.
  3. new F(): الكائن الجديد.
  4. call / apply / bind: القيمة التي تحددها أنت.
  5. الدالة السهمية: ترث this من النطاق المحيط.

الدالة السهمية لا تملك this خاصًا بها، وbind ترجع دالة جديدة مثبتة.

مثال برمجي

كود JavaScript

"use strict";
const user = {
name: "Sara",
hello() { return "Hi " + this.name; },
later() { return [1].map(() => this.name); },
};
console.log(user.hello());
console.log(user.later());
const detached = user.hello;
try {
detached();
} catch (e) {
console.log(e.name);
}
function greet(greeting) { return greeting + ", " + this.name; }
console.log(greet.call({ name: "Omar" }, "Hello"));
console.log(greet.apply({ name: "Lina" }, ["Hey"]));
const bound = greet.bind({ name: "Zain" });
console.log(bound("Yo"));
Hi Sara
[ 'Sara' ]
TypeError
Hello, Omar
Hey, Lina
Yo, Zain

فهم الكود

فصل الدالة عن كائنها (detached) يجعل this قيمته undefined فيرمي الخطأ. call تمرر الوسائط واحدًا واحدًا، وapply كمصفوفة، وbind تنشئ دالة جديدة.

جرّب بنفسك

  1. متى تُحدد قيمة this في الدوال العادية؟

    • وقت التعريف

    • وقت الحفظ

  2. ما الفرق بين call و apply؟

    • call تأخذ الوسائط منفصلة و apply تأخذها في مصفوفة
    • لا فرق
    • apply أسرع دائمًا
    • call للكائنات فقط

    • دالة جديدة مثبتة عليها this
    • نتيجة الدالة
    • undefined
    • كائنًا فارغًا
    الإجابة والشرح
