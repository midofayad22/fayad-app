v-if و v-else

تعلّم كيف تعرض أو تخفي عناصر HTML بناءً على شروط معينة.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

v-if و v-else

تستخدم v-if لعرض عنصر عندما يكون الشرط صحيحًا.

ويمكن استخدام v-else لعرض عنصر بديل عندما يكون الشرط غير صحيح.

v-if تتحكم في العرض

استخدم v-if وv-else لإظهار عناصر مختلفة حسب حالة البيانات.

مثال برمجي

الكود


<div id="app">
<p v-if="isLoggedIn">
مرحبًا بك مرة أخرى!
</p>
<p v-else>
من فضلك قم بتسجيل الدخول.
</p>
</div>
<script>
const { createApp } = Vue;
createApp({
data() {
return {
isLoggedIn: true
};
}
}).mount("#app");
</script>

مرحبًا بك مرة أخرى!

فهم الكود

v-if تختبر الشرط.

إذا كانت القيمة true يظهر العنصر.

v-else يستخدم للفرع الآخر عندما يكون الشرط غير صحيح.

اعرض رسالة مختلفة عندما تكون قيمة isLoggedIn صحيحة أو خاطئة.

  4. ما الخطأ هنا؟ <p v-if="ok">نعم</p> <span>فاصل</span> <p v-else>لا</p>

    • v-else يجب أن يأتي مباشرة بعد عنصر v-if
    • لا يمكن استخدام p مع v-if
    • v-else لا يقبل نصاً
    • لا يوجد خطأ
    الإجابة والشرح

    الإجابة الصحيحة: v-else يجب أن يأتي مباشرة بعد عنصر v-if

    v-else يجب أن يلي v-if أو v-else-if مباشرة، وإلا لن يتعرف Vue عليه.

  5. إذا كانت قيمة الشرط في v-if خاطئة، ماذا يحدث للعنصر؟

    • يُخفى بـ display:none فقط
    • يتحول لونه إلى الرمادي
    • لا يُعرض في DOM
    • يُعرض مرتين
    الإجابة والشرح

    الإجابة الصحيحة: لا يُعرض في DOM

    v-if يضيف العنصر إلى DOM أو يزيله بحسب الشرط، وليس مجرد إخفاء بصري.
