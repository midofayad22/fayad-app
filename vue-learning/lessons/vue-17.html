ref و reactive

تعلّم الفرق الأساسي بين ref و reactive وكيف تستخدمهما مع البيانات التفاعلية.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

ref و reactive

ref() تستخدم لإنشاء Reactive Reference ويمكنها التعامل مع قيم بسيطة مثل Number وString.

reactive() تستخدم لإنشاء Reactive Object.

ref للقيم و reactive للكائنات

استخدم ref للقيم التفاعلية وreactive عندما تحتاج إلى Reactive Object.

مثال برمجي

الكود


<div id="app">
<h2>{{ count }}</h2>

<script>
const { createApp, ref, reactive } = Vue;
createApp({
setup() {
const count = ref(0);
const user = reactive({
name: "FAYBIT"
});
function increment() {
count.value++;
}
return {
count,
user,
increment
};
}
}).mount("#app");
</script>
