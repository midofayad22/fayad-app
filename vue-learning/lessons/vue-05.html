Methods

تعلّم كيف تستخدم Methods لتنفيذ العمليات والتعامل مع تفاعل المستخدم.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

Methods

Methods هي دوال نستخدمها لتنفيذ عمليات داخل تطبيق Vue.

يمكن استدعاء Method من Template عند حدوث Event مثل الضغط على زر.

Methods تنفذ العمليات

يمكنك وضع الدوال داخل methods ثم استدعاؤها من Template.

مثال برمجي

الكود


<div id="app">
<button @click="sayHello">
اضغط هنا
</button>
</div>
<script>
const { createApp } = Vue;
createApp({
methods: {
sayHello() {
alert("Hello Vue!");
}
}
}).mount("#app");
</script>

فهم الكود

نضع الدوال داخل methods.

@click="sayHello" تستدعي الدالة عند الضغط.

يمكن للـ Method قراءة البيانات وتعديلها وتنفيذ عمليات مختلفة.

جرّب بنفسك

أنشئ زرًا يستدعي Method عند الضغط عليه.

اختبر نفسك

  1. أين نضع Methods في Options API؟

    • methods
    • functions
    • actions
    • events
    الإجابة والشرح

    الإجابة الصحيحة: methods

  2. كيف نستدعي Method عند الضغط؟

    • @click
    • @hover
    • @press-only
    • @mouse
    الإجابة والشرح

    الإجابة الصحيحة: @click

  3. ما وظيفة Method؟

    • تنفيذ عملية أو منطق معين
    • إنشاء قاعدة بيانات تلقائيًا
    • تغيير نظام التشغيل
    • حذف HTML
    الإجابة والشرح

    الإجابة الصحيحة: تنفيذ عملية أو منطق معين

  4. ما الخطأ في هذا الكود؟ <button @click="add">+</button> methods: { add: this.count++ }

    • الزر لا يدعم click
    • add يجب أن تكون دالة وليست تعبيراً
    • methods يجب أن تكون خارج الكائن
    • لا يوجد خطأ
    الإجابة والشرح

    الإجابة الصحيحة: add يجب أن تكون دالة وليست تعبيراً

    كل Method يجب أن تكون دالة مثل add() { this.count++ }، وإلا لن تُستدعى عند الضغط.

  5. كيف نصل إلى data داخل Method في Options API؟

    • عبر this مثل this.count
    • عبر window.count
    • عبر document.count
    • لا يمكن الوصول إليها
    الإجابة والشرح

    الإجابة الصحيحة: عبر this مثل this.count

    داخل Methods يشير this إلى نسخة المكون، فنقرأ ونعدل data عبره.
