v-bind

تعلّم كيف تربط خصائص HTML بالبيانات باستخدام v-bind.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

v-bind

Directive v-bind تستخدم لربط Attribute في HTML بقيمة موجودة في بيانات Vue.

يمكن استخدام الاختصار : بدلًا من كتابة v-bind:.

استخدم : لربط Attributes

يمكنك ربط src وhref وclass وstyle وغيرها من Attributes ببيانات Vue.

مثال برمجي

الكود


<div id="app">
<img :src="imageUrl" alt="Vue Logo">
</div>
<script>
const { createApp } = Vue;
createApp({
data() {
return {
imageUrl: "https://vuejs.org/images/logo.png"
};
}
}).mount("#app");
</script>

تم ربط مصدر الصورة بالبيانات باستخدام v-bind.

فهم الكود

:src هو اختصار لـ v-bind:src.

Vue تأخذ قيمة imageUrl وتضعها داخل Attribute الخاص بـ src.

جرّب بنفسك

اربط src الخاص بالصورة بمتغير موجود في Vue.

اختبر نفسك

  1. ما الاختصار الخاص بـ v-bind؟

    • :
    • @
    • #
    • $
    الإجابة والشرح

    الإجابة الصحيحة: :

  2. ماذا يفعل v-bind؟

    • يربط Attribute ببيانات Vue
    • ينشئ قاعدة بيانات
    • يضيف JavaScript إلى النظام
    • يحذف العنصر
    الإجابة والشرح

    الإجابة الصحيحة: يربط Attribute ببيانات Vue

  3. أي صيغة صحيحة لربط src؟

    • :src="imageUrl"
    • @src="imageUrl"
    • #src="imageUrl"
    • $src="imageUrl"
    الإجابة والشرح

    الإجابة الصحيحة: :src="imageUrl"

  4. ما الخطأ في هذا السطر إذا أردنا ربط الصورة بالمتغير imgUrl؟ <img src="imgUrl">

    • لا يوجد خطأ
    • يجب استخدام {{ imgUrl }} داخل src
    • ينقص الاختصار : فيصبح src نصاً ثابتاً
    • الصور لا تدعم الربط
    الإجابة والشرح

    الإجابة الصحيحة: ينقص الاختصار : فيصبح src نصاً ثابتاً

    بدون v-bind أو : يُعامل imgUrl كنص حرفي، والصحيح :src="imgUrl".

  5. أي سطر يربط الخاصية disabled بالمتغير isLocked؟

    • <button disabled="isLocked">
    • <button {{ disabled }}>
    • <button v-disabled="isLocked">
    • <button :disabled="isLocked">
    الإجابة والشرح

    الإجابة الصحيحة: <button :disabled="isLocked">

    نستخدم :attr للربط بقيمة ديناميكية، وهنا يتعطل الزر عندما تكون isLocked صحيحة.
