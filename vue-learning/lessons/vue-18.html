watch

تعلّم كيف تراقب تغير البيانات التفاعلية باستخدام watch.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

watch

تستخدم watch() لمراقبة تغير قيمة Reactive معينة.

وهي مفيدة عندما يؤدي تغير قيمة معينة إلى تنفيذ Side Effect أو عملية إضافية.

راقب تغير البيانات

استخدم watch عندما تحتاج إلى تنفيذ Logic إضافي عند تغير قيمة Reactive.

مثال برمجي

الكود


<div id="app">
<input v-model="search">
<p>البحث: {{ search }}</p>
</div>
<script>
const { createApp, ref, watch } = Vue;
createApp({
setup() {
const search = ref("");
watch(search, (newValue) => {
console.log("Search:", newValue);
});
return {
search
};
}
}).mount("#app");
</script>

فهم الكود

watch() تراقب مصدرًا Reactive.

عندما تتغير القيمة يتم تشغيل Callback.

newValue تحتوي على القيمة الجديدة بعد التغيير.
