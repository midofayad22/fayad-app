ربط Class و Style

تسمح Vue بربط CSS Classes وInline Styles بالبيانات.

هذا مفيد عندما تريد تغيير شكل العنصر بناءً على حالة معينة.

تحكم في الشكل باستخدام البيانات

يمكنك تغيير Class أو Style بشكل ديناميكي بناءً على البيانات.

مثال برمجي

الكود


<div id="app">
<p :class="{ active: isActive }">
حالة العنصر
</p>
</div>
<script>
const { createApp } = Vue;
createApp({
data() {
return {
isActive: true
};
}
}).mount("#app");
</script>

حالة العنصر — Active

فهم الكود

:class تستخدم لربط CSS Class بالبيانات.

في المثال، Class باسم active تظهر عندما تكون isActive تساوي true.

يمكن أيضًا استخدام :style لربط Inline Styles.

جرّب بنفسك

اربط Class باسم active بحيث تتم إضافته عندما تكون isActive صحيحة.

اختبر نفسك

  1. كيف نربط CSS Class بشكل ديناميكي؟

    • :class
    • @class
    • #class
    • v-css-only
    الإجابة والشرح

    الإجابة الصحيحة: :class

  2. متى تظهر active في المثال؟

    • عندما تكون isActive صحيحة
    • دائمًا
    • عندما تكون CSS محذوفة
    • عندما يتغير عنوان الصفحة
    الإجابة والشرح

    الإجابة الصحيحة: عندما تكون isActive صحيحة

  3. أي Directive تستخدم لربط Inline Style؟

    • :style
    • @style
    • #style
    • v-css
    الإجابة والشرح

    الإجابة الصحيحة: :style

  4. ما class الناتج؟ <div :class="{ red: isRed, big: isBig }"> isRed=true, isBig=false

    • red big
    • big
    • red
    • لا شيء
    الإجابة والشرح

    الإجابة الصحيحة: red

    في صيغة الكائن تُضاف الأسماء التي قيمتها صحيحة فقط.

  5. كيف نكتب خاصية CSS ذات اسم مركب مثل font-size في :style؟

    • :style="{ font-size: size }"
    • :style="{ fontSize: size + 'px' }"
    • :style="font-size=size"
    • style="{{ size }}"
    الإجابة والشرح

    الإجابة الصحيحة: :style="{ fontSize: size + 'px' }"

    داخل كائن JavaScript نستخدم camelCase مثل fontSize أو نضع الاسم بين علامتي اقتباس.
