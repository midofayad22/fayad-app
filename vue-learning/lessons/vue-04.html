البيانات والتفاعلية

البيانات في Vue ليست مجرد قيم ثابتة؛ Vue تستطيع مراقبتها وتحديث الواجهة عندما تتغير.

هذه الفكرة تسمى Reactivity وهي من أهم أفكار Vue.

البيانات تقود الواجهة

عندما تتغير البيانات التفاعلية، تقوم Vue بتحديث الواجهة المرتبطة بها.

مثال برمجي

الكود


<div id="app">
<h2>Count: {{ count }}</h2>
<button @click="count++">
Increase
</button>
</div>
<script>
const { createApp } = Vue;
createApp({
data() {
return {
count: 0
};
}
}).mount("#app");
</script>
Count: 0

فهم الكود

count موجود داخل data().

عند تنفيذ count++ تتغير قيمة البيانات.

Vue تلاحظ التغيير وتحدث {{ count }} تلقائيًا.

  5. أي جزء يميّز البيانات التفاعلية عن متغير JavaScript عادي؟

    • لونها في المحرر
    • أن Vue تتتبع تغيّرها لتحديث الواجهة
    • أنها لا تقبل التعديل
    • أنها تُحفظ في قاعدة بيانات
