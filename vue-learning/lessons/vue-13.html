المكونات Components

تعلّم مفهوم Components وكيف تساعدك على بناء واجهات قابلة لإعادة الاستخدام.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

Components

Component هو جزء مستقل وقابل لإعادة الاستخدام من واجهة المستخدم.

تقسيم التطبيق إلى Components يجعل الكود أكثر تنظيمًا وأسهل في الصيانة.

Components تجعل الواجهة قابلة لإعادة الاستخدام

قسّم الواجهة إلى أجزاء صغيرة مستقلة يمكن إعادة استخدامها في أكثر من مكان.

مثال برمجي

الكود


<div id="app">
<user-card></user-card>
</div>
<script>
const { createApp } = Vue;
const UserCard = {
template: `
<div>
<h2>FAYBIT</h2>
<p>Vue Developer</p>
</div>
`
};
createApp({
components: {
UserCard
}
}).mount("#app");
</script>
FAYBIT

Vue Developer

فهم الكود

UserCard هو Component قابل لإعادة الاستخدام.

قمنا بتسجيله داخل components.

بعد ذلك يمكن استخدامه داخل Template باستخدام <user-card>.

جرّب بنفسك

أنشئ Component بسيطًا يعرض اسمًا ووصفًا ويمكن إعادة استخدامه.

اختبر نفسك

  1. لماذا نستخدم Components؟

    • لإنشاء أجزاء قابلة لإعادة الاستخدام
    • لاستبدال JavaScript
    • لإنشاء نظام تشغيل
    • لحذف HTML
    الإجابة والشرح

    الإجابة الصحيحة: لإنشاء أجزاء قابلة لإعادة الاستخدام

  2. ما فائدة تقسيم التطبيق إلى Components؟

    • تنظيم الكود وإعادة استخدام الأجزاء
    • إلغاء CSS
    • منع JavaScript
    • حذف البيانات
    الإجابة والشرح

    الإجابة الصحيحة: تنظيم الكود وإعادة استخدام الأجزاء

  3. هل يمكن استخدام Component أكثر من مرة؟

    • نعم
    • لا
    • فقط داخل CSS
    • فقط داخل Database
    الإجابة والشرح

    الإجابة الصحيحة: نعم

  4. ما الخطأ عند استخدام <Card /> في القالب إذا لم نسجل المكون أو نستورده؟

    • لا يوجد خطأ
    • القوالب لا تقبل المكونات
    • Vue لن يعرف المكون ولن يعرضه
    • يجب أن يكون الاسم بالأرقام
    الإجابة والشرح

    الإجابة الصحيحة: Vue لن يعرف المكون ولن يعرضه

    يجب تسجيل أو استيراد المكون قبل استخدامه في القالب.

  5. ما الذي يحصل عند وضع <Counter /> ثلاث مرات في الصفحة؟

    • تظهر نسخة واحدة فقط
    • تُنشأ ثلاث نسخ مستقلة لكل منها حالتها
    • يحدث خطأ
    • تشترك النسخ في نفس البيانات دائماً
    الإجابة والشرح

    الإجابة الصحيحة: تُنشأ ثلاث نسخ مستقلة لكل منها حالتها

    كل استخدام ينشئ نسخة مستقلة من المكون ببياناته الخاصة.
