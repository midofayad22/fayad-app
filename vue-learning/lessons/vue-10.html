v-on والأحداث

تعلّم كيف تتعامل Vue مع أحداث المستخدم مثل click باستخدام v-on.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

v-on والأحداث

تستخدم v-on للاستماع إلى Events التي تحدث على عناصر الصفحة.

الاختصار الشائع لـ v-on:click هو @click.

@click يتعامل مع الضغط

يمكنك استخدام @click لتشغيل منطق معين عند ضغط المستخدم على عنصر.

مثال برمجي

الكود


<div id="app">
<p>تم الضغط {{ count }} مرة</p>
<button @click="count++">
اضغط
</button>
</div>
<script>
const { createApp } = Vue;
createApp({
data() {
return {
count: 0
};
}
}).mount("#app");
</script>

تم الضغط 0 مرة

فهم الكود

v-on تستخدم للاستماع إلى Events.

@click هو الاختصار لـ v-on:click.

عند الضغط على الزر يتم تنفيذ الكود الموجود بعد @click.

جرّب بنفسك

أنشئ زرًا يزيد قيمة العداد عند الضغط عليه.

اختبر نفسك

  1. ما الاختصار لـ v-on:click؟

    • @click
    • :click
    • #click
    • $click
    الإجابة والشرح

    الإجابة الصحيحة: @click

  2. ما وظيفة v-on؟

    • الاستماع إلى Events
    • إنشاء قاعدة بيانات
    • ربط الصور فقط
    • تغيير HTML بالكامل
    الإجابة والشرح

    الإجابة الصحيحة: الاستماع إلى Events

  3. أي Event يحدث عند ضغط المستخدم على زر؟

    • click
    • hover-only
    • load-css
    • database
    الإجابة والشرح

    الإجابة الصحيحة: click

  4. أي صيغة تنفّذ save عند الضغط على الزر فقط وليس عند عرض الصفحة؟

    • @click="save"
    • click="save"
    • {{ save() }}
    • v-if="save"
    الإجابة والشرح

    الإجابة الصحيحة: @click="save"

    @click يربط الدالة بحدث الضغط، أما {{ save() }} فتُنفَّذ أثناء العرض وclick بدون @ مجرد خاصية.

  5. كيف نستمع لضغط مفتاح Enter في حقل إدخال؟

    • @keyup.enter="submit"
    • @enter="submit"
    • v-enter="submit"
    • @press="enter"
    الإجابة والشرح

    الإجابة الصحيحة: @keyup.enter="submit"

    المعدّلات مثل .enter تُضاف بعد اسم الحدث لتقييد الاستجابة بمفتاح معين.
