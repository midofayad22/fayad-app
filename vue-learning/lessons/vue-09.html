v-for

تعلّم كيف تعرض عناصر متعددة من Array باستخدام v-for.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

v-for

تستخدم v-for لتكرار عنصر HTML لكل عنصر موجود داخل Array أو Collection.

وهي من أكثر Directives استخدامًا عند إنشاء القوائم.

v-for تعرض القوائم

يمكنك استخدام v-for لتكرار عنصر HTML اعتمادًا على عناصر Array.

مثال برمجي

الكود


<div id="app">
<ul>
<li v-for="item in items">
{{ item }}
</li>
</ul>
</div>
<script>
const { createApp } = Vue;
createApp({
data() {
return {
items: ["HTML", "CSS", "JavaScript"]
};
}
}).mount("#app");
</script>

  • CSS
  • JavaScript

فهم الكود

v-for="item in items" تمر على جميع عناصر items.

في كل مرة يتم إنشاء نسخة من العنصر الموجود داخل الـ Template.

عند استخدام Arrays مع v-for من الأفضل استخدام key عندما يكون ذلك مناسبًا.
