افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

Composition API

Composition API توفر مجموعة من Functions تساعدك على تنظيم منطق Component بطريقة أكثر مرونة.

من أشهر Functions الموجودة فيها ref() و reactive() وcomputed().

Composition API لتنظيم Logic

تسمح لك Composition API بتجميع Logic المرتبط ببعضه في مكان واضح وقابل لإعادة الاستخدام.

مثال برمجي

الكود


<div id="app">
<button @click="increment">
{{ count }}
</button>
</div>
<script>
const { createApp, ref } = Vue;
createApp({
setup() {
const count = ref(0);
function increment() {
count.value++;
}
return {
count,
increment
};
}
}).mount("#app");
</script>

فهم الكود

setup() هي المكان الأساسي لكتابة Logic باستخدام Composition API.

ref(0) تنشئ قيمة Reactive.

داخل JavaScript نستخدم count.value للوصول للقيمة.

عند إرجاع count وincrement يمكن استخدامهما داخل Template.
