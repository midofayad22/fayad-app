النماذج والتحقق

تعلّم كيفية التعامل مع Forms وإضافة Validation بسيطة باستخدام Vue.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

النماذج والتحقق

يمكن استخدام v-model لربط قيم Form بالبيانات.

ويمكنك استخدام Methods للتحقق من البيانات قبل تنفيذ عملية الإرسال.

تحقق من البيانات قبل الإرسال

اربط حقول Form بالبيانات ثم تحقق من القيم قبل إرسالها أو تنفيذ العملية.

مثال برمجي

الكود


<div id="app">
<form @submit.prevent="submitForm">
<input v-model="name" placeholder="الاسم">
<button type="submit">
إرسال
</button>
<p v-if="error">
{{ error }}
</p>
</form>
</div>
<script>
const { createApp } = Vue;
createApp({
data() {
return {
name: "",
error: ""
};
},
methods: {
submitForm() {
if (!this.name.trim()) {
this.error = "من فضلك اكتب اسمك";
return;
}
this.error = "";
alert("تم الإرسال");
}
}
}).mount("#app");
</script>

فهم الكود

v-model تربط Input بالبيانات.

@submit.prevent تمنع إرسال Form بالطريقة الافتراضية.

داخل submitForm() نتحقق من البيانات قبل تنفيذ العملية.

جرّب بنفسك

أنشئ Form يتحقق من أن الاسم ليس فارغًا قبل الإرسال.

اختبر نفسك

  1. ما فائدة Validation في Forms؟

    • التأكد من صحة البيانات قبل استخدامها
    • إنشاء CSS
    • إنشاء Components
    • تغيير لون المتصفح
    الإجابة والشرح

    الإجابة الصحيحة: التأكد من صحة البيانات قبل استخدامها

  2. ما الذي يمكن استخدامه لربط Input بالبيانات؟

    • v-model
    • v-route
    • v-check-only
    • v-input-data
    الإجابة والشرح

    الإجابة الصحيحة: v-model

  3. ماذا تفعل .prevent مع submit؟

    • تمنع السلوك الافتراضي للمتصفح
    • تحذف Form
    • تنشئ Component
    • تغلق الصفحة
    الإجابة والشرح

    الإجابة الصحيحة: تمنع السلوك الافتراضي للمتصفح

  4. ما فائدة @submit.prevent على النموذج؟

    • يمنع إعادة تحميل الصفحة ويسمح لدالتنا بمعالجة الإرسال
    • يحذف الحقول
    • يمنع كتابة أي بيانات
    • يرسل النموذج مرتين
    الإجابة والشرح

    الإجابة الصحيحة: يمنع إعادة تحميل الصفحة ويسمح لدالتنا بمعالجة الإرسال

    بدون prevent يعيد المتصفح تحميل الصفحة قبل أن نتحقق من البيانات.

  5. أي شرط تحقق مناسب لمنع إرسال بريد فارغ؟

    • if (email) send()
    • if (!email) { error = 'Required'; return }
    • email = ''
    • if (email === email) send()
    الإجابة والشرح

    الإجابة الصحيحة: if (!email) { error = 'Required'; return }

    نفحص القيمة، وإذا كانت فارغة نعرض رسالة خطأ ونوقف الإرسال بـ return.
