بنية تطبيق Vue

تعرّف على الطريقة الأساسية لإنشاء تطبيق Vue وربطه بعنصر HTML.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

يبدأ تطبيق Vue عادةً باستخدام createApp().

بعد إنشاء التطبيق نستخدم mount() لتحديد عنصر HTML الذي سيعمل بداخله التطبيق.

createApp تبدأ التطبيق

نستخدم createApp لإنشاء تطبيق Vue ثم mount لربطه بعنصر HTML.

مثال برمجي

الكود


<div id="app">
<h1>{{ title }}</h1>
</div>
<script>
const { createApp } = Vue;
createApp({
data() {
return {
title: "My Vue App"
};
}
}).mount("#app");
</script>
My Vue App

فهم الكود

createApp() تنشئ تطبيق Vue.

data() تحتوي على البيانات المستخدمة داخل التطبيق.

mount("#app") تجعل Vue تتحكم في العنصر الذي يحمل id="app".

اختبر نفسك

  1. ما الوظيفة الأساسية لـ createApp()؟

    • إنشاء تطبيق Vue
    • إنشاء قاعدة بيانات
    • تغيير نظام التشغيل
    • إنشاء ملف CSS
    الإجابة والشرح

    الإجابة الصحيحة: إنشاء تطبيق Vue

  2. ما الطريقة التي تربط تطبيق Vue بعنصر HTML؟

    • mount()
    • attach()
    • connect()
    • link()
    الإجابة والشرح

    الإجابة الصحيحة: mount()

  3. ما الذي تحدده mount() عادةً؟

    • العنصر الذي سيعمل بداخله تطبيق Vue
    • لون الصفحة
    • اسم قاعدة البيانات
    • نوع المتصفح
    الإجابة والشرح

    الإجابة الصحيحة: العنصر الذي سيعمل بداخله تطبيق Vue

  4. ما نتيجة هذا الكود إذا لم يوجد عنصر #app في الصفحة؟ createApp({}).mount('#app')

    • يظهر التطبيق في أعلى الصفحة
    • لا يُعرض التطبيق لأنه لا يوجد عنصر يتصل به
    • ينشئ Vue عنصر #app تلقائياً
    • تتحول الصفحة إلى تطبيق Vue كاملة
    الإجابة والشرح

    الإجابة الصحيحة: لا يُعرض التطبيق لأنه لا يوجد عنصر يتصل به

    mount يحتاج عنصراً موجوداً يطابق المحدد، وإلا لا يجد Vue مكاناً ليعرض فيه التطبيق.

  5. ما الترتيب الصحيح لبدء تطبيق Vue؟

    • mount ثم createApp
    • createApp ثم mount
    • لا يهم الترتيب
    • mount فقط دون createApp
    الإجابة والشرح

    الإجابة الصحيحة: createApp ثم mount

    نحتاج أولاً كائن التطبيق من createApp ثم نستدعي عليه mount لربطه بعنصر HTML.
