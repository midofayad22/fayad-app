افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

Props

Props هي الطريقة الأساسية لتمرير البيانات من Parent Component إلى Child Component.

تساعد Props على جعل Components أكثر مرونة وقابلية لإعادة الاستخدام.

Props تمرر البيانات إلى المكونات الأبناء

يمكن للـ Parent إرسال بيانات إلى Child من خلال Props.

مثال برمجي

الكود


<div id="app">
<user-card name="FAYBIT"></user-card>
</div>
<script>
const { createApp } = Vue;
const UserCard = {
props: ["name"],
template: `
<h2>Hello {{ name }}</h2>
`
};
createApp({
components: {
UserCard
}
}).mount("#app");
</script>
Hello FAYBIT

فهم الكود

props: ["name"] تحدد أن Component يستقبل Prop باسم name.

Parent يمرر القيمة باستخدام <user-card name="FAYBIT">.

داخل Child يمكن استخدام {{ name }}.

جرّب بنفسك

مرر اسمًا من Parent إلى UserCard باستخدام Props.

اختبر نفسك

  1. ما الاستخدام الأساسي لـ Props؟

    • تمرير البيانات إلى Child Component
    • إنشاء CSS
    • إنشاء قاعدة بيانات
    • تشغيل Browser
    الإجابة والشرح

    الإجابة الصحيحة: تمرير البيانات إلى Child Component

  2. من أين تأتي Props عادةً؟

    • من Parent Component
    • من نظام التشغيل
    • من CSS
    • من المتصفح فقط
    الإجابة والشرح

    الإجابة الصحيحة: من Parent Component

  3. هل يمكن للـ Child استخدام قيمة Prop؟

    • نعم
    • لا
    • فقط في CSS
    • فقط في Database
    الإجابة والشرح

    الإجابة الصحيحة: نعم

  4. كيف يمرر الأب قيمة النص 'Ali' إلى prop اسمها name؟

    • <Child name="Ali" />
    • <Child {{ name }} />
    • <Child @name="Ali" />
    • <Child v-on:name="Ali" />
    الإجابة والشرح

    الإجابة الصحيحة: <Child name="Ali" />

    النص الثابت يُمرر كخاصية HTML عادية، ولتمرير متغير نستخدم :name.

  5. لماذا لا يجب أن يعدّل الـ Child قيمة prop مباشرة؟

    • لأنها قيمة ثابتة لا تُقرأ
    • لأن البيانات تتدفق من الأب إلى الابن وملكيتها للأب
    • لأن Vue تحذف الـ props
    • لا مشكلة في التعديل
    الإجابة والشرح

    الإجابة الصحيحة: لأن البيانات تتدفق من الأب إلى الابن وملكيتها للأب

    تدفق البيانات في اتجاه واحد يجعل التطبيق أسهل في التتبع، ولتغييرها يُرسل الابن حدثاً للأب.
