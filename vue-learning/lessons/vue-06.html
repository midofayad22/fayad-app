Computed Properties

تعلّم كيف تنشئ قيمًا مشتقة من البيانات باستخدام Computed Properties.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

Computed Properties

Computed Property هي قيمة يتم حسابها اعتمادًا على بيانات أخرى.

وهي مفيدة عندما نحتاج إلى إنشاء نتيجة مشتقة من البيانات الموجودة لدينا.

Computed للقيم المشتقة

استخدم Computed عندما تحتاج إلى حساب قيمة اعتمادًا على بيانات أخرى.

مثال برمجي

الكود


<div id="app">
<h2>{{ fullName }}</h2>
</div>
<script>
const { createApp } = Vue;
createApp({
data() {
return {
firstName: "Abdullhamid",
lastName: "Fayad"
};
},
computed: {
fullName() {
return this.firstName + " " + this.lastName;
}
}
}).mount("#app");
</script>
Abdullhamid Fayad

فهم الكود

computed تحتوي على القيم المشتقة.

fullName() تعتمد على firstName وlastName.

عندما تتغير البيانات التي تعتمد عليها Computed، تقوم Vue بإعادة حسابها عند الحاجة.

  4. ما الفرق العملي بين Computed وMethod لحساب fullName؟

    • Computed تُخزّن نتيجتها وتعيد الحساب فقط عند تغير اعتماداتها
    • لا فرق إطلاقاً
    • Method تُخزّن النتيجة دائماً
    • Computed لا تعمل في القالب
