Semantic HTML

تعلّم معنى Semantic HTML ولماذا تساعد في تنظيم وفهم الصفحة.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

العناصر الدلالية

هي عناصر لها معنى واضح للمتصفح والمطور مثل <header> و <article>.

مثال برمجي

هيكل دلالي

<header>رأس الصفحة</header>
<main>المحتوى</main>
<footer>الذيل</footer>
رأس الصفحة
المحتوى
الذيل

فهم الكود

تساعد العناصر الدلالية تحسين محركات البحث SEO وسهولة الوصول.

جرّب بنفسك

اكتب كود HTML

اكتب هيكل صفحة باستخدام العناصر الدلالية.

اختبر نفسك

  1. ما الفائدة الرئيسية من استخدام العناصر الدلالية (Semantic HTML)؟

    • تحسين هيكلة الكود ومحركات البحث SEO وقارئات الشاشة
    • زيادة سرعة اتصال الإنترنت للمستخدم
    • تغيير تصميم الصفحة أوتوماتيكياً
    الإجابة والشرح

    الإجابة الصحيحة: تحسين هيكلة الكود ومحركات البحث SEO وقارئات الشاشة

  2. أي عنصر دلالي يفضل استخدامه للمحتوى المستقل كالمقالات والأخبار؟

    • <article>
    • <div>
    • <span>
    الإجابة والشرح

    الإجابة الصحيحة: <article>

  3. أي عنصر دلالي يمثل المنطقة الفرعية أو الشريط الجانبي بالصفحة؟

    • <aside>
    • <section>
    • <nav>
    الإجابة والشرح

    الإجابة الصحيحة: <aside>

  4. أين يجب أن يُكتب حقوق النشر وروابط التواصل في أسفل الصفحة بشكل دلالي؟

    • div فقط
    • header
    • footer
    • aside
    الإجابة والشرح

    الإجابة الصحيحة: footer

    footer عنصر دلالي يصف المحتوى الختامي. استخدام div يعمل بصرياً لكن لا يخبر المتصفح ولا قارئ الشاشة بمعناه.

  5. موقع يتكون كله من عناصر div متداخلة. ما العيب الأساسي مقارنة بالعناصر الدلالية؟

    • الصفحة لا تُعرض إطلاقاً
    • div يبطئ الموقع بشكل كبير
    • لا يمكن إضافة CSS إلى div
    • لا تعبّر عن دور كل جزء، فتصعب القراءة وإمكانية الوصول والفهرسة
    الإجابة والشرح

    الإجابة الصحيحة: لا تعبّر عن دور كل جزء، فتصعب القراءة وإمكانية الوصول والفهرسة

    div يعمل تماماً وقابل للتنسيق، لكنه بلا معنى. العناصر الدلالية توضح الأدوار فتفيد المطورين وقارئات الشاشة ومحركات البحث.
