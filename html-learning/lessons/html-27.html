Textarea

تعلّم استخدام textarea لإدخال نصوص متعددة الأسطر.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

مربع النص المتعدد الأسطر

يسمح عنصر <textarea> بكتابة نصوص طويلة ومقالات ورسائل التواصل.

مثال برمجي

مربع ملاحظات

<textarea rows="4" cols="50" placeholder="اكتب ملاحظتك"></textarea>

فهم الكود

الخصائص rows و cols تحددان الأبعاد بالأعمدة والأسطر.

جرّب بنفسك

اكتب كود HTML

أنشئ textarea لكتابة رسالة مع تحديد عدد الأسطر.

اختبر نفسك

  1. ما العنصر المناسب لإدخال نص مطول يتكون من عدة أسطر كالملاحظات؟

    • <textarea>
    • <input type="text">
    • <p>
    الإجابة والشرح

    الإجابة الصحيحة: <textarea>

  2. ما الخاصية المحددة لارتفاع مربع النص بعدد الأسطر؟

    • rows
    • cols
    • height
    الإجابة والشرح

    الإجابة الصحيحة: rows

  3. هل يمتلك وسم textarea وسم إغلاق منفصل؟

    • نعم، يمتلك وسم إغلاق </textarea>
    • لا هو وسم مغلق ذاتياً
    • فقط مع النماذج المتقدمة
    الإجابة والشرح

    الإجابة الصحيحة: نعم، يمتلك وسم إغلاق </textarea>

  4. أين يُكتب النص الابتدائي داخل textarea؟

    • في السمة value
    • بين وسمي الفتح والإغلاق
    • في السمة rows
    • في السمة alt
    الإجابة والشرح

    الإجابة الصحيحة: بين وسمي الفتح والإغلاق

    textarea يأخذ محتواه كنص بين وسميه وليس بالسمة value كما في input. لذلك يحتاج وسم إغلاق.

  5. textarea ارتفاعه rows=3 وكتب المستخدم عشرة أسطر. ماذا يحدث؟

    • يُقص النص ويضيع
    • يتمدد الحقل تلقائياً بلا حدود
    • يظهر شريط تمرير ليبقى النص كله متاحاً
    • يتوقف عن قبول الكتابة
    الإجابة والشرح

    الإجابة الصحيحة: يظهر شريط تمرير ليبقى النص كله متاحاً

    rows يحدد الارتفاع المرئي فقط، والنص الزائد يبقى محفوظاً ويظهر معه تمرير عمودي.
