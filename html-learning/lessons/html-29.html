Iframes

تعلّم أساسيات تضمين صفحات أو محتوى خارجي باستخدام iframe.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

التضمين بـ Iframe

يسمح <iframe> بتضمين خرائط جوجل أو مقاطع يوتيوب أو صفحات خارجية.

مثال برمجي

تضمين صفحة

<iframe src="https://example.com" width="100%" height="200"></iframe>

مربع تضمين محتوى خارجي يظهر هنا

فهم الكود

الخاصية src تحدد رابط الصفحة المضمنة.

جرّب بنفسك

اكتب كود HTML

أنشئ iframe مع العرض والارتفاع المناسبين.

اختبر نفسك

  1. ما وظيفة العنصر <iframe>؟

    • تضمين صفحة أو موقع أو ميديا خارجية داخل الصفحة الحالية
    • إنشاء إطار أحمر حول الفقرة
    • تشغيل الصوت فقط
    الإجابة والشرح

    الإجابة الصحيحة: تضمين صفحة أو موقع أو ميديا خارجية داخل الصفحة الحالية

  2. ما هي الخاصية المحددة لرابط الصفحة الخارجية المضمنة داخل iframe؟

    • src
    • href
    • link
    الإجابة والشرح

    الإجابة الصحيحة: src

  3. ما الخصائص المستخدمة لضبط أبعاد إطار التضمين؟

    • width و height
    • size و scale
    • max و min
    الإجابة والشرح

    الإجابة الصحيحة: width و height

  4. وضعت iframe لموقع آخر فظهر إطار فارغ. ما أحد الأسباب المحتملة؟

    • المتصفح لا يدعم iframe
    • الموقع الآخر يمنع تضمينه في إطارات
    • الإطار يحتاج alt
    • يجب كتابة الرابط داخل p
    الإجابة والشرح

    الإجابة الصحيحة: الموقع الآخر يمنع تضمينه في إطارات

    كثير من المواقع ترسل ترويسات مثل X-Frame-Options أو CSP تمنع التضمين، فيظهر الإطار فارغاً رغم أن شيفرتك صحيحة.

  5. كتب طالب iframe href="https://example.com". ما الخطأ؟

    • يجب كتابة link
    • يجب كتابة alt
    • السمة الصحيحة هي src
    • لا خطأ
    الإجابة والشرح

    الإجابة الصحيحة: السمة الصحيحة هي src

    iframe يحدد الصفحة المضمنة بالسمة src وليس href. href خاصة بالروابط. ويفضل إضافة title لوصف الإطار.
