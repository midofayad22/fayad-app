ما هي HTML؟

HTML اختصار لـ HyperText Markup Language. وهي لغة الترميز الأساسية المستخدمة لبناء هيكل صفحات الويب.

HTML تخبر المتصفح بنوع المحتوى الموجود في الصفحة، مثل العناوين والفقرات والروابط والصور والنماذج.

الفكرة الأساسية

HTML تبني هيكل الصفحة

يمكنك تخيل الموقع مثل مبنى: HTML تبني الهيكل، وCSS تهتم بالمظهر، وJavaScript تضيف السلوك والتفاعل.

مثال برمجي

أول كود HTML لك

<h1>مرحبًا بك</h1>
<p>أهلًا بك في FAYBIT.</p>
مرحبًا بك

أهلًا بك في FAYBIT.

فهم الكود

العنصر <h1> يستخدم لإنشاء العنوان الرئيسي.

العنصر <p> يستخدم لإنشاء فقرة.

اختبر نفسك

  1. ماذا تعني اختصار كلمة HTML؟

    • HyperText Markup Language
    • HighText Machine Language
    • Home Tool Markup Language
    الإجابة والشرح

    الإجابة الصحيحة: HyperText Markup Language

  2. ما الوظيفة الأساسية لـ HTML؟

    • بناء هيكل صفحة الويب الأساسي
    • تنسيق وتلوين العناصر فقط
    • إدارة قواعد البيانات والتحكم بالسيرفر
    الإجابة والشرح

    الإجابة الصحيحة: بناء هيكل صفحة الويب الأساسي

  3. أي عنصر يستخدم لإنشاء فقرة نصية عادية؟

    • <p>
    • <text>
    • <paragraph>
    الإجابة والشرح

    الإجابة الصحيحة: <p>

  4. أي عبارة عن HTML صحيحة؟

    • لغة برمجة تحتوي على حلقات وشروط مثل بقية اللغات
    • لغة ترميز تصف بنية الصفحة ومعنى محتواها
    • لغة تنسيق مسؤولة عن الألوان والخطوط فقط
    • لغة قواعد بيانات لتخزين بيانات المستخدمين
    الإجابة والشرح

    الإجابة الصحيحة: لغة ترميز تصف بنية الصفحة ومعنى محتواها

    HTML تضع علامات على المحتوى لتخبر المتصفح ما هو العنوان وما هي الفقرة وما هو الرابط. لا تملك منطقاً برمجياً، فالتنسيق من مهام CSS والتفاعل من مهام JavaScript.

  5. تريد أن يتغير لون الصفحة ويظهر حساب جديد عند ضغط الزائر على زر. ماذا تحتاج إضافة إلى HTML؟

    • مزيداً من وسوم HTML فقط
    • ملف صور بصيغة أخرى
    • JavaScript للتفاعل و CSS للألوان
    • لا شيء، فـ HTML تفعل ذلك تلقائياً
    الإجابة والشرح

    الإجابة الصحيحة: JavaScript للتفاعل و CSS للألوان

    HTML وحدها تصف المحتوى فقط ولا تنفذ أي منطق عند الضغط. نستخدم JavaScript للتفاعل و CSS للتنسيق، وهما يعملان فوق بنية HTML.
