Images

تعلّم إضافة الصور إلى صفحات الويب باستخدام img.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

إضافة الصور

عنصر <img> هو عنصر ذاتي الإغلاق يستخدم لضم الصور للصفحة.

مثال برمجي

إضافة صورة

<img src="logo.png" alt="شعار الشعار" width="200">

عنصر صورة يظهر هنا بحسب المسار المحدد

فهم الكود

src يحدد المسار و alt تقدم وصفاً للصورة.

جرّب بنفسك

اكتب كود HTML

أضف وسم صورة مع تحديد العرض وخصائص alt.

اختبر نفسك

  1. أي عنصر ينشئ صورة في HTML؟

    • <img>
    • <image>
    • <pic>
    الإجابة والشرح

    الإجابة الصحيحة: <img>

  2. هل يمتلك العنصر <img> وسم إغلاق منفصل </img>؟

    • لا، هو عنصر ذاتي الإغلاق (Self-closing)
    • نعم، يجب إغلاقه دائماً بوسم منفصل
    • فقط في الإكواد القديمة
    الإجابة والشرح

    الإجابة الصحيحة: لا، هو عنصر ذاتي الإغلاق (Self-closing)

  3. ما هي الخاصية المحددة لمسار ورابط ملف الصورة؟

    • src
    • href
    • path
    الإجابة والشرح

    الإجابة الصحيحة: src

  4. صورة بالسمة src="pic.jpg" فقط، ولم يوجد الملف. ماذا يظهر وما العيب الإضافي؟

    • تظهر أيقونة صورة مكسورة ولا يوجد نص بديل لوصفها
    • يظهر نص تلقائي يصف الصورة
    • تتحول الصورة إلى رابط
    • تظهر الصفحة فارغة تماماً
    الإجابة والشرح

    الإجابة الصحيحة: تظهر أيقونة صورة مكسورة ولا يوجد نص بديل لوصفها

    عند فشل التحميل يعرض المتصفح أيقونة مكسورة، ولو وُجدت alt لظهر نصها بدلاً منها. غياب alt يضر أيضاً بقارئات الشاشة.

  5. ما أفضل طريقة لجعل الصورة تظهر بعرض 200 بكسل دون تشويه نسبتها؟

    • تحديد width و height بقيم مختلفة تماماً عن الأصل
    • تحديد width فقط بالقيمة 200 وترك الارتفاع يُحسب تلقائياً
    • كتابة 200 في السمة alt
    • وضع الصورة داخل p
    الإجابة والشرح

    الإجابة الصحيحة: تحديد width فقط بالقيمة 200 وترك الارتفاع يُحسب تلقائياً

    عند تحديد البعد الواحد فقط يحافظ المتصفح على نسبة العرض إلى الارتفاع. تحديد قيمتين غير متناسبتين يمدد الصورة ويشوهها.
