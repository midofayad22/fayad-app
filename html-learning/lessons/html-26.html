Select & Option

تعلّم إنشاء قوائم اختيار منسدلة باستخدام select وoption.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

القوائم المنسدلة Dropdowns

أنشئ قائمة منسدلة باستخدام <select> والخيارات <option>.

مثال برمجي

قائمة اختيار

<select>
<option>مصر</option>
<option>السعودية</option>
</select>

فهم الكود

يمكن إعطاء القيمة الحقيقية لكل خيار باستخدام خاصية value.

جرّب بنفسك

اكتب كود HTML

أنشئ قائمة اختيار تحتوي على لغتين بـ option.

اختبر نفسك

  1. ما هو الوسم الذي ينشئ القائمة المنسدلة للاختيار؟

    • <select>
    • <dropdown>
    • <choose>
    الإجابة والشرح

    الإجابة الصحيحة: <select>

  2. ما هو الوسم الذي يمثل كل خيار فرعي داخل قائمة select؟

    • <option>
    • <item>
    • <list>
    الإجابة والشرح

    الإجابة الصحيحة: <option>

  3. ما هي الخاصية المستخدمة لتحديد القيمة المرسلة للسيرفر عند الاختيار؟

    • value
    • name
    • data
    الإجابة والشرح

    الإجابة الصحيحة: value

  4. عنصر option له value="eg" ونصه Egypt. ماذا يُرسل إلى الخادم عند اختياره؟

    • Egypt
    • eg
    • EgyptEg
    • لا شيء
    الإجابة والشرح

    الإجابة الصحيحة: eg

    يرسل المتصفح قيمة السمة value وليس النص المعروض. إن لم توجد value فيرسل نص الخيار.

  5. كيف تسمح للمستخدم باختيار أكثر من خيار من القائمة؟

    • إضافة عدة عناصر select
    • إضافة السمة multiple إلى select
    • كتابة value متعددة
    • لا يمكن ذلك
    الإجابة والشرح

    الإجابة الصحيحة: إضافة السمة multiple إلى select

    السمة multiple تحول القائمة إلى قائمة متعددة الاختيار، ويضغط المستخدم Ctrl أو Shift لتحديد أكثر من عنصر.
