Input Types

تعلّم أنواع input المختلفة وكيف تحدد نوع البيانات التي يدخلها المستخدم.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

أنواع حقول الإدخال

تحدد الخاصية type نوع البيانات مثل text, password, email, number.

مثال برمجي

أنواع الإدخال

<input type="email" placeholder="البريد">
<input type="password">


فهم الكود

نوع password يختفي فيه النص لحماية السرية.

جرّب بنفسك

اكتب كود HTML

أنشئ حقل بريد إلكتروني وحقل كلمة مرور.

اختبر نفسك

  1. ما هو نوع الحقل المناسب لإدخال كلمات المرور وتشفيرها ظاهرياً على الشاشة؟

    • type="password"
    • type="text"
    • type="hidden"
    الإجابة والشرح

    الإجابة الصحيحة: type="password"

  2. ما نوع الإدخال المخصص لاختيار التاريخ من تقويم تفاعلي؟

    • type="date"
    • type="time"
    • type="calendar"
    الإجابة والشرح

    الإجابة الصحيحة: type="date"

  3. أي نوع يضمن مطابقة المدخلات لصيغة البريد الإلكتروني؟

    • type="email"
    • type="text"
    • type="mail"
    الإجابة والشرح

    الإجابة الصحيحة: type="email"

  4. ماذا يعرض المتصفح لحقل input كُتب نوعه type="foo" وهو غير معروف؟

    • يتعامل معه كحقل نص عادي
    • يخفي الحقل
    • يعرض رسالة خطأ
    • يعامله كزر
    الإجابة والشرح

    الإجابة الصحيحة: يتعامل معه كحقل نص عادي

    القيمة الافتراضية لـ type هي text، والقيم غير المعروفة تعود إليها. لذلك يبقى الحقل قابلاً للكتابة.

  5. تريد حقلاً لإدخال عدد القطع المطلوبة بحيث تظهر أسهم زيادة ونقصان. ما النوع المناسب؟

    • text
    • password
    • email
    • number
    الإجابة والشرح

    الإجابة الصحيحة: number

    النوع number يقبل أرقاماً فقط ويعرض أسهم الزيادة والنقصان في أغلب المتصفحات. text يقبل أي حرف دون هذه المزايا.
