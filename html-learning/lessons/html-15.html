Labels & Buttons

تعلّم استخدام labels مع inputs وإنشاء الأزرار.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

العناوين والأزرار

ربط الـ label بالحقل يحسن سهولة الوصول والاستخدام.

مثال برمجي

ربط Label بـ Input

<label for="user">الاسم:</label>
<input id="user" type="text">

فهم الكود

خاصية for في label تطابق خاصية id في input.

جرّب بنفسك

اكتب كود HTML

قم بربط label بحقل إدخال بـ id مناسب.

اختبر نفسك

  1. ما هي الخاصية في وسم <label> التي ترتبطه بمعرف الحقل id؟

    • for
    • to
    • target
    الإجابة والشرح

    الإجابة الصحيحة: for

  2. ما فائدة استخدام وسم Label بجانب حقل الإدخال؟

    • تحسين استخدام القارئات وسهولة النقر وتحديد الحقول
    • تغيير شكل الحقل وتلوينه تلقائياً
    • حفظ البيانات بالمتصفح
    الإجابة والشرح

    الإجابة الصحيحة: تحسين استخدام القارئات وسهولة النقر وتحديد الحقول

  3. أي وسم يمثل زراً تفاعلياً قابلاً للنقر؟

    • <button>
    • <click>
    • <press>
    الإجابة والشرح

    الإجابة الصحيحة: <button>

  4. label له for="email" بينما الحقل له id="mail". ماذا ينتج؟

    • الاثنان مرتبطان رغم اختلاف الاسم
    • لا ارتباط، فالضغط على النص لا يركز الحقل
    • يظهر خطأ ويتوقف النموذج
    • يتحول الحقل إلى زر
    الإجابة والشرح

    الإجابة الصحيحة: لا ارتباط، فالضغط على النص لا يركز الحقل

    قيمة for يجب أن تطابق id الحقل تماماً. عند عدم التطابق لا يحدث الربط فتفقد فائدة الضغط على التسمية وقراءتها لقارئ الشاشة.

  5. زر button داخل نموذج دون تحديد type. ماذا يفعل عند الضغط؟

    • لا يفعل شيئاً
    • يعيد تعيين الحقول
    • يرسل النموذج لأن النوع الافتراضي submit
    • يغلق الصفحة
    الإجابة والشرح

    الإجابة الصحيحة: يرسل النموذج لأن النوع الافتراضي submit

    النوع الافتراضي للزر داخل النموذج هو submit. لتجنب الإرسال غير المقصود حدد type="button".
