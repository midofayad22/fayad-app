Meta Elements

تعلّم أساسيات Meta Elements ودورها في معلومات الصفحة.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

وسوم Meta

تزود المتصفح بترميز النصوص وحجم الشاشة والمعلومات الإضافية.

مثال برمجي

ترميز وسوم الشاشة

<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">

وسوم الميتا الأساسية لضبط الترميز والاستجابة

فهم الكود

UTF-8 يضمن دعم اللغة العربية بشكل صحيح بدون رموز غريبة.

جرّب بنفسك

اكتب كود HTML

اكتب وسم تحديد الترميز للغة العربية UTF-8.

اختبر نفسك

  1. ما فائدة وسم <meta charset="UTF-8">؟

    • دعم وعرض اللغة العربية وجميع اللغات بدون رموش غريبة
    • تغيير عرض الصفحة
    • توفير الحماية للموقع
    الإجابة والشرح

    الإجابة الصحيحة: دعم وعرض اللغة العربية وجميع اللغات بدون رموش غريبة

  2. أي وسم ميتا يضمن تجاوب الصفحة مع شاشات الهواتف والموبايل؟

    • <meta name="viewport">
    • <meta name="mobile">
    • <meta name="screen">
    الإجابة والشرح

    الإجابة الصحيحة: <meta name="viewport">

  3. أين توضع جميع وسوم Meta داخل هيكل المستند؟

    • داخل عنصر <head>
    • داخل عنصر <body>
    • في تذييل الصفحة
    الإجابة والشرح

    الإجابة الصحيحة: داخل عنصر <head>

  4. ما الذي قد يحدث لنص عربي إذا غاب إعلان الترميز UTF-8؟

    • قد تظهر الحروف مشوهة أو رموز غريبة
    • يتحول النص إلى صورة
    • تتوقف الصفحة عن العمل
    • يتحول الاتجاه إلى اليمين تلقائياً
    الإجابة والشرح

    الإجابة الصحيحة: قد تظهر الحروف مشوهة أو رموز غريبة

    بدون ترميز واضح قد يخمّن المتصفح ترميزاً خاطئاً فيعرض الحروف غير الإنجليزية بشكل مشوه. لذلك نضع meta charset في head.

  5. مطور يقول إن meta viewport يصغّر الصفحة في الهاتف. أي وصف أدق؟

    • يضبط عرض الصفحة وتكبيرها الأولي ليتناسب مع جهاز العرض
    • يضغط الصور
    • يغير ألوان الصفحة
    • يمنع الطباعة
    الإجابة والشرح

    الإجابة الصحيحة: يضبط عرض الصفحة وتكبيرها الأولي ليتناسب مع جهاز العرض

    القيمة المعتادة width=device-width, initial-scale=1 تجعل المتصفح يستخدم عرض الجهاز الفعلي بدل افتراض عرض كبير، فتعمل التصاميم المتجاوبة.
