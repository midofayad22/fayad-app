الخدمات Services

تعرف على كيفية استخدام Services لتنظيم المنطق المشترك والقابل لإعادة الاستخدام.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

الـServices هي Classes تحتوي على منطق قابل لإعادة الاستخدام. تُستخدم عادةً للتعامل مع APIs والمصادقة والبيانات المشتركة وBusiness Logic والـLogging وغيرها من الوظائف التي لا يفضل وضعها داخل Component.
مثال برمجي

مثال على الكود

import { Injectable } from '@angular/core';
@Injectable({
providedIn: 'root'
})
export class UserService {
getUsers() {
return ['Ali', 'Mido', 'Sara'];
}
}

  3. أي عبارة تصف هذا الموضوع بشكل أفضل؟

    • الـServices هي Classes تحتوي على منطق قابل لإعادة الاستخدام. تُستخدم عادةً للتعامل مع APIs والمصادقة والبيانات المشتركة وBusiness Logic والـLogging وغيرها من الوظائف التي لا يفضل وضعها داخل Component.
    • يسمح Dependency Injection للـClass باستقبال الأشياء التي يحتاج إليها بدلًا من إنشائها بنفسه. وهذا يحسن إعادة الاستخدام والاختبار وفصل المسؤوليات.
    • يقوم Angular Router بربط URLs بالمكونات. ويسمح للتطبيق بالتصرف كتطبيق يحتوي على صفحات متعددة مع بقائه Single-Page Application. ويمكن أيضًا استخدام Guards وParameters وChild Routes وLazy Loading.
