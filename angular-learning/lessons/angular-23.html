HTTP Client

تعرف على كيفية تواصل تطبيقات Angular مع APIs وخدمات الـBackend.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

يُعد HttpClient الأداة الأساسية في Angular لإرسال HTTP Requests. ويمكنه تنفيذ GET وPOST وPUT وPATCH وDELETE، ويعمل بشكل طبيعي مع Observables.

مثال على الكود

this.http
.get('/api/users')
.subscribe(users => {
console.log(users);
});

  3. أي عبارة تصف هذا الموضوع بشكل أفضل؟

    • يُعد HttpClient الأداة الأساسية في Angular لإرسال HTTP Requests. ويمكنه تنفيذ GET وPOST وPUT وPATCH وDELETE، ويعمل بشكل طبيعي مع Observables.
