أساسيات RxJS

تعرف على أساسيات RxJS والـOperators المستخدمة مع Observables.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

RxJS هي مكتبة للـReactive Programming تعتمد على Observables. وتوفر Operators مثل map وfilter وswitchMap وdebounceTime وcatchError لتحويل والتحكم في تدفقات البيانات غير المتزامنة.
مثال برمجي

مثال على الكود

import { map } from 'rxjs/operators';
users$
.pipe(
map(users => users.length)
)
.subscribe(count => {
console.log(count);
});

  3. أي عبارة تصف هذا الموضوع بشكل أفضل؟

    • RxJS هي مكتبة للـReactive Programming تعتمد على Observables. وتوفر Operators مثل map وfilter وswitchMap وdebounceTime وcatchError لتحويل والتحكم في تدفقات البيانات غير المتزامنة.

    • تقوم Pipes بتحويل القيم لأغراض العرض دون تغيير البيانات الأصلية. ويوفر Angular Pipes جاهزة مثل uppercase وlowercase وdate وcurrency وnumber وpercent، كما يمكنك إنشاء Custom Pipes.
