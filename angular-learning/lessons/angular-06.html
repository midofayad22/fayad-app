ربط البيانات Data Binding

تعرف على كيفية ربط Angular بين بيانات الـComponent وواجهة المستخدم.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

يقوم Data Binding بربط الـComponent Class بالـTemplate. ويوفر Angular عدة أنواع مثل Interpolation وProperty Binding وEvent Binding وTwo-Way Binding، مما يقلل الحاجة إلى التعامل اليدوي مع DOM.
مثال برمجي

مثال على الكود

export class AppComponent {
username = 'Mido';
}
<h2>{{ username }}</h2>

  3. أي عبارة تصف هذا الموضوع بشكل أفضل؟

    • يقوم Data Binding بربط الـComponent Class بالـTemplate. ويوفر Angular عدة أنواع مثل Interpolation وProperty Binding وEvent Binding وTwo-Way Binding، مما يقلل الحاجة إلى التعامل اليدوي مع DOM.
    • تستخدم Interpolation الأقواس المعقوفة المزدوجة لعرض Expressions داخل الـTemplate. يقوم Angular بتقييم التعبير وتحديث القيمة المعروضة عندما تتغير البيانات المرتبطة به.
    • يستخدم Property Binding الأقواس المربعة لربط خصائص عناصر HTML بقيم ديناميكية من الـComponent. ويُستخدم مثلًا مع الصور وحالة الأزرار والخصائص التي تتغير أثناء تشغيل التطبيق.
