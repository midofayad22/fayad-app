Lifecycle Hooks

تعرف على مراحل دورة حياة Components في Angular.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

تمر Components في Angular بمراحل مختلفة منذ الإنشاء وحتى التدمير. وتسمح Lifecycle Hooks مثل ngOnInit وngOnChanges وngAfterViewInit وngOnDestroy بتنفيذ Logic في أوقات محددة.
مثال برمجي

مثال على الكود

import { OnInit } from '@angular/core';
export class AppComponent implements OnInit {
ngOnInit() {
console.log('Component initialized');
}
}

  3. أي عبارة تصف هذا الموضوع بشكل أفضل؟

    • تمر Components في Angular بمراحل مختلفة منذ الإنشاء وحتى التدمير. وتسمح Lifecycle Hooks مثل ngOnInit وngOnChanges وngAfterViewInit وngOnDestroy بتنفيذ Logic في أوقات محددة.
