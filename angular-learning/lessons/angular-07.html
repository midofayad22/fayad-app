Interpolation

تعرف على كيفية عرض بيانات الـComponent داخل HTML باستخدام Interpolation.

افتح الدرس التفاعلي (محرر + اختبار + تتبّع التقدم)يعمل التمرين والاختبار وحفظ التقدم في الصفحة التفاعلية.

تستخدم Interpolation الأقواس المعقوفة المزدوجة لعرض Expressions داخل الـTemplate. يقوم Angular بتقييم التعبير وتحديث القيمة المعروضة عندما تتغير البيانات المرتبطة به.
مثال برمجي

مثال على الكود

export class AppComponent {
title = 'Fayad Angular';
}
<h1>{{ title }}</h1>

  3. أي عبارة تصف هذا الموضوع بشكل أفضل؟

    • تستخدم Interpolation الأقواس المعقوفة المزدوجة لعرض Expressions داخل الـTemplate. يقوم Angular بتقييم التعبير وتحديث القيمة المعروضة عندما تتغير البيانات المرتبطة به.
    • يستخدم Property Binding الأقواس المربعة لربط خصائص عناصر HTML بقيم ديناميكية من الـComponent. ويُستخدم مثلًا مع الصور وحالة الأزرار والخصائص التي تتغير أثناء تشغيل التطبيق.
    • يستخدم Event Binding الأقواس العادية للاستماع إلى DOM Events. وعند حدوث الحدث يستطيع Angular استدعاء Method داخل الـComponent أو تنفيذ Expression.
