# New courses: Advanced JavaScript, Bootstrap 5, Tailwind CSS

All three use the shared lesson engine (`content/<id>/index.js`, pages generated by `tools/make-course-pages.mjs`), the sandboxed runner and the
standard completion rule (every quiz question answered correctly). They have no legacy implementation, so there is no `?engine=legacy` rollback;
reverting means removing the course from `js/catalog.js` and the homepage.

| Course | id | Lessons | Runtime | Page |
|---|---|---|---|---|
| Advanced JavaScript | `ajs` | 22 | `js` (Worker) | `/advanced-javascript/advanced-javascript.html` |
| Bootstrap 5 (5.3.8) | `bs` | 20 | `html` + vendored Bootstrap | `/bootstrap-learning/bootstrap-learning.html` |
| Tailwind CSS (v4.3.3) | `tw` | 20 | `html` + vendored `@tailwindcss/browser` | `/tailwind-learning/tailwind-learning.html` |

Advanced JavaScript does not repeat the basic JavaScript course: it covers scope/closures/`this`, functional patterns, prototypes and classes,
descriptors, Proxy/Reflect, iterators/generators, Map/Set/Weak*, symbols and tagged templates, the event loop, Promise combinators, async patterns,
AbortController and async iterators, custom errors, advanced regex, observer pattern and performance/memory.

## Verification
- `tests/ajs-content.test.mjs` runs every example in Node and requires its output to equal the output printed in the lesson; practice starters must run.
- `tests/bs-engine.test.mjs` renders every example in the real sandboxed preview and checks Bootstrap CSS/JS loaded, a lesson-specific element exists,
  and that modal/accordion/tooltip/toast really work.
- `tests/tw-engine.test.mjs` compiles every example with the vendored compiler and checks a documented computed style (this caught a v4 change: buttons no longer get `cursor: pointer`).
- `tests/ajs-engine.test.mjs` covers sidebar, content, worker execution, runaway-loop handling, quiz-gated completion and mobile layout.

## Authoring
Lessons are written in a compact table (`lessons-a.js`, `lessons-b.js`) expanded by `index.js`. `preview: { head, baseCss }` on an `html` track injects
trusted library markup into the preview document (`js/playground/playground.js` `files.head`); never learner input.

## Limits
- Lesson text is Arabic only for now (English falls back to Arabic with the untranslated notice).
- Tailwind's in-browser compiler is for learning only; lessons say so and teach the real build setup.
- Bootstrap Sass customization is not run in the browser; lesson 19 teaches CSS-variable customization instead.
- Vendored libraries: see `vendor/README.md`.
