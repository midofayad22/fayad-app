## Search and SEO design decisions
- Index source of truth = `content/**` + `js/catalog.js` + game metadata; generated by `tools/build-search-index.mjs` (no hand-written results). Ships as a single JSON (< ~300 KB gzip target), loaded on first focus, not on page load.
- No external search service. Matching in the browser: normalised prefix + token match, Damerau-Levenshtein ≤ 1–2 for tokens ≥ 4 chars, synonym map (e.g. المتغيرات ⇄ variables, حشو ⇄ padding), BM25-style field weights (title > keywords > headings > body).
- SEO: this is a static site, so crawlable lesson pages are generated at build time (`tools/build-pages.mjs`) from the same content files. Original FAYBIT text only; external references are linked and labelled "External reference".
- Vercel serves the generated files; `sitemap.xml`/`robots.txt` are generated, not hand-edited.
